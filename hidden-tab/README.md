# 瘾账 · Hidden Tab

> 香烟是一本人人抽着、却没有人记过的账。戒烟失败的第一杀手往往不是烟瘾，
> 是「破戒即全毁」的错误算术——一支烟在叙事里等于全部清零，于是破一支就
> 破一包。本件把这句话变成可证伪的假命题：**lapse ≠ relapse ≠ 全毁**。

## 问题定义

**谁**：抽了多年、戒过几次都没戒成的吸烟者（以及帮 TA 记账的家人）。

**什么场景**：第 N 次「最后一支烟」之后。戒了 79 天，酒局破了两支，然后
「反正已经破了」的声音出现——一周后回到一天一包。重新戒的时候，上次 79 天
的努力在自我叙事里被一句话清零：「又没忍住，全毁了」。

**什么问题**：戒烟的全部数据——戒了多少天、身体恢复走到哪一站、破戒破在
哪一天、上次尝试死在哪天、省下多少钱——**没有任何账本记录**。没有分母的
「我意志力差」永远是一个不可证伪的自我叙事。成瘾医学把那个心理机制叫
**戒绝违反效应**（abstinence violation effect）：把一次破戒解读为「全毁了」，
从而放弃整个尝试。这笔账从来没有人替戒烟的人算过。

**价值**：

1. **一支烟不清盘**——lapse（attempt 内的破戒日）≠ relapse（连续 ≥3 天
   回到基线 ≥50%，才截断）≠ 全毁，三条边界全部确定性算术，用你自己的历史
   回答「破了一支之后到底发生了什么」；
2. **恢复时钟**——所有工具只数「戒了几天」，没有人告诉你这 N 天里身体走到
   了哪一站：20 分钟心率回落、12 小时一氧化碳半排、2 周循环改善、1 年冠心病
   风险减半……按你的 streak 排成车站，下一站倒计时到天；
3. **三本没人记的账**——钱（按你自己的基线算「已省」）、时间（每支 5 分钟，
   一年 ≈ 19 天没坐在烟头上）、生理（恢复车站）；
4. **一支烟的真实价格**——不是它本身的 1 块 2 毛 5，是你历史上「从 lapse 到
   relapse」的平均距离 × 你的基线——这个数字从你自己的复吸史里长出来，
   别人代替不了（样本 <2 如实 DECLINE，不编统计）；
5. **STALLED 灯**——复发之后没有新的 quit、账本却说你在戒的自欺状态被点名：
   重新 quit 不丢人，账本记得你每一次都回来。

## 形态

方法论（METHODOLOGY.md）+ 零依赖 CLI（Python 3.8+ 标准库）+ 手编 TSV 账本。

```bash
python3 hidden_tab.py report   examples/smoking.tsv --price 25   # 总账
python3 hidden_tab.py clock    examples/smoking.tsv               # 恢复时钟
python3 hidden_tab.py relapse  examples/smoking.tsv --price 25   # 复吸审计
python3 hidden_tab.py trigger  examples/smoking.tsv               # 触发审计
python3 hidden_tab.py simulate examples/smoking.tsv smoke 1       # 反事实沙盒
python3 hidden_tab.py validate examples/smoking.tsv               # 账本体检
```

## 账本

TSV 事件流，一行一个事件，只记变化不记每天：

```
date	kind	n	baseline	trigger	note
2026-03-02	quit		15		第一次戒烟
2026-04-11	smoke	3		酒局	老同学婚礼
2026-08-31	today					打卡：连续 27 天
```

- `kind`：`smoke`（吸烟日，`n` = 当日根数）/ `quit`（戒烟开始，`n` 留空，
  `baseline` = 戒前日均）/ `today`（打卡行：把账本末日记到今天，除此之外
  不参与算术——账本自锚定，全件无墙钟）；中英别名互通（烟/戒烟/打卡 …）。
- `trigger`：可选标签（酒局/加班/饭后……自由文本），喂给触发审计。
- **两种记账语义镜像披露**：无烟期「没记 = 没抽」；复发后的活跃吸烟期
  「没记 = 按基线在抽」（插补逐日披露）。抽烟是默认态的地方，账本不假装
  你只抽了记下的那几根。
- 粗用法：只在 quit 和破戒那天动笔，`baseline` 写在 quit 行上——一分钟上手；
  细用法：戒前也逐日记，触发/星期分布从你的历史里长出来。

## 设计

**lapse / relapse / attempt / clean 四个词的算术定义**（全部钉死在测试里）：

| 词 | 定义 | 后果 |
|---|---|---|
| lapse | attempt 内的吸烟日，未连成复发模式 | 不清盘；钱账按「基线 − n」记账（抽超了如实扣） |
| relapse | 连续 ≥ `--relapse-days`(3) 天吸烟，且日均 ≥ 基线 × `--relapse-line`(0.5) | streak 在复发起点截断，进入活跃吸烟期 |
| attempt 口径 | quit 起算，lapse 不断，relapse 才断 | 「戒烟第 N 天」的 N；恢复时钟按它走 |
| clean 口径 | 连续纯无烟天，一支即断 | 最严格的自检镜，与 attempt 口径并排亮出 |

**双口径是立场**：一支烟不清盘（attempt）与一支即断（clean）是同一本账的
两种读法，工具假装只有一种口径才是误导。恢复时钟按 attempt 口径走——身体
的恢复不因一支烟归零，但复吸后风险回升，账本不粉饰：累计纯无烟天数与已达
到的里程碑永久保留，活跃吸烟期的时钟如实停车。

**三桶恒等式**（validate 钉死）：`已省 = 基线 × 跨度 − 实抽`，分解为
`clean 桶（基线 × 无烟天） + lapse 桶（Σ(基线 − n)，可为负） + relapse 桶（0）`，
三桶之和与总额恒等，9 位小数。

**Exit codes**：0 绿（当前尝试存活）· 2 账本损坏 · 3 薄账/样本不足
（无 quit 行、无基线、复发样本 <2——算术照出，判级拒绝）· 4 红
（STALLED：复发后没有新的 quit）。

**诚实条款**：baseline 是你自己的声称，账本不抓包；里程碑是人群统计先验
不是医学承诺，医生说的永远赢；不构成医疗建议，红灯指向医生与戒烟门诊；
不折现不复利（投资是另一本账）；报告只打印 basename，全件无墙钟，
`--as-of` 钉死逐字节可复现。

## 验收标准（全部转成自动化测试，68 tests）

1. **样例真值手算钉死**：attempt1 跨度 108 / clean 77 / lapse 2 天 5 根 /
   复发 05-20 / 活了 79 天 / 已省 1180（插补 26 天 390 根披露）；
   attempt2 跨度 75 / clean 73 / 已省 1122 / trailing clean 27；
   全史 2302 根 = ¥2,877.50（@¥25/包）、累计纯无烟 150、最长纯无烟 42；
   输出逐串断言。
2. **lapse 不清盘**：单日 25 根（超基线）仍是 lapse，桶为负、恒等式保持；
   连续 2 天 < 阈值不复发。
3. **relapse 边界**：恰 3 连天且日均恰在线上（≥）→ 复发；复发需要基线，
   无基线不硬判（如实 alive）。
4. **复发期插补**：01-10 起复发、跨度内 10 天、记 3 行、插补 7 天、
   实抽 = 30 + 70、已省 = 10×19 − 100，逐项断言。
5. **三桶恒等式 / saved 定义 / clean 双算法（游走==扫描）/ relapse 双算法
   （游程==起窗）/ 天数分解恒等**：validate 全过 exit 0；坏账本 exit 2；
   红灯账本的 validate 仍过（账本坏与账本红是两回事）。
6. **基线三级回退**：quit 行声称 > `--baseline` 补缺（永不覆盖声称）>
   前 28 天逐日反推（≥3 行才反推）> 无（钱账 DECLINE exit 3）。
7. **STALLED 灯**：复发后无新 quit → report/clock exit 4，文案含
   「重新戒不丢人」；打卡行不洗白红灯。
8. **恢复时钟**：75 天到达前 5 站、下一站差 15 天；死亡尝试时钟停在复发
   前夜（已走 9 天）；里程碑表严格递增、`--milestone` 追加排序、
   `--no-default-milestones` 清空。
9. **边界**：quit 当天吸烟 = lapse 日、时钟锚次日；同日双 quit 去重后行覆盖；
   today 行只推 as-of 不参与算术（带 n 即 exit 2）。
10. **as-of 裁剪**：钉回 05-10 复发未发生（alive，已省 1045）；钉回 07-29
    （span 42 / clean 42 / 已省 630）；未来行裁剪不报错；同一本账三次运行
    逐字节一致；全件无 `date.today` / `datetime.now` / `time.time`。
11. **薄账分层**：无 quit 行 → exit 3 吸烟算术照出；无基线 → exit 3；
    relapse 单样本 → exit 3 拒报均值；trigger 零破戒日 → exit 0 好消息。
12. **simulate 恒 exit 0**（沙盒不执法）；无基线推演 DECLINE exit 3。
13. **隐私**：报告只打印 basename，不回显调用方路径。

## 与近邻的边界

- **afterburn** 管喝进去的账（小时级药代动力学：睡前残留）；本件管戒掉后的
  账（月年级恢复时钟）——一个怕今天喝多了，一个怕这次又全毁了。
- **redline** 给跑量装转速表防过量运动；本件防「破戒即全毁」的心理清零。
- **leave-debt** 的年假批次不用就作废；本件的 streak 只累积不作废——复吸
  清掉的是 attempt 口径的当前段，累计纯无烟永久保留。
- **shadow-base** 的连续月是外部政策口径的资格；本件的连续天是自报行为账
  的身体恢复——同为会清零的连续量，一个清在政策，一个清在复发。
- **deficit-illusion** 有实测秤可以反解自报漏记；本件没有秤，所以更诚实——
  只算写下的，baseline 是声称不是测量。
- **scapegoat** 对嫌疑食物做 Fisher 因果检验；本件的触发审计只做描述统计
  ——烟瘾的触发是行为学常识，不需要法庭。
- **medicine-rollcall** 的药盒有两口钟（包装/开封）；本件的恢复只有一口钟，
  但它不因一支烟倒转——都反对「盒还在=药还好」式的语义幻觉。

## 样例速览

小陈，账本从 2025-06-01 记到 2026-08-31（457 天）：第一次戒烟 79 天死于
加班周（不是酒局那 3 根——最后一场 lapse 之后 38 天，连续 3 天 15 根弹回）；
第二次戒烟至今 75 天，酒局 2 根、加班 1 根都没能清盘，clean 口径连续 27 天。
已省 2,302 根 = ¥2,877.50；5,610 + 5,912 分钟没坐在烟头上；身体已过
「1 个月：肺纤毛开始再生」，下一站「3 个月：肺功能显著改善」还差 15 天。
一支烟的真实价格：样本只有 1 个，账本拒绝回答——宁可不说，不编统计。
