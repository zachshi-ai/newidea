# METHODOLOGY · 赶考线

## 1. 为什么单位是「章节闭」，不是分钟

备考的一切投入度量（分钟、天数、连击、题量）都是**输入**；考试唯一结算的是
**输出**——大纲覆盖。输入和输出之间的汇率（每百小时闭几章）因人因科目而异，
且会随章节难度漂移。把汇率摆上台面，「我很努力」和「我在前进」第一次可以分开审计：
样例账本里小北投了 82 小时闭了 13 章（15.8 章/百小时），数学的汇率（17.4）高于
英语（15.3）——同样的分钟花在数学上多买进度。分钟账没有作废，它只是被降级为
**分母**：`allocation` 用它算每小时期望分，`report` 用它暴露汇率漂移。

## 2. 三个速率与窗口选择

- **required** = 剩余章节 ÷ 剩余天数。不是建议，是算术：考试不关心你的感受，
  只关心这个数能否被你的身体跑出来。
- **proven** = 尾随 `--peak-window`（默认 28 天）窗内闭章数 ÷ 窗长。均值口径而非
  中位——闭章是稀疏整数事件，中位会退化成 0 而惩罚正常节奏；均值如实计入尖峰，
  因为尖峰也是真跑出来的天数。
- **peak** = 全账本上任意 28 天滑动窗的最大闭章数 ÷ 28。**用窗口不用单日最高**：
  单日闭 3 章是熬夜的噪声，28 天窗闭 8 章才是「你维持过一个月的速度」——MATH-DEAD
  的裁决引用的是这个可维持值，冤枉不了任何人。

窗口 28 天取月尺度（月是承诺的最小现实单位）；考前冲刺期可调小，长周期考试
（CPA 一年备考）可调大。窗口只是尺度，三线的**相对位置**才是裁决内容。

## 3. 判级阶梯的语义

```
multiple = required / proven

ON-PACE   ≤ 1.0            照现在的跑法来得及
STRETCH   ≤ stretch-line    要提速但量级在努力范围内（1.5 倍以内）
REDLINE   > line 且 required ≤ peak   物理可能，但每一周都必须是峰值周
MATH-DEAD required > peak   按你证明过的速度也追不平——日历问题
```

REDLINE 和 MATH-DEAD 的分界线是 peak 而不是任何倍数：倍数再吓人（如 10x），
只要峰值证明过你能跑出来，账本就不宣布死刑；反之倍数只有 1.6x，但你的峰值
从没到过 required，日历也已经关死。**判的是日历，不是态度。**

STRETCH 线默认 1.5 是先验不是真理：短期冲刺可以 `--stretch-line 2`，
身体是唯一约束的备考者可以收紧——参数永远赢。

## 4. MATH-DEAD 的伦理，与算术豁免

「按历史峰值也追不平」是备考里最贵的信息，也是最没人敢交付的信息：督学不敢说
（要续费）、App 不敢说（要日活）、亲友不会算。账本敢说，因为它只宣告日历事实，
不宣告人的能力——peak 是你**证明过**的速度，超过它意味着当前方法/时间预算下
数学不可行，出路是换方法、换时间预算、换目标或换考期，全是人的决定。

两层判级适用不同的薄账规则：统计判级（REDLINE/ON-PACE 等依赖速率估计的）
在 < 7 个有行天或闭章 < 3 时拒答 exit 3——3 天的速率不是速率是噪声；但
**考日已到/已过还有剩章**的 MATH-DEAD 是纯日历算术，再薄也裁决——考场上
不存在「样本不足」。

## 5. 错配账的经济学：每小时期望分

`allocation` 的核心量是 **pts/hour = 科目权重 ÷ 科目累计小时**——你的时间在
每门科目上的边际产出单价。考试按权重付钱，于是理性策略是把下一小时投给
pts/hour 最高的科目；而真实行为恰恰相反（舒适科目吸时间）。样例账本里
major 的 pts/hour 是 78.3、全场第一，却只拿到 2.3% 的时长；english 拿了
55.7% 的时长、单价只有 2.2。错配灯不劝你放弃舒适科目——它只把「爽」的
价格标出来。

三个灯位：
- **TILTED**：时长占比 − 权重占比 ≥ `--tilt-line`（15pp）——超投；
- **STARVED**：反向差超线——饿着，且通常正是 pts/hour 最高那门；
- **NEVER**：有权重、零分钟——空白不是饥饿，单独点名（空白货架不该混在
  饿货架上；`--tilt-line` 再宽，空白永远值得被看见）。

## 6. 账本口径

- **闭章日** = 该章最晚的 done 行日期。done 是**闭章宣告**：学完那天记一行
  done，中间天记 open 或不记。多轮复习再记 done 会把闭章日推后——账本把
  复习当**投资**（进时长账、抬高该科分母）而不当**新进度**；若你要让复习
  占进度，那是你的口径，账本照实记账。
- **章时长** = 全部行分钟之和（含 open 行）——投入是事实，不管闭没闭。
- **烂尾章** = 只有 open 行的章，永不闭，在 report 里以 open 计数单独可见。
  把它记进去而不是删掉，是因为「开了头没学完」正是速率盲区的组成部分。
- **权重**是科目级口径：全体科目给全（每章一行 weight，科目期望分 = Σ章），
  或全不给；混给 exit 2——半本有权重的账算出的占比是谎言。
- **as-of** 缺省 = 账本最大日期（账本自锚定）；`--as-of` 钉死可复现，也用于
  回放历史（把 as-of 钉回 7 月 1 日，你会看到当时它已经红着）。

## 7. FAQ

**Q: 我的考试没有「章」怎么办？**
A: 章是你选的进度原子：真题套数、题库 block、单词 list、案例体数都行。
判级只需要三样：总量、闭章标记、日期。粒度自己定——粒度太粗会让速率
阶梯化（整月不闭章），太细会让记录成本吃掉学习时间。

**Q: 学习 App 导不出分钟数？**
A: minutes 列可留空（按 0 计）。速率法庭只需要闭章日期；错配账没有分钟
会退化为覆盖分布对比——判级不受影响，损失的只是 pts/hour。

**Q: REDLINE exit 4 会不会太凶？**
A: exit code 是给脚本的，语义是「处于需要干预的状态」；人看的是措辞。
REDLINE 的措辞给的是杠杆（峰值需 95 天 vs 日历 105 天——还来得及，但每一周
都是峰值周），MATH-DEAD 给的是出路清单。账本不鼓励也不安慰。

**Q: 为什么不给「建议每天学几小时」？**
A: 那是 required 乘一个系数就能自己算的数（required × 你的每章小时数）。
但「学几小时」取决于你的方法效率（汇率），而汇率是你账本里最私人的数字——
账本把它算给你看，不替你拍板。

**Q: 二战/多考期的账怎么记？**
A: 每个考期一本目录（各自的 syllabus.tsv + study.tsv）。账本不建模「二战
的章更熟」——那是你的先验，不是账本的。
