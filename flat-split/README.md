# 同檐 · Flat Split

> 合租的第一天,四个人在群里说好「水电平摊」;十二个月后的退租交接里,四个人算出五个版本的账。电费按人头还是按表、垫付的网费谁欠谁、三千块的洗衣机怎么折旧——微信 AA 只管单笔转账,长期共住的账从没有人替你加总。**每个人的记忆都对自己有利,而账本对谁都一样。**

## 它是什么

一套手编的合租账本(4 个 TSV)+ 一个零依赖 Python CLI,把同一屋檐下的三类钱钉进同一本账:

| 账本 | 记什么 | 回答什么 |
|---|---|---|
| `household.tsv` | 谁、哪个房间、住到哪天 | 分摊的权重从哪来(月中出入按人日) |
| `bills.tsv` | 每笔共同账单:金额、分摊规则、垫付人 | 这笔钱谁该出、谁先垫了 |
| `meters.tsv` | 每次抄表:总表 + 各房间读数 | 按表分摊的段,和损耗有没有超线 |
| `assets.tsv` | 公共资产:购置价、出资人、折旧年限 | 公共东西住掉的是折旧,退出时怎么算 |

四个命令,共用同一本账:

```
flat-split report  ~/合租/          # 逐月分摊总表:每人应付·垫付·净额 + 三盏灯
flat-split settle  ~/合租/          # 净额清算:整月几十笔红包压成一笔转账
flat-split assets  ~/合租/          # 公共资产台账:折旧·usage charge·GAP 审计
flat-split validate ~/合租/         # 账本体检:恒等式 + 双路径重放
```

样例账本在 [examples/](examples/):三居室合租十二个月,从平摊的美好时代,到空调季的电费之争、连续三个月一个人垫付、小马退租时留下的 usage 缺口,到阿花月中接租。`report --as-of 2025-05-31` 钉回第一年春天,当时三盏灯全灭——灯不是天生的,是一笔笔账不记出来的。

## 为什么是账本,不是又一个 AA 小程序

AA 收款解决的是**一笔**钱当场收齐;合租的痛在**跨期**:

1. **分摊规则没有天然正义。** 按人头有按人头的理(房间一样大),按表有按表的理(空调 24 小时开)。所以账本不裁决规则,它只要求规则**逐单显式声明**(`per_head` / `by_meter`),然后执行到底——规则之争要室友当面谈,机器只负责让算术没有争议。
2. **垫付是信用的出借。** 「你先交一下网费」三个月后就成了罗生门。账本给每笔账单记一个 `payer`,净额清算把一整年的几十笔红包压缩成一笔转账,`Σ净额 ≡ 0` 钉到分。
3. **公共资产住掉的不是钱,是折旧。** 洗衣机 3000 块八年的寿命,每个人住一个月就「住掉」了 `月折旧 ÷ 人数`。`assets` 把它变成按月的 usage charge,而 **GAP 审计**点名那个最经典的合租结局:一笔回收账都没记,等室友搬走才想起来——摊派只及在住者,那笔账永远收不回了。

## 三盏灯,各管各的案

- **LOSS 表损灯**:按表段的公区损耗(总增量 − Σ房间增量)超容差(通识先验:电 8%、水 12%、气 5%,`--loss-cap` 一句话翻案)。损耗本身按人日摊给全员——公区本来就有冰箱和灯;超线不是要谁赔,是该去查漏、查私拉、查表了。恰线不亮。
- **SKEW 垫付集中灯**:同一人连续 ≥3 个月垫付占比超 80%(恰线不亮、单笔月不参与)。不是谁坏——是有人在替所有人垫钱,该收账了。
- **GAP 走人白住灯**:已退租者在住役月里,一笔回收账(`bills.category = 资产名`)都没有。回收账开始记了,历史滚存视为结清;从来没记过,才是收不回。灯的意思不是谁坏,是账动晚了。

任一灯亮,`report` / `assets` exit 4——灯的意思是「拿着这本账去和室友当面聊」,不是指控。

## 账本纪律

- `by_meter` 账单的日期必须恰为该科目抄表日——抄表那天记按表账单,段就是两张账单之间的读数差;首抄无上期、段内读数断裂都是账坏(exit 2)。
- 房间读数必须有同日总表;读数倒退、房间增量超过总增量都会被点名。
- 所有金额 Decimal 到分;每人份额四舍五入后的尾差,吃给确定的一人(份额最大、同额按名字序)——`Σ逐人 ≡ 账单额` 恒等式逐月钉到分,同账任何机器重放逐字节一致。
- 日期必须补零(`2025-3-1` 是账坏);行尾制表符容忍——手编账本从表格粘出来的日常。
- 空账(没有账单行)不是账坏,是还没开始记:exit 3,报错文案教你怎么记第一行。

## 本地知识赢

折旧年限有品类先验(洗衣机 8 年、沙发 5 年、路由器 4 年、小家电 3 年),账本 `years` 列一句话翻案;品类账本没教过就如实 `n/a`,不判 GAP 不装懂。表损容差、垫付集中线全部是 `--` 旗标。**先验的谦卑:宁可不亮灯,不编线装懂。**

## 诚实条款

本件不是法官:分摊规则的选择、灯的处理、要不要向走了的人追讨 usage,全是人的决定,机器只保证算术没有争议。合租的账是几个人的共同敏感数据——不连任何接口,不上传任何字节,没有服务器,一切都在这个目录里。零墙钟:缺省 as-of 锚定账本最大日期,`--as-of` 钉死,同账任何机器任何一天输出逐字节一致。

## 与近邻的边界

- **true-pocket** 对账医疗自付(自己口袋出去了多少)——本件对账合租共摊(几个人之间谁该出多少)。
- **gift-ledger** 记随礼(社会货币,双向对价)——本件记共住(同一屋檐的 AA,单向成本分摊)。
- **iou** 记亲友借贷的敞口与时效——本件的净额清算住在月租周期里,没有时效,只有下个月。
- **float-loan** 审公司报销(对方是系统,回款确定)——本件审室友垫付(对方是人,靠的是账本不是 SLA)。
- **move-line** 算「该不该搬」——本件管「住了之后怎么摊」。
- **scope-creep** 对质装修增项(对承包商的变更单流)——本件对账同居分摊(对室友的共住账)。
- **past-prime** 管设备超役——本件只按直线折旧给公共资产记账,超役如实披露残值归零,不展开。
- **handoff** 交底要紧物在哪——本件结算公共东西的折旧残值:一个怕找不到,一个怕算不清。
