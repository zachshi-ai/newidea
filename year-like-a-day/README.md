# 度年如日 · Year Like a Day

> 度日如年是因为苦，度年如日是因为重复——没有人给你出过这张账单。
> Days drag when they hurt; a year vanishes when it repeats. Nobody ever billed you for that.

## 一句话

「时间越过越快」是成年人最普遍的抱怨，却是所有账本之外的感觉：日历记录你要去哪，日记记录你感觉如何，待办记录你要做什么——**没有任何一本账记录你「第一次遇见什么」**，而记忆恰恰是用第一次计时的：回忆的长度不跟天数走，跟新异事件的密度走，routine 压缩记忆，于是日历翻过十二页、回忆只装订出两页，一年过起来像一天。`year-like-a-day` 把「初事」（第一次的经历）补进账本，从一行一条的手编 TSV（日期/品类/一句话/同行人）确定性算出六本账：**密度账**——日均初事与年化（样例 16 个初事 / 243 天 = 0.0658/天，年化 24 个/年）对上**中位数月基线**（0.0328/天——旅行爆发月抬的是均值不是基线，你的「普通月份」由中位数保护）；**灰条纹账**——连续零初事的天数第一次有了边界和长度（2/09→4/11 的项目 crunch 是一条 62 天的条纹，而当前这条已经 57 天没断过；全年 243 天里 227 天是灰的，93.4%——「一年怎么一晃就没了」从此有分母）；**回忆月账**——追平你自身密度需要的每月初事数就是地板（ceil(16/243×30)=2），够地板的月是 LIVE、不够的是 BLUR，8 页日历只装订出 2 章；**供新结构**——品类排行（place 31.2%）、买来的新意 vs 走进去的新意（18.8% vs 81.2%）、**供新者**排行（阿芳在场的初事 9/16=56.2%——「我这一年都是他带给我的」第一次是句可以审计的话）、断供最久的品类（person 已 204 天）与整类空白（media 从未发生——整个货架都是没花过的初事）；**反事实**——给历史上每段灰条纹按每 7 天一个初事重放：总数 16→43（守恒恒等式 16+27=43 精确钉死）、最长条纹 62→6 天、按真实标尺够格装订的月份 2→8——**每周一个初事，你的一年八章**；**变灰门禁**——气候性变灰要求双信号同时成立（近 90 天密度 < 基线×0.5 ∧ 当前条纹 ≥ 21 天），绝对沙漠（≥ 60 天）单信号即爆，击穿 exit 4——样例账本 8 月 31 日双信号齐爆：0.0111 < 0.0328×0.5，条纹 57 天。诚实条款：账本只管新、不管甜——破财也是初事，好坏归阴晴表；初事是自报的，补记允许（记忆重构），漏记会让条纹虚长——初事账只认写下的；供新者是共同出现统计，不是「多约谁就一定有新意」的承诺；它不下价值判断，制造不制造初事，仍是人的决定。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 被通勤—工位—外卖—刷手机循环填满的 30+ 上班族；年底写总结时「想不起今年发生了什么」的人；刚刚意识到自己已经很多个月没做过「第一次」的事、想改又不知道从哪改起的人；以及每一个在跨年夜感叹「今年怎么一眨眼就过了」却说不出快在哪里的普通人。 |
| **场景** | 跨年夜 / 生日 / 年度复盘，想把「这一年过得快不快、实不实」说清楚；某个周日晚突然想查「我上一次做全新的事是哪天」；想劝自己（或伴侣朋友）「我们最近日子太重复了」，但这句话没有数据支撑；开始记录之后，想知道什么在给你的记忆供新、什么品类已经断供。 |
| **问题** | **体感时间没有账本**：① 加速不可见——「时间越过越快」只有感觉没有度量，日历的天数均匀流逝，记忆的天数却稀密悬殊，没有人把这两本账对过；② 条纹不可见——回忆里「糊成一片」的那几个月，从来没人指出它的确切边界和长度，于是也无法确认它结束了没有；③ 归因不可能——不知道是什么在给自己供新（旅行？新人？新技能？），也就不知道少了对生活意味着什么；④ 行动无杠杆——「多出去走走」是口号，没有人能告诉你每周一个初事到底能把一年从「一章」变成「几章」。 |
| **价值与意义** | 1) **第一次有度量**：把「日子越过越快」从无法讨论的体感变成密度、基线、条纹、地板四个可审计的数——样例一年 24 个初事、93.4% 的日子是灰的，抱怨从此有分母。<br>2) **遗忘有单位**：灰条纹是遗忘的计数单位，`streaks` 给每一段糊掉的日子标出起止与长度，`today` 告诉你正站在哪一条上、站了几天。<br>3) **供新有归因**：`sources` 回答「谁 / 什么在给你的记忆供货」——把「生活单调」拆成品类断供清单，把「多亏了这个人」变成可复核的共现统计。<br>4) **行动有杠杆**：`simulate --every 7` 把「每周一个初事」翻译成账上的差别——最长条纹 62→6 天、够格装订的月份 2→8：你不需要更努力地活，只需要每周花掉一个初事。 |

## 核心思想：记忆不是用天计时的，是用「第一次」计时的

日历的天数是均匀的，记忆的天数不是。认知科学里反复被验证的直觉是：回忆的长度正比于那段日子里**新异事件**的密度——第一次总是被记住，第 N 次总是被折叠。所以「一年像一天」不是修辞，是记账口径的差异：日历记了 365 天，记忆只记住了初事之间的间隔。本件做的事只有一件：**给初事记账，让记忆的口径可以被审计。**

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **密度账 report** | 日均初事 = 总数 ÷ 覆盖天数（首条初事 → 今天，无初事的日子照算）；年化 ×365；近 30/60/90 天窗口分列 | 「我的一年，按记忆的口径有多少天？」 |
| **中位数月基线 baseline** | 各月密度（初事 ÷ 该月覆盖天数）取中位数——爆发月抬均值不抬基线，你的「普通月份」受中位数保护 | 「对我来说，什么样的一个月算正常？」 |
| **灰条纹 streaks** | 连续零初事的天数为一条；覆盖首日本身不会灰；当前条纹 = 含今天的条纹；清单按 `--min`（默认 14 天）上榜 | 「回忆里糊成一片的那段，从哪天到哪天？」 |
| **回忆月 months** | 地板 = ceil(总数 ÷ 覆盖天数 × 30)：追平你自己日均密度所需的每月初事数；够地板的月 LIVE，不够 BLUR | 「日历翻过的页数里，记忆装订了几页？」 |
| **供新结构 sources** | 品类七选一（place/person/skill/food/event/media/other，不猜）；买来的新意（food/media）vs 走进去的新意（place/person/skill/event）分列；供新者 = people 列共现计数；断供天数与整类空白单列 | 「什么 / 谁在给我的记忆供货？哪里已经断供？」 |
| **反事实 simulate** | 对每段 ≥N 天的灰条纹按每 N 天一个初事重放（默认 N=7）：密度、最长条纹、回忆月重算；守恒恒等式 新总数 == 旧总数 + 插入数 精确打印；**地板钉在真实账本的 pace 上**——反事实回答「按你真实生活定下的标尺，会有几个月够格」，不陪跑一个水涨船高的标尺 | 「每周一个初事，我的一年差多少？」 |
| **变灰门禁 gate / today** | 气候性变灰 = 双信号同时成立（近 90 天密度 < 基线 × collapse-ratio(0.5) ∧ 当前条纹 ≥ streak-cap(21 天)）；绝对沙漠 = 当前条纹 ≥ desert-cap(60 天) 单信号即爆；阈值全部可调；击穿 exit 4 | 「我是不是正在变灰？今天该从哪补起？」 |
| **账本体检 validate** | 恒等式 Σ月 == Σ品类 == 总数；密度恒等式 总数 ÷ 覆盖天数 精确打印；缺省与口径披露 | 「这本账配不配得上结论？」 |

三条边界刻在实现里：

- **只管新，不管甜**——账本不采集「好 / 坏」，破产、失恋、住院也是初事，它们确实会被记住；日子过得好不好归阴晴表（mood-barometer）的账本，两本账互不越界。
- **初事是自报的**——工具不扫描你的相册和足迹；补记允许（记忆本来就会重构），但未来日期在解析层直接拒绝（exit 2）——初事不能发生在明天；漏记不会留痕，只会让条纹虚长：初事账只认写下的。
- **相关不是因果，工具不裁判**——供新者是共现统计，「阿芳在场的初事占 56.2%」不等于「约阿芳必有新意」；门禁爆灯说的是统计事实（密度塌了、条纹超线），不是对你生活的判决——制造不制造初事，仍是人的决定。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

```bash
python3 year_like_a_day.py --today 2026-08-31 report firsts.tsv
```

## 命令速查

```bash
python3 year_like_a_day.py report   firsts.tsv                 # 总账：密度/基线/条纹/回忆月/供新，门禁 exit 4
python3 year_like_a_day.py months   firsts.tsv                 # 月历：每月初事、LIVE / BLUR
python3 year_like_a_day.py streaks  firsts.tsv --min 14        # 灰条纹清单：最长/当前/灰天占比
python3 year_like_a_day.py sources  firsts.tsv                 # 供新结构：品类/买vs走/供新者/断供
python3 year_like_a_day.py simulate firsts.tsv --every 7       # 反事实：每周一个初事重放历史
python3 year_like_a_day.py today    firsts.tsv                 # 今日简报：条纹/断供/门禁灯
python3 year_like_a_day.py gate     firsts.tsv                 # 只跑变灰门禁（击穿 exit 4）
python3 year_like_a_day.py validate firsts.tsv                 # 账本体检：恒等式/披露
```

全局参数 `--today YYYY-MM-DD` 钉死「今天」，保证覆盖区间、当前条纹与快照跨机器逐字节可复现。

## 账本格式（可手编 TSV，一行一个初事）

```text
date	category	note	people
2026-01-01	event	元旦第一次看海上日出	
2026-01-17	person	经老周介绍认识阿芳	阿芳
```

- `date` 为 YYYY-MM-DD，**晚于 --today 的行在解析层拒绝**（初事不能发生在未来，exit 2）。
- `category` 七选一：`place | person | skill | food | event | media | other`，大小写归一，不认识的值直接 exit 2——账本不猜。
- `note` 一句话非空——写不出的初事记不住，也不配进账。
- `people` 可选，同行人，`、 , ; / &` 皆可分隔，自动去重；留空即独行初事，独行与结伴在账上等价。
- 同一日期同品类同内容是账目腐败（exit 2）；同一天两个不同初事是好事，正常记两行。
- 一天 30 秒：睡前问自己一句「今天有没有第一次？」，有就一行，没有就不写——不写本身就是数据。

## 验收标准（全部转为自动化测试，54 个）

1. **解析守卫**：缺表头/错表头、日期格式、未来日期、非法品类（不猜，大小写归一）、空 note、列数不足、同日同品类同内容重复行——全部 exit 2；注释与空行跳过；乱序输入按日期稳定排序；people 多分隔符切分去重；三列（无 people）合法。
2. **密度与覆盖**：覆盖区间 = 首条初事 → --today（无初事的日子照算）；密度恒等式 总数 ÷ 覆盖天数 精确（样例 16/243 = 0.065843621 钉死）；年化 = 日均 × 365。
3. **基线**：月表按自然月裁剪覆盖天数；基线 = 各月密度中位数（样例 (1/31+1/30)/2 = 0.0328 钉死）；**爆发月免疫**——插入 20 个初事的爆发月后基线只挪一个中位档（< 0.002），永不变成爆发月本身。
4. **灰条纹**：跨月条纹连续重算（1/31 → 3/2 之间是一条 29 天的条纹）；覆盖首日不灰；当前条纹含今天；今天有初事则当前条纹归零；样例账五条纹（62/18/17/35/57 天）逐一钉死。
5. **回忆月**：地板 = ceil(总数/覆盖×30)（16/243 → 2、5/200 → 1 钉死）；LIVE/BLUR 按地板判定；样例 8 页装订 2 页。
6. **供新结构**：品类计数/份额/断供天数/never 口径（never = 覆盖天数）；供新者计数排序；消费型 vs 成长型分法定义并加总还原总数。
7. **门禁语义**：双信号纪律——条纹超线但密度健康 → exit 0（「忙月藏得住一条条纹」）；密度塌方 ∧ 条纹超线 → 气候性变灰 exit 4；绝对沙漠 ≥ 60 天单信号 exit 4（基线被零月拉塌到 0 时的救援门）；三个阈值全部可调且方向正确；report 与 gate 判定一致。
8. **THIN 拒判**：覆盖 < 60 天或初事 < 5 条，report/months/streaks/sources/simulate/gate 一律 exit 3；today 用 5 条下限；validate 永不拒判、只披露 THIN。
9. **反事实**：插入点 = 每段条纹内第 N、2N、…天（条纹从零初事首日起算）；`--every 1` 填满全部灰天、最长条纹归零；`--every 30` 只插 4 个；守恒恒等式精确；**地板钉在真实 pace**——回忆月只会变多不会变少；`--every 0` exit 2。
10. **可复现**：同一账本同 `--today` 两次运行逐字节一致；换 `--today` 覆盖区间随之变化（243 → 212 天）；examples 快照有 CI 字节级校验。
