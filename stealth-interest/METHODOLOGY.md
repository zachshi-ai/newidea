# 暗息 · Stealth Interest — 方法论

## 1. 为什么真实利率 > 名义费率：等本等息的数学

消费分期几乎全是**等本等息**（flat）结构：每期还固定本金 `P/n` 加固定手续费
`P·r`（r 是每期费率，**按原始本金计算**）。但你的欠款是逐月下降的——第 k 期
期初你只欠 `P·(n−k+1)/n`，手续费却始终按全额本金收。

定义真实月利率 i 为内部收益率（IRR）：解

```
P = Σ_{k=1..n} (P/n + P·r) / (1+i)^k
```

**定理（翻译倍数）**：i > r 对一切 n ≥ 2、r > 0 严格成立；且

```
i ≈ r · 2n/(n+1)
```

直觉：手续费按全额本金收，而你的平均占用只有约 `(n+1)/2n` 的本金，
所以真实价格被放大约 `2n/(n+1)` 倍。n=12 时 1.846 倍——7.2% 的名义
年化真实是 ~13%。

**边界恰等**：n=1 时只有一期付款、无余额递减，`i = r` **精确成立**
（测试钉到机器精度）。倍数从 1（单期）单调升到 ≈2（长期）——分期越长，
「费率」这个词撒谎撒得越厉害。

主样例（12000 元 × 12 期 × 0.6%/期）：月供 1,072（本金 1,000 + 手续费 72）、
总手续费 864、月 IRR 1.0862%、名义年化 13.03%、有效年化 13.84%、倍数 1.81x。

## 2. 求解器与独立对拍

CLI 用二分法在 [1e−12, 1] 上解 IRR；测试用**独立实现的牛顿法**先解出
真值钉死（`off-track` 的 crosscheck 惯例），两边必须一致到 1e−9。
不收敛 / 现金流同号 / 数据荒谬 → exit 2，**报错而不是报一个荒谬数**。

近似公式 `2n/(n+1)` 只作对照披露（与精确解误差 < 3%），不进任何判级——
判级永远用精确 IRR。

## 3. 收费时点：首期一次收更贵

有些平台把全部手续费加在首期（upfront）。同样 864 总费，upfront 的真实年化
13.86% > flat 13.03%——**钱收得越早，你的真实成本越高**。手续费总额相同
不代表价格相同；本件两种 mode 都解。

## 4. 提前结清法庭：两把镜子

**剩余手续费规则**（remaining，多数平台）下的主样例，已还 3 期：

- 剩余本金 9,000，剩余手续费 648（9 期 × 72），未来付款 9,648。
- 结清额 = 9,000 + 648 = **9,648 = 未来付款总额**。

**零节省定理**：remaining 规则下，结清额 ≡ 未来付款额，利息节省恒为 ¥0。
提前结清的唯一效果是把 9 期付款提前到今天——按你的收益率，这是**净损失**
（流动性成本）。verdict：KEEP。

**边际镜（决策用）**：继续持有 = 一笔 9,000 元、9 期、每期 1,072 的等本等息
贷款，真实年化 16.96%（钉值）。**你的任何低息替代（闲钱、房贷余力、3% 的
消费贷）都值得拿来结清——如果平台免收剩余手续费**。waived 规则下结清省
名义 648 元，verdict 用 `--yield` 对比边际利率：低于 → PAYOFF，高于 → KEEP，
不给 → exit 3 只出算术。

**平均镜（只披露，不进判级）**：把结清事件放进全程现金流重新解 IRR——
remaining 规则下平均资金成本从 13.03% 跳到 **24.14%**：你已经付掉的 3 期
手续费（sunk 216 元）被压进只剩 3 个月的使用期里。这不是「提前还款的成本」，
是「整个计划的平均成本被你自己的止损动作显影了」。两把镜子回答两个问题：
**该不该继续**（边际镜 16.96%），**这单生意整体有多亏**（平均镜 24.14%）。
混淆两镜是分期数学里最常见的自欺。

**尾期爆炸**：边际真实利率随已还期数**单调上升**（13.03% → … → 86.40%）。
最后一期：欠 1,000，还 1,072，一个月 = 月息 7.2% = **年化 86.4%**（精确：
i = P·r ÷ (P/n) = n·r）。你最后几期的钱，定价是高利贷级的—— waiver 规则
为什么少见，这就是原因。

**违约金门禁**：pct 规则（按剩余本金收 X% 违约金）下若结清额 > 未来付款
总额 → exit 4：宁可不断。样例 9,000 × 1.10 = 9,900 > 9,648。

## 5. 免息定价：与折扣的换算

免息分期的真实价值 = 留在手里的现金 × 你的收益率 × 占用时间，严格算法是
PV 差：`breakeven_discount(y) = P − Σ payment/(1+y_m)^k`。

主样例：12,000 免息 12 期 vs 现金折扣 400。年化 2% 时分期付款流的 PV =
11,872.16 > 11,600（折扣价）→ **折扣胜出 272.16**。盈亏平衡折扣 127.84；
反过来折扣 400 对应盈亏平衡收益率 6.49%/年——**免息分期 = 一笔 6.5% 的
确定性年化收益，前提是你放弃的折扣是 400**。两边的数平台各说各的，
换算本件来做。

无 `--yield` 时只出名义账（折扣 vs 总手续费），名义打平才拒裁——名义
胜负分明时不需要假设你的收益率。

## 6. stack：暗息总账

多笔分期叠加，没人看见的三笔钱：

- **隐性负债** = 全部未来付款（样例 ¥21,162.67）——它们已经签约，只是还没出账；
- **暗息余额** = 剩余手续费（样例 ¥1,496.00）——其中零一分还能省的，取决于
  每单的 prepay_rule，但没有任何账单会把这行加总给你看；
- **月供峰段** 占收入比 > 通识红线（默认 30%，月供不超收入三分之一）→ exit 4。

逐单另给**剩余边际真实年化**（第 4 节的边际镜），按剩余本金加权出组合口径。

## 7. 监管新规之后，本件为什么还成立

2021 年起监管要求信贷产品展示年化利率。但（a）商户分期、教育分期、线下
手机店仍普遍只报「月费率」；（b）展示了年化，也没有任何工具回答**提前结清
省不省、免息换折扣哪个值、三笔分期加起来月供多少**——这三问是本件的主场；
（c）展示口径是否被正确解出，你可以用本件自己验。本件不读平台数据、
不联网，你看到的每个数都能用一支手编 TSV 重算。

## 9. FAQ

**Q: 为什么没有日期？** 分期的全部数学是期数数学（period-based），不是日历
数学。没有日期就没有时区、没有 as-of、没有时钟——全件零锚定，比「账本
自锚定」更强：任何机器任何一天逐字节一致。

**Q: fee_rate 是每期还是每年？** 每期（与平台报价同口径）。0.6% 或 0.006
双写法。年化由本件翻译，不让你换算。

**Q: 为什么默认 --rule remaining？** 多数平台提前结清剩余手续费照收。这是
通识先验不是事实断言——你的合同说了算，--rule waived/--penalty 永远赢。

**Q: 24% 的平均成本能用来做决策吗？** 不能。已付手续费是 sunk cost，决策
只看边际镜（16.96%）。平均镜的存在理由是披露「这单生意整体有多亏」，
让它进决策是把沉没成本再付一遍。

**Q: 会联网查各平台规则吗？** 永远不会。规则参数化，合同永远赢，本地计算，
不上传任何字节。
