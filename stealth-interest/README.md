# 暗息 · Stealth Interest

> 分期付款的手续费率是营销数字，不是利率。「月费率 0.6%」的真实价格是年化 13.03%——
> 平台不翻译，因为翻译过来不好看；你的直觉不翻译，因为没人教过你要翻。

## 一句话

把消费分期（花呗/白条/信用卡分期/商户分期）的**名义手续费率**翻译成**真实资金成本**，
并审计三件平台永远不会替你算的事：提前结清到底省不省息、免息分期到底免没免、
多笔分期的暗息总额到底有多少。

## 角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 用过分期付款的普通消费者：双 11 分期了手机、白条挂了笔记本、花呗常年账单的人。不觉得自己在借钱——「每期才 1,072」听起来像会员费，不像贷款 |
| **场景** | ① 结账页弹出「分 12 期，月费率 0.6%」的瞬间；② 已还 3 期，攒了一笔闲钱，纠结要不要提前结清；③ 年底盘点，发现同时挂着 3 笔分期，从没见过一张总账 |
| **问题** | 1. **费率幻觉**：等本等息结构下本金逐月归还、手续费却按全额本金收，真实年化 ≈ 名义 × 2n/(n+1)——12 期 0.6%/月（名义 7.2%）真实是 **13.03%，1.81 倍**。这个换算没人替你做（监管 2021 年起要求展示年化，但商户分期、教育分期、手机店仍只报月费率；就算展示了，13% 意味着什么也没人说）<br>2. **提前还款幻觉**：多数平台**剩余手续费照收**——提前结清恰好等于把未来所有付款提前到今天，**利息一分不省，只损失流动性**。「提前还 = 省利息」的直觉恰恰是错的；更隐蔽的是：分期的暗息后段更贵（手续费固定、余额变小），**最后一期的钱相当于月息 7.2% 的高利贷，年化 86.4%**<br>3. **免息幻觉**：免息分期的真实价值 = 占用你额度的时间 × 你的收益率，它和现金折扣是一对没人换算过的选择<br>4. **隐性负债**：多笔分期叠加，未来还要付多少、其中多少是已签约的暗息，从没有一张总账 |
| **价值** | rate 把费率翻成人话（月 IRR / 名义年化 / 有效年化 / 相对名义的倍数）；prepay 用**零节省定理**（剩余手续费照收 ⇒ 结清额 ≡ 未来付款额 ⇒ 利息节省恒为 0）和边际真实利率给提前结清开庭；offer 算出免息与折扣的盈亏平衡点；stack 拼出多笔分期的逐月月供、暗息余额与月供占收入红线；validate 做账本体检。全部本地计算、不连任何接口、无日期无时钟，同一本账任何机器逐字节一致 |

## 验收标准

| # | 验收项 | 判据 |
|---|---|---|
| 1 | 翻译定理 | 12 期 × 0.6% flat：月 IRR = 1.0862%，名义年化 13.03%，有效年化 13.84%，倍数 1.81x；n=1 时真实 = 名义**恰等**（单期无余额递减）；对 1..24 期 × 0.2%..1.5% 全网格真实 > 名义严格成立 |
| 2 | 近似对照 | 解析近似 nominal × 2n/(n+1) 与二分法精确解误差 < 3%（n=12 时 13.29% vs 13.03%） |
| 3 | 收费时点 | 同样总费、首期一次收（upfront）比每期收（flat）更贵：13.86% > 13.03%（钉值 13.8560%） |
| 4 | 零节省定理 | remaining 规则下结清额 ≡ 未来付款额（逐分恒等），利息节省 = ¥0.00，verdict KEEP exit 0 |
| 5 | 边际利率 | 继续持有的边际真实年化随已还期数**单调上升**（13.03% → 86.40%）；最后一期边际月利率恰 = n·r（86.40% 精确钉死）；paid=3 时边际 16.96%（钉值） |
| 6 | 平均成本镜 | remaining 规则下第 3 期结清，全程平均资金成本 13.03% → **24.14%**（钉值）：提前结清把已付手续费压到更短的使用期上，不是止损是加价；决策只认边际镜，平均镜只披露 |
| 7 | 违约金门禁 | pct 规则下若结清额 > 未来付款总额 → exit 4（宁可不断）；waived 规则下名义节省 = 剩余手续费 ¥648 |
| 8 | 借低还高 | waived 规则下 verdict 需要 --yield：低于边际真实利率 → PAYOFF，高于 → KEEP，不给 → exit 3（算术照出，裁决挂起） |
| 9 | 免息定价 | 12000 免息 12 期 vs 现金折扣 400：@年化 2% 折扣胜出 272.16（PV 11,872.16 vs 11,600）；盈亏平衡折扣 = 127.84、盈亏平衡收益率 = 6.49%（全部钉值） |
| 10 | 名义对照 | 无 --yield 时 offer 只出名义账：折扣 400 < 有息分期总费 864 → TAKE-CASH（名义口径 exit 0）；名义打平才 exit 3 |
| 11 | stack 总账 | 三笔样例（12k/24 期 + 8k/24 期 + 6k/6 期）：未来付款 ¥21,162.67、剩余本金 ¥19,666.67、**暗息余额 ¥1,496.00**；月供峰段 1–6 月 ¥2,493.33 |
| 12 | 负担红线 | 月供峰值占收入比 > --burden-line（默认 0.30，月供不超收入三分之一的通识线）→ exit 4（salary 10000 绿 24.9% / salary 5000 红 49.9%） |
| 13 | 账本体检 | 重复行 / paid>months / 负数 / 未知 mode、rule / 缺列 / 缺文件 → exit 2；空账本 → exit 3；费率接受小数（0.006）与百分号（0.6%）双写法 |
| 14 | 门禁可调 | rate/prepay/offer 的 --line 与 stack 的 --burden-line 全部参数化；不给 --line 只翻译不判级——数字自己会说话 |
| 15 | 可复现 | 全件无日期无时钟：无 as-of、无 today，同一本账任何机器任何一天逐字节一致（比账本自锚定更强的零锚定）；报告只打印 basename，不回显调用方路径 |

## 快速开始

```bash
# 翻译一笔分期：月费率 0.6% 到底是多少钱
python3 stealth-interest/stealth_interest.py rate --principal 12000 --months 12 --fee-rate 0.006

# 提前结清法庭：已还 3 期，剩余手续费照收的合同规则下省多少
python3 stealth-interest/stealth_interest.py prepay --principal 12000 --months 12 \
  --fee-rate 0.006 --paid 3 --rule remaining

# 免息 vs 现金折扣
python3 stealth-interest/stealth_interest.py offer --price 12000 --months 12 \
  --cash-discount 400 --yield 0.02

# 多笔分期总账（示例账本见 stealth-interest/examples/plans.tsv）
python3 stealth-interest/stealth_interest.py stack stealth-interest/examples/plans.tsv --salary 10000
```

## 账本格式

`plans.tsv`，一单一行，`#` 开头为注释：

```text
platform   item       principal  months  fee_rate  paid  mode  prepay_rule
huabei     phone-12k  12000      12      0.006     3     flat  remaining
jingdong   laptop-8k  8000       24      0.005     10    flat  waived
merchant   tour-6k    6000       6       0.008     0     flat  remaining
```

- `fee_rate`：每期手续费率，小数（0.006）或百分号（0.6%）双写法
- `paid`：已还期数，可留空 = 0
- `mode`：flat（每期收费，默认）/ upfront（首期一次收全部手续费）
- `prepay_rule`：remaining（剩余手续费照收，多数平台）/ waived（剩余手续费全免）/ pct（按剩余本金收违约金，违约金率在 CLI 用 --penalty 给）

## 与近邻的边界

- **nav-illusion**：同一族求解器（IRR 二分法），那边解**投资端**收益率（你的钱生钱的成绩单），本件解**融资端**成本（你借平台的钱的真实价格）。资产负债表的两侧。
- **redemption**：房贷的合同利率受监管明示（4.2% 就是 4.2%），提前还款按剩余本金计息、无手续费结构；本件是消费分期端——费率是营销数字，提前还款规则本身就是坑。
- **cart-line**：同一张结算页的另一半——那边解剖凑单的总价幻觉（敌人是你自己的手），本件解剖支付方式的真实成本幻觉（敌人是对方的费率）。
- **card-tax**：储值卡的闲置余额税（你 prepaid 的钱没花掉），本件是分期的暗息（你后付的钱变贵了）。
- **smooth-sailing**：收入端现金流平滑，本件是负债端真实成本；shadow-base 是工资条对社保系统，本件是结账页对资金成本。

## 诚实条款

- **政策永远赢**：手续费规则、提前结清规则、违约金，以你的平台合同为准；本件全部参数化（--rule/--penalty/--fee-rate），不内置任何平台数据库，默认值只写多数平台的通识口径（remaining）。
- **不发明钱**：所有涉及机会成本的裁决（--yield、--salary）不给就只出算术、不判级——拒绝替你假设你的闲钱收益率。
- **不构成财务建议**：本件是计算器不是信贷顾问；它把费率翻译成人话，签不签、还不还是人的决定。
- **平均镜与边际镜**：决策只认边际真实利率；全程平均成本（含已付 sunk fee）只作披露，METHODOLOGY 里有完整的两镜之辨。
