# 贴线 · Borderline

> 体检报告只给快照，身体却住在斜坡上——「正常」是区间，不是方向。
> Lab reports give snapshots; your body moves on a slope. A zero-dependency ledger that turns years of annual checkup values into trend slopes, runway-to-the-line, and an honest status ladder.

---

## 一句话

体检报告每年都给同一句安慰：「正常」。但「正常」是区间，不是方向——尿酸 396 和 421 在报告里是同一个词，哪怕后者正以每年 8 个点的速度向 428 的上限爬，两年后就「突然」偏高了。报告是快照思维：本年数值 vs 参考区间，输出「正常/偏高」的二元结论；健康风险却住在趋势里——**跨线是结果，爬坡才是过程**。本件把散在每年报告里的检验值抄成一本可手编的纵向账本（TSV：指标/日期/数值/单位/参考区间），从你对自己算出三样报告永远不会给你的东西：**Theil-Sen 斜率**（全部成对斜率取中位，一次化验失误绑架不了七年数据）、**余量年数**（按当前斜率几年到线——空腹血糖 5.1→6.0 七年全部「正常」，距线只剩 0.7 年）、**状态阶梯**（OVER 越线 / BORDERLINE 贴线爬坡 / WATCH 在爬但余量足 / STEADY 没在爬 / THIN 拒判）。门禁语义是「**还在爬的都要有个说法**」：越线仍在爬与贴线爬坡亮红灯 exit 4，越线但已企稳的说明有人在管，不进门禁。噪声地板（净涨幅不足参考区间宽度 10% = 化验噪声）与诚实条款（不足 3 次拒判、单位冲突拒收、区间变更标注、无同期不比较）保证它不喊狼来了——示例账本实测：噪声地板砍掉的是两行「余量 44 年/46 年」的荒谬警报，而真正该盯的「余量 3.6 年」的血压因此不被淹没。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 年年体检、报告里开始出现箭头的 30+ 上班族；拿着一沓历年报告想搞清「到底在变好还是变坏」的人；复查后想验证干预（减重/戒酒/吃药）有没有真的把曲线压下去的人；帮父母管体检报告的子女。 |
| **场景** | 报告出来那一晚（只看见两个箭头，不知道这个方向已经持续几年）；复诊之前（医生问「之前是什么水平」，只能翻邮箱里的 PDF）；换体检机构（参考区间变了，数字没法直接比）；决定要不要为某个指标改生活方式（值不值、有没有用）。 |
| **问题** | ① **快照思维抹掉方向**：连年爬坡的「正常」与年年平稳的「正常」在报告里是同一个词，二元结论的信息损失率是 100%——它删掉的恰恰是「方向」这个最要命的维度；② **没有自己的历史**：历年数值散在各年的 PDF 里，没人汇总，「偏高↑」出现时你既不知道爬了几年，也不知道爬多快；③ **「偏高」即迟到**：跨线那天是爬坡的结果，只盯越线等于只接迟到的警报——真正有用的是「正在赶来的」；④ **换医院账就断**：区间一变数字不可比，旧报告变废纸；⑤ **干预无对账**：减重三个月，尿酸降没降、降幅占区间宽度几个点，没人算，「感觉好了点」说了不算。 |
| **价值与意义** | ① **斜率代替快照**：Theil-Sen 成对斜率取中位，对单点离群免疫——把抽血前没空腹的那次化验降级为它本来的身份（噪声）；② **余量年数**：第一次给指标装上倒计时，「按当前速度 0.7 年到线」比「正常」两个字有用一万倍；③ **状态阶梯 + 门禁语义**：「还在爬的都要有个说法」——已越线但企稳的是「在管」，贴线爬坡的是「blind spot」，两者在报告里都只占一个词的位置；④ **噪声地板与诚实条款**：宁可拒判不喊狼来，3 次测量才判趋势、涨幅不足区间宽度 10% 是化验抖动；⑤ **区间变更处理**：越线史按当年区间记、余量按最新区间算，换医院不断账；⑥ **干预对账**：▽ 在降记功——净跌占区间宽度 16% 的转氨酶被账本记为「方向是对的，保持」；⑦ 零依赖 + 纯本地 + `--today` 钉死逐字节可复现。 |

## 核心思想：把「正常/偏高」换成「在不在爬、几年到线」

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **Theil-Sen 斜率** | 全部成对斜率取中位（3-7 个点的年代，OLS 会被一次化验失误绑架） | 「这个指标每年爬多快？」 |
| **余量年数 runway** | (最新参考上限 − 最新值) ÷ 斜率 | 「照这个速度，几年到线？」 |
| **噪声地板** | 净涨幅 < 参考区间宽度 × 10% → 化验噪声，不算在爬 | 「是真在爬，还是化验在抖？」 |
| **状态阶梯** | OVER（越线）> BORDERLINE（在爬且余量 ≤ 3 年）> WATCH（在爬，余量 > 3 年）> STEADY（没在爬）> THIN（< 3 次，拒判） | 「它现在在哪个档位？」 |
| **门禁语义** | BORDERLINE，或 OVER 且仍在爬 → exit 4；越线已企稳 = 在管，不进门禁 | 「谁必须有一个说法？」 |
| **区间变更** | 越线史按当年各自的区间记，余量按最新区间算 | 「换了医院，账还连得上吗？」 |
| **样本纪律 THIN** | 不足 3 次测量拒判趋势——任何两点都完美共线，斜率无意义 | 「这本账够不够格下判断？」 |

三条设计立场刻在实现里：**斜率用中位不用回归**——3-7 个数据点的年代，稳健比精确重要，一次失误的 500 不该把七年的 9 点/年改成 82 点/年；**门禁只咬「还在爬」**——越线但已企稳的说明医生或生活方式已经接管，工具的职责是找没人管的；**地板是给WATCH 挡噪声的**——没有地板的版本在示例账本上输出「肌酐余量 46 年」，等于建议一个 42 岁的人为 88 岁的肾挂号。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 命令速查

```bash dd:ignore
python3 borderline.py panel ledger.tsv --today 2026-09-04        # 全指标面板与判灯（红 → exit 4）
python3 borderline.py trend ledger.tsv --marker uric-acid        # 单指标全史：逐年值、首越年、斜率、余量
python3 borderline.py next ledger.tsv --today 2026-09-04         # 复查节奏：专项复查/半年加测/年度照旧/继续攒
python3 borderline.py validate ledger.tsv --today 2026-09-04     # 账本体检：点数、区间变更、新鲜度
python3 borderline.py markers                                    # 常见指标：单位、惯犯清单、科室
```

账本是一份可手编的 TSV（Tab 分隔），每行 = 某年体检的某项指标：

```
uric-acid	2023-09-12	432	µmol/L	208	428	医院A
ldl	2025-09-10	3.38	mmol/L	-	3.4	医院B
```

参考下限没有就写 `-`（如只有上限的 LDL）；备注可省。单位全史必须一致——换医院单位变了（µmol/L → mg/dL）请先折算再入账，工具会拒收混记。

## 一个真实样例

老陈（42 岁）2019-2025 七年体检、9 项指标 58 次测量，见 [examples/ledger.tsv](examples/ledger.tsv)。2025 年的报告点了 2 项：尿酸偏高、超重。2026-09-04 他把七年报告抄成账本跑了一次 panel：

```
贴线面板 · 最新体检 2025-09-10（距今 12 个月） · 9 项指标 · 58 次测量 · 2019 年起

  状态       指标                最新      参考区间        余量       斜率       备注
  ✗ OVER     bmi                   25.3   18.5-23.9       已越线     +0.37/年   2022 首越 · 线上 4 次 · 仍在爬
  ✗ OVER     uric-acid              452   208-428         已越线     +9.02/年   2023 首越 · 线上 3 次 · 仍在爬
  ▲ BORDER   ldl                   3.38   ≤ 3.4         0.2 年     +0.13/年   贴线爬坡 · 距线 0.2 年
  ▲ BORDER   fasting-glucose          6   3.9-6.1       0.7 年     +0.15/年   贴线爬坡 · 距线 0.7 年
  ○ WATCH    sbp                    133   90-139        3.6 年     +1.66/年   在爬 · 余量 3.6 年
  · STEADY   alt                     29   9-40 *            —     -0.40/年   ▽ 在降
  · STEADY   creatinine              74   57-97             —     +0.50/年   化验噪声内
  · STEADY   hemoglobin             153   130-175           —     +0.50/年   化验噪声内
  ◌ THIN     tsh                    2.4   0.55-4.78         —           —   n=2，满 3 次才判趋势

  * alt 的参考区间自 2024-09-10 起变更（9-50 → 9-40）：余量按最新区间算

判定  RED —— 4 项在爬：越线的还在爬（bmi、uric-acid）；贴线的快到线（ldl、fasting-glucose）
```

（完整输出：[examples/sample-panel-red.txt](examples/sample-panel-red.txt)，exit 4）报告点了 2 项，这本账点了 4 项：**空腹血糖七年全部「正常」，按 +0.15/年的斜率距 6.1 的上限只剩 0.7 年**——这就是快照思维的盲区（[examples/sample-trend-glucose.txt](examples/sample-trend-glucose.txt)）；尿酸的全史则是一场慢动作越线：93% → 95% → 97% → 98% → 101%，2023 年首次越线后三年仍以 +9.02/年 在爬（[examples/sample-trend-uric.txt](examples/sample-trend-uric.txt)）。而 alt（转氨酶）2022 年冲到 42 之后连降三年回到 29，账本给它记功：「▽ 在降——如果是干预的功劳，账本记得它」。

`next` 把面板翻译成复查节奏（[examples/sample-next.txt](examples/sample-next.txt)）：越线在爬的 3-6 个月内专项复查（附科室：尿酸 → 内分泌/风湿免疫），贴线的半年加测，血压「在爬但余量 3.6 年」年度照旧但下次重点盯，tsh 点数不足「继续攒」。 Creatinine 与 hemoglobin 斜率虽为正，净涨幅只占区间宽度的 2-5%，被噪声地板拦在「化验噪声内」——**它们不是趋势，是抖动**。

## 与哪些点子不混淆

- 与 **slow-leak**（暗漏）：暗漏管房子的三表（对照物是去年同期，抓异常突变与蠕升）；贴线管身体的指标（对照物是医学参考区间上限，抓朝临床线的系统性逼近）。共享「蠕升不可体感」的直觉，但阈值语义完全不同——一个是同比 +25%，一个是区间上限与余量年数。一个管钱包，一个管身体。
- 与 **redline**（加量红线）：红线管训练负荷的急性/慢性比——输入是你**练了多少**，周粒度，问「练多少安全」；贴线管体检的检验值——输入是身体对你一切的**反应结果**，年粒度，问「身体在往哪走」。红线的账本要天天记，贴线的账本一年只添几行。
- 与 **afterburn**（余燃）：余燃是药代动力学——小时级、半衰期常数驱动、算今晚这杯到几点；贴线是纵向统计——年级、从你自己的数据里回归、算这条线几年到。一个的参数来自人群实验，一个的斜率来自你本人。
- 与 **expiry-cliff**（到期悬崖）：悬崖的有效期是外部授予的给定日期（护照/保单/域名），翻日历就能算；贴线的「到线日」没人发给你，是从自己的历史斜率推出来的**会移动的悬崖**——减重五斤、戒啤酒三个月，斜率就变，倒计时就重算。
- 与 **wilting-point**（凋萎点）：凋萎点给植物装水位计（安全线/凋萎线之间的到天倒计时，看浇水习惯）；贴线给自己装跑道灯（参考区间内的到年倒计时，看身体走向）。一个的变量是你浇不浇，一个的变量是你怎么活。

## 验收标准（已全部转成自动化测试）

| # | 标准 | 测试 |
|---|---|---|
| A1 | 账本解析：坏行带行号 exit 2（列数/日期/未来体检/数值/参考区间/文件缺失） | `test_a1_*` |
| A2 | THIN：不足 3 次测量不判趋势（◌ THIN），永不触发门禁；越线事实照常显示 | `test_a2_*` |
| A3 | 斜率：成对斜率取中位（median(10, 10.5, 11) = 10.5）；离群免疫（混入一次 500 后 < 20，OLS 会给 82） | `TestSlope` |
| A4 | 噪声地板：净涨幅 < 区间宽度 10% 不算在爬（90,91,92 → STEADY）；斜率 ≤ 0 不算 | `test_a4_*` |
| A5 | BORDERLINE：在爬且余量 ≤ 3 年门禁（恰 3.0 触发）；> 3 年 → WATCH exit 0 | `test_a5_*` |
| A6 | OVER：越线仍在爬 → 门禁 exit 4；越线已企稳 → exit 0（在管） | `test_a6_*` |
| A7 | 首越年份与线上次数按当年各自的区间记（示例 uric-acid 2023 首越、线上 3 次；bmi 2022、4 次） | `test_a7_*` |
| A8 | 余量按最新区间算（示例 fasting-glucose 0.7 年、ldl 0.2 年、sbp 3.6 年） | `test_a8_*` |

| A10 | trend：未知指标 exit 3 并列出现有指标；越线（首次）/（第 N 次）标注 | `test_a10_*`、`test_a7_*` |
| A11 | 空账本 exit 3 | `test_a11_*` |
