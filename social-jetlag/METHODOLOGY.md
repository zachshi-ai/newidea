# METHODOLOGY · 社交时差记账法

> social-jetlag 的每一个数字都来自一行日志的确定性运算，但**选哪个数、不选哪个数、把哪个数叫「债」**都是方法论决定。本文记录每条规则的动机、推导与已知局限。

## 1. 立场：把「困」拆成两个变量

睡眠医学早就把两件事分开：**睡眠量**（duration，睡了多少）与**睡眠时相**（phase，睡在生物钟的哪个位置）。日常语言没有这个区分——只有一个「困」。于是产生本工具针对的核心误诊循环：

```
周一很难受 → 诊断为「缺觉」 → 药方「早点上床」
     ↑                              ↓
     └── 尝试失败（相位后移的人躺下睡不着）→ 自责 → 放弃 → 下一个周一
```

社会时差（social jetlag）概念的提出者 Roenneberg 有一个精确的比喻：工作日的闹钟把你的生物钟往社交时间拽，自由日它弹回去——**你每周都在自己身上飞两个来回**。本工具的全部工作，是把这场无人记录的每周飞行变成一本可查的账：一本是**债**（时长账户），一本是**时差**（相位账户）。两本账独立记账、独立判决，因为它们的药方相反：治债要**多睡**，治钟要**定时**（固定起床时间 + 晨间光照，按需用锚点平移）；用治债的药治钟，只会失败。

## 2. 为什么是中点，不是「睡到几点」

报告一个夜的自然醒时刻会犯两类错：晚睡但准时醒的人会被判「没问题」（实际相位已后移），早睡晚起的人会被判「睡懒觉」（实际两小时都是债）。**中点对入睡端与起床端各半敏感**——入睡推迟 1 小时贡献 0.5 小时，起床推迟 1 小时贡献 0.5 小时——它同时编码了「睡多久」与「睡在哪」，而且对入睡记录里的系统性偏差（见 §6）天然减半。这正是 MCTQ（Munich ChronoType Questionnaire）五十万人量级研究选择中点作为时相度量的原因：它是单夜里信息量最大的一个标量。

## 3. 账本一：睡眠债

- **每夜时长** = (wake − sleep) mod 24h。跨午夜自动处理：23:00→07:00 是 8 小时，不是负数。
- **SDw / SDf** = 工作日 / 自由日夜时长的**中位数**（默认；`--mean` 切换为均值，见 §5）。
- **每工作日债务** = max(0, SDf − SDw)。自由日中位时长被当作**需求**的代理变量——这是整个账本最重要的假设：你自由日睡到的长度近似你身体要的长度。它不完美（自由日也可能睡过头超过需求），所以有了 MSFsc 与还债率做交叉校验。
- **周债务** = 日债务 × 每周工作日夜数（从日志实际比例折算：n_work × 7 / 总夜数）。**不假设 5:2**——倒班者、4 天工作制、休假周都自动得到正确的权重。
- **年化** = 周债务 × 52。年化是叙事装置不是新信息：6h40m/周听着能忍，346h40m/年（≈ 14.5 个整夜）拒绝被忍。
- **还债率** = 自由日总超睡 ÷ 工作日总亏欠（逐夜对中位数求和）。三态：< 100% 是**deadbeat**（为还不起的贷款付时差利息）；≥ 100% 是**fare**（债还了，票价是每周两次相位跳跃）；无正债务时 n/a。注意这个比值是**会计恒等式的两面**——它只描述交换，不评价交换是否值得，评价是读者拿着 SJL 一起看的事。

## 4. 账本二：社交时差

- **MSW / MSF** = 两类夜睡眠中点的中位数。**SJL = MSF − MSW**，正值 = 猫头鹰方向（自由日中点更晚），负值 = 云雀/倒班方向（自由日更早），工具对方向敏感、对判决取绝对值。
- **2 小时红线**：在社会时差的实证文献里，SJL ≥ 2h 反复出现在与更高 BMI、抑郁症状、吸烟与咖啡因摄入等指标的相关性分析中（Wittmann et al. 2006 首次系统量化；Levandovski et al. 2011 的抑郁相关；Roenneberg 系列的综述）。1 小时以下的错位在多数研究中接近无害。**诚实条款**：这些都是人群级横断面的相关性，不是因果，更不是临床阈值——个体解读时把它当作「值得注意/基本无碍」的分界，而不是疾病判据。本工具不提供医疗建议。
- **为什么用中位数而非均值**：MCTQ 是一次性问卷，每人每象限只有一个值，无从谈中位数；日志版每象限有多个夜晚，而真实生活一定混入聚会夜、生病夜、带娃夜。一次周五狂欢不该污染整月的 MSF。要复现问卷口径，`--mean` 一键切换，报告口径在输出里永远可见。

## 5. MSFsc：把还债从时差里剔掉

自由日的超睡里混着两种成分：**自然相位表达**（你的钟本来就想睡到那时）和**还债**（工作日欠的，周末补）。直接用 MSF 当生物钟会把前者高估。MCTQ 的处理：先算周平均时长 SDweek，自由日超出 SDweek 的部分视为还债，并假设还债发生在**早晨一侧**（晚睡更多是相位，赖床更多是还债），于是把 MSF 拉回超睡的一半：

```
MSFsc = MSF − max(0, SDf − SDweek) / 2
```

本工具对原公式的两处偏离，都在报告里可见：
1. **SDweek 用日志实际 work:free 比例加权**，不是固定 5·SDw + 2·SDf / 7——因为日志知道你这周到底上了几天班，问卷只能假设。
2. **默认中位数**（§4），`--mean` 恢复问卷口径。

读法：mia 的 MSF 是 06:35，MSFsc 是 06:06——还债成分只值 29 分钟，钟仍偏在 06:06；她的 SJL 从 +2h50m 只降到 +2h21m，判定不变。**MSFsc 与 SJL 的差值就是「你以为的时差」里属于债的那部分**；若校正后判定从 HIGH 跌到 ALIGNED，说明你的错位几乎全是还债，那确实是「换个作息还债」就能解的问题。两种情形，两种处方——这就是拆账的意义。

## 6. 记录规范：账本只对诚实的账负责

- **一行一夜，记主睡眠**。午睡不计入（v1 不建模多相睡眠）；夜间醒来的碎片时长按你的诚实合并。
- **kind 按当天有无强制起床判**，不按星期几：调休上班的周六是 `work`，休假但设了闹钟送娃的周三也是 `work`。判定权在你，账本的义务只是把两种夜分开。
- **记「尝试入睡」还是「睡着」？** 记你上床关灯的时刻即可。它会引入 10–20 分钟的系统偏差，但注意两点：其一，中点对单端偏差减半（约 5–10 分钟）；其二，你两类夜**同样**偏差，而 SJL 是差值——偏差在差值里大面积相消。一致性比精确性重要：选定一种口径就别换。
- **建议的最小样本**：两周以上、至少 3 个自由日。工具对不满足者直接打印警告（`validate` 也会报），报告不会假装一个小样本是稳定的。

## 7. simulate 的外生假设

三个反事实都是**算术，不是预测**，假设边界如下：

- **flat**（周末不再补觉）：自由日**入睡时刻不变**，时长砍到 SDw。它回答的不是「你会睡得多好」，而是「你的时差里有多少是超睡贡献的」——mia 的答案是 40 分钟，剩 2h10m 是纯相位。flat 之后债务账户关闭（自由日不再暴露需求），所以债务行显示「账本关闭，不是债务清零」——这是刻意与「债=0」区分开的语义。
- **anchor ±m**：全部自由日两端刚性平移 m 分钟，时长不变。平移是线性的，所以 MSF 与 SJL 的移动可精确预期。
- **target m**：anchor 的反解——把 |SJL| 压到 m 所需的最小平移，方向永远朝 MSW。它给的是**改多大幅度**，不是「如何做到」；怎么做（光照、固定闹钟、就寝锚点）是处方学，本工具不开。

## 8. 边界情形

| 情形 | 处置 | 理由 |
|---|---|---|
| wake == sleep | 报错（带行号） | 0 小时与 24 小时在模 24h 下不可区分，宁拒勿猜 |
| 只有 work 或只有 free | report/simulate 退出码 3；validate 正常输出并标注 | SJL 是差值，单侧日志没有差值可言；但体检仍然可用 |
| 日期乱序 | 容忍，跨度按排序后计算 | 追记日志常补漏，顺序无关度量 |
| 重复日期 / 坏时间 / 坏 kind | 报错（带行号） | 账本对脏数据的第一道防线是拒绝入账 |
| 单夜 > 16h | validate 警告 | 多半是记错了 AM/PM 或日期 |
| 跨时区旅行的一夜 | v1 无特殊处理 | 本地挂钟记账，旅行夜会以噪声形式进入中位数——被中位数吸收，但建议短期旅行行用 `#` 注释掉 |
| 全部夜晚同一时刻 | 正常计算 | 中位数=均值，报告照常 |

## 9. FAQ

**为什么不直接读可穿戴设备的数据？** 三个理由：其一，手环的睡眠分期（深睡/浅睡）在可预见的版本里仍不可靠，而入睡/醒来两个时刻恰好是它测得最准的两个量——本工具只需要这两个量，就不该为不需要的精度上传整晚数据；其二，零依赖是本仓库的宪法，手环 SDK 不是标准库；其三，数据主权——一本可以手编、可以 grep、可以进 git 的 TSV 账本，比一个云端的睡眠画像更符合「账本」这个词的本义。从 Apple Health / 手环导出的入睡-醒来对，几分钟就能整理成本工具的 TSV 格式。

**我每晚睡够 8 小时，为什么还是困？** 你可能就是本工具的 target 用户：睡够 8 小时治债，治不了 2 小时的时差。跑一次 `report`，先看 SJL 行。

**「早睡早起」为什么对我没用？** 如果 MSFsc 判定仍是 HIGH，你的问题大概率在相位不在债——相位不是意志力参数，它是被光照与时序拖着的。先跑 `simulate target 60` 看需要移动多大幅度，再考虑用固定起床时间（连自由日）去锚，而不是用「早点躺下」去顶。

**负 SJL 是什么人？** 云雀（自由日起得更早）与部分早班倒班者。工具的判决取绝对值——错位 2 小时的云雀与错位 2 小时的猫头鹰同样越过红线，方向只影响处方方向。

**这与「睡眠卫生」建议冲突吗？** 不冲突，互补：睡眠卫生是处方学，本工具是诊断学。先诊断（债还是钟），再选处方；把睡眠卫生当成无差别的保健品，正是「困」这个含混词的产物。

## 10. 已知局限（v1）

- **需求时长是代理变量**：SDf 是需求的代理，不是测量。失眠者（躺 9 小时睡 6 小时）的 SDf 虚高，本工具会高估其债务——日志里诚实记录「尝试入睡」而非「睡着」会部分缓解，但不消除。
- **不建模相位动态**：中点是静态快照，不建模型太阳能把钟推多快；`target` 给幅度不给速度。
- **午睡、碎片睡眠、旅行夜**都不在 v1 的账本里（见 §8）。
- **无因果、无诊断**：2h 线是人群相关性的分界，不是医疗判据。账本负责让讨论有数字，判断请留给本人与专业人士。
