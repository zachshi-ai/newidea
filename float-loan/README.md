# 无息贷款 · Float

> 每一笔没回的垫款，都是你借给公司的无息贷款——利率为零、期限不定、没有合同、无人感谢。
> Every unreimbursed advance is an interest-free loan you made to your employer: no rate, no maturity, no contract, no thanks.

---

## 一句话

垫出去的钱没有账本。出差垫机票酒店、垫采购、垫团建，报销走流程动辄一个月，垫款散落在发票袋、聊天记录和记忆里——「管道里有多少钱、哪笔最老、该去催哪笔」没有人答得上来；公司的 DSO（应收账款周期）有整个财务部门盯着，你自己的应收账款连一行记录都没有。更没人记的是那笔真正的损失：被财务驳回、超标自担的垫款，报销叙事把它悄悄吞了。本件把每笔垫付记成一行事件流（TSV：日期/事项/金额/回款/品类，**回款列三态：留空=在途、0=自担、日期=回款日**），从同一本账开出五本账：**三态恒等式**（回款+在途+自担=总垫付，残差钉到小数六位）、**周期分布**（P50/P90/最慢，样例 8 笔回款 P50 24.0 天、P90 29.0 天/最慢 36 天）、**催办线 = 自己回款史的 P90**（财务流程的快慢是公司的参数，你的 P90 才是「多慢算不正常」的个人基线——超过它，这不是慢，是忘了）、**浮存金**（在途本金×年化÷365×持有天数，逐笔贡献加总恒等：样例半年 ¥68.47——利息是笑话，这正是重点：真正的成本不是 3% 年化，是在途本金从生活费里消失而你毫无察觉）、**回款速率与排空预测**（¥22,923 ÷ 135 天窗口 = ¥170/天 → 在途 ¥6,416 约 38 天排空）。示例账本实测：采购-项目服务器 ¥3,280 已躺 58 天、超催办线 29 天——pipeline 亮 RED exit 4，nudge 开出催办单；自担 ¥287（出租车被财务以「无发票抬头」驳回）单独立碑——**自担不入浮存，它不是占款，是损失，利率算不出被驳回的钱**。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 经常垫钱的上班族：出差垫差旅的销售/工程师/交付、垫采购的行政助理、垫团建的组织者、被「先走垫付流程」的项目经理——中国职场最普遍的灰色现金流。 |
| **场景** | 出差回来贴发票的那个晚上；财务说「发票抬头错了重开」然后石沉大海的第 N 天；信用卡账单来了、发现几千块被垫款占着的时候；季度底想知道「公司到底欠我多少票子」的时候。 |
| **问题** | ① **管道不可见**：垫款以每月几千的速率流出，以公司流程的速率流回，「现在有多少在途」只有到现金流吃紧时才被感知；② **账龄没有基线**：哪笔算「拖太久了」全凭感觉——你觉得 20 天就该到账，财务的常态是 35 天，而你自己上十笔回款的中位其实是 24 天，这个基线从来没有被写下来；③ **催办无依据**：去财务催款像求人办事，因为你说不出「这笔已 58 天、我历史上 90% 的垫款 29 天内到账」这种话；④ **自担被吞**：被驳回、超标、丢发票的垫款是真实损失，但「报销」这个动词把它们和「还没到账」混在一起，永远不算账；⑤ **占用无成本**：垫款是无息贷款，公司免费用你的钱，你连利息是多少都不知道——不知道，就永远不觉得它是钱。 |
| **价值与意义** | ① **三态账本**：回款/在途/自担三分，恒等式钉死——「垫了多少」第一次有分母，「贴了多少」第一次从「报销的噪音」里被拆出来立碑；② **催办线**：用你自己回款史的 P90 标定「多慢算不正常」——催办从求人办事变成出示证据：「这笔已 58 天，超我个人 P90 29 天」；③ **浮存金显形**：在途本金 × 年化机会成本，逐笔贡献加总恒等——数字诚实地小（半年 ¥68.47），小得正好揭穿这本账的真正量级：**利息是笑话，遗忘才是灾难**；④ **排空预测**：回款速率 = 你和公司联合流程的吞吐量，在途 ÷ 速率 = 管道排空天数——「钱什么时候回来」从玄学变成 Little's law；⑤ **门禁可进脚本**：存在超催办线的在途 → pipeline/nudge exit 4——红灯的含义不是「去撕破脸」，是「去替财务想起他们自己的流程」；⑥ 零依赖 + 纯本地 + `--today` 钉死逐字节可复现；不连财务系统、不猜流程、不替你发消息。 |

## 核心思想：把「有笔钱没报」换成一条看得见的管道

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **三态** | 回款列：留空=在途 / 0=自担 / 日期=回款日 | 「这笔钱现在是死是活？」——报销叙事只有「报了/没报」两态，丢了第三态 |
| **三态恒等式** | 回款 + 在途 + 自担 = 总垫付（残差 1e-6） | 「账平吗？」——一笔不多，一笔不少 |
| **催办线** | 自己回款周期的 P90（<3 笔不标定） | 「多慢算不正常？」——用你的历史，不用你的情绪 |
| **账龄** | --today − 垫付日；超催办线即超龄 | 「哪笔在被遗忘？」 |
| **浮存金** | 金额 × 年化/365 × 持有天数，逐笔贡献加总恒等；自担不入 | 「公司免费用了我多少现金？」——诚实地小 |
| **回款速率** | 回款总额 ÷（首笔垫付→末笔回款窗口），<3 笔不出 | 「管道多快排空？」——Little's law 的个人版 |
| **自担账** | repaid=0 的行单列、指名、合计 | 「哪些钱是真丢了？」——报销从不给它们立碑 |

三条设计立场刻在实现里：**催办线只用你自己的历史标定**——公司的 SLA 是它的参数不是你的基线，回款 <3 笔时 nudge 直接 exit 3 拒绝开工（没有周期史，「不正常」就还是感觉）；**自担不入浮存**——被驳回的钱不是占款是损失，把它算进「机会成本」等于用 3% 年化稀释 100% 的损失；**浮存金诚实到刺眼**——它算出来总是小钱，账本不放大它，只用它反衬真正的成本：无人看管的在途本金。

## 与近邻的边界

smooth-sailing（旱涝保收）的 FAQ 亲自把**报销排除在收入外**（「它是你的钱吗？不是，它是负现金」）——被排除的那本账正是本件：smooth-sailing 管你的收支节律，本件管你被公司占用的应收。job-funnel（求职漏斗）数的是投递转化，本件数的是垫付回款——同为「个人对机构的等待」，一个等 offer，一个等回款。gift-ledger（人情账）记的是对等关系里的往来余额，本件记的是雇佣关系里的单程占用——**垫款不需要回礼，只需要回款**。search-tax（寻物税）把「找不到」记成事件流，本件把「没到账」记成事件流——同构的事件流账本，不同的人生黑洞。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 账本格式

一份可手编的 TSV，每行 = 一笔垫付（事件流，同日多笔合法）：

```
date	item	amount	repaid	category	note
2026-06-20	差旅-广州交付	3870	2026-07-15	差旅	正常周期
2026-07-08	采购-项目服务器	3280		采购	发票重开后无音讯
2026-04-03	出租车-超标	287	0	差旅	财务驳回
```

- `repaid` 三态：留空（或 `-`）= 在途；`0` = 自担（被拒/超标，真·贴钱）；`YYYY-MM-DD` = 回款日（须 ≥ 垫付日且 ≤ today，时间不允许倒流，到账不能预记）；
- `category` 可选（默认 other，`-` 记 other），自由取名，用于贡献分解；`note` 可选；
- 坏行带行号 exit 2：列数/日期/金额/回款列非法、垫付或到账在未来。

## 命令速查

```bash dd:ignore
python3 float_loan.py pipeline floats.tsv --today 2026-09-04   # 在途管道（有超龄 → exit 4）
python3 float_loan.py stats floats.tsv --today 2026-09-04      # 总账：三态恒等式 + 周期分布 + 品类分解
python3 float_loan.py float floats.tsv --apr 18 --today 2026-09-04  # 浮存金（--apr 默认 3）
python3 float_loan.py nudge floats.tsv --today 2026-09-04      # 催办单（超线 exit 4；样本薄 exit 3）
python3 float_loan.py validate floats.tsv --today 2026-09-04   # 账本体检
```

## 一个真实样例

小周，交付工程师，半年垫了 12 笔：差旅 7 笔、采购 3 笔、团建 2 笔，见 [examples/floats.tsv](examples/floats.tsv)。9 月 4 日翻开账本（`pipeline`，exit 4）：

```
在途管道 · 3 笔 ¥6,416（垫付 12 笔 · 回款 8 · 自担 1） · 最老 58 天
  催办线 29.0 天（自己回款史的 P90）——超过它，这不是慢，是忘了

    #  事项                品类           金额  账龄  状态
    1  采购-项目服务器     采购         ¥3,280  58天  ✗ 超催办线 29 天
    2  差旅-西安验收       差旅         ¥2,750  22天  ○ 线内
    3  团建-季度下午茶     团建           ¥386   9天  ○ 线内

判定 RED —— 1 笔超催办线（采购-项目服务器）：¥3,280 在被遗忘。nudge 看催办单。
```

总账（`stats`）：回款 ¥22,923 + 在途 ¥6,416 + 自担 ¥287 = ¥29,626，残差 0.000000；回款周期 P50 24.0 天 / P90 29.0 天 / 最慢 36 天；回款速率 ¥170/天 → 在途约 38 天排空。催办单（`nudge`，exit 4）只有一行：采购-项目服务器 ¥3,280，已 58 天，超线 29 天（垫付 2026-07-08）——这就是他 7 月那句「发票抬头错了重开」的下文：**财务说重开，然后双方都忘了，账本没忘**。浮存金（`float`，--apr 3）：12 笔逐笔持有天数 × 3%/365，半年合计 ¥68.47——「利息是笑话，遗忘才是灾难」。而自担那 ¥287，账本的原话是：**「这是真·贴钱：出租车-超标 ¥287 被财务的『不符合规定』吃掉，报销叙事从不给它立碑」**。

## 诚实条款

这本账只记你声称的事实：不连财务系统、不读你的聊天记录、不猜报销流程走到哪一环——垫付日和到账日靠你手记，账龄的精度就是你的记账精度。催办线是观察性统计：P90 来自你自己那 8 笔，样本越少线越抖，所以 <3 笔拒绝标定。浮存金的年化是参数不是真理——余额宝 3、理财 4、信用卡 18，`--apr` 一改数字就变，唯一不变的是它诚实地小：这本账真正的产出不是那几十块利息，是一条看得见的管道、一条有出处的催办线，和一块给自担损失的碑。催办单开着，发不发消息是人的决定——账本只拒绝让你继续「忘了」。
