# 年轮 · Kin Ring

> 树的年轮记的是树经历的年份;家的年轮记的是家里每个人被疾病抵达的年纪。你的年龄是一枚指针,逐条扫过这些刻度——扫过哪一圈,没人替你数过,直到体检表「家族史」一栏永远空白。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 30–55 岁「上有老」的人:爸妈开始出现慢性病,同龄人的父母开始离世,自己第一次在陪诊椅上坐满一下午 |
| **场景** | ①陪父亲看病,医生头也不抬地问「家族里有人得过这个吗」——全家只有一句「好像我爷爷是胃不好的」;②自己过 43 岁生日,忽然想起哥哥是 42 岁确诊糖尿病的:你已经比他确诊那天更老了;③体检机构问卷「一级亲属病史:□无 □有」,你勾不出任何一个框;④想给爷爷的「脑溢血」补个年份,能回答你的人已经不在了 |
| **问题** | 家族病史是医学上最便宜的风险线索——一级亲属(父母/同胞/子女)的确诊史决定筛查的起点年纪,这是各国指南的公开常识。但它只活在口传里:(a) 分散在每位亲戚的记忆中,凑不齐一张完整清单;(b) 没有年龄锚点——「走得早」是几岁?差 5 岁和差 25 岁是两种人生;(c) 证人会死——一位长辈的确诊年份往往只存在于另一位老人的记忆里,失传是不可逆的。日历记行程、账单记钱、相册记生活,没有任何一本账记录「家里谁、得过什么病、几岁确诊」 |
| **价值** | 把口传变成对账:①**年龄带对齐**——你的年龄逐条扫过亲人的确诊年纪,🔴REACHED(已到)/🟡NEAR(5 年带内,恰线即亮);②**同病聚集**——归一化病名 ≥2 条且含一级亲属 → 一条可以直接带去问医生的证据链;③**该问清单**——缺年份的(UNDATABLE)、零记录的长辈、祖辈空白(BROKEN),趁证人还在,变成能问出的一句话。年轮不预测你会得什么病,它只回答一个从没人替你算过的问题:**你已经活到家里谁的年纪了** |

**本件不是**:不是医生、不诊断、不评估风险、不推荐任何筛查项目。REACHED 的意思仅仅是「你活到了家里某人被确诊的年纪」——多数有家族史的人终生不发病,基线概率仍在多数一边。

## 二、账本形态

手编 TSV,8 列,两种行型:

```tsv
type	key	rel	birth	status	dx	dxyr	note
person	父亲	parent	1952	alive		家族里唯一记得上一辈的人
dx	父亲				2型糖尿病	2000
```

- **person 行**(一人一行):`key` 是你叫他的称呼(被 dx 引用);`rel` 固定词表 `me/parent/sibling/child/grandparent/uncle-aunt/cousin/spouse/other`(中文短名如 `爷爷`、`配偶` 也收);`birth` 四位年份或 `?`;`status` 为 `alive/dead/dead:YYYY`
- **dx 行**(一病一行):`key` 指向 person(允许前向引用——先记病后补人都行);`dxyr` 四位年份或 `?`;**右侧缺列视为空**,手编从表格粘贴不拘小节,超过 8 列才拒
- 声明:`# as-of: YYYY-MM-DD`(至多一条,年龄对齐的「今天」);`# gone: <rel>`(承认某辈确已无从问起——账本不指控诚实的人)
- `me` 是账本主角:替谁记,谁是 me。me 的出生年是对齐的锚,不能是 `?`

## 三、灯(各管各的案)

| 灯 | 点亮条件 | 它在说什么 |
|---|---|---|
| 🔴 **REACHED** | 你已到达某位血亲(长辈/同辈)被确诊的年纪(Δ≤0) | 不是判决,是把「该和医生聊家族史」这句话提前到体检桌上 |
| 🟡 **NEAR** | 距那道年纪 0<Δ≤5 年,恰线即亮 | 提前量的全部价值——5 年带,够一次主动开口 |
| 🔴 **CLUSTER** | 归一化病名相同 ≥2 条(非本人/同住人),且 ≥1 条来自一级亲属 | 带去问医生的证据链;纯二级聚集只披露不亮灯——一级才算门槛 |
| 🔴 **BROKEN** | 祖辈整辈零记录且未 `# gone` | 这一代正在失去最后的证人;`# gone: grandparent` 是承认,不是失职 |
| ⚪ UNDATABLE | 缺出生年或确诊年,年龄带对不上 | 辅灯不抬闸,进 ask 清单变成一句话问题 |

**三条通道,互不越界**:子女的病不对齐你的年纪——它是家系证据(进 CLUSTER),不是你的时钟;配偶无血缘,同住人病史单列;本人的病史进 SELF 通道单列——自己的病历在就诊卡里,不需要对齐自己。

## 四、命令

```bash
python3 kin_ring.py report   kin.tsv            # 年龄带对齐 + 灯(账面带灯 exit 4)
python3 kin_ring.py report   kin.tsv --as-of 2012-06-01   # 时间机器
python3 kin_ring.py kin      kin.tsv            # 家族名册:各辈覆盖一眼见底
python3 kin_ring.py ask      kin.tsv            # 该问清单:趁长辈还在
python3 kin_ring.py validate kin.tsv            # 双路径重放 + 恒等式
```

退出码:`0` 绿 · `2` 账坏(表头/行型/亲属词表/年份不补零/年轮倒转/确诊早于出生/me 锚缺失) · `3` 空账或薄账拒判(零 person、只有 me 零病史) · `4` 账面带灯(REACHED/NEAR/CLUSTER/BROKEN 任一)。

## 五、样例走读(老周,43 岁)

哥哥 2021 年确诊 2 型糖尿病,那年 42 岁;今年老周 43 岁生日,意识到自己已经比哥哥确诊那天更老了。账本 6 人 6 病:

- **🔴 REACHED**:哥哥的糖尿病(42 岁)——「你今年 43——已到达哥哥确诊的年纪」
- **🟡 NEAR ×3**:父亲高血压(46 岁确诊,Δ+3)、父亲糖尿病(48 岁,**Δ+5 恰线**即亮)、姑妈乳腺癌(47 岁,Δ+4)
- **🔴 CLUSTER**:2型糖尿病 ×2(父亲 48 + 哥哥 42),一级亲属 2 条
- **⚪ UNDATABLE**:爷爷的卒中,年份无人知晓——ask 生成一句话问题
- **母亲零记录**:71 年人生在账上一次确诊都没有——真的没有,还是没问过?

时间机器 `--as-of 2012-06-01`:29 岁的老周看这本账,哥哥的确诊是「后视」行(如实呈现、对齐跳过、退出聚集),全灯熄灭。**年轮一直在那里,指针只是还没扫到**——这就是为什么要趁早把刻度刻下来:刻度会失传,指针不会等人。

## 六、设计立场

- **年龄带按公历年差计,粒度 ±1 年**。机器只算年轮,不装懂月龄;灯的语义是「时机」不是「风险评分」,±1 年不改变该不该开口。
- **零墙钟**。年龄对齐依赖 `# as-of:` 声明或 `--as-of` 钉死;两者都没有时 REACHED/NEAR 闸跳过并显著披露——宁可对不上,不借系统时钟装懂。CLUSTER/BROKEN/UNDATABLE 不依赖时钟,照判。
- **机器不算叙事**。「她生前说她姑妈也是瘤子」是口传不是数据,ask 只负责把它变成下一个问题。归一化只做字形(NFKC/空白/大小写),不做医学同义——「II型」≠「2型」,机器不发明没教过的等价。
- **确定性**。同账任何机器任何一天逐字节一致;报告只打 basename;`validate` 双路径重放(parse→evaluate ×2,含行号)逐字段全等。
- **诚实条款**。家族史改的是问诊桌上的时机,不是命运的概率;账本只存本地、不连任何接口;问不到的就 `# gone` 承认,空着的「?」本身就是一座碑。

## 七、与近邻的边界

- **handoff** 管财物的位置(家里有什么、在哪、谁知道),本件管病史的年轮(家里谁到过哪个年纪)——同是「只活在一个人脑里的家底」,一个怕找不到,一个怕问晚了。
- **borderline** 管自己的体检指标趋势(看自己的线),本件管上两代的风险线索(对齐别人的钟)。
- **off-track** 管孩子的生长曲线(往下一代看),本件往上两代看——同一个道理:孤立的一次测量没有意义。
- **cry-wolf** 管想象出来的灾难(多数不来,需要对账),本件管家里真实发生过的病(都来过,需要刻度)。
- **medicine-rollcall / stack-dose** 管药(货架上的钟、嘴巴里的加法),本件管病与年纪(家族的年轮)。
