# METHODOLOGY · 体感通胀

## 0. 一句话方法论

> 把「东西越来越贵」从一句体感变成一本账：用你基期月的购物篮做权重（Laspeyres 固定篮子），量出「保持原样的生活」现在的代价；把总通胀分解到品目找出惯犯；再用固定篮子与实际账单的差值，把**你已经做出的让步**（换便宜货、砍量）从「没涨多少」的假象里拎出来。

## 1. 为什么固定篮子是体感锚点

你抱怨通胀时，脑子里的比较对象从来不是「我今天实际花的钱 vs 去年实际花的钱」——那里面混着你自己做的调整。你真正在意的是：**「如果我什么都没变，我要多花多少」**。

这正是 Laspeyres 指数的定义：基期数量做权重，只让价格动。

```
L = Σ p₁·q₀ / Σ p₀·q₀
```

- p₀/q₀：基期月的单价与数量（你的生活快照）
- p₁：对比期单价（当月没买的，用最近一次观测价 carry-forward，并计入 imputed）

Laspeyres 有个著名的「上偏」：它假定你完全不做替代，涨价的东西照买不误。对宏观统计这是偏差，对个人体感这恰恰是**保真**——你感觉到的失控感，就是那个「没变的代价」。所以本件把 Laspeyres 放在 C 位当**体感锚点**，而不是像教科书那样急着用 Fisher 修正它。

## 2. 三把尺子各自回答什么

| 尺子 | 公式 | 回答 | 何时会分歧 |
|---|---|---|---|
| Laspeyres | Σp₁q₀/Σp₀q₀ | 保持原样要多花多少（体感锚点） | 涨价品目你照买 → L 最高 |
| Paasche | Σp₁q₁/Σp₀q₁ | 按你现在实际买的东西算涨了多少 | 你已经换便宜货 → P 低于 L |
| Fisher | √(L·P) | 两者的几何中庸 | 官方味道的「公允值」 |

L 和 P 的裂缝本身就是信息：**L − P 大，说明你已经被涨价改变了行为**。样例账本 L = +12.88%、P = +12.65%，裂缝不大，因为真正的行为变化（砍外卖量、换洗发水）发生在品目之外。

## 3. 覆盖率、uncovered 与插补：指数的诚实条款

指数最怕的不是算错，是**假装有价格**。本件的披露规则：

- **uncovered**：基期品目在基期之后（base, period] 区间内一次都没再出现——它现在的价格无从谈起，从指数中剔除，但在报告里点名。它可能是你戒掉的东西（好事），也可能是你忘了记账（坏事），工具不猜。
- **imputed**：基期后买过、但对比期当月没买的品目，用最近一次观测单价 carry-forward，逐品目计数披露。样例里 2/11 是插补：洗发水 A（2025-12 后消失）与洗洁精（只在单月买）。
- **拒答门**：基期篮子 < 5 品目，或覆盖率 < 50% → exit 3，报告只给「REFUSED」。从三笔小票外推年度通胀是算命，工具拒绝表演。
- **THIN 横幅**：覆盖率 50%–60% 仍然给结论，但挂横幅提醒「下面这个指数 leans on stale prices」。

**为什么以「基期之后是否出现过」论覆盖，而不是「对比期当月是否买到」**：很多生活品目不是月月买（洗洁精、洗衣液），若按当月论，它们的缺失会把覆盖率砸穿。出现过 = 市场还认识你，carry-forward 一两个月的陈旧度可接受；从未再出现 = 市场不认识了，剔除。

## 4. 贡献分解：恒等式，不是模型

每个品目对你总通胀的贡献：

```
contrib_i = (p₁ᵢ − p₀ᵢ) · q₀ᵢ / Σ p₀·q₀     （单位：百分点）
```

它有一个被测试钉死到 9 位小数的性质：

```
Σ contrib_i = L − 1     （精确成立，不是近似）
```

因为分子分母同权重展开，加总时逐项相加。所以红黑榜不是「某种打分」，是**总通胀的会计拆分**：外卖 +4.65pp + 咖啡豆 +2.32pp + …… = +12.88pp，一个不多一个不少。降价品目的贡献为负，自动落到 cooling 一侧。

**top-2 集中度**回答另一个问题：你的通胀是「一两个惯犯」还是「全面开花」。惯犯 → 针对性替换有杠杆；开花 → 该看的是总量预算。集中度 ≥ 50% 时报告直说「half your inflation comes from two items」。

## 5. 让步差：官方替代偏差的个人版

官方价格统计（多数国家的 CPI）在底层汇总时使用链式/旋转篮子，允许篮子随消费行为更新。这是合理的方法论——**但它有一个体感副作用：你的让步被吸收进了指数**。肉贵了你买鸡，指数里记作「涨得温和」，而你的体感记作「我连肉都吃不起」。两个都对，它们在测不同的东西：指数测「维持效用的成本」，你测「维持原样的成本」。

`drift` 把这件事翻到个人尺度：

```
让步差 = 固定篮子通胀(L) − 实际账单增速
```

- **让步差 > 0**：账单涨得比篮子慢 → 你已经让步了（换便宜货、砍量）。差值就是让步的规模。样例：+12.88% vs +7.60% → **+5.28pp**，配对证据是 ¥45 洗发水 A → ¥22.9 洗发水 B、外卖 10 次 → 8 次。
- **让步差 < 0**：账单涨得比篮子快 → 你在买更多/更好，没有降级。
- 配对规则刻意保守：只配**同品类**、**更便宜**、价格最接近的新品目；跨品类永不配对（咖啡豆消失了不代表它被大米替代了）。

**边界（诚实条款）**：实际账单增速混入了购买量的变化，所以让步差是**方向性证据**，不是纯净的价格效应——它回答「你让步了吗、大概多大规模」，不回答「让步里几块钱来自换货、几块来自砍量」。配对清单是让步发生地的证据，不是精确归因。

## 6. 年化口径与它的外推警告

```
年化 = (1 + 累计)^(12/n) − 1，n = 对比期与基期的月数差
```

17 个月累计 +12.88% → 年化 +8.93%。年化让不同跨度的账本可以对话，也给了红线一个稳定口径（默认 5%）。**警告**：这是复利外推，不是预测——过去 17 个月涨 8.9% 不代表明年也涨 8.9%，它只回答「以这个速度持续一年是多快」。红线判定用的是这个外推值，把它当「当前速度」读，别当预测读。

## 7. 单月基期的脆性

基期只有一个月，这是 Laspeyres 篮子的定义使然，也带来真实的脆性：

- **促销月陷阱**：赶上双 11 做基期，p₀ 全线偏低，此后每个月都在「涨价」。建议用 `months` 命令看每月密度与支出，挑一个普通的、记满的月份。
- **季节品**：羽绒服、空调扇会在基期缺席或失真。要么不记它们，要么接受它们在冬天亮红灯。
- **行的粒度**：price 记行总价，qty 记数量，单价 = 总价 ÷ 数量。同一品目当月多行会自动加权混合。

## 8. 品目命名约定

指数只认 slug。三条纪律：

1. **跨月稳定**：`eggs-30pc` 每次都叫 `eggs-30pc`，别这个月叫 `鸡蛋` 下个月叫 `eggs`。
2. **规格变了就换名**：250g 咖啡豆换成 500g，是两个品目（`coffee-beans-250g` / `coffee-beans-500g`）——价格不可比的品目放一个篮子里只会污染指数。
3. **品类用于降级配对**：category 是自由文本，但 drift 只在同品类内找替补，品类随手乱写会让配对失明。

## 9. FAQ

**Q：能和官方 CPI 对比吗？**
不能直接比数字，只能比方向。范围（你的篮子没有汽车和房租权重，除非你记账）、权重、季节调整、链式方法全都不同。本件是**你的账单显微镜**，不是宏观温度计。官方 CPI 的价值在于当对照组：它 +0.1%、你 +8.9%，说明「平均人」的让步与权重和你的处境差异巨大——这个差异本身就是结论。

**Q：我不记账，从哪开始？**
不用全记。挑你最在乎、最高频的 10-15 个品目（鸡蛋、牛奶、咖啡豆、外卖、通勤……），每次买完记一行。指数的意义在篮子的稳定，不在账本的全。

**Q：算出来是负的怎么办？**
你的价格在跌（或者你赶上促销季做基期了）。先看 board 的 cooling 一侧确认是真降价还是基期陷阱。负通胀也是信息——它和体感的差距同样值得追问。

**Q：促销和凑单怎么算？**
照实记。促销拉低的当月单价是你的**真实支付价**，跨店跨月择时本身就是对抗通胀的策略，不是噪声。单月基期的脆性见第 7 节。

**Q：为什么拒答门是 5 品目 / 50%？**
5 是「一个篮子」的最低配置——再少的话单个品目的价格跳动会直接劫持指数（一个品目占 20% 权重起）。50% 是「多数还是真的」的及格线——过半价格靠 carry-forward 撑着的指数，是考古不是测量。两个数都可讨论，但「总有结论」不可讨论：宁可 exit 3，不给假洞见。

**Q：数据隐私？**
账本是本地 TSV，CLI 不联网，零依赖零遥测。小票是消费隐私，一行都不出电脑。

## 10. 与相关工作的边界

- **官方 CPI / 统计局的篮子**：方法论同源（指数理论），对象相反——它测平均人的效用成本，本件测你的原样成本。见第 5 节。
- **记账 App**：记账是数据供给，本件是数据分析。App 告诉你这个月花了多少，本件回答「为什么感觉变穷了」。
- **仓库内其他消费向点子**：cost-per-wear / repair-ledger / 订阅审计回答「单笔消费值不值」，本件回答「价格水平在怎么动」——先看涨价的源头，再决定砍什么。
