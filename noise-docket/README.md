# 声讨 · Noise Docket

> 噪音事件发生即蒸发：日历记你的行程、相机记你的生活、账单记你的钱，
> 唯独没有一行记录「昨晚 23:47-00:31，楼上连续拖桌椅 44 分钟」。到投诉那一刻，
> 你的证据只剩情绪记忆——而情绪记忆在任何调解桌上都叫「一面之词」。
> 物业问「具体什么时间？几次？多久？」，你只有一团「经常！特别吵！」的愤怒；
> 打 110，警察到场时楼上已经安静了；邻居承诺「会注意的」，两周后一切照旧。
> 邻里噪音是城市投诉的常年前列，却可能是唯一**连一本账都没有**的纠纷。

## 一句话

把每次噪音事件抄成一行**可手编的事件账**（日期/开始/时长/来源/强度/证据），
从同一本账开出五本账：**总量与近窗判级**（QUIET / NOTABLE / SEVERE / UNBEARABLE）、
**法定禁令时段点名**（休息日全天的电钻、22 点后的装修——账本里最硬的事实）、
**规律与趋势**（星期×时段热区、近窗前后半在恶化还是回落）、
**整改验证**（标记日前后窗对比：改善 71.8% 还是照旧，拿数字翻篇或升级）、
**一页情况说明**（只陈述事实、不含一个主观形容词，物业/居委会/12345 底稿直接可用）。

## 角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 城市公寓里正被邻里噪音困住的住户：楼上孩子的跑跳与深夜拖桌椅、隔壁连月不休的装修、楼道口棋牌室的散场喧哗——已经到了「想投诉」的临界点，但每次伸手都发现手里没牌 |
| **场景** | ① 深夜 23:47 被拖桌椅声惊醒，明天还有早会——上楼怕吵架，忍着睡不着；② 周末找物业，物业问「都什么时间？几次？持续多久？」你说得越模糊，物业越有理由归档为「偶发摩擦、邻里互谅」；③ 打 110，警察到场时安静了——「当时没抓到现场」，你像个撒谎的孩子；④ 邻居当面承诺「会注意的」，两周后照旧，你甚至开始怀疑是不是自己太敏感；⑤ 12345 转办要你写「情况说明」，光标闪了二十分钟，写不出三行有数字的话 |
| **问题** | 1. **事件发生即蒸发**：没有任何账本记录噪音——到求助那一刻，证据只剩情绪记忆，而每次求助的通行证都是同一张「事实清单」，你恰恰没有<br>2. **愤怒没有分母**：夜间的烦躁把「一个月 8 次」放大成「天天吵」——没有分母的愤怒既折磨自己，又让投诉在别人耳朵里显得夸张；反过来真实的恶化（装修进入第二阶段）也没有刻度，不知道该等还是该升级<br>3. **升级没有线**：「再忍忍」与「正式投诉/报警留档」之间没有判据，什么时候忍是修养、什么时候忍是纵容，全凭当晚心情抽签<br>4. **整改没有验证**：邻居说改了、物业说谈了，之后呢？没有前后对比，「改善」永远靠感觉——好了就白好，没好就只能再吵一架 |
| **价值** | report 出总量账与近窗判级（样例账本：29 天 19 次 857 分钟、夜间占 31.9%、禁令时段装修 5 次，近窗 338 分钟判 UNBEARABLE exit 4）；pattern 出星期×时段热区与前后半趋势（回落中），并披露**在场抽样**——你只在家时记账，白天事件系统性缺席；verify 以标记日为界对账（8-01 物业调解+隔音垫：31.9 → 9.0 分/天，**改善 71.8%，夜间 7 → 0**——「隔音垫不是客气话，是账本上的台阶」）；letter 把账本渲染成一页克制的情况说明（只用日期/时刻/时长/来源这些亲历者最硬的证词，**主观强度不上信**）；validate 做语法、恒等式与双算法体检。全部本地计算、不连任何接口；as-of 缺省 = 账本最大日期，`--as-of` 是时间机器（钉回装修第 11 天：近窗 538 分钟，**当时就已经 UNBEARABLE**——账本证明你忍了 11 天才求助），同一本账任何机器任何一天逐字节一致 |

## 验收标准

| # | 验收项 | 判据 |
|---|---|---|
| 1 | 总量恒等式 | 样例账本：19 次 · 857 分钟 · 有噪日 18/29（62.1%）；Σ来源分钟 = 857（装修 535 + 拖动 158 + 脚步 112 + 棋牌 40 + 宠物 12）；夜间 273 + 日间 584 = 857；最长单次 100 分钟（07-13 合法时段施工） |
| 2 | 近窗判级 | 近窗 07-21 → 08-03：10 次 · 338 分钟（≥300 顶格线）· 夜间 4 · 禁令装修 2 → 判级 UNBEARABLE exit 4；OFF-HOURS 灯亮、LONG-NIGHT 灯熄；趋势前半 259 分/6 次 → 后半 79 分/4 次「回落中」 |
| 3 | 时间机器 | `--as-of 2026-07-21`：近窗 9 次 538 分钟 → UNBEARABLE——装修第 11 天账本已经顶格；缺省 as-of（账本最大日期）与显式钉回逐字节一致 |
| 4 | 夜间口径边界 | 22:00 恰开始算夜间、21:59 不算；05:59 算、06:00 不算（夜间含起点不含终点）；口径 `--night-start/--night-end` 可调 |
| 5 | 禁令口径边界 | 工作日 20:00 恰开始即禁令、19:59 否；12:00 恰禁令、11:59 否；13:59 禁令、14:00 否；07:59 禁令、08:00 否；周六/周日全天禁令；`--holidays 2026-10-01` 后周四节假日全天禁令；`--rest` 可改口径；**禁令只对装修类生效**（夜里跑跳是夜间问题不是禁令问题） |
| 6 | 禁令时段点名 | 全史禁令装修 5 次逐条可列（7-11 周六、7-16 周四夜、7-18 周六、7-24 周五夜、7-25 周六）；合法施工 3 次（工作日上午）不点名 |

| 8 | LONG-NIGHT 灯与薄账豁免 | 合成账本 3 天 1 次 23:10 电钻 120 分钟：覆盖 <14 天判级 DECLINE，但 LONG-NIGHT 灯亮 → exit 4（一次凌晨长钻不需要统计也能站住）；同账本换白天 20 分钟脚步 → 无灯 DECLINE exit 3 |
| 9 | 判级线全可调 | `--unbearable-line 500` 时样例近窗 338 分回落为 SEVERE（夜间 4 ≥ 3）；`--night-line 10` 后夜间线抬走、338 ≥ 180 仍 SEVERE；近窗累计恰 59 分 QUIET / 恰 60 分 NOTABLE（边界钉死） |
| 10 | UNBEARABLE 双通道 | 合成账本：近窗 5 次短夜噪各 10 分钟（累计仅 50 分）→ 夜间次数通道单独顶格 UNBEARABLE；近窗 0 夜间但 320 分钟白天 → 累计通道单独顶格 |
| 11 | verify 钉值 | `verify --since 2026-08-01 --label 物业调解+隔音垫`：前窗 26 天 17 次 830 分 31.9 分/天、后窗 3 天 2 次 27 分 9.0 分/天，变化 71.8% 判 IMPROVED exit 0，夜间 7 → 0，恒等式（前窗+后窗=全史，次数/分钟/夜间三口径）残差 0 |
| 12 | verify 薄账与反向 | `--since 2026-08-03` 后窗仅 1 次 → IMPROVED 但附「继续记录再完全信任」薄账提示；合成账本标记日后翻倍 → 判 WORSE exit 4（谈过之后反而更响，拿数字去升级）；标记日早于账本首日 exit 3 |
| 13 | letter 只陈述事实 | 信内钉值：19 次、857 分钟、夜间 7 次占 36.8%、禁令 5 条逐行（含星期与时刻）；top5 长单带 [有录音/录像] 标注（rec 列 Y）；**强度列不上信**——5 分的事件在信里也只有日期/时刻/时长/来源；落款「仅陈述个人记录到的事实，不含主观评价」；exit code 联动判级（样例 exit 4） |
| 14 | 别名归一 | 电钻≡装修≡renovation≡打孔、跑跳≡脚步≡steps、麻将≡棋牌、犬吠≡宠物——不同写法聚合到同一来源分类 |
| 15 | validate 体检 | 样例三恒等式全过 exit 0；跨午夜 2 次披露（按开始日归属、开始时刻判夜间/禁令）；近窗双算法（集合过滤 == 逐日游走 338==338）；mins=0 / start 24:30 / 坏日期 / 未知来源 全部 exit 2；同日同源重叠 → 警告不拒收（可能是同一次的分段记录） |
| 16 | 抽样披露 | pattern 输出「在场抽样披露」：账本只覆盖你在场的时刻，白天事件系统性缺席是记账姿势的属性不是楼里的安静——投诉时不过度声明「全天都吵」 |
| 17 | pattern 钉值 | 时段桶：09-12 七次 472 分（白天施工全在上午）、19-22 五次 112 分、22-24 七次 273 分；星期分布：一 6 次（7-27 双事件）、四/六各 4 次、周日 0 次（装修队周日休息——规律第一次可见）；类型×夜间交叉：夜间拖动 4 次 158 分、夜间装修 2 次 75 分、夜间棋牌 1 次 40 分 |
| 18 | 零锚定可复现 | 源码无任何系统时钟调用（源码扫描钉死）；缺省 as-of = 账本最大日期；报告只打印账本 basename；同一本账任何机器任何一天逐字节一致 |

## 快速开始

```bash
# 总量账 + 近窗判级 + 灯与趋势（样例：UNBEARABLE exit 4）
python3 noise-docket/noise_docket.py report noise-docket/examples/events.tsv

# 规律账：星期×时段热区 + 前后半趋势 + 在场抽样披露
python3 noise-docket/noise_docket.py pattern noise-docket/examples/events.tsv

# 整改验证：物业调解+隔音垫之后，是真的好了还是又要吵起来
python3 noise-docket/noise_docket.py verify noise-docket/examples/events.tsv \
    --since 2026-08-01 --label "物业调解+隔音垫"

# 一页情况说明：物业/居委会/12345 的底稿，只陈述事实
python3 noise-docket/noise_docket.py letter noise-docket/examples/events.tsv --to "物业服务中心"

# 时间机器：钉回装修第 11 天——当时就已经 UNBEARABLE
python3 noise-docket/noise_docket.py report noise-docket/examples/events.tsv --as-of 2026-07-21

# 账本体检：语法、恒等式、跨午夜归属、近窗双算法
python3 noise-docket/noise_docket.py validate noise-docket/examples/events.tsv
```

## 账本格式

TSV，一行一次事件，列：`date / start / mins / source / strength / rec / note`。

```
date	start	mins	source	strength	rec	note
2026-07-09	22:47	44	拖动	4	Y	深夜拖桌椅 惊醒
2026-07-11	09:40	95	装修	5	Y	隔壁开工 第一个休息日也在施工
2026-07-15	23:50	30	拖动	4	-	跨午夜 结束于次日 00:20 归属开始日
2026-08-01	11:20	12	宠物	2	-	物业上门调解 楼上加装隔音垫 当日仅此动静
```

- **source**：装修/脚步/拖动/宠物/音响/棋牌/人声/机械/其他，别名自动归一（电钻≡装修、麻将≡棋牌、犬吠≡宠物）
- **strength**：1-5 主观强度，可留空——只进你自己的账，**不上 letter**（主观评价不上信）
- **rec**：`Y` 或文件名 = 该时点有录音/录像；账本不检查文件，但 letter 会对这些条目标注 [有录音/录像]——调解桌上一方陈述 + 可核对的材料是两回事
- **跨午夜**：按开始日归属，开始时刻判夜间/禁令；validate 逐条披露
- **note**：自由备注；把「物业上门」「装了隔音垫」这类**标记日**写进备注，verify 就有了上下文

## 判级与灯

判级只看**近窗**（缺省 14 天，`--window` 可调），全史统计照出——账本陪伴整个周期，整改后判级回落，翻篇有依据：

| 判级 | 通识线（全部可调） | 含义 |
|---|---|---|
| UNBEARABLE | 近窗夜间 ≥5 次 或 累计 ≥300 分钟 | 顶格红灯：不用再忍，也不用再解释，把账本递出去 |
| SEVERE | 近窗夜间 ≥3 次 或 累计 ≥180 分钟 | 越过红灯线：每一次求助都需要这份账本，现在就该出示 |
| NOTABLE | 近窗夜间 ≥1 次 或 累计 ≥60 分钟 | 黄灯：记着，别让它在没有分母的记忆里发酵 |
| QUIET | 其余 | 绿灯：账面上的噪音在通识线以下 |
| DECLINE | 覆盖 <14 天 | 判级拒绝：噪声不是几天的事，继续记（单次灯照出） |

灯（独立于判级，亮灯即 exit 4）：

- **OFF-HOURS**：近窗存在**法定禁止时段的装修**——法定休息日/节假日全天、工作日 12:00-14:00 与 20:00-次日 8:00（《噪声污染防治法》通识口径，参数可调，地方条例永远赢）。法定禁令线一次也该有个说法；`--legal-line 0` 可关闭
- **LONG-NIGHT**：近窗存在夜间长单（单次 ≥90 分钟且落在夜间）——一次凌晨长钻不需要统计也能站住

exit code：`0` 正常 · `2` 账本语法错误 · `3` DECLINE（薄账拒判级）· `4` 红灯（判级 SEVERE+ 或任一灯亮）

## 诚实条款

- **账本不做声学鉴定**：强度 1-5 是主观标尺，它记的是**频率 × 时段 × 时长**——这三样只有亲历者知道、也最难被否认；手机分贝 App 没有计量校准，一个不可信的 dB 数字在调解桌上还不如一句「22:47 到 00:31，44 分钟」
- **单方记录是一方陈述**：账本建议对重点事件标注录音/录像的存在（rec 列），letter 会带 [有录音/录像] 标注——它不出庭、不定性违法，它把事实摆上桌
- **夜里的痛苦不按次数打折**：夜间微觉醒让你对 3 次夜噪的痛苦可能超过白天 20 次——账本计数，不裁判痛苦；判级给夜间单列通道，正是因为夜间不只是「次数多」的问题
- **账本只覆盖你在场的时刻**：白天上班不在家，白天的事件系统性缺席——pattern 把这件事印在报告里，投诉时不过度声明「全天都吵」
- **它不是报警器**：不连麦克风、不做实时监测、不自动分贝；记账的手是唯一的传感器——这本账的价值恰恰在于每一行都是你亲历的证词

## 与近邻的边界

- **borrowed-silence（预支安静）**：同是噪音，那边量它对你**耳蜗**的剂量（dB 硬通货、3dB 交换率、终身额度），这边量它对你**生活与邻里关系**的占用（次数/时段/时长，不需要分贝）——那边的受害者是你的听力，这边的受害者是你的睡眠和证据链
- **mood-barometer（阴晴表）**：那边记情绪反应（你的心），这边记外部事件（别人的吵）——同一晚可以都记，两本账不混
- **float-loan（无息贷款）**：催办单同构——把「求人办事」变成「出示证据」；那边催的是回款，这边举的是噪音
- **filial-desk（孝心工单）**：复发链/整改验证同构——「复发是唯一审计员」；那边审计教学效果，这边审计整改效果（verify 的前后窗就是噪音版的 90 天观察窗）
- **make-it（来得及）**：同为个人经验分布——那边回答通勤概率，这边回答噪音规律
- **slow-leak（暗漏）**：那边是月度聚合的连续量蠕升，这边是逐次事件的离散频次——同一类「看不见的恶化」，两种时间粒度
