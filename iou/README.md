# 欠条 · IOU

> 借出去的钱,第二天就开始没人记得——转账那一刻没有凭证、没有期限、没有利息,催收的那一刻没有证据、没有底线、没有退路。
> Every informal loan is an IOU nobody wrote down: no proof, no maturity, no interest — and when it's time to ask for it back, no evidence and no script.

---

## 一句话

亲友借贷是法院民事案件的第一大案由,却是唯一没有账本的债权:微信转账救急、饭局上开口、住院押金周转——「过两天还你」之后,这笔钱就从所有系统里消失了,银行 App 只显示转出记录、聊天记录沉进历史、大脑只记得「他好像还欠我点啥」。三个月后开始尴尬,一年后连细节都要翻手机,三年后连法律都不再保护——**民间借贷的通识诉讼时效是三年,而没有人记得自己最后一次催讨是哪天**。本件把每笔借出与回款记成一行事件流(TSV:date/kind/who/amount/note/promised,kind ∈ lend 借出 / repay 回款 / chase 催讨 / forgive 销账),从同一本账开出五本账:**敞口恒等式**(借出−回款−销账=敞口,Σ人均余额钉到小数六位;样例 36,300−15,800−1,000=19,500)——「外面飘着多少钱」第一次有数字;**催收线 = 自己回款史的 P90**(样例 5 笔周期 [28,32,118,179,376] 天 → P90 297.2 天——「多算拖太久」从脸皮问题变成统计问题;样本 <3 笔退通识 90 天并显著披露,民间借贷没有 SLA 文化,拒绝服务比通识垫底更不诚实);**时效账**(起算日 = 约定日或借出日,chase 一行把起算重置到主张日、通识续命三年——法律不保护躺在权利上睡觉的人,账本不让你睡过头;届满当日即算已过,余量 ≤90 天进危险区);**催收单**(超线未清逐笔点名,只给日期/金额/天数这些亲历者最硬的证词,催不催、怎么说是人的决定);**借出前门卫 should**(「表哥又开口了」——名下还有 12,000 未清、历史回款率 40%、账龄 1,148 天:CAUTION exit 4,借不借你决定,但先看看自己的历史);**人情化率**(forgive 销账是本件的诚实条款:有些借出去的钱,社会角色最终就是赠与——它把「心里硌一下」变成有分母的数字)。 FIFO 是全部算术的地基:亲友回款从不指定冲哪笔,最老先清是会计默认;回款/销账超过未清余额、催讨时名下无账,一律 exit 2——账本不许两边加起来对不上。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 借过钱给亲友同事的普通人——债权人视角。表哥装修周转、同事换手机、发小住院押金、前室友房租救急:中国式人情社会里,几乎每个成年人都有一笔「不好意思提的本金」飘在外面。 |
| **场景** | 转账那一晚(「过两天还你」,没有第二句话);三个月后开始尴尬(提了伤感情、不提自己憋屈);一年后想开口却发现连金额和日期都要翻聊天记录;对方又一次开口借钱的那一晚(「这次借不借」全凭心软);以及三年后的某一天——权利睡过了时效,连法庭都不再受理。 |
| **问题** | ① **敞口不可见**:外面飘着多少钱没有数字——银行的流水、微信的转账记录、聊天框里的「过两天」,没有一处加总;② **账龄没有基线**:「拖太久」是脸皮问题不是统计问题——你觉得半年该还,他上笔借款拖了一年,你的历史里从来没有一条线;③ **开口无证据**:催款像翻旧账、像斤斤计较,因为你说不出「2022 年 10 月那笔 20,000,你回了 8,000,剩 12,000 到今天 1,320 天」这种话;④ **重复受害**:历史借 2 万只回 8 千的人再开口,没有先验拦截你当场心软;⑤ **时效在燃烧**:通识诉讼时效三年、催讨重新起算——但没人记得自己催过没有、哪天催的,权利就在沉默里过期。 |
| **价值与意义** | ① **敞口恒等式**:借出−回款−销账=敞口,Σ人均余额逐分钉死——「飘在外面」从感觉变成一张人均表;② **催收线**:用你自己回款史的 P90 标定「多慢算不正常」——催收从撕破脸变成出示证据;③ **时效账**:chase 自动续命起算日,时效余量倒计时到天——「再不催,连法律都不帮你了」第一次有闹钟;④ **催收单**:可照着念的事实底稿(日期+金额+天数,不带一个情绪词);⑤ **借出前门卫**:历史回款率与未清余额摆在你脸上,让「心软」至少是看过账的心软;⑥ **人情化率**:销账让「这钱我不要了」有一个正式的会计动作——止损和心理止损同时完成。 |

## 核心思想:把「不好意思」换成一条有出处的证据链

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **四态事件流** | lend 借出 / repay 回款 / chase 催讨(不带金额) / forgive 销账 | 「这笔钱现在处于哪种命运?」——记忆只有「欠着/还了」两态,丢掉了「催过」和「不要了」 |
| **敞口恒等式** | Σlend − Σrepay − Σforgive ≡ Σ人均余额(残差 1e-6) | 「账平吗?」——一笔不多,一笔不少 |
| **FIFO 抵扣** | 回款从最老未清笔开始冲(亲友回款从不指定冲哪笔) | 「这笔还清了吗?」——最老先清是会计默认,不是猜测 |
| **催收线** | 自己回款周期的 P90(≥3 笔);不足退通识 90 天并披露来源 | 「多慢算不正常?」——用你的历史,不用你的情绪 |
| **时效起算** | max(约定日或借出日, 最后一次催讨日);整 N 年届满,届满当日即已过 | 「法律还站在我这边吗?」——通识口径三年,`--statute-years` 可调 |
| **chase 续命** | 催讨一行把该人全部未清账的起算重置到主张日 | 「我主张过吗?」——账本替你记得,法律只保护不睡觉的权利 |
| **借出前门卫** | 历史回款率 <50% 且名下有未清 → CAUTION exit 4(恰 50% 不亮,宁少报) | 「这个人还能不能借?」——你的历史是唯一的征信报告 |
| **人情化率** | Σforgive ÷ Σlend | 「有多少借出最终成了赠送?」——让「算了」有正式的会计动作 |

三条设计立场刻在实现里:**催收线的来源必须披露**——P90 是你的历史,通识 90 天是垫底,报告里写清楚是哪一种,通识线顶班时报告不许冒充你的历史;**chase 记的是你主张过,不是对方认过**——已读不回的催讨在法庭上未必续命,账本只负责让你别睡过,法律判断请交给律师;**forgive 是销账不是回款**——它不进回款率(那是对方的信用),只进人情化率(那是你的慈悲),两种宽厚不许混账。

## 与近邻的边界

float-loan(无息贷款)审**公司报销流程**里的垫款——对方是财务系统,回款确定性高,等待的是流程,成本是浮存金利息,它的每一笔都值得催;本件审**亲友借贷**——对方是人,回款不确定,等待的是人心,成本是社交税,本件一半的价值在「决定不催」和「决定不要了」。gift-ledger(人情账)记随礼的双向对价——礼金是社会货币,互相流动,算净余额防自欺;本件是单向本金——借出不是为了回礼,是为了回款,但 forgive 庭承认有些借款最终的社会角色就是赠与。smooth-sailing(旱涝保收)管自雇收入的波动节律,本件管确定性为零的应收。recoup(回血)裁决卖还是送(闲置物的清算经济学),本件裁决催还是免(飘着的本金的沉默经济学)。noise-docket(声讨)同用「亲历者最硬的证词」开情况说明——那边举噪音,这边举欠款;float-loan 的催办单是替对方想起流程,本件的催收单是替关系出示证据。expiry-cliff(到期悬崖)管凭证的显式到期日,本件的时效没有到期日——它恰恰住在「没人记录」里,所以要用 chase 把它一次次续上。

## 安装(零依赖)

只需 Python 3.8+,无需 `pip install` 任何东西。

## 账本格式

一份可手编的 TSV,每行 = 一个事件(事件流,同日多笔合法,乱序载入即排序):

```
date	kind	who	amount	note	promised
2022-10-08	lend	表哥·阿伟	20000	装修周转,说好过年还	2023-02-01
2023-02-03	repay	表哥·阿伟	8000	过年回了个零头
2025-08-15	chase	表哥·阿伟	0	微信上提了一嘴,回了个「嗯」
2026-05-20	forgive	发小·强子	1000	病还没好利索,这 1000 不要了
```

- `kind` 四态,lend/借出、repay/回款(还款/还)、chase/催讨(催)、forgive/销账(销/送)中英同效;
- `chase` 行不带金额(amount 填 0 或留空)——催讨是动作不是流水;`chase` 时该人名下必须有未清余额;
- `promised` 约定日只对借出行有意义,不得早于借出日;它是时效起算的优先锚;
- `repay`/`forgive` 不得超过该人未清余额——多回的部分先查人名再查账;repay 不得早于该人首笔借出;
- 坏行带行号 exit 2:列数/日期/kind/人名/金额非法、约定穿越、销账超余额、催讨无账可催。

## 命令速查

```bash dd:ignore
python3 iou.py report examples/iou.tsv --as-of 2026-05-20          # 总账:敞口恒等式+判级(红灯 exit 4)
python3 iou.py book examples/iou.tsv --as-of 2026-05-20            # 人均明细:FIFO 逐笔未清+时效起算日
python3 iou.py nudge examples/iou.tsv --as-of 2026-05-20           # 催收单:超线逐笔点名+事实底稿(exit 4)
python3 iou.py should examples/iou.tsv --who 表哥·阿伟 --amount 4000 --as-of 2025-11-29  # 借出前门卫
python3 iou.py validate examples/iou.tsv --as-of 2026-05-20        # 账本体检:恒等式+双算法
```

参数:`--as-of` 缺省=账本最大日期(零墙钟);`--grace-days 90` 通识催收线;`--statute-years 3` 通识时效(参数不是法律意见);`--statute-warn 90` 危险区;`--monthly-spend`(给了才做敞口翻译);`--expose-months 2` / `--soft-line 0.5` 横幅线。

## 一个真实样例

老周,42 岁,四年借出去七笔,见 [examples/iou.tsv](examples/iou.tsv)。2026 年 5 月 20 日翻开账本(`report`,exit 4):

```
欠条总账 · 15 笔事件(2022-10-08 → 2026-05-20) · as-of 2026-05-20 · 账本 iou.tsv
  借出 ¥36,300(7 笔) − 回款 ¥15,800(5 笔) − 销账 ¥1,000(1 笔) = 敞口 ¥19,500
  恒等式核验:Σ人均余额 = 敞口,残差 0.000000——一笔不多,一笔不少
  回款周期:P50 118.0 天 · P90 297.2 天(5 笔样本)
  催收线 297.2 天(自己回款史的 P90)——超过它,这不是慢,是忘了

  人                  余额 队头账龄 时效余量  回款率  状态
  表哥·阿伟        ¥16,000  1,320天    818天   33.3%  ✗ 超催收线
  发小·强子         ¥2,000    853天    610天   40.0%  ✗ 超催收线
  前室友·阿凯       ¥1,500    656天    439天    0.0%  ✗ 超催收线
  同事·小蔡             ¥0        —        —  100.0%  · 清
  表姐·静静             ¥0        —        —  100.0%  · 清

判定 STALE —— 3 人未清超催收线,¥15,500 在沉默里免息续借。
```

三笔账,三种命运,全在同一本账里。**表哥·阿伟**:2022 年借 20,000 说好过年还,回了 8,000 的零头;2025-08-15 老周在微信上提了一嘴——就这一行 chase,把时效起算从约定日 2023-02-01 重置到主张日,2028-08-15 前法律都站在他这边;2025-11-30 表哥又开口 4,000,`should` 在借出前夜就亮过 CAUTION(历史回款率 40%、名下 12,000 未清)——老周没顶住,账本把这两笔都记得清清楚楚。**发小·强子**:住院押金 5,000,催了一次一周后回 2,000,2026-05-20 老周销账 1,000(「病还没好利索」)——人情化率 2.8%,这本账里他的慈悲有据可查。**前室友·阿凯**:1,500,人搬走了,从未催讨——时效起算还挂在借出日,余量 439 天,是全账最紧的一根发条:每拖一天都在消耗法律留给他的窗口。催收单(`nudge`,exit 4)给每人一份事实底稿——「2022-10-08 借出 ¥20,000,说好 2023-02-01 还——未清 ¥12,000,已 1,320 天」——催不催、怎么开口,是人的决定;时间机器(`--as-of 2028-09-01`)演示账本停更的代价:三笔全过时效,判定 STATUTE——**这就是没人记账的结局**。

## 诚实条款

这本账只记你声称的事实:不连银行、不读微信、不查征信——借出日和回款日靠你手记,证据链的硬度就是你的记账硬度。催收线的来源永远披露:P90 是你的历史,通识 90 天是垫底,通识线顶班时报告不许冒充你的历史。时效是通识先验不是法律意见:三年起算、催讨重置是流传最广的民间口径,具体到你的合同、你的转账备注、你所在地的法庭,律师说的永远赢——账本只负责把「你主张过」这件事记到天。chase 记的是你主张过,不是对方认过:已读不回的催讨在法庭上未必续命,但「从未主张」连争的余地都没有。人情化率不是慷慨的价目表:它不鼓励你销账,也不指责你销账,它只让「这钱我不要了」从心里的一句话变成账本上的一行——止损和心理止损,从此有据可查。催收单开着,发不发消息是人的决定;借出前门卫亮着,借不借也是人的决定——账本只拒绝让你在「不好意思」里继续沉默。
