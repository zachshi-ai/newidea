# METHODOLOGY · 低价签的方法论

## 0. 一句话

**比价比的是合同价,决定真实成本的是报价单的完整性**——低价签的利润不在那一行行单价里,在没写的那几行里;审计的对象因此不是「贵不贵」,而是「全不全」。

## 1. 为什么增项要分四类,而不是记一笔总额

「超支 5 万」是一个数,不是一种病。四种病的成因不同、责任人不同、药也不同:

| 类 | 机制 | 责任 | 药 |
|---|---|---|---|
| **upgrade 签字升级** | 你主动要的(岩板、三层实木) | 你的预算管理 | 无对错,记进预算,别记进仇恨 |
| **forced 被动必做** | 不做不行,报价单里没有(防水/找平/垃圾清运) | 对方的报价完整性 | 下一份合同:漏项审计前置(judge) |
| **drift 开口量差** | 单价没宰你,量爆炸(280m→612m) | 开口合同的结构 | 写上「单价 × 封顶量」,把开口变成半闭口 |
| **padded 行业增利** | 同行默认含,他单收(管理费/搬运/税点) | 谈判地位 | 三家比价的证据、换人或谈价的依据 |

只记总额的人结算时只有一个情绪;分类的人手里有四张不同的牌。**不分类的增项总额没有意义**——这句话刻在 audit 的瀑布输出里。

分类的时机是签字当天,不是结算时。回忆会把每一笔增项都磨成「当时没办法」——forced 会膨胀,padded 会被遗忘,upgrade 会改写成「是他们劝我的」。**当场分类是唯一的皮肤游戏**:账本的价值不在于它记得准,在于它逼你在信息最全的那一刻表态。

## 2. 分类口诀

- **你不提,他就不会做** → upgrade。判定人是你的购物欲,不是他。
- **你不签,工程就停** → forced。停工一天,你亏的是工期和已付款的抵押,他亏的是下一个工地的口碑——不平衡就是勒索空间。报价单里该有而没有,是 forced 的铁证。
- **问三家公司,两家含** → padded。不需要哲学,需要两个电话。
- **报价单里的开口项长量** → drift。挂靠规则:量差行的条目名与开口条目命中同一基线 key(或互为前缀),qty 记**超出的量**,final = est + 量差由工具还原。

边界情形(padded vs forced)确实模糊——成品保护是规范还是发明?答案在你的城市不在代码里,所以工具只给口诀、只登记、不判决。三个电话比一次吵架便宜。

## 3. 低价幻觉指数:为什么它是下界,以及为什么下界就够杀人

```
幻觉指数 = 漏项中位预估 ÷ 合同小计
真实底价 = 合同 + 漏项中位预估
```

它只统计一件事:**报价单没写、但行业常识认为该写的行,按常识中位价「补」回合同里**要花多少钱。它刻意排除两样东西:

- 排除 upgrade——那是你的选择,不是他的报价;
- 排除开口爆量——量在开工前不可知,任何「预估爆量」都是伪精度。

所以 28.3% 的指数配 55.1% 的真实增项率并不矛盾:**指数是「什么都不改、什么都不爆」也要付的钱,是增项的下界**。下界就足以裁决,因为低价签的辩护词永远是「我们单价便宜」——而指数证明的是:就算单价便宜是真的,你漏写的字也会把便宜加倍还回去。

红线 15% 的语义:一份报价单,「什么都不做」就能预见两成的蒸发,这份合同的价格标签本身就是假的。

## 4. 诱饵×开口:为什么单价便宜反而危险

杀局的两个零件单独看都无辜:

- **单价诱饵**:¥38/m vs 常识 45–90(下沿 0.84x)。单看像「让利」。
- **按实结算(est=open)**:工程行话叫「开口」,预估 280m 只是参考。

合起来是定价权的完整转移:你以为是「38 元 × 用多少算多少」,实际是「他决定用多少米」。示例账本里 280m 变 612m——2.19x——按常识中位价 67.5 算,612m 本来就该值 ¥41,310;他收 ¥23,256 看着仍「便宜」,但合同里那行白纸黑字写的是 ¥10,640。**你的参照系在签单那一刻被他换掉了**。

判据因此写成合取:单价 < 下沿 × 0.85 **且** est=open,缺一不红。单价低但闭口,是让利;单价正常但开口,是常规风险;两个都有,是杀局标配。谈判脚本只有一句:**开口项写上「单价 × 封顶量」,超封顶他自担**——这一句把开口变成半闭口,杀局拆掉一半。

## 5. 双价目表:签单时的市场价,增项时的垄断价

同一个工地,两套价格:

- 签单前:你是待标项目,单价是市场价(甚至低于市场价——那是获客广告);
- 增项时:你停工等他,半途换人 = 双倍付钱,你的议价能力归零,单价是他写多少是多少。

示例:墙面找平常识 25–60,增项收 95(上沿 1.58x);材料搬运常识 0–1,000,收 2,400(2.40x)。宰客价的判据:增项单价 > 常识上沿 × 1.5。1.5 的宽容度是刻意的——区间本身有噪声,红线只抓「无法用任何行情解释」的定价。

按比例计的条目(管理费/税票)不参与单价审计,按合同额比例落位:8.0% 恰在上沿之上,3.5% 区间内——**比例类是 padded 的重灾区,因为基数是整份合同**。

## 6. 常识基线:先验垫底,行情永远赢

内置 14 项基线(universal 6 + conditional 8)是**典型城市的常识先验**,作用只有三个:冷启动、给缺失项定价、给诱饵/宰客提供参照系。它不是行情价,区域、楼层、年代、材料档位都在改写它。

所以覆盖是一等公民:`--baselines my.tsv` 七列(key/aliases/low/high/unit/cond/typical)整表替换。测试钉死了这个语义:把水电区间改成 140–180,B 单那条 ¥55 的水电也从「正常」翻成「诱饵」——**先验是可覆盖的,判罚跟着行情走,账本不垄断真相**。

`typical` 列存典型量(防水 14㎡、找平 240㎡),缺失项的中位预估 = typical × 中位单价;置 0 表示量不可预估,该缺失项只点名、不报价——诚实比完整重要。

## 7. 「含基层处理」:话术如何骗过关键词审计

gaps 靠关键词匹配判断覆盖。话术的第一战场就在这里:报价单写「乳胶漆(含基层处理)」,关键词命中「基层处理」,找平被判「已覆盖」——结算时工长说「你这墙面误差超普通找平范围」,9,120 照样发生。

工具对这类条目不做魔法:匹配是匹配,话术是话术。所以 conditional 清单永远附带一句人话——**「含基层」「含找平」是增项话术高发区,签约前追问一句:找平另算钱吗,什么情况算「超范围」**。把答案写进合同备注,是唯一比审计更硬的东西。

## 8. 为什么不读 PDF、不联网比价、不认识装修公司

- **不读 PDF**:报价单 OCR + 表格还原的出错率,在一份要拿来对簿的账本里不可接受。抄录二十一行是二十一次「我现在知道了」的学习;粘贴是粘贴,理解是理解。
- **不联网比价**:平台报价单是另一个广告位。本件的参照系是可覆盖的常识先验 + 你自己记的账,不是又一个想卖你流量的入口。
- **不认识公司**:给它一份公司黑名单,三个月就过期;给它一套审计方法,十年不过期。

## 9. FAQ

**Q:增项都已经签字了,audit 还有用吗?**
三个用处:复盘(四分类告诉你下次的 5 万会从哪四条管道流走)、谈判(padded 列 ¥14,740 是「同行都含」的实锤,结算撕逼时是弹药)、验证(judge 的预测——6 项 universal 缺失——与 forced 的实际发生逐条对照,你的审计眼光会长)。最值钱的是第四个:下一套房。

**Q:半包/清包能用吗?**
能。账本只认「条目 × 数量 × 单价」,包装方式无关。清包的主材自购条目照抄,增项审计照跑。

**Q:增项率红线为什么是 30%,幻觉为什么是 15%?**
30%:行业里「全包结算 = 合同 × 1.3」已经是被广泛引用的经验区间,超它不是个案是模式。15%:幻觉指数只统计可预见的部分(下界),一份报价单在「什么都不发生」时就能预见 15% 蒸发,价格标签已经失真。两个都可用参数/基线覆盖——判据给你,阈值可以辩,账本不说谎。

**Q:漏项清单才 14 项,太少了?**
14 项是 universal+conditional 的**最常回收**清单(垃圾清运/管理费/税票三项的回收率接近 100%),不是穷举。`--baselines` 可以加你所在城市的特殊项(老房加项: windows 窗套拆除、燃气改造;南方:外墙保温……)。清单是起点,你的上一份结算是终点。

**Q:量差为什么要单独一类?它不就是 forced 吗?**
不是。forced 是**报价完整性**的病(该写没写),drift 是**开口结构**的病(写了但按实结算)。药的差别是致命的:forced 要「把漏项写进合同」,drift 要「给开口加封顶」——混在 forced 里,你会拿着正确的诊断吃错的药。

**Q:工具说 ✗ 不签,可我已经签了。**
那 ✗ 是给下一次的。本件没有「追回」功能,只有「看清」功能——看清的复利在第二份合同。

## 10. 术语表

| 术语 | 释义 |
|---|---|
| 低价签(lowball) | 用低于成本的报价中标,靠增项收回利润的签约策略 |
| 增项 | 合同外、结算时发生的费用,本件必须四选一归类 |
| 开口 / 闭口 | 按实结算 / 总价包干。开口项是量差风险的载体 |
| 诱饵价 | 单价 < 常识下沿 × 0.85 |
| 宰客价 | 增项单价 > 常识上沿 × 1.5 |
| 低价幻觉指数 | 漏项中位预估 ÷ 合同小计——增项的下界 |
| 真实底价 | 合同 + 漏项中位预估——什么都不改也要付的钱 |
| forced | 被动必做:不签工程就停,且报价单该有而没有 |
| padded | 行业增利:问三家公司,两家含,他单收 |
