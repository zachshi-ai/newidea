# 低价签 · Lowball

> 增项不是在结算时发生的,是签合同那一刻就注定的:低价签单是获客手段,增项是盈利模式——他不是便宜,是分期收款。比价比的是合同价,决定真实成本的是**报价单的完整性**:报价单里没有的东西,不是不花钱,是还没开始收。
> The lowball quote wins the bid on purpose: the missing line items are the business model. This ledger audits what the cheap quote forgot, prices the amnesia, and stands between your hand and the pen.

---

## 一句话

第一次装修的人拿到一份「全包 9.3 万」的报价单,比价时只看到一个数——合同价;而决定他最后付多少钱的,是这份报价单**漏写了什么**。装修行业的低价签单是理性的:先按低于市场的单价和压低的预估量把合同签进来,再靠防水、找平、垃圾清运、管理费、税点这些「不做不行」的增项把利润收回来——那时你已停工等他,半途换人等于双倍付钱,议价能力归零;每一笔增项你都亲笔签了字,「都是我同意的」。本件把装修合同抄成两份可手编的账本(quote.tsv 报价单 + addons.tsv 增项流水),对便宜开庭:**漏项审计**对照行业常识清单(垃圾清运/成品保护/管理费/税票/开荒保洁五项无条件必含,防水/找平/闭水/搬运按需求触发)逐条点名,缺失项按常识区间预估「回来收钱的价格」,算出**低价幻觉指数**(样例合同 ¥93,002 + 漏项中位 ¥26,322 = 真实底价 ¥119,324,指数 28.3%——它统计的是「什么都没改、什么都没爆」也要付的钱,是增项的下界不是预测);**诱饵×开口识别**盯死标准杀局——水电改造单价 ¥38/m 低于常识下沿(45–90)0.84x 且按实结算,开工后预估 280m 变 final 612m(2.19x),「单价没宰你,量爆炸了」,那行 ¥10,640 结算时变成 ¥23,256;**宰客单价对账**抓「同一个工地、两套价目表」——增项时墙面找平收 ¥95/㎡(常识 25–60,上沿 1.58x)、材料搬运收 ¥2,400(常识 0–1,000,2.40x);**四分类瀑布**把每一笔你签过字的增项归位(签字升级 19.7% / 被动必做 27.0% / 开口量差 24.6% / 行业增利 28.8%),四种病四种药:升级是预算管理、被动是报价完整性、量差是开口风险、增利是谈判依据——不分类的增项总额没有意义;示例账本结算 ¥144,238,增项率 55.1%,而同一间房被你嫌「贵 3.7 万」的另一份报价单,judge 裁决全绿——**那份贵的才是便宜的:9.3 万的底价是 11.9 万,13 万的底价还是 13 万**。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 一生装一两次房的业主(中国每年 1,300 万+ 套交付/翻新,绝大多数业主是第一次也是唯一一次);在两份报价单之间比价的人;开工后被工长的增项单追着签字的人;结算时看着「为什么超了 5 万」发懵的人。 |
| **场景** | 两份报价单摆在桌上,一份 9.3 万一份 13 万,所有人都说「选便宜的」;开工第三周工长拿着单子来:「你家墙面误差超范围,要加找平 9,120,签个字明天继续干」——对照物、比价、退路都没有,签字的手比脑子快;结算时增项混成一团,吵都没法吵。 |
| **问题** | ① **比价的变量是错的**:所有人比「合同价」,但合同价是获客广告,真实成本 = 合同 + 漏项回收 + 开口爆量 + 你自己的升级——便宜的报价单和诚实的报价单是两个东西;② **报价单里没有的东西不是不花钱,是还没开始收**:防水、闭水、找平、垃圾清运、成品保护、管理费、税票,行业默认该含的「忘了」写,开工后每一项都回来收钱,而那时你停工等他、没有议价能力;③ **诱饵×开口是标准杀局**:单价压到常识下沿以下(38 vs 45–90)让你觉得「水电好便宜」,按实结算把总量留白(预估 280m → final 612m)——诱饵的本体是预估数,不是单价;④ **增项审批发生在信息真空里**:每一笔你都签了字,但签字那一刻没有对照物、没有常识区间、没有分类——「都是我同意的」和「我被结构性地宰了」可以同时为真;⑤ **结算的愤怒没有结构**:超支 5 万是一个数,不是五种病——不分类的增项总额没有意义。 |
| **价值与意义** | ① **judge 把审计搬回签字之前**:漏项清单 + 幻觉指数 + 诱饵×开口三查,✗ 不签的裁决附谈判脚本(「先让漏项进报价单、开口项写上单价×封顶量,再回来谈价格」)——这是本件的灵魂命令;② **低价幻觉指数**:把「他为什么这么便宜」变成一个数——合同价 ÷ 真实底价,缺失的每一行按常识中位预估回收价;③ **四分类恒等式**:结算 ≡ 合同 + 升级 + 被动 + 量差 + 增利,每笔增项签字当天就归类(当场分类是唯一的皮肤游戏),结算时愤怒有结构、谈判有靶子;④ **双价目表对账**:增项单价 vs 常识区间,低于下沿 0.85x 是诱饵价、高于上沿 1.5x 是宰客价——签单时的市场价,增项时的垄断价;⑤ **sign 签字门禁**:工长递来单子,先过闸(区间定位/合同对照/分类口诀/推荐记账行),闸门替脑子争取三分钟;⑥ 零依赖 + 纯本地 + 不连任何平台不猜本地行情,签不签、忍不忍、换不换,人的决定。 |

## 核心思想:把「他为什么这么便宜」变成一本可以审计的账

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **四分类瀑布** | upgrade 签字升级(你不提他就不会做)/ forced 被动必做(你不签工程就停)/ drift 开口量差(单价没宰你,量爆炸了)/ padded 行业增利(问三家公司两家含) | 「这 5 万超支是哪种病?」——四种病四种药,不分类的增项总额没有意义 |
| **漏项审计** | 常识清单 14 项:universal 无条件必含(垃圾清运/成品保护/管理费/税票/开荒保洁/搬运上楼)+ conditional 需求触发(拆除/砌墙/水电/防水/闭水/找平/贴砖/乳胶漆),关键词匹配报价单 | 「报价单里该有而没有的是什么?」——缺失即预测:开工后回来收钱的清单 |
| **低价幻觉指数** | 漏项中位预估 ÷ 合同小计;红线 15% | 「这份便宜有多少是还没写的字换来的?」——它统计的是「什么都不改也要付」的钱,是增项的**下界**不是预测 |
| **诱饵×开口** | 单价 < 常识下沿×0.85 且 est=open → 杀局标配,红线 | 「单价便宜为什么反而危险?」——低价单价 + 量不可控 = 签单后每一米都是他的定价权 |
| **开口爆量** | drift 量差挂靠开口条目,final÷est > 1.5 红线 | 「按实结算到底多能爆?」——预估是广告,结算是真相 |
| **宰客单价** | 增项单价 > 常识上沿×1.5 → 第二张价目表,红线 | 「为什么增项的单价比合同贵这么多?」——进门之前你是客户,进门之后你是砧板 |
| **签字门禁** | sign 单笔过闸:区间定位 + 合同对照 + 分类口诀 + 推荐记账行 | 「这笔字该不该签?」——三分钟内给你对照物,签,是你知情的选择 |
| **裁决** | judge:universal 漏项 ≥ 2 ∨ 幻觉指数 > 15% ∨ 诱饵×开口 → ✗ 不签(exit 4) | 「这份单子现在能签吗?」——不能时附谈判脚本,能时告诉你「这份贵是诚实的贵」 |

三条设计立场刻在实现里:**常识区间是先验不是行情**——典型城市常识值只为冷启动垫底,`--baselines` 一份 TSV 整表覆盖,本地价格永远赢(测试钉死:把水电区间改到 140–180,B 单的 55 也翻成诱饵,判罚跟着行情走);**分类是自报的**——工具给口诀不给判决,把「问三家公司两家含」的验证成本留给你,因为 padded 与 forced 的边界在你所在的城市,不在代码里;**缺口是下界**——幻觉指数只统计「什么都没改、什么都没爆」也要付的钱,upgrade 与爆量永远在指数之外,所以 28.3% 的指数配上 55.1% 的真实增项率不是矛盾,是分层。

**与近邻的边界**:redemption(赎契)审房贷的还钱端——金融合同的摊销结构,本件审装修合同的执行结构——工程合同的增项解剖;move-line(挪窝线)裁决租与搬的居住决策,本件裁决签与不签的工程合同;repair-ledger(续命账)是拥有期的维修经济学(修还是换),本件是工程期的增项经济学(这份便宜是不是便宜);dusty-subs 吃灰订阅审「按月扣钱的惯性」,本件审「一次性大额合同里的留白」;cart-line(凑单线)解剖电商结算页的总价幻觉,本件解剖工程报价单的总价幻觉——都是「平台/公司省略的每一元就是差额」,但凑单的敌人是你自己的手,低价签的敌人是对方的笔;felt-inflation 量篮子价格的长期漂移,本件量一张合同从签约价到结算价的短期蒸发。

## 安装(零依赖)

只需 Python 3.8+,无需 `pip install` 任何东西。

## 账本格式

两份可手编的 TSV(金额 = qty × unit_price,行级自洽,破坏即 exit 2):

`quote.tsv`(报价单,一行一条,est 标记开口项):

```
item	qty	unit	unit_price	amount	est	note
水电改造(按实结算)	280	m	38	10640	open	按实结算 · 预估 280m
墙面乳胶漆(两底两面)	240	㎡	48	11520	fixed	—
```

`addons.tsv`(增项流水,一行一笔——每一行都是你签过字的单子,kind 四选一,**当场分类**):

```
item	kind	qty	unit	unit_price	amount	note
卫生间防水(两遍)	forced	14	㎡	85	1190	开工后第 3 天「你家没报防水」
水电改造量差	drift	332	m	38	12616	612m − 预估 280m · 单价同合同
管理费(结算补收)	padded	1	项	7440	7440	合同额 8% · 报价单没写
```

- kind 分类口诀:**upgrade** 你不提他就不会做;**forced** 你不签工程就停;**padded** 问三家公司两家含;**drift** 报价单里的开口项长量(条目名须与开口条目同类挂靠,qty 记**超出的量**);
- 常识基线内置 14 项(universal 6 + conditional 8),`--baselines my.tsv` 整表覆盖(key/aliases/low/high/unit/cond/typical 七列)。

## 命令速查

```bash dd:ignore
python3 lowball.py judge  examples/quote.tsv            # 签字前裁决报价单(✗不签 → exit 4)——灵魂命令
python3 lowball.py gaps   examples/quote.tsv            # 漏项审计 + 低价幻觉指数
python3 lowball.py audit  examples/quote.tsv examples/addons.tsv   # 增项总账:四分类瀑布/开口爆量/宰客单价
python3 lowball.py prices examples/quote.tsv examples/addons.tsv   # 单价对账:诱饵价与宰客价
python3 lowball.py sign   examples/quote.tsv --item 墙面找平 --qty 96 --price 95 --unit 元/㎡   # 签字门禁
python3 lowball.py validate examples/quote.tsv examples/addons.tsv # 恒等式体检
```

通用参数:`--baselines` 覆盖常识基线、`--cap` 增项率红线(默认 30%)、`--gate-universal` 漏项门(默认 2)。

## 一个真实样例

小陈,89㎡ 老房翻新。A 公司「全包 ¥93,002 拎包入住」签了合同,B 公司同户型报 ¥130,012 被全家嫌贵pass。十二张签过字的增项单之后,见 [examples/quote.tsv](examples/quote.tsv) 与 [examples/addons.tsv](examples/addons.tsv)。签字前如果有人跑一次 `judge`(exit 4):

```
报价单裁决 · 21 条 · 合同 ¥93,002(签字之前跑一次,这是本件的灵魂命令)

  漏项:universal 6 项 / conditional 3 项 → 漏项中位预估 ¥26,322
  诱饵×开口杀局:
    ✗ 水电改造(按实结算):单价 ¥38/m = 常识下沿 0.84x 且 est=open——低价单价 + 量不可控,签单后每一米都是他的定价权
  低价幻觉指数 28.3%(红线 15%) → 真实底价 ¥119,324(合同 + 漏项中位)
  裁决 ✗ 不签——universal 漏项 6 项;幻觉指数 28.3%;诱饵×开口杀局。这份便宜是用还没写的字换的
```

结算后 `audit`(exit 4):

```
增项总账 · 合同 ¥93,002(21 条)· 账面增项 ¥51,236(12 笔)· 推定结算 ¥144,238
增项率 +55.1%(红线 30% / 黄线 24%)✗ 超红线

── 四分类瀑布(每一笔你都签过字,但性质完全不同)────────────
  签字升级     ¥10,070   19.7%  你主动要的——预算内选择,无对错(3 笔)
  被动必做     ¥13,810   27.0%  不做不行——报价单该有而没有的,现在用垄断价收(4 笔)
  开口量差     ¥12,616   24.6%  单价没宰你,量爆炸了——开口合同把总量留白(1 笔)
  行业增利     ¥14,740   28.8%  同行默认含,他单收——谈判与换人的依据(4 笔)

── 开口爆量 ──
  水电改造(按实结算):预估 280m → final 612m = 2.19x(红线 1.5x)✗
    —— ¥38/m 看着便宜,按 final 结算 = ¥23,256,比合同里那行 ¥10,640 贵 119%
── 宰客单价 ──
  墙面找平 ¥95/㎡ vs 25–60 /㎡ → 1.58x ✗
  材料搬运上楼 ¥2,400/屋 vs 0–1000 /屋 → 2.40x ✗
```

而那份被嫌贵的 B 单(`judge examples/quote-good.tsv`,exit 0):漏项 0、幻觉 0.0%、无杀局——「这份单子的贵,是诚实的贵」。**¥93,002 的底价是 ¥119,324、结算 ¥144,238;¥130,012 的底价还是 ¥130,012——比价比错了变量,省下的 3.7 万是用 5.1 万增项和三个月停工吵架买的**。

## 验收标准(全部转成自动化测试)

1. **解析层**:21+12+30 行示例账本零告警载入;表头缺列 / 列数不足 / 空条目名 / 条目重复 / 非数字 / 负数单价 / `amount ≠ qty × unit_price` / `est` 与 `kind` 非法枚举 / 空账本 / 文件不存在,一律 exit 2;
2. **四分类恒等式**:Σ四类 ≡ 增项总额(残差 < 1e-6);结算 ≡ 合同 + Σ四类;示例账本精确等于 upgrade ¥10,070 / forced ¥13,810 / drift ¥12,616 / padded ¥14,740;
3. **增项率红线**:51,236 ÷ 93,002 = 55.1% > 30% → audit exit 4;`--cap 0.6` 时率线让位但宰客单价独立顶住 exit 4;全 upgrade 25% 构造 → 黄线 exit 1;
4. **开口爆量**:final = est + 量差(612m),ratio 2.19x > 1.5 红线;量差挂靠不到开口条目 → exit 2;同 key 桥接(「水电改造量差」↔「水电改造(按实结算)」);
5. **漏项审计**:示例报价单 universal 缺 6 项、conditional 缺 3 项;幻觉指数 = Σ中位预估 ÷ 合同小计 = 28.3%,真实底价 ¥119,324;B 单 30 条全覆盖指数 0.0%;
6. **漏项门禁**:universal 缺 ≥ 2 或幻觉 > 15% → judge/gaps exit 4;`--gate-universal` 可调;报价单 < 5 条 → exit 3 拒判;
7. **诱饵×开口**:单价 38 < 45×0.85 且 open → 红线;`--baselines` 把区间改到 140–180 后,B 单 55 也翻诱饵——先验可覆盖,判罚跟行情;
8. **宰客单价**:找平 95(1.58x 上沿)、搬运 2,400(2.40x)→ prices exit 4;pct 行按合同额比例审计(8.0% 区间上半、3.5% 区间内);无基线条目标注「自报,只登记不审计」;
9. **签字门禁**:宰客样例 exit 4 附上沿倍数;区间内样例 exit 0;低于下沿 exit 1 并提示开口风险;推荐记账行是可直粘 addons.tsv 的七列制表符行;
10. **THIN 拒答**:增项流水 < 3 笔 → audit/prices exit 3;报价单 < 5 条 → judge/gaps exit 3;
11. **逐字节复现**:示例输出不依赖当前时间,`examples/build_examples.py --check` 对 9 份快照做字节级校验,CI 中运行。

## 诚实条款

四分类是签字人当场自报的——把一张「杂项 ¥8,000」记成 forced 还是 padded,是你对自己诚实的瞬间,工具只给口诀不给判决;常识区间是先验不是行情,你的城市、你的楼层、你的年代都在改写它(`--baselines`);它不读 PDF、不联网比价、不认识任何装修公司,账本里只有你抄进去的行;幻觉指数是下界,真实增项永远在指数之上运行;它不回答「装修该花多少钱」,只回答「这份便宜是怎么炼成的」——签不签、忍不忍、换不换,人的决定。
