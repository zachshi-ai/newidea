# 躺亏 · Dormant Loss

> 定期存款的利率是有期限的:合同利率只在存入日到到期日之间兑现。到期日之后,**钱一分不少,价格却由银行的默认动作接手**——自动转存进的是转存日的挂牌价,什么都不做则是活期。App 只推送「您的存单已到期」,从不翻译「从此这笔钱每年少拿多少」;到期后的每一天,本金纹丝不动,利息按活期蒸发——而活期利率低到损失毫无体感,**这正是它安静的原因**。有人替你记贷款,没有人替你记存款。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 手里有定期存款/大额存单的家庭——尤其是**替爸妈管存单的中年人**(父母的存单散在几家银行,一半是纸质单据,连 App 都没有);和在利率下行通道里看着老存单一张张到期的人 |
| **场景** | 三年前 3.55% 的大额存单今天到期,App 弹一条「存单已到期,本息已转存」;爸妈打电话问「银行说帮我自动转了,转的多少?」——没人答得上来;2024–2026 存款利率六连降,每一张到期单都掉进更低的档;家里利率最高的一笔老存单,反而是最容易被「急用钱」提前支取的那笔 |
| **问题** | ①**没有掉档视图**——定期存款的利率是分段的:合同价只在期限内兑现,到期后执行价(转存挂牌价或活期)从没有人替你翻译成「每年少拿多少」;②**沉默=活期没人说破**——到期不办,银行替你选最低价,而「自动转存」是银行的默认动作不是你的决定;③**提前支取税没有账**——差三个月到期的钱急取,全部利息按活期重算,痛感只在柜台那一刻;④**老合同是稀缺资产没人提醒**——利率下行时代,2%+ 的存单是家里最值钱的纸,但「提前支取按活期」的警告只印在条款里 |
| **价值** | `report` 把每笔存单翻译成「当前执行利率/掉档深度/累计躺亏」并点四盏灯(样例:六笔 95 万,躺亏合计 **¥28,689**,当前年化速率 **¥15,370/年 = 每天 ¥42.11**——工行 20 万 @3.55% 沉默 832 天躺亏 ¥15,956,**已吃掉合同利息的四分之三**);`timeline` 逐段展开利率时间线,「沉默=活期」写在每一段上;`calendar` 给未来的「私人降息日」;`decide --rate` 拿你抄来的真实报价对拍两世界(样例:48 万存三年 @1.25% vs 继续躺,差 **¥17,279**);时间机器钉回工行到期前一天,躺亏只剩 ¥585.62——**大额躺亏全是之后两年半的沉默,账本让它看得见** |

**本件不是**:不是理财产品推销员(decide 只对拍你抄来的报价,不回答「存不存」「存哪家」)、不是风险审计(存款保险与理财波动不在范围,这是利率账不是风险账)、不是银行对账单(它审计的是价格不是余额——钱一分不会少,少的是价格)。

## 二、账本形态

一个目录两份手编 TSV(`--dir`,缺省当前目录)。数据源是**抽屉里的存单和银行 App 的存单页**,抄一笔就是一行——这就是全部数据工程:

```tsv
# deposits.tsv —— 存单合同账(一行一笔)
bank	principal	rate	months	start	tag	realized	note
工行	200000	3.55	36	2021-05-10		21527.95	大额存单 到期没人管
邮储	80000	3.575	60	2020-02-29		14358.96	爸妈的纸质存单 闰日存的
```

```tsv
# renewals.tsv —— 主动事件账(可选;只记「发生了的事」,沉默=活期)
date	tag	kind	rate	term	note
2023-11-20	建行一	renew	1.35	12	到期自动转存 转存日挂牌
2025-06-15	中行一	renew	0.95	6	儿子帮办 半年期
```

- **renew 留白即沉默**:renewals 只记转存(renew,带转存日利率与期限)与取走(withdraw);两段之间的空白自动按活期补齐——**你对存单的每一次沉默,银行都按最低价翻译,账本把这句翻译写出来**
- **tag 区分多笔**:同一银行多笔存单时用 tag,renewals 靠它引用;留空默认 = bank 名
- **realized 是验钞列**:抄 App 的「已到账利息合计」,validate 与时间线重放对拍,抄错当场 GHOST
- **提前支取 = withdraw 落在到期日之前**:通识口径全程按活期重算(不建模靠档),提前支取税躺账本看见

## 三、五命令

```
python3 dormant_loss.py report                  # 掉档总账:每笔执行利率/掉档/躺亏 + 四灯
python3 dormant_loss.py timeline                # 利率时间线:逐段展开 + 每段账
python3 dormant_loss.py calendar --months 18    # 到期日历:私人降息日 + 正在发生的降息
python3 dormant_loss.py decide --rate 1.25      # 转存对拍:锁定 vs 继续躺,两世界利息差
python3 dormant_loss.py validate                # 恒等式与账本体检
```

### 状态桶(每笔存单,as-of 时点)

`在保`(合同期内)→ `躺活期`(到期后沉默)→ `转存存续`(转存段未到期)→ `已取走`(结案,历史留账)→ `提前支取`(结案,且吃了税)

### 灯

| 灯 | 级别 | 语义 |
|---|---|---|
| **SLEEPING-DEMAND** | 🔴 exit 4 | 存在躺活期的钱,且 躺活期本金 > 线(--red-amount,缺省 1 万)**或**当前年化躺亏 > 线(--red-yearly,缺省 1 千),双闸**恰线不亮**——宁少报不冤枉 |
| **RESET-DOWN** | 🟡 | 转存/续存价比原合同掉超 --reset-line(缺省 0.25pp,恰线不亮)——「转存了」不等于「安全了」,转存价是银行的默认价不是你的价 |
| **EARLY-TAX** | 🟡 | 提前支取过的存单——差 N 天到期的钱按活期拿完了,提前支取税躺账本看见 |
| **PRIME-HOLD** | 🔵 | 合同期内且利率 > --prime-line(缺省 2.0%,恰线不亮)——利率下行时代的老合同是稀缺资产,提前支取按活期,**锁住它** |

### 退出码语义

`0` 绿灯/黄灯/蓝灯 · `2` 账坏(缺列/坏日期/负本金/非整数月/tag 重复/悬空引用/坏 kind/renew 缺利率期限/withdraw 带价/同日二义/事件早于存入/存续期转存/取走后再动/GHOST) · `3` 空账或拒答(decide 缺 --rate、无可对拍对象) · `4` SLEEPING-DEMAND

## 四、样例:王家的两代存单

六笔 95 万,两代人的利率史(as-of 2026-08-20,账本最大日期,零墙钟):

- **工行 20 万 @3.55% 大额存单**,2024-05-10 到期,没人管——沉默 832 天,躺亏 **¥15,956.16**,吃掉了合同利息(¥21,300)的四分之三 🔴
- **建行 10 万 @2.60%**,到期自动转存 1.35%——「转存了」不等于「安全了」,再到期又沉默 638 天,合计躺亏 ¥5,710.68 🟡
- **中行 15 万 @2.05%**,儿子帮转了半年 0.95%,又到期躺平——躺亏 ¥2,865.62 🟡
- **邮储 8 万 @3.575%,爸妈的纸质存单**,闰日存入 60 月 → 2025-02-28 到期(月末钳制),躺 538 天——躺亏 ¥4,156.60
- **农行 30 万 @2.15% 在保**——PRIME-HOLD 🔵:老合同是稀缺资产,提前支取按活期,锁住它
- 当前年化速率 **¥15,370/年 = 每天 ¥42.11**;`decide --rate 1.25 --term 36 --liquid 50000`:48 万锁定 vs 继续躺,三年差 **¥17,279.34**
- **时间机器 `--as-of 2024-05-09`**(工行到期前一天):躺亏只剩建行转存降档的 ¥585.62——**大额躺亏全是之后两年半的沉默**

## 六、与近邻的边界

- **redemption**:资产负债表的两侧——那边审**你欠银行的债**(摊销结构与预付决策),本件审**银行欠你的钱**(存款端的利率掉档);它的「闲钱开庭」拿存款利率当参数,本件审计参数背后的那本账
- **shadow-base**:那边管**强制缴费**的社保有没有被缩水(福利账),本件管**自愿储蓄**的利息有没有被降档(储蓄账)
- **nav-illusion**:那边算投资的行为差(XIRR−TWR,收益不确定),本件算无风险利率的**确定性掉档**——一个审计你的手,一个审计银行的默认
- **expiry-cliff**:凭证到期是失效(钱/权没了),存单到期钱一分不少——**掉的是价格,不是存在**;悬崖管「还有没有」,本件管「还值多少」
- **dusty-subs**:敌人都是「默认状态的静默」,方向相反——订阅是钱流出去换服务(你忘了用它),躺亏是利息没流进来(你忘了查它)
- **slow-leak**:那边审三表的**用量异常**(突变/蠕升/底座,物理量),本件审利率的**档位掉落**(价格结构)——一个问这个月为什么多,一个问这笔钱为什么少
- **stealth-interest**:同是利率翻译,方向相反——那边翻译**你付给平台**的手续费真实年化,本件翻译**银行付给你**的利率什么时候变了
- **float-loan**:那边是钱被别人占用(垫款在途等回款),本件是钱在自己手里睡觉——都是「钱在错误的利率上」
- **handoff**:久悬户是钱找不到了(**位置**问题),本件是钱在账上睡错价格(**价格**问题)
- **past-prime**:电器判废是资产倒计时,存单到期是**利率**倒计时——到期那天东西都还在,但「好时候」结束了

## 七、诚实条款

1. **活期利率与灯线是通识先验**:demand 0.05%、reset 0.25pp、prime 2.0%、红线 1 万/1 千全部 `--` 翻案,**银行挂牌永远赢**
2. **两种计息基如实分开**:定期段利息按月基(银行整期算法:本金×年利率×月数/12),活期段按天基(÷365),躺亏统一天基;不建模按季结息滚存、靠档计息、部分提前支取——realized 容差(max(1分, 0.5%))兜底,宁可容差,不装精确
3. **不预测利率**:账本只陈述已发生的掉档;decide 只对拍你抄来的真实报价,不给 `--rate` 就不判——账本不发明市场行情
4. **不构成投资建议**:红灯指向银行柜台;钱放哪、存多久、要不要留活期,是人的决定;理财/基金/保险不在账本范围,存款保险额度不建模——这是利率账,不是风险账
5. **沉默=活期是通识默认**(到期不取转活期);约定转存的合同另有约定,以存单白纸黑字为准——账本记发生了的事,不是合同的全部细节
6. **抄错当场抓**:realized 到账利息与时间线重放差超容差 → GHOST exit 2;存单是白纸黑字,你抄的账自己会证明你抄错了
7. **存款是家庭最敏感的数字之一**:不连任何接口、不上传任何字节;抄一笔存单的一行是全部数据工程,账本只存在本地
8. **零墙钟**:as-of 缺省 = 账本最大日期,`--as-of` 钉死后同一本账任何机器任何一天逐字节一致,报告只打印账本目录名

## 八、快速开始

```bash
cd dormant-loss
python3 dormant_loss.py report --dir examples                 # 王家的掉档总账(红灯 exit 4 是故事)
python3 dormant_loss.py timeline --dir examples               # 利率时间线:沉默=活期写在每一段上
python3 dormant_loss.py calendar --dir examples --months 18   # 未来的私人降息日
python3 dormant_loss.py decide --dir examples \
        --rate 1.25 --term 36 --liquid 50000                  # 锁定 vs 继续躺,差多少
python3 dormant_loss.py report --dir examples --as-of 2024-05-09   # 时间机器:躺亏是后来的沉默
python3 dormant_loss.py validate --dir examples               # 恒等式与验钞
python3 -m unittest discover -s tests                         # 51 项验收测试
```
