# 挪窝线 · Move Line

> 涨租 12% 的愤怒是真的，但该不该搬是一道算术题：搬家税月摊多少、便宜的房子用多少通勤时间付账、替代房源要便宜过哪条线——忍与挪之间，第一次有一条算出来的线。
> A rent increase feels like an insult; moving house is a toll booth. Move Line computes the break-even increase where enduring stops being rational.

---

## 一句话

续租季的涨租通知只展示一个数字——涨幅，而涨幅激起的唯一反应是愤怒；可「涨多少」从来不是决策变量，真正的题目是**搬家的总成本和留下的总成本哪边更低**。搬家的一次性成本（中介费、搬家公司、拆装、保洁、宽带、请假误工）散落且从没人列全，「搬家麻烦」是一团感觉而不是一个数字；便宜的房子往往更远，省下的租金被通勤时间吃掉多少没人算过；搬家费的回本期和你打算再住的年数从不被对照——「省 305/月，回本 17 个月，可你只打算住 X 年」。本件把现居与候选房源抄成可手编的账本（homes.tsv：住处/月租/通勤/角色；move.tsv：搬家一次性成本），算出**年净成本 = 年房租 + 年通勤税（单程分钟 ×2 × 年通勤天数 × 时薪 ÷ 60）+ 年搬家税（一次性成本 ÷ 预计再住年数）**，并对涨租通知开庭：**忍价线**（实线）= 使「搬到最优候选」与「留在现居」年净成本相等的涨幅——没有候选时退化为**盲搬线** = 搬家税月摊 ÷ 现租。示例账本实测（现租 4,500、房东报价 +12% 到 5,040、搬家税 5,220、两个候选）：**盲搬线 +3.2%**（替代房源月租上限 4,355）；**实线 +5.2%**（由同通勤的「同小区两期B」钉出，无差异点 4,735/月）——+12% 越线 6.8 个点，裁决 ✗ 挪（exit 4）；但把「预计再住」从 3 年改成 1 年，实线升到 +11.7%，同一份 +12% 变成 ◐ 掷币——**先回答「住多久」，再回答「忍不忍」**；陷阱灯同时点名「滨江壹号A」：月租最低（名义省 700/月）、年净成本最贵，省下的租金要用 11,500/年 的通勤税赎回——**你不是在省钱，是在花时间买折扣**。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 收到续租通知、限期答复的租房客（中国城镇租房人口 2 亿+，每年一次）；在「涨 8% 忍了」和「涨 12% 必搬」之间反复横跳的人；被中介推着看「便宜但更远」房源、险些用通勤换租金的人。 |
| **场景** | 房东发来「明年 +12%，半个月内答复」的晚上；中介朋友圈全是「急租好房」、朋友劝搬家人劝忍的那两周；看房回来发现「便宜 700 的房子通勤翻倍」、算不清值不值的时候；和房东谈判前，想知道「涨多少以内是我不搬的底线」的时候。 |
| **问题** | ① **涨幅是唯一被展示的数字**：+12% 直接引爆情绪，而搬家的真实代价（一次性成本 + 通勤改道 + 空窗风险）散落且从未被列全——直觉只比较「新租 vs 旧租」两个数，漏掉整个搬家侧；② **搬家税隐形**：中介费半月租、搬家公司、拆装、保洁、宽带、误工，加起来五千多，从没有一张清单，更没人把它摊到月——「麻烦」无法和「每月多 540」放在同一张桌上比较；③ **通勤时间税没人折算**：便宜的房子用通勤时间付账，但「每天多 50 分钟」折成钱是 11,500/年——这笔账在每一次「搬去远一点」的决定里缺席；④ **回本期 vs 居住期从不对照**：搬家费回本要 17 个月，你只签一年——回本那天又该搬家了；⑤ **没有线，每次续租都是重新投票**：去年 +5% 忍了今年 +12% 爆发，其实你的忍价线根本没变过——变的只有愤怒。 |
| **价值与意义** | ① **忍价线进场**：实线 = 最优候选的无差异涨幅，盲搬线 = 搬家税月摊 ÷ 现租——「房东最多涨 X% 你都不该挪」第一次是一个算出来的数，不是一声怒吼；② **搬家税显形**：一次性成本逐项列账、按预计居住年数直线摊销成「月供」（5,220 ÷ 3 年 = 145/月 = 现租的 3.2%），糊涂账护栏扫出账上没有的常见漏项（起租重叠/宠物安置/修复扣押金）——每漏一项，线就虚低一分；③ **通勤时间税**：时薪 × 分钟 × 天数折算进年净成本，便宜但远的房源在陷阱灯下现形；④ **裁决带**：涨幅越线 2 个点以上 → ✗ 挪（exit 4，可进脚本）；±2 个点内 → ◐ 掷币（钱分不出胜负，用非钱因素收尾）；线内 → ✓ 忍（忍是算术不是软弱）；⑤ **敏感性矩阵**：再住年数 × 通勤时薪的忍价线网格——同一份 +12%，在「住 1 年 × 时薪 60」是掷币、在「住 3 年 × 时薪 60」是挪、在「住 3 年 × 时薪 30」现居按 0% 涨都已是净最贵——答案不取决于愤怒，取决于你打算住多久和时间值多少钱；⑥ 零依赖 + 纯本地 + 不抓房源不预测市场，挪不挪仍是人的决定。 |

## 核心思想：把「涨了百分之几」换成两本年净成本

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **年净成本** | 月租×12 + 年通勤税（单程分钟×2×年通勤天数×时薪÷60）+ 年搬家税（一次性÷预计居住年数，仅搬家方） | 「住在那边的真实年价」——房租只是其中一项 |
| **搬家税** | 一次性成本按预计再住年数直线摊销成月供 | 「挪一次窝的月供是多少？」——搬得越勤税率越高，搬家费是租客的印花税 |
| **实线（忍价线）** | 最优候选的无差异涨幅：解「搬到它 = 按新租金留下」 | 「房东涨过几个点，搬就比忍便宜？」 |
| **盲搬线** | 搬家税月摊 ÷ 现租；替代房源的月租上限 = 现租 − 搬家税月摊 | 「还没有候选时，线在哪？」——只量搬家税本身，不量市场 |
| **裁决带** | 涨幅 − 线：< −2pp ✓ 忍；±2pp ◐ 掷币；> +2pp ✗ 挪（exit 4） | 「这份通知过不过线？」——误差带承认时薪与搬家税都是估计 |
| **陷阱灯** | 候选中月租最低且年净成本最贵者 | 「省下的租金被什么赎走了？」——通勤税 |
| **回本灯** | 回本月数 = 搬家税 ÷ 每月净省；超过预计居住期即亮灯 | 「这笔搬家费住得回来吗？」 |
| **糊涂账护栏** | 十类常见搬家成本关键词扫描，缺类挂横幅 | 「账本漏了什么？」——漏项让线虚低，裁决偏向不明智的忍 |

三条设计立场刻在实现里：**搬家税为 ¥0 就拒绝裁决**（exit 3——「搬家是免费的？」漏记的搬家税会把线虚压到骗你搬家，validate 例外，它的职责正是诊断空账）；**盲搬模式诚实披露**（无候选时 judge/cap 自动退化为盲搬线并声明「只量搬家税本身，不量市场」，而不是拒绝回答）；**实线为负要说话**（候选按 0% 涨都已净更便宜时，谈判目标从「忍不忍」变成「少亏多少」）。

**与近邻的边界**：repair-ledger（续命账）裁决「修还是换」，比的是边际每服务年成本——那是**拥有物的维修经济学**，本件裁决「忍还是挪」，比的是两份租约的年净成本加一次性摊销——**租赁的搬迁经济学**，二者共享「转换有价」的骨架，但领域、账本、门槛互不相通。make-it（来得及）量化「这条通勤路线多久、几点出门」——本件只把通勤分钟当作成本输入折成钱，不关心它的分布；life-tag 计算你的真实时薪——本件的时薪是一个自报参数（默认 60、每份报告披露），不生产时薪；expiry-cliff 管租约到期日的提前量——本件管到期前那笔账怎么算；felt-inflation 把房租装进篮子算指数——本件不开指数，只做单笔决策。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 账本格式

两份可手编的 TSV：

`homes.tsv`（住处账本，role 必须恰好一个 current）：

```
name	rent	commute	role	note
梧桐里	4500	25	current	住了三年的两居
同小区两期B	4590	25	candidate	同通勤
滨江壹号A	3800	50	candidate	便宜但远
```

`move.tsv`（搬家一次性成本账本，押金可退不算，起租重叠按多付的日租金记）：

```
item	amount	note
中介费	2250	半月租
搬家公司	1200
请假误工	420	半天调休折价
```

- `rent` 月租（元，> 0）；`commute` 单程通勤分钟（≥ 0，支持 22.5）；名字重复、现居缺失或出现两个，一律 exit 2；
- 成本项名自由取，糊涂账护栏按关键词扫十类：中介费/搬家运输/家具家电拆装/宽带迁移/换锁/开荒保洁/误工请假/起租重叠/宠物安置/修复与押金扣损。

## 命令速查

```bash dd:ignore
python3 move_line.py cap homes.tsv move.tsv                        # 盲搬线：替代房源租金上限（无候选也可用）
python3 move_line.py judge homes.tsv move.tsv --offer 5040         # 裁决涨租通知（✗挪 → exit 4）
python3 move_line.py judge homes.tsv move.tsv --pct 8 --years 1    # 按涨幅、按一年口径
python3 move_line.py compare homes.tsv move.tsv --offer 5040       # 候选对账单：陷阱灯/回本灯
python3 move_line.py toll homes.tsv move.tsv                       # 搬家税单 + 糊涂账护栏
python3 move_line.py sensitivity homes.tsv move.tsv --offer 5040   # 年数×时薪的忍价线矩阵
python3 move_line.py validate homes.tsv move.tsv                   # 账本体检
```

通用参数：`--wage` 通勤时薪（默认 60 元/时）、`--days` 年通勤天数（默认 230）、`--years` 预计再住年数（默认 3）。

## 一个真实样例

阿澄在梧桐里住了三年，月租 4,500、通勤单程 25 分钟。2026-08-30 房东通知续租 +12%（5,040），半个月内答复；中介推来两个候选——同小区两期B（4,590，同通勤，「房东急租」）和滨江壹号A（3,800，通勤翻倍，「名义便宜 700」）。她把一切抄进账本，见 [examples/homes.tsv](examples/homes.tsv) 与 [examples/move.tsv](examples/move.tsv)。搬家税单（`toll`）：6 项共 5,220，糊涂账护栏扫出 3 类没记的常见成本——起租重叠/双租 · 宠物安置 · 修复与押金扣损。盲搬线（`cap`）：**+3.2%**，替代房源月租上限 4,355。对账单（`compare --offer 5040`）：

```
搬家对账单 · 基准：现居按房东报价 ¥5,040/月 · 通勤时薪 ¥60/时 · 年通勤 230 天 · 摊销 3 年 · 裁决带 ±2.0 个点 · 搬家税 ¥5,220 → ¥1,740/年

  #  住处                月租  年净成本    月均   实线  vs 基准
  1  同小区两期B       ¥4,590   ¥68,320  ¥5,693  +5.2%  省 ¥3,660/年 · 回本 17.1 个月（预计住 3 年）
  2  滨江壹号A         ¥3,800   ¥70,340  ¥5,862  +9.0%  省 ¥1,640/年 · 回本 38.2 个月（预计住 3 年）
  —  梧桐里·现居       ¥4,500   ¥65,500  ¥5,458      —  不涨的现居 ¥65,500——搬家要赢的是涨价后的 ¥71,980

陷阱灯：滨江壹号A 月租最低、年净成本最贵——省下的租金 ¥700/月，代价是 ¥11,500/年 通勤税（多 25 分钟 ×2 × 230 天 × ¥60/时）
回本灯：滨江壹号A 回本 38.2 个月 > 预计居住 3 年——住不满一轮，搬家费收不回来
线在 +5.2%——judge 看这份 +12.0% 的裁决
```

裁决（`judge --offer 5040`，exit 4）：

```
裁决 · 现租 ¥4,500 → 报价 ¥5,040（+12.0%） · 通勤时薪 ¥60/时 · 年通勤 230 天 · 摊销 3 年 · 裁决带 ±2.0 个点 · 搬家税 ¥5,220
  实线 +5.2%（¥4,735/月，由最优候选「同小区两期B」钉出）——涨幅超过它，搬就比忍便宜
  候选实线：同小区两期B +5.2% · 滨江壹号A +9.0%
  裁决 ✗ 挪——+12.0% 越线 6.8 个点：这份通知的每一个点都在替搬家出资
  诚实条款：时薪是参数不是真理（--wage）；搬家税靠自报（漏项见 toll）；挪不挪，人的决定
```

但把口径换成「只打算再住一年」（`judge --offer 5040 --years 1`）：实线升到 +11.7%，同一份 +12% 落进误差带，裁决变成 ◐ 掷币——**+12% 的愤怒值得被算术复核，而算术的第一问是「你打算住多久」**。敏感性矩阵（`sensitivity --offer 5040`）把整件事摊开：

```
忍价线敏感性 · 行=再住年数 · 列=通勤时薪 · 每格=越线即挪的最小涨幅（裁决对照 +12.0%）
  年数＼时薪       ¥30/时     ¥60/时    ¥120/时
  1 年            +4.8% ✗   +11.7% ◐   +11.7% ◐
  2 年            -0.1% ✗    +6.8% ✗    +6.8% ✗
  3 年            -1.7% ✗    +5.2% ✗    +5.2% ✗
  5 年            -3.0% ✗    +3.9% ✗    +3.9% ✗
读法：住得越久线越低（搬家税摊薄）；时间越不值钱，远方越便宜——负线意思是现居按 0% 涨已是净最贵。
先回答「住多久」，再回答「忍不忍」：同一份 +12.0%，在不同格子里是三个不同的裁决。
```

三本账读过之后：对阿澄（时薪 60、打算再住三年）这份 +12% 值得挪，但挪的方向是同小区两期B 而不是滨江壹号A——陷阱灯挡住了「用 11,500/年 通勤税赎 700/月 折扣」的冲动；搬家税 5,220 摊 3 年 = 月供 145，回本 17.1 个月；而如果她明年就要换城市，账本会说这份涨幅其实是平手——**忍价线不裁决愤怒，只裁决数字**。

## 诚实条款

时薪、通勤天数、预计居住年数是三个参数，不是三条真理——每份报告把口径印在页眉上，改一个参数，线就移动；搬家税靠自报，糊涂账护栏只能提醒你漏了哪类，不能替你想起宠物托运花了多少。它不抓房源、不预测市场、不算押金利息、不管租约里写了什么——只把你抄进来的两个数（房租与通勤）和一份搬家税单，翻译成一条线。裁决 ✗ 挪 不是搬家指令：它说的是「这份涨幅在替搬家出资」，至于采光、邻居、猫怎么办、搬家的疲惫值多少，账本一概不知——◐ 掷币 就是给这些非钱因素留的座位。
