# 暗蛀 · Silent Rot

> 牙是身体里唯一「治疗只做加法」的器官：补过的牙不会变回原牙、根管杀死的是
> 神经本身、拔掉的就是没有——治疗阶梯（封闭 → 充填 → 根管 → 牙冠 → 拔除 →
> 种植）价格只升不降，而整段升级路几乎无痛：牙釉质没有神经，「疼了才去」的
> 直觉恰恰是「到根管了才去」。病历跟着医院走、牙跟着你走——口腔是每个人身上
> 唯一没有账本的资产。

## 一句话

把每次口腔事件抄成一本**牙位级事件流账本**（日期/牙位/事件/费用/医嘱），
重放出每颗牙在**治疗棘轮**上的位置与造价，开庭三条从没人算过的账：
**无痛进展的拖延天数**（发现 → 处理隔了多久、跨了几级、账面价差多少）、
**护理覆盖的空白天数**（你的口腔有多久没有过一次专业目光）、
**复查随访的欠账**（根管后有没有冠、种植体年检、观察复查）。

## 角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 有过一次「早知道当初就补了」时刻的上班族：牙医说半年洗一次牙、上次洗牙是五年前；体检报告写「建议口腔科就诊」、从来没去；根管完医生叮嘱「三个月后来做冠」、之后再没出现过 |
| **场景** | ① 体检又查出「浅龋建议充填」，医生说完你点头，回家就忘——上一次这样的医嘱是三年前，那颗牙今年做了根管；② 换城市/换医院，新牙医问「这颗牙以前治过吗」，你只能摇头发明历史；③ 根管完想着「不疼了不用做冠」，两年后牙劈了，拔掉种上，一颗牙吃掉一辆电动车；④ 想确认「我到底在这张嘴里花了多少钱」，没有任何系统答得上来 |
| **问题** | 1. **牙史没有账本**：口腔病历困在各医院的系统里、互不相通，牙跟着你走而病历不跟着——每颗牙的等级、上次治疗、医嘱，全靠记忆，而记忆只覆盖最近一次疼痛<br>2. **无痛进展没有刻度**：龋病从牙釉质到牙髓全程静默，「不疼 = 没事」的错觉持续数年；发现（医嘱观察）与处理之间隔着的那几年，从没有任何账本把它记成拖延<br>3. **复查全靠「想起来」**：洗牙周期、观察复查、根管后的冠修复、种植体年检——医学通识里有节奏，你的日历里没有；尤其是根管后不戴冠，牙体脆化易劈裂，劈了就是拔+种，前面所有钱白花<br>4. **拖延的价格无人出示**：价目表是公开的（补 ¥320 → 根管+冠 ¥4,800 → 种植 ¥12,000），拖延把你在哪一级、跨了几级、差价多少，摆在明处却从没人替你对过 |
| **价值** | report 出全口棘轮分布与五灯判级（WATCH-HOLD / SILENT / CARE-GAP / NO-CROWN / NEVER-SEEN）；ratchet 挂出价签牌——不是预测，是价目表；silent 开庭拖延账（天数/跨级/账面价差，拔除是终点不算价差）；due 出复查日历与随访欠账；cost 出年度分布、KEEP/FIX/REBUILD 瀑布与牙位造价排行；validate 做棘轮合法性与恒等式体检。全部本地计算、不连任何接口；as-of 缺省 = 账本最大日期，`--as-of` 是时间机器（钉回当年看当年的嘴），同一本账任何机器任何一天逐字节一致 |

## 验收标准

| # | 验收项 | 判据 |
|---|---|---|
| 1 | 恒等式 | 样例账本：KEEP ¥790 + FIX ¥280 + REBUILD ¥17,900 = 总额 **¥18,970**（残差 0）；Σ牙位造价 + 全口护理 = 总额；重建倍数 **16.73x** |
| 2 | 棘轮合法性 | 降级（crown 后 fill）、死牙复活（missing 后 fill）、双拔、种植体上任何非种植事件 → 全部 exit 2；种植分期（implant ×2）累计合法；补后再发现（继发龋）合法且重新挂起 |
| 3 | 观察挂起钉值 | 36 号自 2022-11-05 挂起 **1394 天**、48 号挂起 **1107 天**（> 365 亮 WATCH-HOLD）；47 号挂 0 天（进行时） |
| 4 | SILENT 闭环钉值 | 16 号：2022-11-05 发现浅龋 → 2025-10-02 根管，拖延 **1062 天**、跨级 +3，处理链（根管 1200 + 冠 3600）= ¥4,800，账面价差 **+4,480**；38 号：观察 688 天 → 拔除，价差 **—**（拔除是终点不是升级）；统计：中位 875 天 |
| 5 | CARE-GAP | 护理覆盖（scaling∪check∪fluoride）空白：2016-03-12 → 2020-11-15 空白 **1709 天**、2022-11-05 → 2026-03-14 空白 **1225 天**（> 730 亮灯） |
| 6 | NO-CROWN | 合成账本：根管后 221 天无冠亮灯 exit 4；恰 180 天戴冠不亮（以 crown 行为准，边界钉死） |
| 7 | 判级线全可调 | `--watch-line 2000` 时 WATCH-HOLD 熄灭其余不变；`--silent-line 2000` 时 SILENT 熄灭；拖延恰 365 天不亮、+1 天亮 |
| 8 | due 钉值 | 36 逾期 1304 天、48 逾期 1017 天、46 种植年检逾期 428 天 → exit 4；16 冠随访剩 82 天 DUE-SOON；47 恰 90 天 DUE-SOON（**含边界**）；scaling 剩 196 天 OK |
| 9 | NEVER-SEEN | 全史无 scaling/check 行 → 全口点名 exit 4（没有记录不等于没洗过，但等于没法管） |
| 10 | 薄账分层 | 闭环 < 2 条：统计判级 DECLINE exit 3，逐条账与灯**照出**（一条拖延也是算术）；超线闭环单条即亮灯 exit 4 |
| 11 | 价签覆盖 | `--price fill=480` 后 16 号价差变 +4,320——价签是先验，本地价格永远赢 |
| 12 | 别名归一 | 补牙≡fill≡充填、根管≡rct≡杀神经、拔≡extract、洗牙≡洁治、观察≡watch≡found |
| 13 | 时间机器 | `--as-of 2022-12-31` 截断回放：总额 ¥1,710（不是全史）、38 号当时已红（688 天）、16/36 刚挂起 56 天、rootcanal 尚不存在 |
| 14 | 零锚定可复现 | as-of 缺省 = 账本最大日期，与显式钉回**逐字节一致**；报告只打印 basename；源码无任何系统时钟调用 |
| 15 | 牙位语法 | FDI 恒牙 11-48、乳牙 51-85（54 乳牙充填合法）；19/49/50/86/abc 全部 exit 2；scaling 必须 tooth 空、found 必须有 tooth、check 两者皆可 |

## 快速开始

```bash
# 全口总账：棘轮分布 + 挂起观察 + 拖延闭环 + 护理空白 + 五灯判级
python3 silent-rot/silent_rot.py report silent-rot/examples/ledger.tsv

# 治疗棘轮：每颗牙的等级、造价、升级链，墙上挂价签牌
python3 silent-rot/silent_rot.py ratchet silent-rot/examples/ledger.tsv

# 无痛进展法庭：发现 → 处理的拖延天数、跨级数、账面价差
python3 silent-rot/silent_rot.py silent silent-rot/examples/ledger.tsv

# 复查日历：洗牙/检查/观察复查/冠随访/种植年检
python3 silent-rot/silent_rot.py due silent-rot/examples/ledger.tsv

# 口腔经济：年度分布、KEEP/FIX/REBUILD 瀑布、牙位造价排行、缺牙缺席账
python3 silent-rot/silent_rot.py cost silent-rot/examples/ledger.tsv

# 账本体检：棘轮合法性 + 恒等式 + 双算法重放
python3 silent-rot/silent_rot.py validate silent-rot/examples/ledger.tsv

# 时间机器：钉回 2022 年底，看当时的嘴（38 的拖延已经红着）
python3 silent-rot/silent_rot.py report silent-rot/examples/ledger.tsv --as-of 2022-12-31
```

## 账本格式

一份手编 TSV（示例由 `silent-rot/examples/build_examples.py` 生成，
`--check` 逐字节校验）。首行为表头，`#` 开头行跳过。每次口腔事件一行——
看牙回来抄小票上的三个事实：哪天、哪颗牙（或不分牙）、做了什么、多少钱、
医生说了什么。

`ledger.tsv`——口腔事件流水：`date / tooth / event / cost / note`

- **tooth**：FDI 牙位。恒牙 11-48（第一位象限：1 右上 / 2 左上 / 3 左下 /
  4 右下；第二位牙位：1 中切 → 8 智齿，如 16 = 右上第一磨牙、38 = 左下智齿），
  乳牙 51-85（象限 5-8，位 1-5）。全口事件（洗牙/涂氟）留空；口腔检查可空
  （全口）可值（单牙复查）。
- **event**：受控词表，中英别名归一——
  `found`（发现/观察：医嘱观察、疑似龋、未处理）·
  `sealant`（窝沟封闭）· `fill`（补牙/充填）· `rootcanal`（根管/杀神经）·
  `crown`（牙冠）· `extract`（拔除）· `implant`（种植/固定桥）·
  `scaling`（洗牙/洁治）· `check`（检查/体检/复查）· `fluoride`（涂氟）
- **cost**：数字，可空（默认 0，如挂号外的观察行）
- **note**：医嘱原文、材料、医院——「建议充填」这四个字是 silent 法庭的证物

## 判级与门禁

| 灯 | 条件 | 默认线 | exit |
|---|---|---|---|
| WATCH-HOLD | 观察挂起超线（发现之后人没有再出现） | 365 天 | 4 |
| SILENT | 发现 → 处理的闭环拖延超线 | 365 天 | 4 |
| CARE-GAP | 护理覆盖空白超线（两次专业目光之间） | 730 天 | 4 |
| NO-CROWN | 根管后无冠超线（牙体脆化易劈裂，劈了就是拔+种） | 180 天 | 4 |
| NEVER-SEEN | 全史无任何护理记录 | — | 4 |
| due 欠账 | 任一周期项 OVERDUE（含 DUE-TODAY） | — | 4 |
| （拒答） | silent 统计判级：闭环 < 2 条 | — | 3 |

exit 约定全仓一致：0 正常 / 2 账本坏 / 3 拒答或薄账 / 4 门禁红。
薄账只拦统计口径，不拦算术：单条拖延也是日历事实，灯照样亮、账照样出。

## 与近邻的边界

- **medicine-rollcall 药箱点名**：同是健康审计，那边管**外购药品**的双钟
  （包装效期/开封效期——药是消耗品，死了就换一盒），本件管**身体资产**的
  治疗史（牙坏了不能换，种植是替代不是复原）。
- **borderline 贴线**：同是纵向健康账，那边是化验指标的**连续量**
  （Theil-Sen 抗抖动、余量年数），本件是离散事件流的**状态机**
  （棘轮只升不降）。
- **repair-ledger 续命账**：同是「修的钱」，那边裁决**修还是换**——机器有
  「换新」的选项；本件的器官没有原装可换，棘轮的尽头是替代品。
- **slow-leak 暗漏**：共同的敌人是**看不见的恶化**——那边是用量蠕升的连续
  信号，本件是无痛进展的离散跳变（浅龋 → 牙髓之间的那几年）。
- **odometer-illusion 里程错觉**：同是「哪口钟说了算」的结构，那边里程钟/
  日历钟取 max，本件的复查**只有日历钟**——牙不看你开多少公里。
- **expiry-cliff 到期悬崖**：同是日期账，那边管凭证的**失效提前量**
  （提前办），本件管治疗的**进展间隔**（拖了更贵）。
- **safety-floor 兜底**：同是「存在 ≠ 有保障」，那边保单存在 ≠ 保额够，
  本件「治过」≠「在随访」——根管做完了不等于冠戴上了。
- **fat-creep 缓胖**：同是健康的蠕变，那边是体重的连续蠕涨（每天 +0.6 克），
  本件是牙位等级的离散升级（一次跨三级）。

## 诚实条款

账本不是牙医：它不诊断、不预测哪颗牙会坏，价签牌挂的是**价目表**不是
预言——「16 号牙再劈裂的价签是拔+种 ¥12,800」是市场事实，不是对 16 号牙
的诅咒。账面价差是「价目表 × 已发生的时间线」两个账本事实的对照，不是
「早补就一定省 4,480」的反事实断言（个体路径有差异，也许当时补了也会
继发龋）；拔除闭环不算价差——拔除是终点不是升级，而智齿那 688 天的拖延
代价（三次冠周炎、三次请假）记在痛苦里，账本看得见天数、不定价痛苦。
价签是通识先验，`--price` 全覆盖，你家乡牙科的报价单永远赢。账本只记你
抄回来的事实，你手里的病历和小票是唯一的 verify。全部线可调
（`--watch-line` / `--silent-line` / `--check-line` / `--crown-line` /
`--price`），参数永远赢。补不补、拔不拔、约不约复查，永远是人的决定——
账本只拒绝让「发现了」继续沉默。
