# 针链 · Shot Chain

> 免疫不是一年一次的事件,是一条不能断的链:猫三联三年一环、狂犬一年一环、体外驱虫一月一环——环环相扣,断一环,前面的针可能全部白打。而疫苗本的持有人是医院,不是主人:它散落在打过针的每一家医院的系统里,换一家医院就死一次。针链把这条链从医院系统里赎回来,记成你手里的一页对账单。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 城市养宠家庭:一到三只猫狗、换过至少一次医院或城市、每年春节要把宠物送去寄养的主人 |
| **场景** | ①春节订寄养,机构前台照着免疫证明念「狂犬 2 月 20 号到期,退房 22 号——到期日横跨寄养期,补完种再来」:拒收发生在前台,而到期日印在账上两个月了;②搬家换城市,新兽医问「猫三联哪年打的」,答「好像 2022?在前一家医院」,免疫史跟着旧医院失散,医生只能按未免疫重新起程序;③捡回来的猫没有过往史,「它打过吗?不知道,当时看着像打过」——盲区一放两年;④每月一次的体外驱虫,12 月用过、1 月忘,没人会为「少滴一个月」报警,但蚊媒季的心丝虫敞口就是从这个月开始的 |
| **问题** | 宠物免疫/驱虫是一条**周期异构的多条链**:疫苗链以年为周期、驱虫链以月为周期,链的连续性决定免疫是否成立——疫苗周期中断的代价不是「补一针」,而是按未免疫**重新起链**(重新全套或先做抗体检测);狂犬作为法定管理人畜共患病更是到期即失效,没有宽限。但这些链的完整性从没有对账工具:医院系统记的是「在我这里打的针」,不记「这条链断没断」;日历提醒假设你不会漏,漏了之后也不会告诉你世界变成什么样。日历记行程、账单记钱、相册记生活,**没有任何一本账记录「它、哪条链、末针哪天、断没断」**——而有五个时刻是别人向你要这本账的:换医院、搬家、寄养、托运、抓咬暴露 |
| **价值** | 把免疫从「医院系统里的碎片」变成主人手里可对账的链:①**链完整性账本**——每宠 × 六条内置链(猫三联/犬联苗/狂犬/体外/体内/心丝虫)一盏灯:🟢OK / 🟡DUE(预警窗与宽容期,恰线即亮)/ 🔴BROKEN(链断,动作是重新起链不是补一针)/ 🔴MISSING(零记录盲区);②**行动清单**——只列要动手的链,按截止日升序,贴冰箱那一行;③**交接卡**——寄养/托运/新兽医核对的一页纸,机构要看的链状态、末针日期、核对栏一次给齐;④**时间机器**——`--as-of` 钉回过去看当时的世界:断链不是一天发生的,是没人看的那个月里长出来的 |

**本件不是**:不是兽医、不做医疗判断。周期先验全部是公开常识(宠物医院门口海报都印着的数字),你的兽医的程序永远赢;BROKEN 的意思是「这条链超期了,该和兽医谈怎么重起」,不是任何诊断。账本在你自己的机器上,不连任何接口、不上传任何字节。

## 二、账本形态

手编 TSV,5 列,两种行型:

```tsv
type	pet	item	date	note
pet	阿福	dog			柯基,2 岁,2024-06 接回来的弟弟
shot	阿福	core-dog	2025-03-12	瑞鹏,八联系列第三针(完成)
```

- **pet 行**(一宠一行):`item` 列填物种 `cat/dog`(中文短名 `猫/狗` 也收);`date` 列留空
- **shot 行**(一针一行):`item` 填链名,词表收中文别名——`猫三联/三联/fvrcp`、`四联/六联/八联/dhpp`、`狂犬/rabies`、`体外/体外驱虫/跳蚤/蜱虫`、`体内/体内驱虫/打虫`、`心丝虫/heartworm`;`date` 是接种日(补零);`note` 惯例记医院与批号
- 手编从表格粘贴不拘小节:右侧缺列视为空、行尾制表符容忍、`#` 注释行、shot 允许前向引用(先记针后登记宠)
- 六条链的物种归属固定:猫四链(猫三联/狂犬/体外/体内),狗五链(犬联苗/狂犬/体外/体内/心丝虫)——物种与链矛盾是抄录错误,拒绝

## 三、灯(各管各的案)

| 灯 | 点亮条件 | 它在说什么 |
|---|---|---|
| 🔴 **BROKEN** | as-of 已过「末针 + 周期 + 宽容线」 | 链已断——下一针不是补一针,是重新起链:疫苗链约兽医重新全套或先做抗体检测;狂犬额外点名暴露敞口(逾期接种的它抓咬了人,人要打疫苗、它要隔离观察);心丝虫提示补做前先问兽医要不要抗原检测 |
| 🟡 **DUE** | 已到期但宽容期内(恰线即亮),或进入预警窗 | 动手窗口的余额天数;**预警窗不超过周期的 1/3**——月月钟最多提前 10 天亮,年钟提前 30 天,所以月月驱虫不会永远黄着 |
| 🔴 **MISSING** | 该宠该链**全时间零记录** | 不是账坏,是盲区:领养/捡回的免疫史跟着上一个主人失散了。反问句替你问出那句「它真的从来没打过,还是你不知道?」——带它验一次抗体,盲区就能变成实线 |
| ⚪ **NOT-YET** | 时间机器下剪切后零记录(第一针在 as-of 之后) | 不抬闸:当时它确实还没打,没打过的针不构成盲区指控——这是后视行的另一半诚实 |
| 🟢 **OK** | 其余 | 下次日期照给,余天数照报 |

**周期先验(全部可翻案,兽医的程序永远赢)**:猫三联/犬联苗 1,095 天(指南三年周期)、狂犬 365 天宽容为零(法规不讲宽容——证上的有效期印着,寄养机构照着念)、体外驱虫 30 天宽容 15、体内驱虫 90 天宽容 15、心丝虫 30 天宽容 15。`--cycle rabies:1095` 一句话翻案(海外三年),`--grace fvrcp:0` 收紧宽容。

## 四、命令

```bash
python3 shot_chain.py report   shots.tsv --as-of 2026-02-10  # 全量对账单:每宠每链一盏灯
python3 shot_chain.py next     shots.tsv --as-of 2026-02-10  # 行动清单:只列要动手的,贴冰箱那行
python3 shot_chain.py brief    shots.tsv --as-of 2026-02-10  # 交接卡:寄养/托运/新兽医的一页纸
python3 shot_chain.py validate shots.tsv                     # 恒等式 + 双路径重放
```

退出码:`0` 全绿 · `2` 账坏(表头/行型/词表/日期不补零/假日期/物种链矛盾/重复登记/未知链=拒绝猜测) · `3` 拒判(空账;或薄账未钉 as-of——只有登记没有针,锚定无从谈起) · `4` 账面带灯(BROKEN/DUE/MISSING 任一)。

## 五、样例走读(小满,春节寄养前夜)

小满,两只猫一只狗,腊月廿三(as-of 2026-02-10)订好了 2 月 14 日的寄养。账本 3 宠 13 针:

- **阿福**(柯基,2 岁):犬联苗 🟢(2028 年才到期);**狂犬 🟡——2 月 20 日到期,寄养期 14–22 号横跨到期日**:账本在订寄养之前就亮了,不是机构前台拒收那一刻;体外驱虫 🟡 已逾期 14 天、宽容还剩 1 天;体内驱虫 🟡 逾期 7 天;**心丝虫 🔴 链断于 1 月 24 日**——12 月用过、1 月忘,断在冬天,而南方蚊媒季从不按日历走
- **煤球**(狸花,2 岁,捡回来的):猫三联与体外驱虫 🔴 **MISSING**——免疫史跟着上一个主人失散了;狂犬 🔴 断了 240 天(领养当年打过、之后没续);体内驱虫 🔴 断了 28 天
- **年糕**(乳白,8 个月,幼猫):三针妙三多系列齐全——**链只认末针**,2028 年 10 月才到期;狂犬、体外、体内全 🟢。年糕是对照面:只要按时,这本账本来不响

时间机器钉回 **2025-12-20**:剪掉 3 针后视行,全账只剩 🔴3 🟡1,阿福当时全绿——**断链不是一天发生的,是没人看的那个月里长出来的**。

寄养机构的核对栏(brief 尾部):`□ 狂犬证在有效期(到期日横跨寄养期的,先补种再入住)`——2 月 10 日看到这一行的人,来得及;2 月 14 日被前台念出来的人,来不及。

## 六、恒等式与确定性

- **恒等式一**:Σ 账本 shot 行 ≡ Σ 各宠各(非空)链针数——每一针恰好属于一条链
- **恒等式二**:非空链数 + MISSING 盲区数 ≡ 宠数 × 各自适用链数(猫 4 / 狗 5)——链空间守恒,盲区是账本的一部分而非账本的缺失
- **双路径重放**:解析层(路径 A)与文本层独立重放(路径 B)对每宠每链比针数、末针日期、末针行号三字段,全等才绿灯;每条链的末针带 `(L行号)`,grep 回账本逐行可查
- **零墙钟**:缺省 as-of 锚定账本最大日期并如实披露(「未钉 as-of,缺省锚定账本末日」),`--as-of` 钉死即逐字节可复现——同账任何机器任何一天输出一致,报告只打 basename

## 七、诚实条款与边界

- 账本不是兽医:不做免疫程序设计、不判断该不该打、不解释抗体滴度。周期先验是公开常识的**简化**——严格程序(幼年系列后的 1 年加强)你家兽医可能另开,`--cycle` 一句话改成他的程序,先验是默认值不是真理
- MISSING 不等于「没打」:它只说账本上没有。领养史不明的猫,一次抗体检测就能把盲区变实线——账本把这句话放在每一行 MISSING 下面
- 狂犬的暴露提醒是法定常识不是恐吓:逾期接种的猫狗抓咬人,人打疫苗、它隔离观察——这是公开的管理规则,账本只负责告诉你证在哪天失效
- 宠物健康数据不出本机:不连任何接口、不上传任何字节、没有遥测。全部维护成本是一年一顿饭的盘点
