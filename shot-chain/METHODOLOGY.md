# 针链 · Shot Chain —— 方法论

## 0. 一句话

宠物免疫/驱虫是**周期异构的多条链**,链的连续性决定免疫是否成立;本件把链从医院系统里赎回来,记成主人手里可对账的账本,并给每条链一盏灯。

## 1. 模型:从「针」到「链」

直觉把免疫当**事件**:「今年打过疫苗了吗?」事件模型只能回答是/否。兽医学回答的是**连续性**:疫苗建立的免疫记忆有周期,周期内的针环环相扣;周期中断,免疫状态回到「未免疫」,代价是重新起链(重新全套程序,或先做抗体检测),而不是「补一针」。

于是最小模型是:

```
链(pet, item) = 按 date 排序的 shot 序列
末针 = max(shot.date)
到期日 = 末针 + cycle
断线日 = 到期日 + grace
```

链的**状态**只由末针与 as-of 的相对位置决定——账本不管下一次怎么打(幼年系列、加强程序、抗体检测是兽医的判断题),只管这条链断没断。这是刻意的减法:程序因物种、年龄、疫苗类型、地区法规而异,但对账只依赖一个数字——末针距今多久。

## 2. 六条链与两个钟

| 链 | 周期 | 宽容 | 钟型 |
|---|---|---|---|
| 猫三联 fvrcp | 1095 天 | 60 | 年钟/三年钟 |
| 犬联苗 core-dog | 1095 天 | 60 | 年钟/三年钟 |
| 狂犬 rabies | 365 天 | **0** | 法规钟 |
| 体外驱虫 flea | 30 天 | 15 | 月月钟 |
| 体内驱虫 worm | 90 天 | 15 | 季钟 |
| 心丝虫 hw | 30 天 | 15 | 月月钟 |

两个设计决定:

- **狂犬宽容为零**。其余链的宽容线承认「生活会漏几天」;狂犬的失效期是法规写死的——证上的有效期印着,寄养机构、托运检疫、暴露处置全都照着念。给宽容就是给假安心。
- **周期先验全部可翻案**(`--cycle/--grace/--warn`)。先验是公开常识的简化,你家兽医的程序永远赢;没有先验的链(词表外)直接拒绝——不发明没教过的链,与「未知药名拒绝猜测」同一立场。

## 3. 灯的恰线语义

判灯全部**含端点**,恰线即亮:

```
as_of == 到期日        → DUE(余 0 天,已逾期 0 天)
as_of == 断线日        → DUE(宽容还剩 0 天)
as_of == 断线日 + 1    → BROKEN
as_of == 到期日 - 预警窗 → DUE(预警恰亮)
as_of == 到期日 - 预警窗 - 1 → OK
```

线的价值在端点上:恰线亮是对「该动手了」最诚实的读法——不是「快到了」(模糊),而是「今天就是窗口的边界」。

**预警窗不超过周期的 1/3**(`warn_eff = min(--warn, ⌊cycle/3⌋)`):若月月钟(30 天)也用 30 天预警窗,驱虫链将永远黄着——永久亮着的灯等于没有灯。收敛后月月钟最多提前 10 天亮,年钟提前 30 天,黄灯重新成为事件。

## 4. 盲区与后视行:两种「零记录」

时间机器(`--as-of` 早于账本末日)会剪掉晚于 as-of 的后视行,剪后可能出现新的零记录。两种零必须分开,否则时间机器会冤枉人:

- **全时间零记录 → MISSING(🔴,抬闸)**:领养/捡回的免疫史失散,这是盲区,是账本要照亮的对象;
- **剪切后零记录 → NOT-YET(⚪,不抬闸)**:第一针在 as-of 之后,当时它确实没打——没打过的针不构成盲区指控。

恒等式二给盲区以账本地位:**非空链数 + 盲区数 ≡ 宠数 × 适用链数**。盲区不是账本的缺失,是账本的一部分——这正是「账本还不完备」(exit 4)的门禁语义:只记了一件事的主人,五链盲区照亮正是账本要对他说的话。

## 5. 双路径重放与守恒

账坏不可判灯,而「账没坏」必须可验证:

- **路径 A**(解析层):TSV → 类型化行对象 → 聚合;
- **路径 B**(文本层):直接从原始文本逐行重放,不经过路径 A 的任何产物。

两层对每宠每链比三个字段:针数、末针日期、末针行号。任何一层对账本的理解发生漂移,重放当场对不上(exit 2)。在此基础上钉两条恒等式:Σshot 行 ≡ Σ各链针数(逐针守恒);非空链 + 盲区 ≡ 链空间(链空间守恒)。

## 6. 零墙钟

免疫对账天然要「今天」,但墙钟杀死可复现性。本件的取舍:缺省 as-of 锚定账本最大日期并如实披露;要审「今天」,`--as-of "$(date +%F)"` 一句话。同账任何机器任何一天逐字节一致——报告是账本的状态,不是跑报告那一刻的快照。

## 7. 边界

- 不是兽医:不设计免疫程序、不判抗体、不解释滴度;BROKEN 的动作文案以「约兽医」结尾
- 不是法规数据库:狂犬周期按城市年度通识 365 内置,海外/特殊法规 `--cycle` 翻案
- 不是寄养机构:brief 交接卡是主人照账本如实填写的一页纸,机构照单核验——账本不替机构做决定
- 不连任何接口:宠物健康与住址关联(宠物名+小区=家门)是敏感数据,全部计算在本机完成
