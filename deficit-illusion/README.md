# 赤字幻觉 · Deficit Illusion

> 你记了 1386 大卡，身体收到了 1857——瘦不下来的原因不在代谢里，在没被记下来的那部分生活里。
> Your diary says 1386 kcal; your body got 1857. The deficit you believe in is the illusion.

## 一句话

认真减肥的人天天上秤、（试图）记录饮食，两本账却从来没人对过：「按我的账每天亏 700 大卡，8 周该瘦 11 斤，秤上只有 3 斤半，昨天还暴涨 1 斤多」。`deficit-illusion` 把两本手编 TSV（晨重 + 自报摄入）放上**能量守恒的天平**，开出五本账：**表观 TDEE**——把你的日记当真时，你的身体「必须」在烧的热量（样例 1658 kcal/天，只比基础代谢高 17%——荒谬的不是代谢，是日记）；**漏记账**——先验消耗 − 表观消耗 = 每天漏记 470 kcal，**漏记系数 1.339**（你记 3 顿、身体收到 4 顿，25% 的摄入是隐形的；营养学文献反复测到普通人低估 20–50%，你第一次知道自己在哪个位置）；**账面 vs 秤**——按你的账 49 天『该』减 4.72 kg、秤上实际 1.73 kg，差额 2.99 kg 逐克有主；**水重分离**——「日环比 ≥0.8 kg」的假反弹直接判数学不可能（+1 kg 脂肪需要单日净余 7700 kcal ≈ 三天半的总消耗，是水和糖原在演戏），火锅退潮伪造的「掉秤加速」也被 spike shadow 豁免；**速率门禁**——7 日均重差分越过得体重 1%/周的线亮 MUSCLE RISK（代餐猛掉的那周，肌肉在陪葬）。平台期法庭对「吃得没多却停了」开庭：要么漏记在扩大，要么代谢在适应——先修记录 14 天，再谈代谢。账本自锚定：缺省 as-of = 账本末日，`--as-of` 钉死，同一本账任何机器任何一天跑出的结果逐字节一致。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 认真减重的人——每天晨起上秤、用薄荷健康/MyFitnessPal 或纸笔记饮食，已经坚持了三周以上，且真的想搞明白「为什么瘦不下来」，而不是只想被安慰。 |
| **场景** | 第八周周末的崩溃时刻：饮食 App 说这周又亏了 4900 大卡，体重却比上周还重 0.4 kg——昨天那顿火锅让秤 +1.4 kg，「我 metabolism 是不是坏了」的怀疑第三次出现；以及每一顿没称油、没数外卖、估了个「大概 800」的饭——它们从账面上消失，从没从身体里消失。 |
| **问题** | ① **两本账从没人对过**：自报摄入是一路的声称，体重是一路的实测，中间隔着一个 20–50% 的系统性低估（营养学用代谢病房和双标水反复测到的铁律），但「**我**低估多少」从没有工具替你算过；② **单日波动淹没趋势**：水、钠、糖原、肠道内容物让体重每天 ±1–2 kg，而真实的脂肪速率只有每天 −0.05 kg 量级——「昨天暴涨 1.4 kg」和「这周怎么不动了」全是噪声在说话；③ **TDEE 全靠公式猜**：BMR × 活动系数误差 ±20%，没有人用你自己的秤和账反推过你的真实消耗；④ **平台期两种病分不清**：记录劣化（漏记扩大）和代谢适应（消耗真降）症状相同、药方相反。 |
| **价值与意义** | ① **第一次对账**：表观 TDEE 是纯算术——把你的日记当真，你的身体必须烧多少才对得上你的秤；它荒谬到低于合理生活的那一天，就是账本被戳穿的那一天；② **漏记有了自己的数字**：系数 1.34 不是道德审判，是认知校准——人对分量、油、调料、饮料的系统性目测误差第一次有了个人读数；③ **假反弹免疫**：脂肪在数学上不可能一天长 1 kg，账本替你把这句话说死，火锅后的恐慌从第三天变成第二天早上的一条豁免记录；④ **猛掉也拦**：>1% 体重/周的速率里肌肉在陪葬，门禁替未来的你保住基础代谢；⑤ **诚实条款**：体重是唯一的硬通货，摄入只是声称——所有灯都亮给记录的人，不是身体出了问题。 |

## 核心思想：能量守恒不会谈判，只会揭发

减肥的宇宙常数只有一条：**吃进的 − 烧掉的 = 存下的（×7700 kcal/kg）**。这个等式里没有「体质」这个变量，也没有奇迹的位置。本件把等式当成审计工具，对你的两本账开庭：

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **表观 TDEE** | apparent = 自报日均 − 7700×ΔW ÷ 天数（窗口对齐：掐头去尾各 3 天，摄入与 ΔW 严格同窗） | 「如果我的日记是真的，我的身体必须在烧多少？」——烧得荒谬，就是日记在撒谎 |
| **漏记账** | 需要先验（`--tdee` 或 Mifflin-St Jeor 公式参数）；漏记 = 先验 − 表观；漏记系数 = 真实摄入 ÷ 自报摄入；TDEE ±15% 敏感性区间照给——**即使按对你最有利的消耗，仍漏 151 kcal/天** | 「我到底漏了多少？我是不是文献里的普通人？」 |
| **水重分离** | 日环比 \|Δ\| ≥ 0.8 kg → 假反弹，附脂肪不可能性论证；涨 spike 后 14 天内的差分（退潮伪造的「掉秤加速」）与跌 spike 后 6 天内的差分标 CONFOUNDED，不进门禁 | 「昨天 +1.4 kg 是失败吗？这周掉得特别快是有效吗？」——都不是，是水 |
| **速率门禁** | 7 日均重差分（以 e 结尾的窗 − 一周前的窗），非豁免差分 \|d\| ≥ 1% × 当窗体重/周 → MUSCLE RISK exit 4 | 「这个速度健康吗？」——猛掉的不全是脂肪，肌肉与水都在陪跑 |
| **平台期法庭** | 连续 ≥5 个非冲突差分日 \|d\| ≤ 0.18 kg/周 = 平台段；段内自报 vs 段前同窗自报：吃得没多（或更少）却停了 → RECORD-OR-ADAPT，段尾触到末端 7 天内 = ACTIVE exit 4；比段前多 ≥100 → BEHAVIOR（吃回来了，账本先于体重看见） | 「卡住是代谢坏了吗？」——要么漏记在扩大，要么代谢在适应；先修记录，再谈代谢 |
| **反事实 simulate** | `continue`：近端差分外推（实测节奏，不经公式，横幅假设吃法与记账毛病原样保持）；`intake N`：真实摄入压到 N 的推演（需先验），对照行明示「自报 1382 却瘦不动 vs 真实 1600 并如实记录」的差距 | 「照这样下去什么时候到目标？把吃量压到 N 呢？」 |
| **账本体检 validate** | Σkcal 复算恒等、表观反代残差 < 1e-6、首窗均重重算、覆盖率与账本空洞披露 | 「这本账配不配得上结论？」 |

三条边界刻在实现里：

- **体重是唯一的硬通货，摄入只是声称**——所有归因从秤长出来；漏记账的可靠性依赖你给先验，不给 `--tdee`/公式参数就只出表观账，绝不发明你的消耗。
- **薄账分层**——跨度 < 21 天或体重读数 < 10 天：算术照常出账（行数、覆盖、均值），统计判级 DECLINED exit 3；摄入覆盖 < 50% 时漏记账直接 DECLINE（一半的日子没记，系数会系统性失真）。
- **账本自锚定**——缺省 as-of = 账本末日，`--as-of` 钉死；报告只打印账本 basename，绝不回显调用方路径；同一本账在任何机器、任何日期跑出的结果逐字节一致（CI 快照校验）。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

```bash
python3 deficit_illusion.py report examples/ledger.tsv --sex f --age 30 --height 168 --activity 1.5
```

## 命令速查

```bash
python3 deficit_illusion.py report     examples/ledger.tsv --sex f --age 30 --height 168 --activity 1.5 --goal 62   # 总账 + 灯汇总
python3 deficit_illusion.py trend      examples/ledger.tsv                     # ISO 周表 + 速率差分 + 假反弹清单
python3 deficit_illusion.py reconcile  examples/ledger.tsv --tdee 2100         # 表观 TDEE + 漏记系数 + 敏感性
python3 deficit_illusion.py rate       examples/ledger.tsv                     # 速率门禁（spike shadow 豁免）
python3 deficit_illusion.py plateau    examples/ledger.tsv                     # 平台段法庭
python3 deficit_illusion.py plateau    examples/ledger.tsv --as-of 2026-07-19  # 钉死到度假周末重放：ACTIVE exit 4
python3 deficit_illusion.py simulate   examples/ledger.tsv continue --goal 62  # 按当前节奏推演
python3 deficit_illusion.py simulate   examples/ledger.tsv intake 1600 --sex f --age 30 --height 168 --activity 1.5  # 反事实
python3 deficit_illusion.py validate   examples/ledger.tsv                     # 恒等式与覆盖披露
```

Exit codes：**0** 绿 · **2** 账本损坏（坏行/重复日期/出界值）· **3** 样本太薄拒绝判级 · **4** 红灯（RECORD GAP / MUSCLE RISK / ACTIVE 平台）。

## 账本格式（可手编 TSV，一天一行）

```text
date	kg	kcal	note
2026-06-08	68.0	1599	开始认真记录，目标 62kg，办了体脂秤
2026-06-14	68.2	1538	晚上海底捞庆功，菜没数，凭记忆估的
2026-06-15	69.2	1431	秤 +1.4kg？！昨晚就吃了一顿火锅
2026-07-14	67.2	1524	暑假出游，早午饭经常并一顿
```

- `date`（YYYY-MM-DD）必填，全账唯一（重复 = 手抄事故 exit 2）。
- `kg`：晨重，当天没上秤留空；`kcal`：当天自报摄入，没记留空——**缺席不进任何分母，但也不假装你那天绝食**（覆盖率如实披露）。
- `note` 可选，喂给报告当证据（火锅、代餐、度假）。
- kg 合法域 20–350、kcal 0–10000，出界 exit 2。
- 记录纪律：体重每天一次固定条件（晨起、如厕后、同一天平）；饮食记「入口的总和」——油、饮料、酱料都算。漏记就是本件审计的对象，别为了好看补数字，那是给自己喂假数据。

## 验收标准（全部转成自动化测试，57 个）

- **恒等式**：合成账本（构造已知 TDEE/真实摄入/自报摄入，无噪声）必须被精确复原——apparent TDEE == 真实 TDEE（places=3）；漏记 == 真实摄入 − 自报摄入 == 先验 − 表观（三方恒等）。
- **窗口对齐**：ΔW 的中心天（span−7）与摄入窗口分母同窗——这是「构造真值可复原」的前提，本身有测试钉死。
- **判级阶梯**：HONEST < 1.10 ≤ WATCH < 1.25 ≤ RECORD GAP，三档各有合成账本 + 边界账本（恰 1.25 附近）。
- **spike 语义**：恰 0.8 算 / 0.79 不算（扣除日基线趋势后）；涨 spike 豁免 ±14 天、跌 spike 只豁 6 天，方向性有真值表；样例账本上火锅退潮段（6-23..6-29）必须被豁免、真超速段（7-29）必须不豁免。
- **样例叙事**：56 天账本上 apparent=1658.1、漏记=470.2、系数=1.339、最猛非豁免差分 -0.70@2026-07-29、假反弹恰 2 条、plateau 全账 exit 0（PASSED）/ as-of 7-19 exit 4（ACTIVE）——每个数字断言到 0.1。
- **薄账分层**：<10 天体重 / <21 天跨度 → 判级 exit 3 算术照出；摄入覆盖 13/28 → 漏记账 exit 3。
- **账本纪律**：重复日期/坏日期/坏表头/出界值 exit 2；空格列合法。
- **可复现**：同账本两次运行逐字节一致；报告只含 basename 不含调用方路径；`--as-of` 截断与边界日含当行。

## 诚实条款

- **它不下医嘱**：所有红灯指向的是「你的记录」和「你的速率」，不是诊断；吃着二甲双胍/甲亢/多囊的人在测什么，请与医生讨论——账本分不清代谢疾病和漏记，它只负责把矛盾摆到台面上。
- **7700 是通识常数**（Wishnofsky 近似），对纯脂肪组织成立，糖原与水阶段失真——失真恰恰是 spike shadow 存在的理由；`--kcal-per-kg` 可调。
- **eating disorder 敏感性**：本件不鼓励更低的摄入——速率门禁存在的意义就是拦猛掉；如果你的「记录」开始变成「少记」，那是对这套工具最恶意的用法。
- **先验永远可质疑**：Mifflin-St Jeor 是人群公式，你的真实消耗可能偏 ±15%——所以敏感性区间照给，且「即使按对你最有利的消耗仍漏 151」才是结论的表述方式。

## 与近邻的边界

- **scapegoat（替罪羊）**：那边审「哪种食物导致发作」（因果归因，Fisher 检验），本件审「能量账平不平」（守恒对账，恒等式反解）——一个问嫌疑犯，一个问账本，两边都从可手编日更 TSV 长出结论，但问题空间不相交。
- **redline（加量红线）**：那边给跑量装转速表（训练负荷 vs 伤病），本件给减重速率装转速表（能量缺口 vs 肌肉流失）——同构的「慢性负荷」哲学，一个防跑伤，一个防饿伤。
- **felt-inflation（体感通胀）**：那边对账「官方 CPI vs 你家小票」，本件对账「你的日记 vs 你的秤」——都把「声称」和「实测」的差值命名并定价，一个差值是让步，一个差值是漏记。
- **mood-barometer（阴晴表）**：那边用你自己的历史算情绪基线与回弹，本件用你自己的秤算消耗与漏记——同样拒绝「感觉」，同样薄账拒判。
- **borderline（贴线）**：那边给化验值算斜率与余量年数（Theil-Sen 抗单点），本件给体重算差分与豁免（spike shadow 抗水重）——抗噪哲学各异，因为化验单一个月一张、体重秤一天一台。
