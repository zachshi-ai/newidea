# METHODOLOGY · 掉带 · Off Track

本文回答四个问题:参考数据从哪来、判读规则依据什么、每一盏灯为什么这样设计、以及本件**故意不算**什么。

## 1. 参考数据:一段都没编

百分位判读的物理底座是 LMS 参考表。本件内嵌两族官方数据(子集,只取 Sex/Agemos/L/M/S 四列):

| 表 | 覆盖 | 来源 |
| --- | --- | --- |
| HFA(length/stature-for-age) | 0-24 月 WHO 2006 身长 + 24.5-240.5 月 CDC 2000 身高 | CDC percentile data files(`lenageinf.csv`、`statage.csv`) |
| BMI-for-age | 24-240.5 月 CDC 2000 | `bmiagerev.csv` |

- 原始 CSV 钉在 `references/`,`references/embed_tables.py` 从它生成内嵌常量;CI 之外任何时候都可以对照原件逐节点核对
- 0-24 月与 2-20 月在 24 月处的衔接遵循 CDC 官方口径(24.0 月归身长表,24.5 月起归身高表);身长(躺)与身高(站)天然差约 0.7cm,1.0cm 的"身高倒退"体检容差吸收了这个切换
- 参考系立场:内嵌的是 CDC 2000 / WHO 2006。中国九市标准与之同族但不同值;**过期规则比没有规则危险,城市差异是立场不是漏洞**——本件不内置任何一家"更对"的表,儿保手册上的带就是你的医生的参考,`--` 旗标是全部后门

### LMS 引擎

每个节点给三个参数:L(Box-Cox 幂)、M(中位数)、S(变异系数)。任一测量值 x 在月龄 a 的 z 分数:

```
z = ((x/M)^L − 1) / (L·S)     (L≠0)
z = ln(x/M) / S               (L=0)
百分位 = Φ(z)                  (标准正态 CDF,statistics.NormalDist)
```

半年节点之间线性插值。反方向(由百分位求身高,`next` 命令用)是同一公式的代数逆。自检钉死在 `validate`:每个节点上 `value(P50)==M`、`pct(M)==50`(484 个 HFA + 438 个 BMI 节点全查,容差 1e-6),以及任意百分位的身高严格单调。插值误差相对"跨两条主带"的判读分辨率粗一个量级,不构成判读噪声。

## 2. 三道闸:轨道、窗口、速度

### 闸一:全期带漂移(drift)

把七条主百分位线当作六条轨道带(外加 <P3 与 >P97 两侧),每次测量得到一个带序号 0-7。**全期漂移 = 末次带序 − 首次带序**。|drift| ≥ 2(默认,`--cross-bands`)亮灯,方向分 DOWN(生长衰竭问题)与 UP(加速问题)。

带序约定:**恰在带线上的百分位归高带**(P10 属 P10-P25 带)。这是保守取向:宁少报一条,不制造一场冤案。

恒等式:逐窗带差之(代数)和 ≡ 首末带差(伸缩恒等式,`validate` 钉死)。它防的是带序边界 bug——任何一处 ≥/≤ 写反,恒等式当场断裂。

### 闸二:急性窗口(window)

任一相邻测量窗跨带 ≥2 条独立亮灯,即使全期漂移 <2。设计动机:先涨到 P75、急跌到 P12、再回到 P55 的孩子全期只漂 1 条,但中间那次急跌是不得沉默的信号。注意一个物理事实:**一个不倒退的身高账本在一个半年窗里跨两条带几乎不可行**(相邻半年带间距 ≈ 该年龄段半年增速),所以急性窗口在真实账本上主要靠"增长显著放缓+测量窗口拉长"触发;它的规则价值由单测在引擎层钉死,账本层由身高倒退体检(R10)先行拦截抄录错误。三层防线各司其职。

### 闸三:速度下限(velocity)

逐窗 cm/年(天数按 365.25 折年),对照分段通识下限:

| 月龄段 | 下限(cm/年) |
| --- | --- |
| 24-36 月 | 7 |
| 36-48 月 | 6 |
| 48 月 - 青春期窗 | 5 |
| 青春期窗内(女 ≥10y / 男 ≥12y,`--puberty-girl/boy`) | 4 |

`--velocity-floor X` 一个值覆盖全段。速度线与跨带线**互相独立**:小舟样例的前两窗速度及格,若只看速度线,警报会晚响两年;反之松掉跨带线(`--cross-bands 5`),速度线仍守着。窗中点月龄定段,窗 <120 天不计(测量误差淹没速度信号)。

速度恒等式(`validate` 钉死):Σ(窗长 × 窗速) ≡ Σ 窗身高差(9 位小数)——速度是导数,账是原函数,两边必须互相还原。

## 3. 靶身高:比的对象是投影,不是身高

中位父母身高法(CM'TH):男孩 = (父 + 母 + 13)/2,女孩 = (父 + 母 − 13)/2,±8.5cm(`--target-spread`)为遗传概率区间。

**设计复盘(开发中自纠)**:第一版拿孩子当前身高直接对比靶区间——7 岁 127cm 当然"低于"成年靶 144cm,这是拿身高比成年,荒谬且制造焦虑。正确对象是**当前百分位在 20 岁的同带投影**(假设沿带走到成年)。投影低于靶区间 → BELOW,是"值得测量的画像,不是判决":也有全家都在 P3 的家族性矮小,人家的轨道本来就在低处。投影不亮任何 exit 4 的灯。

## 4. 晚长画像:账本只负责"不与晚长矛盾"

体质性青春期延迟(constitutional delay,"晚长")的经典画像是:身高百分位低 + 骨龄落后 + 最终达标遗传靶。账本能看到的只有前一半的代理:

```
--family-late-bloomer + 投影低于靶区间 + 年龄进入青春期窗 + 速度完好
⇒ 打印画像:"与家族晚长画像一致——但骨龄是唯一裁判,本件拒绝发明它"
```

四条件缺一不打印(速度破线时画像**必须**沉默——速度完好多一个砝码,画像才敢出现)。画像永不改变判级。这句话是本件的诚实底线:确认晚长只有拍骨龄片一条路,工具替你把病历整理好,替你挂号,不替你诊断。

## 5. BMI 轨道:同一台机器,反方向

给了 weight 列就开 BMI 轴:BMI-for-age 百分位、同一套跨带判级、同一门槛。方向语义相反——**向上跨带是儿童肥胖最早的签名**(肥胖的诊断标准本身就是 BMI-for-age ≥P85/P95 的带位)。BMI 出 [8,40] 域的行按 kg/lb 单位疑云跳过并逐行点名。BMI 轴的婴儿(<24 月)没有参考表,n/a 如实显示,不发明。

## 6. 薄账分层与 exit 语义

| 情形 | 行为 |
| --- | --- |
| 合格测量 <2,或首末跨度 <120 天 | 位置照发,轨道/速度判级 DECLINED,exit 0 |
| 0-24 月行 | 展示百分位,不进任何判级(生理性带漂移);披露排除行数 |
| 数据体检失败 | exit 2,算术不发 |
| 任一闸亮灯 | exit 4,列出全部亮灯的闸 |
| 账本正常、无信号 | exit 0,GREEN |

「位置永远发表,只有判级需要更多账」:半夜想知道孩子现在几百分位的家长不该被样本量拦住——这与算术永不挂门禁是同一条纪律。

## 7. as-of:时间机器,不是错误过滤器

缺省 as-of = 账本最大日期(账本自锚定,零系统时钟依赖);`--as-of` 把审计日钉回过去,晚于它的行**被排除而不是报错**。这是有意裁决:儿保账本天然持续追加,"去年这时候他还绿着吗"是合法且高频的重放请求,把未来的行当抄录错误会杀死时间机器。真正的抄录错误(身高倒退、双生日、重复同日)有各自的体检在守。任何 as-of 下任何机器跑同一本账,输出逐字节一致;报告只打印 basename。

## 8. FAQ

**Q:为什么不做生长曲线图?**
图是给"看"的,判读是给"决策"的。手册上印着图,家长缺的是"这算不算问题"的门槛。本件输出的是带序、漂移数、速度与走廊数字——它们可以画成任何图,但先得有人把它们算出来。

**Q:为什么不内置中国标准/WHO 全表/骨龄?**
政策差异是立场不是漏洞;全表内嵌换不来判读精度(半年节点插值已远粗于带距);骨龄需要 X 光,账本不发明自己没有的证据。

**Q:测量误差怎么办?(不同人量、早晚身高差 1-2cm)**
`next` 的走廊文字里写明了测量纪律(同一测量人、脱鞋、尽量晨间);速度窗 ≥120 天起判;跨带门槛 2 条 ≈ 5cm 级别的偏差,单次 1cm 的量法抖动啃不动它。

**Q:孩子在青春期,判得准吗?**
青春期启动时间个体差异大,本件不猜启动日,只做两件保守的事:青春期窗内速度下限放宽到 4 cm/年;靶身高投影承认"沿带到成年"的粗粒度。性别发育异常的信号(如 8 岁前明显加速)由向上跨带灯提示——它不能诊断性早熟,但它会说"这一带涨得不对劲"。

**Q:为什么报告里没有"我家孩子几点进青春期/成年多高"的预测?**
投影是"沿带走到 20 岁"的几何换算,带假设不是预言;青春期变数它背不动。回答"成年多高"的诚实方式是给区间和条件,本件给的就是这个。

**Q:多大年龄后账本就没用了?**
240.5 月(约 20 岁)是参考表顶。骨骺闭合后生长账自然停笔——那是好消息的另一种写法。
