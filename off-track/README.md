# 掉带 · Off Track

**"我的孩子矮不矮"问的是位置,"他还在不在自己的轨道上"问的才是方向。本件判方向。**

一个零依赖 CLI:把儿保手册上的身高体重抄成一本手编账本(TSV,一行一次测量),算出**百分位轨道**——每次测量落在哪条百分位带、整条轨迹漂移了几条带、哪一次测量破了带、分年龄段生长速度是否守线、按父母身高投影的靶身高是否偏离、BMI 轨道是否在悄悄上漂。红灯(exit 4)= **该挂儿童内分泌/生长发育门诊的理由**,不是诊断。

## 角色与场景

| | |
| --- | --- |
| **角色** | 0-18 岁孩子的家长(儿保手册已经记了七八次测量值的人);多孩家庭一人多本 |
| **场景** | 儿保半年一次、医生说"正常";家里老人说"隔壁娃比你家高半头";家长在"晚长"和"矮小症"之间反复横跳,搜索框里躺着没敢问的问题 |
| **问题** | ①"矮不矮"是和平均人比**位置**,50 百分位不是及格线、3 百分位也不是病,但家长只看得懂位置;②儿保手册上历史测量躺了七年,从没人连成线——儿科学公认的警报是**跨越两条主百分位带(crossing two major percentile lines)**,而这个信号只在把测量串成轨道时才存在:每一次儿保单看都可以毫无异常,五年轨迹却从 P75 滑到 P10;③生长速度线(年增 <5cm)太粗,捕捉不到"每年都长、但比自己轨道慢";④靶身高(父母身高的遗传概率区间)从没被算过;⑤同样的机器向上跑,BMI 的带间上漂是儿童肥胖最早的签名 |
| **价值** | 把位置焦虑改写成方向判读:3 百分位沿自己的轨道走,是**健康的小个子**;75 百分位连续掉带,是**需要挂号的大个子**。给家长一个确定性的判读器、一张下次儿保的"安全走廊"数字卡,以及两种误判的拦截——把真性生长迟缓当"晚长"拖着(不可逆),把正常晚长送去打生长激素(过度医疗) |

## 为什么叫"掉带"

儿保手册上印的那七条线(P3/P10/P25/P50/P75/P90/P97)不是装饰,是轨道。儿科判读生长的常识是:**沿带走=健康;跨越两条主带=警报,与绝对百分位无关**。掉带(downward crossing)是生长衰竭的签名,向上跨带是加速(身高加速要问性早熟,BMI 加速就是肥胖)。"矮"是位置,"掉带"是方向——方向才有药,位置只有焦虑。

## 六个命令

| 命令 | 回答的问题 |
| --- | --- |
| `report` | 全景:当前位置百分位、带路径与漂移判级、逐窗速度、靶身高对照、BMI 轨道 |
| `track` | 逐次测量的带序账本——哪一次掉的带,一目了然 |
| `velocity` | 分窗生长速度 vs 年龄段下限(2-3 岁 7、3-4 岁 6、4 岁-青春期 5、青春期 4 cm/年,全部可调) |
| `target` | 靶身高专页:中位父母身高法(父+母±13)/2,±8.5cm 区间;当前百分位投影到 20 岁是否离靶 |
| `next` | **下次儿保的安全走廊**:下次测量长到多少算在轨、掉几条带亮灯——把这个数字带去儿保 |
| `validate` | 引擎自检(每节点 LMS 往返、带边界约定)+ 账本恒等式(带差伸缩、速度加权、BMI 重算) |

## 账本格式(手编 TSV)

```
date        child     born        sex  height_cm  weight_kg
2020-03-15  xiaoman   2018-03-15  F    85.0       11.86
```

- `born/sex` 每行重复是故意的:儿保手册每页都印着生日,行间不一致就是抄录 bug(直接 exit 2)
- 单孩可省 `child` 列;`weight` 可选(给了才开 BMI 轨道);中英文列名/性别别名混用均可(`身高`≡`height_cm`、`女`≡`F`≡`girl`)
- 三十秒抄一行,一年两到六行——这是全仓库最轻的账本,因为测量值本来就是官方给的

## 验收标准

| # | 验收项 | 标准 |
| --- | --- | --- |
| R1 | 位置判读 | 每次测量给出 height-for-age 百分位;LMS 半年节点插值,节点处 P50 往返与中位数恒等(<1e-6),任意百分位严格单调 |
| R2 | 轨道判级 | 全期带漂移 ≥2 条(可调)→ OFF-TRACK exit 4,方向分 DOWN/UP;带线上的百分位归高带(P10 属 P10-P25),恰带行走不亮灯 |
| R3 | 急性窗口 | 任一相邻窗跨带 ≥2 条独立亮灯,即使全期漂移 <2(单测钉死该规则) |
| R4 | 速度守线 | 逐窗 cm/年对照分段下限,破线 exit 4;`--velocity-floor` 单值覆盖全段;速度线与跨带线**独立**——松掉跨带线速度线仍守着 |
| R5 | 婴儿豁免 | <24 月龄的行只展示不判级(生理性带漂移),披露排除行数;BMI 表从 24 月起,之下 n/a 如实说明 |
| R6 | 靶身高 | 中位父母身高法,区间 ±8.5 可调;比较对象是**当前百分位在 20 岁的同带投影**,不是当前身高;靶身高命令缺父母 exit 2 |
| R7 | 晚长画像 | 家族晚长史 + 投影低于靶区间 + 青春期窗年龄 + 速度完好 ⇒ 打印画像,且**明文拒绝发明骨龄**;缺任一条件画像不出现 |
| R8 | BMI 轨道 | 独立百分位轴独立判级;向上漂移点名"儿童肥胖最早签名";BMI 出 8-40  plausible 域的行按单位疑云跳过并披露 |
| R9 | 薄账分层 | 合格测量 <2 或跨度 <120 天:位置照出、判级 DECLINED、exit 0——位置永远发表,只有轨道判级需要更多账 |
| R10 | 账本体检 | 缺必填列/坏日期/坏性别/重复同日/双生日/身高倒退 >1cm/身高体重域外/超表月龄 → exit 2;账本不存在 exit 2 |
| R11 | as-of 时间机器 | 缺省 as-of=账本最大日期;`--as-of` 钉死重放,晚于它的行被**排除而不是报错**(去年你也想重放);逐字节可复现;报告只打印 basename |
| R12 | next 走廊 | 守带下限 / 掉一带观察窗 / 红线三层走廊,红线=守带下限以下再低一带;最低带的孩子如实说明"已无带可掉,速度线兜底";恒 exit 0(沙盒不执法) |
| R13 | 诚实条款 | 报告尾固定:"Not medical advice";红灯文案固定"挂号的理由,不是诊断";全部阈值是通识先验且全部是 `--` 旗标 |
| R14 | 快照 | `examples/build_examples.py --check` 任意 cwd 逐字节复现全部快照;CI 门禁 |

## 样例(四个孩子,四本账)

- **小满**(F):P60 身高带 + BMI P55,七次测量全绿——"正常"应该长这样
- **小舟**(M):**本件存在的理由**。五年从 P75 滑到 P10(身高 drift −4),每次儿保单看最多掉一条带,前两年速度线也不响;同时 BMI 从 P25 爬到 P90。报告三盏红灯:掉带、BMI 上漂、后段速度塌方
- **小树**(M):P10 骑带 + 速度完好 + 投影低于靶区间 + 家族晚长史 ⇒ 绿灯 + 晚长画像(骨龄是唯一裁判,本件拒绝发明它)
- **小豆**(F):两次婴儿期测量——位置 P79.5 照发,轨道判级 DECLINED,exit 0

## 与近邻的边界

- **borderline 贴线**(成人体检指标纵向趋势):那边是固定参考区间内的斜率与余量年数(单指标静区间),本件是**随年龄滑动的人群相对轨道**(LMS 百分位带)+ 跨带计数 + 速度账 + 遗传靶——参考系本身每月都在长
- **fat-creep 缓胖**(宠物体重蠕涨):那边一本秤账看绝对速率(%体重/月),本件有身高坐标系、有百分位带、有靶身高;且方向相反——那边拦"越来越胖",本件主闸拦"越来越慢"
- **redline 加量红线**(训练负荷):那边 ACWR 是负荷比值,本件是人群参考带;共同点只有"阈值都是先验、先验都是旗标"
- **expiry-cliff 到期悬崖**:凭证有日历死线,生长没有——本件没有一条"到某日作废"的线,只有"偏离轨道多少条带"的几何
- **filial-desk 孝心工单**:那是子女给父母的运维账,本件是父母给孩子的生长账——一个家庭的两个方向

## 诚实条款

本件不是生长激素推销员,也不是"晚长"安慰剂。它做三件事:把手册抄成轨道、把"正常"翻译成百分位与速度、把"要不要挂号"变成一个有门槛的问题。它不做的事:不发明骨龄(晚长与否 X 光说了算)、不诊断(红灯指向医生)、不内置中国九市标准(参考表是 CDC 2000 / WHO 2006,儿保手册上的带就是同族参考;政策差异以医生和手册为准)。所有阈值都是通识先验,所有先验都是 `--` 旗标——账本只算它有权算的东西。

## 运行

```bash
python3 off_track.py report ledger.tsv --mom 162 --dad 175
python3 off_track.py next ledger.tsv --next-at 2026-09-15
python3 -m unittest discover -s tests        # 50 tests
python3 examples/build_examples.py --check   # CI byte-check
```
