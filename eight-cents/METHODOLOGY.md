# METHODOLOGY · 八分钱 · Eight Cents

## 1. 一句话

「一公里才八分钱」是购车销售递上来的算法,不是你的算法——本件把你听到的营销口径和你的真实口径并排放在一本账里,用你的桩、你的里程、你抄的报价单把油电两辆车算到「每公里、每年、N 年」三个刻度上,回答销售从不回答的问题:**在你家,差价几年追平,追不平就明说**。

## 2. 为什么是账本

油电抉择是 2026 年中国家庭购车第一纠结,而整个信息环境站在「翻译的对面」:电车销售给的是**能耗口径**(每公里电费,按 100% 家充、谷时电价),油车销售给的是**恐怖故事**(电池八万一块)——两边的数字都成立,两边的数字都不是总账。汽车平台的「用车成本」工具给全国平均口径,不带你的充电条件(有无家充桩是最大变量)、你的年里程、你城市的电价油价。**参数是平均的,结论就不是你的**。

购车决策的痛点不在信息缺失——所有数字都写在报价单和配置单上——而在**没有人把两本账并排**:能耗、保险、保养、车船税、购置税散在五个对话框里,每个对话框都只说自己便宜的那部分。抄两辆车、抄一份你家的事实(年里程/桩/电价),就是全部数据工程;换来的是两个销售的对轰变成一张并排的表,和一句在参数空间里诚实到冷酷的话:「结论不属于车,属于你的桩和里程」。

## 3. 核心模型

### 3.1 两种算法(翻译层)

**营销口径** = energy100/100 × 家充电价——电车按 100% 家充、只算电费,「八分钱」的全部由来;油车对称(油耗 × 油价,只算油钱)。这是对营销话术的通识还原,不是稻草人:销售算给客户听的正是这一项。

**真实口径** = 能耗 + (保险 + 保养 + 车船税)/年里程——固定成本按**你的里程**摊销,这是两本账的分水岭:跑得越多,固定摊越薄,电车能耗优势越显;跑得越少,固定摊越厚,什么能耗优势都被保费吃掉。电车的能耗单价是**加权电价** = 家充占比 × 家充价 + (1−占比) × 公充价——公充 1.35 元/度是家充 0.32 的 4.2 倍,「有没有桩」直接写进每一公里。

真实口径与营销口径的**比值**就是话术溢价:样例王家 8.9 倍、李家 26.6 倍——差额没有一分是「电贵了」,全是营销口径没算的部分。

### 3.2 回本几何(算术层)

落地差 D = (车价+购置税)差,一次性;年省 S = 两车年成本差,可分解为能耗差 + 保险差 + 保养差 + 车船税差(样例王家:省 ¥7,973 能耗 − 多花 ¥1,500 保险 = 年省 ¥7,323)。回本月数 = D/(S/12),闭式;逐月游走(每月还 D − S/12×m,首个非正)做第二算法对拍。三态语义钉死:**贵而省**(正回本)、**贵又不省**(追不平,None)、**便宜且省**(第一天就省,0)——「便宜但更费」从便宜车的视角看是第四态,账本把它翻译回第三态的镜像,回本不存在就是不存在。

### 3.3 翻转里程(判级层)

年成本差是 km_year 的仿射函数,回本超线 ⟺ 年里程 < k\* = (12D/cap − ΔF)/(−Δe)。这个阈值是本件最锋利的输出:样例王家参数下 **7,245 km**、李家参数下 **9,882 km**——同一对车,年里程掉到一万公里以下,「电车省」就在你的生活里失效。validate 用二分扫描独立对拍闭式反解。

### 3.4 三盏灯(判级层)

🔴 **PENNY-MYTH**(加权电价 > 家充价 × --penny-line 1.5,恰线不亮)——八分钱成立的前提是桩,公充占比让每公里电费先翻倍;🔴 **BREAKEVEN-NEVER**(回本 > --payback-cap 120 月,恰线不亮)——追平超出账本愿意辩护的年限;🟡 **INSURANCE-GAP**(年保费差 > 便宜车 × 25%,恰线不亮)——电车保费贵是真实成本,已摊进每公里,点名让看见;🔵 **HOME-CHARGING**(家充占比 > 0.6,恰线不亮)——唯一的蓝灯:桩一年替你省的钱,**省钱的不是电车,是家充桩**。

### 3.5 时间维度(向前,不向后)

本件没有 as-of——账本里没有日期,零墙钟自动成立。它的时间机器向前开:`breakeven --years` 逐年累计成本差表,第 N 年「← 反超」就是回本从数字变成事实的那一年。**向后取证是已有账的清算(躺亏),向前推演是未决账的预演(购车)——同一套时间美学,方向相反**。

## 4. 与直觉的三处对决

1. **「一公里八分钱」是错的——即使它算对了。** 4.3 分/km 的电费是真的,但它回答的不是「这辆车一公里多少钱」,是「这辆车的电费一公里多少钱」。保险摊、保养摊、购置税、公充溢价一样都不是电,一样都从你口袋出。真实口径 38.6 分——**不是电车不省,是省得没有销售说的那么多**;省不省得回差价,取决于你的里程和桩,不取决于话术。
2. **「电车省油钱」是错的半句话。** 完整的句子是「电车省能耗钱,保费要还回去一部分,差价要跑 N 年才追得平,你家没桩就追不平」。样例李家:电车每公里真实成本仍比油车便宜 21.6 分——**每公里都便宜,六年下来反而贵 ¥17,802**,因为差价追平是积分不是比较。
3. **「电池五六年一换八万块」也是错的。** 恐怖故事与话术是同一种东西:都是用一个数字替代一本账。账本的处理方式对两边一视同仁——不信,也不骂,给你参数:把 8 万按持有年限摊进 maint,结论自己会变。**恐怖故事经不起摊销,话术也经不起。**

## 5. 开发中自纠(测试价值记录)

1. **翻案参数污染全局**:`--gas-tax-rate` 直接写模块级变量,进程内第二次 `main()`(测试正是这样调的)被前一次的翻案值污染——11 项测试连环翻车,快照校验跟着炸。翻案参数必须走参数传递到底,任何「函数内部读全局常量」的写法在翻案链上都是断链——躺亏的姊妹教训第二次应验。
2. **红灯不红**:PENNY-MYTH 亮了而 report exit 0——`red` 标志只在 BREAKEVEN-NEVER 分支置位,新灯加了 append 忘了同步布尔。exit 语义必须从 lamps 列表推导,不靠手工同步的状态变量。
3. **二分方向写反**:翻转里程扫描把「payback>cap」归到 hi=mid——k 越大回本越短,方向恰好相反,收敛到错误的根。闭式反解 == 扫描的对拍当场抓住;没有第二算法的算术,方向错误永远沉默。
4. **手算连错,程序全对**:10 年 TCO 手算 ¥312,046.73,程序 ¥284,046.73(141,286.73+142,760,心算加法);函数级测试自造的样例车用默认价 15 万,落地差错成 8,713。关键数字一律独立手算对拍后钉进测试——第 N 次证明这套纪律防的是自己。
5. **灯的作用域与恰线**:HOME-CHARGING 曾对油车也亮(「油车·朗逸 家充 85%」——桩对油车不是资产是车位);初版 `>=` 让恰线亮灯,与全仓库「恰线不亮」美学冲突。灯要有明确的作用域,线要有统一的方向。
6. **三态语义混装**:「便宜但更费」初版返回 0.0——0 的语义是「第一天就省」,不是「没有回本」;breakeven 方向归一后沿用旧 months 也错。回本是三态(或镜像四态)的分支函数,每个分支的语义都要单独钉。

## 6. FAQ

- **汽车平台的「用车成本」工具不够用吗?** 它给全国平均:平均保费、平均电价、默认家充。你的桩、你的里程、你的城市电价、你看中的那两辆车的真实报价——参数是用户的,结论才是用户的;本件全部 6 个参数都是你抄的。
- **电车保值率差是真的,为什么不算折旧?** 二手车折旧的油电差异争议极大(车型/年份/电池技术剧变),账本不猜。要算进账:把差值按持有年限摊进 maint 或 purchase_tax,账本照算。本件给的是**持有期成本**,不是「卖掉那天的结果」——持有期成本是能抄准的,卖价是没人能预测的。
- **电池八万一块的恐怖故事呢?** 见「三处对决」第 3 条:摊进 maint,账本照算。账本不预测你换不换电池,只告诉你换了摊下来每月多少。
- **贷款买车呢?** 全款名义口径,不折现、不建模贷款。贷款的翻译是 stealth-interest 的领域(费率 vs 真实年化);本件管车的持有成本,那边管钱的价格。
- **绿牌/不限行值多少钱?** 城市变量,不折价。限行城市的路权差价请自己加进 purchase_tax 对拍——账本留了口子,不替你估价。
- **为什么不接接口自动填?** 车价/保险是「你的报价」,电价是你家电表的真实数字——抄一遍报价单是全部数据工程,也是结论可信的全部来源。账本不连任何接口。

## 7. 诚实条款(与 README 第七节同源)

营销口径是对话术的通识还原,以你听到的原话为准;真实口径全款名义加总、不折现(钱的时间价值不建模);折旧/电池更换风险/绿牌路权/保险折扣不建模,全部有摊销口子(maint/purchase_tax)但不替你填数;购置税留空走通识默认(油 price/1.13×10% 计税、电免征),新能源购置税 2026–2027 处于减半过渡期,**以办理日政策为准**,purchase_tax 列随时翻案,报告当场披露每辆车的税来自通识还是你填的;不荐车——报告输出的是账,买哪辆是人的决定,全绿的账也只说「这本账里它便宜」;购车是最贵的家庭决策之一,数字以你抄进账本的为准,账本不连任何接口不上传任何字节;零墙钟,账本无日期,同账任何机器任何一天逐字节一致。
