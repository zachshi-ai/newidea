# 八分钱 · Eight Cents

> 「一公里才八分钱,油车一公里六毛,一年省一万多。」电车销售递上来的这句话,是**他的算法**:13.5kWh/100km × 家充谷价,100% 家充、只算电费——不含保险差价、不含购置税、不含公共充电溢价,更不含「你家里有没有桩、一年跑多少公里」。油车销售反击的「电池五六年一换八万块」是同一种东西的镜像:一个数字,替代一本账。同一辆车两种算法,中间没有翻译——本件把翻译写出来:**用你的桩、你的里程、你抄的报价,把油电两本账并排算清,回本几年,追不平就明说**。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 正在油电之间纠结的家庭购车人——首购的年轻人、换购的老车主、给家里增购第二辆车的中年人;每个周末跑 4S 店、被两个销售的对轰夹着拍板的人 |
| **场景** | 电车销售说「一公里八分钱」,油车销售说「电池五六年一换八万」;平台工具给的是全国平均口径,不带你的充电条件;拍完板才发现老小区装不了桩;销售报价单上的保险比油车贵 1500,购置税政策 2026 年起减半——**这些散在五个对话框里的数字,从来没有人替你加总过** |
| **问题** | ①**话术口径冒充总账**——「八分钱」是能耗口径,固定成本(保险/保养/税)被从「每公里」里静默剔除,能耗差被讲成整车差;②**「有没有桩」不是便利问题,是资产负债表问题**——公充 1.35 元/度是家充 0.32 的 4.2 倍,加权电价直接写进每一公里,但没有话术会提这一条;③**「电车省不省」没有分母**——省的是每公里能耗,追的是一次性差价,追几年取决于你的年里程,而年里程只有你自己知道;④**购置税政策在过渡期**——「电车免税」是 2025 年的事,2026–2027 减半,报价单不会主动提醒 |
| **价值** | `report` 把每辆车翻译成「营销口径 vs 真实口径」的每公里解剖(样例:销售说 4.3 分,王家真实 38.6 分,**8.9 倍**——差额全是保险/保养/税的摊销,没有一分是「电贵了」)+ N 年 TCO 并排(王家电车 6 年便宜 ¥18,345;**李家反而贵 ¥17,802**)+ 三盏灯;`breakeven` 给回本几何:王家 **41.9 个月**追平、第 4 年反超,李家 **236.5 个月**——**同一对车,两个世界,结论不属于车,属于你的桩和里程**;翻转里程阈值:王家参数下年里程低于 7,245 km,「电车省」就失效 |

**本件不是**:不是荐车工具(report 输出的是账,不输出「买电车」;折旧/电池风险/绿牌路权不建模,要算自己摊进 maint)、不是贷款计算器(全款名义口径,钱的价格是 stealth-interest 的领域)、不是全国行情查询(全部 6 个参数都是你抄的,账本不发明市场)。

## 二、账本形态

一个目录两份手编 TSV(`--dir`,缺省当前目录)。数据源是**销售报价单、配置单和你家电表**,抄两辆车、抄一份你家的事实——这就是全部数据工程:

```tsv
# cars.tsv —— 候选车账(一行一辆;type=gas 油耗L/100km | ev 电耗kWh/100km)
name	type	price	energy100	insurance	maint	road_tax	purchase_tax	note
油车·朗逸	gas	129800	6.5	4000	800	350		1.5L 自吸 购置税留空走通识默认
电车·海豹	ev	159800	13.5	5500	300	0	7080	纯电 置≈159800/1.13×5% 减半口径
```

```tsv
# usage.tsv —— 用车事实账(一行一参数;同名 profile 构成一份你家的事实)
profile	key	value	note
wang	km_year	18000	跨城通勤
wang	home_price	0.32	自有桩谷时电价
wang	home_share	0.85	基本家充
li	home_share	0	老小区装不了桩 全靠公共
```

- **profile 是本件的灵魂开关**:同一对车,`wang`(有桩 85%,年 18000)和 `li`(无桩,年 6000)是两本完全不同的账——报告逐 profile 出账,`--profile` 单看一家
- **purchase_tax 留空 = 通识默认**(油 price/1.13×10% 计税;电免征),显式填了以填的为准;报告当场披露每辆车的税来自通识还是你填的,电车默认免征时附减半过渡期提醒
- **usage 只认 5 个键**:km_year/gas_price/home_price/public_price/home_share,未知键 = 账坏——宁可拒绝,不静默忽略写错的参数名

## 三、三命令

```
python3 eight_cents.py report              # 油电总账:营销口径vs真实口径解剖+年成本+N年TCO+三盏灯
python3 eight_cents.py breakeven --years 8 # 回本几何:落地差/年省分解/闭式回本/逐年推演/翻转里程
python3 eight_cents.py validate            # 恒等式与账本体检(全双路径对拍)
```

### 灯

| 灯 | 级别 | 语义 |
|---|---|---|
| **PENNY-MYTH** | 🔴 exit 4 | 电车的加权电价 > 家充价 × --penny-line(缺省 1.5,**恰线不亮**)——八分钱成立的前提是桩,你的公充占比让每公里电费先翻倍 |
| **BREAKEVEN-NEVER** | 🔴 exit 4 | 回本 > --payback-cap(缺省 120 月,**恰线不亮**)——差价追不平或追得太久;不是电车不好,是这本账跑不出回本 |
| **INSURANCE-GAP** | 🟡 | 两车年保费差 > 便宜车 × --ins-gap-line(缺省 25%,恰线不亮)——电车保费贵是真实成本,已摊进每公里,点名让看见 |
| **HOME-CHARGING** | 🔵 | 家充占比 > --home-line(缺省 0.6,恰线不亮)——唯一的蓝灯:桩一年替你省的钱摆上桌,**省钱的不是电车,是家充桩** |

### 退出码语义

`0` 绿灯/黄灯/蓝灯 · `2` 账坏(缺列/未知键/type 非枚举/负价格/能耗非正/km_year≤0/home_share 出界/缺必需参数/参数重复/车名重复) · `3` 空账或拒答(单车 breakeven、三车无 --pair、--pair 车名不存在) · `4` 任一红灯(PENNY-MYTH / BREAKEVEN-NEVER)

## 四、样例:同一对车,两个世界

王家(有桩 85%,年 18000 km)与李家(无桩,年 6000 km),看同一对车——油车·朗逸 129,800 / 电车·海豹 159,800(购置税减半 7,080):

- **销售的算法**:电车 4.3 分/km,油车 50.7 分/km——「一年省一万多」
- **王家的算法**:电车 38.6 分(能耗 6.4 + 保险摊 30.6 + 保养摊 1.7),油车 79.3 分——**8.9 倍于话术**;年省 ¥7,322.97(能耗省 7,973 − 保险多花 1,500 + 保养省 500 + 税省 350);落地多 ¥25,593.27 → **回本 41.9 个月,第 4 年反超**,6 年 TCO 电车便宜 ¥18,344.52;翻转里程 7,245 km 🔵HOME-CHARGING:桩一年省 ¥2,127.47
- **李家的算法**:电车 114.9 分(加权电价 1.35 元/度,能耗摊到 18.2 分),油车 136.5 分——**每公里电车仍便宜 21.6 分,但年省只有 ¥1,298.50** → 回本 236.5 个月 🔴BREAKEVEN-NEVER;6 年 TCO **油车反而便宜 ¥17,802.27**;加权电价是话术口径的 4.2 倍 🔴PENNY-MYTH
- `validate` 五重恒等式全绿:每公里分项加总==直接公式、加权电价==分段对拍、TCO 闭式==逐年累加、回本闭式==逐月游走(0/恰cap/追不平三态)、翻转里程闭式反解==二分扫描

## 六、与近邻的边界

- **odometer-illusion**:那边管**已有车**的两口钟(里程钟+日历钟,保养节奏),本件管**未购车**的选择对拍(油电 TCO+回本几何)——一个是养车账,一个是买车账;买完那天,本件退场,那边接手
- **stealth-interest**:那边翻译**钱的价格**(等本等息费率→真实年化),本件翻译**车的话术**(能耗口径→总持有口径);贷款买车时两边接力——它管月供里的水分,本件管车本身的账
- **cost-per-wear**:同是摊销方法论(吊牌价÷次数),那边**回看**已有衣物值不值,本件**前瞻**未购车怎么选——一个用已有的穿着记录,一个用将要跑的里程
- **repair-ledger**:那边是「修 vs 换」同一物的残命比较,本件是「油 vs 电」两个方案的并排账——续命是延缓清算,购车是开局对拍
- **dormant-loss**:那边的时间机器向后开(as-of 取证,已发生的躺亏),本件的向前开(逐年推演,未发生的反超)——同一套时间美学,清算 vs 预演
- **redemption**:那边对拍「提前还贷 vs 留着投资」(负债端的年度重投票),本件对拍「油车 vs 电车」(资产端的开局选择)——同构的 decide,两端的钱
- **true-pocket**:那边把医保结算单的五个数加总成「这次实掏」,本件把五个对话框的数字加总成「这辆车实掏」——同是对抗「分项各自都便宜」的账单幻觉
- **lowball**:那边管装修低价签单后的增项(签合同那一刻注定),本件管购车话术口径背后的差额(听报价那一刻注定)——同是「报价≠落地」的翻译器
- **felt-inflation**:那边用个人小票对抗官方 CPI 篮子,本件用你的参数对抗全国平均口径——参数是用户的,结论才是用户的

## 七、诚实条款

1. **营销口径是对话术的通识还原**(能耗×家充电价,100% 家充、只算能耗),不是稻草人也不是精确复刻——以你听到的原话为准;真实口径含什么,解剖表一行一行写着
2. **全款名义加总,不折现**——钱的时间价值不建模;不建模贷款(月供里的水分找 stealth-interest)
3. **折旧、电池更换风险、绿牌路权、保险折扣不建模**——二手车油电保值争议极大,账本不猜;每个都有摊销口子(maint/purchase_tax),自己填数,账本照算;恐怖故事与话术同罪:都不该绕过摊销直接吓人
4. **购置税留空走通识默认**(油 price/1.13×10% 计税、电免征);新能源购置税 2026–2027 处于**减半过渡期,以办理日政策为准**,purchase_tax 列随时翻案;报告当场披露每辆车的税来自通识默认还是你填的
5. **不荐车**:报告输出账,不输出「买电车」;BREAKEVEN-NEVER 说的是「这本账里追不平」,不是「电车不好」;蓝灯说桩省钱,不说去装桩——装不装、买哪辆,是人的决定
6. **保险是报价不是估算**——抄销售报价单,车损险电油差异真实存在;账本把保费摊进每一公里,让你看见它,不替你砍它
7. **购车是最贵的家庭决策之一,数据以你抄进账本的为准**——不连任何接口、不上传任何字节;抄两辆车、一份用车事实,是全部数据工程
8. **零墙钟**:账本无日期、不读时钟,同账任何机器任何一天逐字节一致,报告只打印账本目录名

## 八、快速开始

```bash
cd eight-cents
python3 eight_cents.py report --dir examples                  # 两家人的两本账(li 亮红灯 exit 4 是故事)
python3 eight_cents.py breakeven --dir examples --profile wang --years 8   # 第 4 年反超
python3 eight_cents.py breakeven --dir examples --profile li               # 236 个月,追不平
python3 eight_cents.py validate --dir examples                # 五重恒等式体检
python3 -m unittest discover -s tests                         # 59 项验收测试
```
