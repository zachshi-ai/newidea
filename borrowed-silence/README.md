# 预支安静 · Borrowed Silence

> 你今天每多听一分贝，都是向明天的安静借的债——这本账没有坏账核销，因为耳蜗毛细胞不会再生。
> Borrowed Silence — a zero-dependency ledger for an irreversible debt: every loud hour today is borrowed from the quiet of your future, and cochlear hair cells don't do bailouts.

---

## 一句话

听力损伤是所有慢性消耗里唯一没有「后悔药」的一种：咖啡因按半衰期代谢归零，跑步超量会超量恢复，唯独噪音对耳蜗的伤害**只增不减**——人耳约一万五千个毛细胞，死一个少一个，哺乳类不可再生。更糟的是剂量本身不可感知：噪音不疼不痒、没有宿醉感，等你在饭桌上第一次听不清对面的人，损失早已成为定局。直觉把音量当成「舒服不舒服」的偏好，身体把它当成**永不代谢的累积账**：地铁上为听清播客把耳机推到 100dB 的人，每个通勤日吃掉 4 个**安全日**（85dB×8h = 1.0），一场不戴耳塞的 livehouse（105dB×2.5h）= 31.7 个安全日——是一整周额度的 6 倍。`borrowed-silence` 的立场：**音量管理的最小可行单元不是「今天吵不吵」，是「这周额度还剩多少、终身账上又记了多少」**。工具从一本可手编的暴露账本（TSV：日期/时间/声源/时长/可选 dB/可选耳塞 NRR）按 NIOSH 3dB 交换率确定性记账：`day` 给当日判灯与 Leq(8h)，`week` 管每周重置的额度账（超支 10.7 倍这种事第一次有了数字），`plan` 把「这周末的演出」对余量过闸——不塞耳塞 31.7 sd 直接 exit 4，塞 NRR32 只花 1.77：同一晚的两种活法差 18 倍，耳塞从口号变成打折券；`lifetime` 记那本只增不减的终身账。耳鸣记录是身体开出的超载回执，账本替你留着对账。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 每天地铁通勤戴耳机的上班族与学生——尤其「音量不推到盖过噪音就听不清」的人；乐迷、KTV 与健身团课常客、乐器排练者；耳机日均 2 小时以上、从不知道「分贝」和自己有关的任何人。 |
| **场景** | 地铁车厢里把音量一格一格往上推的那一刻（环境 85dB，耳机盖噪常到 100dB）；朋友问「周末去不去 livehouse」时（去，还是换个安静的酒馆）；散场后耳朵嗡嗡响、心想「睡一觉就好」的那一刻；体检报告出现「高频听力下降」四个字之后。 |
| **问题** | **剂量与损伤在时间上被切断，且损伤不可逆**：① 噪音暴露没有即时体感——不疼、不累、不留宿醉，剂量在毫无感觉中累积，而毛细胞死亡是不可再生的；② 直觉用「吵不吵」当标尺，但 85dB 的地铁与 100dB 的耳机之间差的是 32 倍能量，直觉对指数物理完全失灵；③ 「大事件」的真实代价没人算过：一场 2.5 小时 105dB 的演出 = 31.7 个安全日，等于不眠不休在 85dB 车厢里站 10 天半，这个数字从来不存在于任何人的决策里；④ 耳鸣（TTS 症状）是身体开出的超载回执，但「睡一觉就好」的文化让它被系统性无视；⑤ 现有工具止步于「分贝计读数」——瞬时读数回答不了「这周还剩多少额度」「这场演出值不值」。 |
| **价值与意义** | ① **安全日单位**：把指数物理翻译成可加减的账（1.0 = 85dB×8h，每 +3dB 同时长剂量翻倍），通勤、演唱会、KTV 第一次能记进同一本账；② **双账本结构**：每周重置的额度账回答「这周怎么活」，只增不减的终身账回答「这么活下去的长期代价」——额度会重置，损伤不会，两本账的存在本身就是本件的论点；③ **耳塞经济学**：NRR32 折减 12.5dB 后，同一场演出从 31.7 sd 跌到 1.77 sd，`plan` 把「戴耳塞」从长辈唠叨变成 18 倍的折扣券；④ **耳鸣回执**：症状行不计剂量，但永远浮出在报告里——它是身体的对账单，不是「睡一觉就好」的小事；⑤ 零依赖 + 纯本地 + 日期全部钉死，逐字节可复现。 |

## 核心思想：把「吵不吵」换成「剂量账本」

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **安全日 safe-day** | `sd = 时长 × 2^((L−85)/3) / 8`；85dB×8h = 1.0，88dB×4h = 100dB×15min = 1.0 | 「这段暴露值多少额度？」 |
| **3dB 交换率** | NIOSH REL：每 +3dB，安全时长减半——能量上自洽的对数物理 | 「为什么耳机比地铁贵 32 倍？」 |
| **耳塞折减** | 实际减免 = (NRR − 7) / 2 dB（NIOSH derating，给真人而非实验室的折扣） | 「戴耳塞到底省多少？」 |
| **Leq(8h)** | `85 + 10·log10(总 sd)`：一天摊成 8 小时连续暴露的等效声级 | 「今天整体相当于多吵？」 |
| **周额度账** | 5.0 sd/周（= 40h @ 85dB，职业一周上限），`--budget` 可调紧 | 「这周还剩多少可花？」 |
| **终身账** | 全账本累计 sd，只增不减；只记物理剂量，不预言听阈 | 「这么活下去的长期代价？」 |
| **症状回执** | `symptom` 行（耳鸣/耳闷）不计剂量，但永远浮出在报告里 | 「身体的对账单记在哪？」 |

三条诚实条款刻在实现里：**账本只算物理剂量，不预言听力**——同样的终身暴露，听阈结局因人而异（ISO 7029 的个体分布横跨几十 dB），本件给的是「有账可查的暴露史」，不是听力图，持续耳鸣超过 48 小时请去看耳科；**声源表是中位数，不是你的耳朵**——地铁 80–95dB、耳机档位换算的误差很大，第 5 列 dB 永远可以覆盖，配合手机分贝计 App 校准，「宁可贵在覆盖，不贵在精确」；**交换率选严不选宽**——OSHA 的 5dB 交换率是执法妥协，本件采用 NIOSH 3dB（能量上自洽、更保守），WHO 更严的 80dB 无风险线用 `--budget` 一行就能切换。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 命令速查

```bash dd:ignore
python3 borrowed_silence.py day examples/week.tsv --date 2026-09-05        # 当日判灯（红 → exit 4）
python3 borrowed_silence.py week examples/week.tsv --end 2026-09-06        # 周额度账（超支 → exit 4）
python3 borrowed_silence.py plan examples/week.tsv livehouse 2:30 \
       --week-of 2026-09-10                                                # 演出对余量过闸（PLUGS/OVER → exit 4）
python3 borrowed_silence.py lifetime examples/week.tsv                     # 终身账：只增不减
python3 borrowed_silence.py sources                                        # 声源缺省表
python3 borrowed_silence.py validate examples/week.tsv                     # 账本体检
```

账本是一份可手编的 TSV（Tab 分隔），第 5 列 dB 覆盖声源表缺省，第 6 列记耳塞 NRR；`symptom` 行只记症状、不计剂量：

```
2026-09-05  20:30  livehouse  2:30        32
2026-09-05  23:40  symptom    tinnitus
```

## 一个真实样例

地铁通勤耳机党小陈，一个月账本见 [examples/week.tsv](examples/week.tsv)（79 行）。周六晚上 livehouse 散场，他看了一眼当天（[examples/sample-day-red.txt](examples/sample-day-red.txt)，退出码 4）：

```
2026-09-05 周六
日剂量  31.7 安全日  ████████████████████████ (3175% of 1.0)   RED
Leq(8h)  100.0 dB(A)  折成 8 小时连续暴露的等效声级

事件分解（最贵的在上）：
  20:30  livehouse           2:30  105.0 dB →   31.7 sd

⚠ 身体的对账单：23:40 记录 tinnitus——耳鸣/耳闷是超载的回执，建议次日保持 <70dB（cafe 以下）
```

一整周的额度账（[examples/sample-week.txt](examples/sample-week.txt)，退出码 4）把模式说穿了他从没算过的账：

```
周总剂量  53.3 安全日   ████████████████████████ (1065% of 周额度 5.00)

超支  48.3 安全日 —— 你这周借走了 10.7 周的安静
额度按周一重置，损伤不重置：终身账 lifetime 只增不减。
```

五个平平无奇的工作日各吃 4.30 sd（通勤耳机 1h@100dB = 4.0），周六一场演出再翻七倍——「就通勤听听歌、周末去了一次现场」的直觉，与账本之间差着 10.7 周。

下周末朋友又约 livehouse。`plan` 把这个决定翻译成两条命（[examples/sample-plan-plugs.txt](examples/sample-plan-plugs.txt)，退出码 4）：

```
  不戴耳塞         105.0 dB →    31.7 sd
  戴 NRR32 耳塞       92.5 dB →    1.77 sd（折减 12.5 dB）

裁决  PLUGS —— 裸奔超余量 6.3 倍，戴上 NRR32 后只花 1.77 sd，装得下（剩 3.23）。
同一晚的两种活法差 18.0 倍：耳塞不是懦弱，是打折券。
```

而 [examples/sample-lifetime.txt](examples/sample-lifetime.txt) 记着那本不会重置的账：26 天里 146.6 个安全日（年化 2059 sd/年），46% 花在通勤耳机、43% 花在 livehouse，外加 3 次身体的回执。额度按周一重置，损伤不重置。

## 与哪些点子不混淆

- 与 **afterburn**（余燃）：同样记「剂量 × 时间」，但咖啡因按半衰期**代谢归零**，噪音剂量**永不代谢**——一个算「今晚血里还烧多少」，一个算「这辈子还剩多少安静」；流动账与累积账，机制上互为镜像。
- 与 **redline**（加量红线）：同是「负荷额度」思路，但跑量超限后身体能超量恢复、越练越强，听力超限没有恢复这回事——红线是转速表，这里是没有倒挡的里程表。
- 与 **midnight-oil**（深夜灯火）：都记「看不见的慢性消耗」，一个从 git 时间戳测燃烧的作息，一个从暴露账本测耳朵的债——一个透支的是精力（可补觉），一个透支的是毛细胞（不可再生）。
