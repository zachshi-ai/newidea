# METHODOLOGY · 预支安静

本文回答「这些数字从哪来、边界在哪、为什么这么设计」。一句话：**剂量是物理，听阈是医学；本工具只做前者，并对后者保持沉默。**

---

## 1. 物理基础：分贝是对数，直觉是线性的

声强级 `L = 10·log10(I/I₀)` dB：声能量每翻一倍，分贝只 +3。人的直觉按分贝线性读数——「100dB 比 85dB 大一点」，但能量上 100dB/85dB = 10^1.5 ≈ **32 倍**。这就是为什么「地铁里把音量推高两格」不是小事：每 +3dB，同样时长的剂量翻一倍。对数物理与线性直觉的这道裂缝，就是本工具存在的理由。

## 2. 剂量公式：NIOSH REL 与 3dB 交换率

美国国家职业安全卫生研究所（NIOSH）1998 年推荐暴露限值（REL）：**85 dB(A) 8 小时 TWA 为 100% 日剂量**，交换率 3dB——

```
允许时长 T(L) = 8h / 2^((L − 85) / 3)
剂量 sd(L, t) = t × 2^((L − 85) / 3) / 8        （单位：安全日，1.0 = 一个满额工作日）
```

| 声级 dB(A) | 安全时长（= 1.0 sd） | 直觉换算 |
|---|---|---|
| 85 | 8 h | 一个工作日 |
| 88 | 4 h | |
| 91 | 2 h | |
| 94 | 1 h | |
| 97 | 30 min | |
| 100 | 15 min | 通勤耳机 1h = 4.0 sd |
| 103 | 7.5 min | |
| 105 | ~4.7 min | livehouse 2.5h = 31.7 sd |
| 110 | ~2.4 min | 演唱会 1h = 40.3 sd |

**为什么不用 OSHA 的 90dB / 5dB 交换率**：OSHA 标准是 1970 年代的执法妥协，5dB 交换率在能量上不守恒（85dB 8h 与 90dB 8h 等价意味着 +5dB 能量只翻 3.16 倍却给了 8 倍时长），NIOSH 与 WHO 均建议 3dB。本件选严不选宽。**为什么不用 WHO 的 80dB / 40h 周**：那是「无风险」保护线（比职业线严 3 倍），日常记账会全员红灯、失去区分度；本件缺省用职业线做周额度，`--budget 1.58` 一行即可切到 WHO 线（40h@80dB 折算 = 12.7 等效 85dB 小时 ≈ 1.58 sd）。

## 3. 「安全日」单位的设计

账本需要一个能把指数物理变成加减法的单位。百分比（NIOSH 剂量 %）的问题是一周额度 500%、演唱会一晚 3175%，数字大到麻木。**安全日**（85dB×8h = 1.0）的好处：它对应一个所有人都懂的东西——一个完整工作日的职业暴露上限；「这场演出 = 31.7 个安全日」比「3175%」更像一笔债。Leq(8h) 作为辅助读数（`85 + 10·log10(总 sd)`）方便与分贝计读数对照。

## 4. 耳塞：从口号到打折券

厂商标称的降噪值 NRR（Noise Reduction Rating）是实验室理想佩戴值。NIOSH 建议 derating：**实际减免 = (NRR − 7) / 2 dB**——戴法歪一点、眼镜腿夹一点、头发垫一点，减免就打对折。本件全程用折减值：NRR32 泡沫塞折减 12.5dB，105dB 的 livehouse 变成耳内 92.5dB，2.5 小时从 31.7 sd 跌到 1.77 sd。**这 18 倍的差距就是「戴耳塞」的全部意义**：它不是舒适偏好，是把不可负担的债打折到可负担。参数里给的是保守折扣；「耳塞存放在出门必带的口袋」比任何数字都重要。

## 5. 双账本：为什么额度会重置，损伤不会

职业卫生的剂量记账以「日/周」为单位，因为身体对声暴露有**有限的短期恢复**（TTS 消退、内耳稳态回复）——这是周额度可以周一重置的依据。但反复超限的恢复并不完全：长期看毛细胞死亡不可再生（哺乳类耳蜗 lacks 再生能力，鸟类可以、人不行）。所以本件强制两本账：

- **周额度账**（`week`/`plan`）：行为指导，回答「这周怎么活」，超支 exit 4；
- **终身账**（`lifetime`）：物理事实，只增不减，回答「这么活下去的长期代价」。

终身账**只记物理剂量、不换算听力损失**：同样暴露史的人，40 岁时的听阈可以差几十 dB（ISO 7029 个体分布），任何「你已损失 X% 听力」的数字都是编造。账本给你暴露史，听力图归听力计。

## 6. 耳鸣与 TTS：身体的对账单

散场后的耳鸣、耳闷、听人声发蒙，是**暂时性听阈偏移**（TTS）的症状——耳蜗在报警。TTS 本身可逆，但流行病学共识是：反复 TTS 是永久性 shift（PTS）的风险信号，「睡一觉就好」的文化让这个报警被系统性无视。账本里 `symptom` 行不计剂量（症状不是暴露），但永远浮出在 `day`/`week`/`lifetime` 报告里——它的角色是**对账单**：剂量说「你借了」，症状说「身体开始催债了」，两者对上的时候，账本只是让你没法再假装没看见。**本工具不做医疗判断；持续超过 48 小时的耳鸣、或单耳突发的听力下降，请直接看耳科**（突发性聋是按小时抢时间的急症）。

## 7. 手机音量怎么估 dB：诚实的不确定度

手机音量条没有分贝刻度，本件的粗估规则：

- **耳机在安静室内**：50% 档 ≈ 65–75dB，75% 档 ≈ 85–95dB，90%+ ≈ 100dB+（设备差异巨大）；
- **耳机在地铁/公交**：为盖过 80–90dB 环境噪，音量常被推到 95–105dB——这是全账本最贵的一行（小陈的账里占 46%）；
- **校准**：装一个 SPL 分贝计 App（手机麦克风测环境声够用），在地铁上量一次车厢噪声、在「平时音量」下用另一台设备贴近耳机量一次，把这两个数写进账本第 5 列。

估不准怎么办？**宁可高估**：把 95 记成 100 的误差是 3.2 倍，把 100 记成 95 的误差是自欺。声源表给的是中位数，第 5 列永远可以覆盖。

## 8. 声源表的出处与波动

内置表取公开文献与测量报告的常见中位（dBA）：地铁车厢 80–95（拥挤线路与新线差异大）、影院 75–90（动作片峰值更高）、livehouse/演唱会 100–110（位置决定一切：音响前 vs 吧台）、KTV 包厢 95–105、健身团课 90–100（为氛围）、吹风机 65–75、割草机 85–95。**同一声源的方差可以到 ±10dB**，所以表只是缺省：惯常去的那个 livehouse 是 108 还是 98，量一次写进第 5 列，从此账本属于你。

## 9. FAQ

**Q：我天天通勤听歌好多年，不也没聋？**
A：三件事你可能没测过——高频听阈（4kHz 听损在语音频段之前，日常对话完全察觉不到）、噪听力损失的「储备」设计（人耳出厂冗余约 20dB，损失在储备内叫「正常」）、幸存者偏差（已经耳鸣的人不发朋友圈）。高频听力下降的第一个受害者是听不清鸟叫和擦玻璃声，第二个受害者是饭桌上的对话。

**Q：降噪耳机算不算保护？**
A：算，而且是真保护——降噪把底噪压掉后，同样的内容只需要更小的音量，这是唯一一种「听得清但剂量更低」的路线。但账本仍要记：降噪后的耳内声级才是计费声级（用第 5 列覆盖）。

**Q：为什么 exit 4 这么多？**
A：因为工具的门卫职责就是把不可负担的决定挡回去：日剂量超 1.0、周额度超支、plan 装不进余量，都是同一句话——**这笔债现在的你付得起，未来的你付不回**。绿灯不需要你，红灯才需要。

**Q：儿童和青少年呢？**
A：更严。发育中的耳蜗与更长的暴露年限意味着同样剂量代价更高；WHO 对青少年的建议（40h/周 @ 80dB）可以直接用 `--budget 1.58` 启用。

**Q：音乐人 / 录音师怎么办？职业需要监听。**
A：入耳式监听（IEM）+ 限幅器是职业保护的标准配置，账本照记不误——你的耳朵是生产资料，这本账对你不是健康文娱，是设备维护计划。

## 10. 边界与免责

- 本工具计算的是**暴露剂量的物理账**，不诊断、不预测、不建议任何医疗方案；
- 声源表与音量估算是**中位数近似**，最贵的几行值得用实测校准；
- 与任何账本一样，它的全部价值建立在**记满**上——漏记的 100dB 通勤不会因为你没记就不吃你的毛细胞。
