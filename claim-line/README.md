# 报险线 · Claim Line

> 报保险的标价是 ¥0，真实价格写在你未来 2–5 年的续保单里。一次 ¥600 的
> 剐蹭报了商业险，隐身保费 ¥6,300——自费线从来不是「2000 以下私了」这种
> 常数，它是你保费的函数。

## 一句话

把「出险了报保险还是自掏腰包」从手感变成一行算术：从你的保单账 + 出险账
重放无赔款优待（NCD）路径，算出**自费线**（= 再报一笔的边际隐身保费），
并审计你为过去的报险已经付掉、还将付掉多少**看不见的保费**。

## 角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 有车的人。车被剐蹭的那一刻，4S 店催你「走保险吧」、对方催你「别报 insurance 涨保费」、你自己拿着一句民间口诀「2000 以下别报」两头打摆 |
| **场景** | ① 停车场剐蹭/追尾的 24 小时决策窗，报不报保险当场要表态；② 续保季看到保费从 4,200 跳到 6,000，「莫名其妙」；③ 年底盘点，发现今年已经报过一次险，第二刀砍不砍 |
| **问题** | 1. **标价幻觉**：报保险的现金标价是 ¥0（保险公司付），真实价格是未来 2–5 年 NCD 折扣的蒸发——示例账本里那笔 ¥600 的报险，全价 **¥6,300 = 维修费的 10.5 倍**。没有人在出险当场替你算这笔账<br>2. **常数口诀是错的**：「2000 以下别报」对保费 3,000 的人是过度自费、对保费 10,000 的人是还不够——自费线是**保费的函数**：深折扣位上 ≈ 1.05× 基准保费，折扣烧断后只剩固定加罚 0.25× 基准/笔<br>3. **第 2 刀悖论**：今年已报过险的人再报一笔只要 1,500，而等一年再报同一笔要 3,000——折扣在重新攒，「反正已经出过险」第一次有算术依据，「等等再报」其实是涨价前锁定<br>4. **免费出口没人走**：无责赔案不进你的账本（你的保险公司没付钱就没有赔款记录）；对方车 2,000 以内的财产损失走交强险，隐身 ≈ ¥570（浮动独立于商业 NCD、幅度小一个量级）——两个出口都没有人换算过 |
| **价值** | decide 给出险当场开五路裁决（CASH / CLAIM / TIE / CTP / OTHERS，带 exit code 可进脚本）；report 审计每笔历史报险的**真实价格定价单**、已付隐身保费与恢复期尾款、冤案榜；renewal 预演下次续保多付多少、记在哪笔出险头上；simulate 跑 cash / claim / ctp / never-claim 四种活法的恢复期总账；validate 做恒等式体检。全部本地计算、不连任何接口、账本自锚定，同一本账任何机器逐字节一致 |

## 验收标准

| # | 验收项 | 判据 |
|---|---|---|
| 1 | NCD 先验表 | 加罚 (1.00, 1.25, 1.50, 1.75, 2.00) 严格递增、折扣 (0.85, 0.70, 0.60, 0.50) 严格递减，越界封顶；`--ncd-sur/--ncd-dis` 整表可覆盖 |
| 2 | 深位烧折扣 | 连无赔 2 的位置报第 1 笔：全价 = (0.40+0.35+0.20+0.10) × 基准 = **1.05× 基准**（基准 6,000 → ¥6,300，恢复期 4 年）；连无赔 3 更贵：0.50+0.35+0.20+0.10 = **1.15×**（¥6,900） |
| 3 | 烧断后固定加罚 | 本年已报 1 笔后再报：隐身保费恰 = **0.25× 基准**（¥1,500），恢复期 1 年——对 (1,1)、(0,2)、(0,3)、(0,4) 四个状态全部成立 |
| 4 | 第 6 笔免费 | 上年出险已封顶 2.00 时（(0,5)），再报一笔的边际隐身保费 = 0 |
| 5 | 两世界必平 | 维修费恰 = 自费线时，报险路径总账 − 无赔路径总账 ≡ 全价（数值残差 < 1e-6，对 (2,0)/(1,1)/(3,0)/(0,0) 四状态钉死）；线下一分钱自掏赢、线上一分钱报险赢 |
| 6 | 边际可加 | 从同一状态连报 4 笔的边际之和 ≡ 两路径直接作差（残差 0.00e+00） |
| 7 | 无责不计次 | fault/channel = other 的赔案对 NCD 路径零影响（你的保险公司没付钱），定价单点名「不占赔款次数」 |
| 8 | 路径恒等式 | 实缴保费 15,300 = 无赔世界 10,800 + 已付隐身 4,500（逐位钉死）；已付隐身 4,500 + 恢复期尾款 6,900 ≡ Σ 逐笔全价 11,400（基准一致时） |
| 9 | 冤案门禁 | 全价 > `--overclaim-line`（默认 3.0）× 维修费 → OVERCLAIM exit 4：示例 ¥600 报险全价 10.50x 在册 |
| 10 | 五路裁决 | decide：cost 1200 → CASH exit 4；1800 → CLAIM exit 0；1550 → TIE exit 0（±`--band` 10% 掷币带，1350/1650 恰在边界内）；`--fault other` → OTHERS exit 0；`--target other` cost 1200 → CTP exit 0（交强隐身 570 三者最便宜）；cost 300 → CASH exit 4（连交强都不值得动） |
| 11 | 免赔额 | `--deductible 500` 把实际线从 1,500 抬到 2,000：同一笔 1600 无免赔 CLAIM、有免赔 CASH |
| 12 | 手动模式 | 无账本时 `decide COST --base B --clean N --claims-ytd M` 当场开庭：--base 6000 --clean 3 → 自费线 6,900；无账本又无 --base → exit 3 并给手动模式提示 |
| 13 | 交强小账 | CTP 隐身 = (0.30+0.20+0.10) × 交强基准 950 = **¥570**（按满折位假设，`--ctp-*` 可调）；交强限额内才有此选项（`--target other` 且 cost ≤ `--ctp-limit` 2000） |
| 14 | 续保预演 | renewal：下次续保 NCD 1.00 → 6,000，无赔反事实 4,200，delta 1,800 记名到 2026-03-11 那笔大修；delta/保费 > 25% → NCD-BURN 横幅；路线图标出与从未出险的重合年 |
| 15 | 薄账分层 | 保单 < 2 个保单年 → 已付隐身与冤案判级 DECLINE exit 3，定价单照出（5000/0.85 账上 800 的报险照算 6.25x）；空 own 账本 → 「没有 own 赔案——保持」exit 0 |
| 16 | 账本体检 | 坏表头/未知 fault/channel/非正金额/坏日期/赔案早于首张保单/超出末年/保单间隔出 300–400 天带/ncd 不在表内 → exit 2；ncd 列与重放对质不一致 → 逐行点名（保单永远赢，账要亮出来）；隐含基准 max/min > 1.15 → WILD-BASE 横幅 |
| 17 | as-of 截断 | `--as-of` 把账针拨回过去（截断语义不是错误）：as-of 2026-01-01 时 3 月大险不可见、状态重算为 (1,0)、自费线 5,100；600 冤案仍在场 exit 4 |
| 18 | 可复现 | 全件无墙钟：缺省 as-of = 账本末日，同一本账任何机器任何一天逐字节一致；报告只打印 basename，不回显调用方路径 |

## 快速开始

```bash
# 历史审计：你为过去的报险多付了多少隐身保费
python3 claim-line/claim_line.py report claim-line/examples/policies.tsv claim-line/examples/claims.tsv

# 出险当场：这笔 1200 报不报
python3 claim-line/claim_line.py decide 1200 --policies claim-line/examples/policies.tsv --claims claim-line/examples/claims.tsv

# 蹭了对方的车：走交强还是自掏还是商业险
python3 claim-line/claim_line.py decide 1200 --target other --policies claim-line/examples/policies.tsv --claims claim-line/examples/claims.tsv

# 没有账本？出险路边手动开庭（基准保费与状态问你的续保报价单）
python3 claim-line/claim_line.py decide 5000 --base 6000 --clean 3 --claims-ytd 0

# 续保预演 / 反事实沙盒 / 账本体检
python3 claim-line/claim_line.py renewal claim-line/examples/policies.tsv claim-line/examples/claims.tsv
python3 claim-line/claim_line.py simulate never-claim --policies claim-line/examples/policies.tsv --claims claim-line/examples/claims.tsv
python3 claim-line/claim_line.py validate claim-line/examples/policies.tsv claim-line/examples/claims.tsv
```

## 账本格式

两本手编 TSV，`#` 开头为注释。**保单账** `policies.tsv`（一行一个保单年，
保费抄商业险保费合计、不含交强险与车船税）：

```text
start       premium  ncd   note
2023-09-15  4200     0.70  连续两年无赔续保
2024-09-15  6000           出险一次续保（重放 1.00）
2025-09-15  5100           无赔一年续保（重放 0.85）
```

- `ncd` 可留空（按出险史重放）；给了以保单为准，与重放不一致会被 validate 点名
- **出险账** `claims.tsv`（一行一次出险）：

```text
date        fault  channel  cost   note
2024-06-03  mine   own      600    停车场剐蹭门板，报了商业险
2025-01-20  other  other    2300   被追尾，对方全责走对方保险
2026-03-11  mine   own      12000  追尾大修：大灯总成+钣金喷漆
```

- `fault`：mine（有责）/ other（无责）
- `channel`：own（自己商业险，烧 NCD 的唯一通道）/ ctp（自己交强险）/ other（对方或第三方）/ cash（自费未报）

## 与近邻的边界

- **repair-ledger**：那边裁决修还是换（拥有期的器件经济学，钱花给师傅，修完不涨价）；本件裁决报还是自掏（保险经济学，钱花给保险公司的未来，报完保单会涨价）。
- **redemption**：那边证明提前还贷 = 一笔年化等于合同利率的无风险投资（负债端）；本件证明不出险 = 攒一段每年 +0.10~0.15× 基准的折扣资产（保险端）——同样都是「名义外的真实价格」，一个在贷款合同里，一个在费率浮动表里。
- **safety-floor**：那边审人身险的保额够不够（出事接不住）；本件审车险的出险用不用（小事动不动）——保与用的分界。
- **card-tax**：储值卡的闲置余额是正向 prepaid（你 prepaid 的钱没花掉）；NCD 是反向 prepaid（你用「不出险」 prepaid 的折扣，一次赔案花掉一截）。
- **border-budget**：签证的 90/180 是每天回血的滚动窗口；出险配额是按保单年清零的年度窗口——同为会清零的额度，回血节奏不同。
- **stealth-interest**：那边翻译「名义 0 利率」的分期，本件翻译「名义 ¥0」的报险——两个标价幻觉共用同一副眼镜。
- **lowball**：装修合同里没有的东西不是不花钱是还没开始收（对方的笔）；商业险里出险没有标价不是不花钱是记在未来（保险公司的表）。

## 诚实条款

- **先验不是监管文本**：NCD 表与交强浮动是 2020 商车综改行业示范口径的通识先验，`--ncd-sur/--ncd-dis/--ctp-*` 整表可调；你的保单、续保报价单、保险公司客服永远赢。
- **基准不变假设**：保费 = 基准 × NCD × 自主定价系数 × 交通违法系数，本件只对 NCD 建模、假设基准两世界共享；隐含基准逐年漂移 >15% 会被 WILD-BASE 横幅点名——那时保费跳变里混着自主系数或险种变更，判级前请知道这个假设在响。
- **不发明状态**：连续无赔年数与赔案次数以账本重放为准；首张保单的 ncd 列是唯一的锚，留空按新保 1.00 处理并披露。账本只记你声称的事实，它不连 12123、不抓保单——抄一遍账本就是对整段保险史的一次 verify。
- **交强是假设账**：交强险没有独立账本，CTP 裁决按「满折位」假设（最保守：把交强隐身算贵，不轻易劝你走交强）；`--ctp-clean` 可调。
- **不构成投保/理赔建议**：它是计算器不是保险顾问；欺诈性报案、骗赔、路径优化成「故意的剐蹭经济学」都不在本件的射程里——它只把标价 ¥0 背后的价格表挂出来，报不报，人的决定。
