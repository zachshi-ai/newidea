# 欠休 · Leave Debt

> 年假是工资的一部分，却是唯一不发对账单的工资：月薪迟到一分钟你都知道，三天年假作废一分钱声音都没有。本件把年假当成**按批次计息的债权**来记账——批次 FIFO 先到期先消耗、作废在到期日终了入账、损失折成钱、节奏外推预测年底蒸发几天、拼假杠杆算出你把额度花在了哪种假上。
> Paid leave is the only part of your salary that never sends a statement. Leave Debt books it as interest-bearing debt: batches expire in FIFO order, voids post at the stroke of midnight, and your vacation shape finally gets a leverage ratio.

---

## 一句话

HR 系统只给你一个余额数字——不给批次、不给到期日、不给「按你自己的休假节奏，年底会有几天蒸发」的预测；「去年剩的 3 天 3 月底清零」散落在员工手册第 14 页，从没有人对着你的余额算过；休了 9 天和真休了假，在 HR 报表里长得一模一样。本件用两本可手编的 TSV（`grants.tsv` 批次授权：哪天授予、几天、哪天清零；`leave.tsv` 休假流水：哪天开始、几天、annual/other）重放出五本账：**批次账**——FIFO 先到期先消耗，到期日当天可用、日终作废，守恒恒等式「授予 = 已休 + 作废 + 余额」残差 0.00e+00；**损失账**——作废天数 × 日薪（示例账本：3/31 日终作废 1.0 天 = ¥600，无声蒸发）；**节奏账**——时间进度 90.9% vs 消耗进度 45.0%（落后 45.9pp），burn 0.0196 天/天线性外推：年底将作废 4.9 天 = ¥2,912；**形状账**——连休段 = 极大连续自由日区间（自由日 = 休假 ∪ 周末 ∪ 法定日 − 调休补班日），拼假杠杆 = 段跨度 ÷ 段内年假：10/9 休 1 天吃到整座国庆桥杠杆 9.0，9/29 休 1 天悬在周中杠杆 1.0——**桥就一板之隔**，平均杠杆 3.69x、碎片段 3/7（消耗额度却几乎不产出恢复）；**还款计划**——剩余 5.5 天 ÷ 5 窗 > 常态节奏 1.0 天/周，如实判 INFEASIBLE：注定作废 0.5 天（¥300），连休或放弃，二选一。`simulate` 给单笔休假过闸：一次休 5.5 天能把预计作废压回线内（exit 0），休 1.5 天之后仍超线 27.3%（exit 4）——**一发入魂救不了，要的是节奏**。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 有年假额度却从不盘点它的打工人；3 月底结转年假悄悄作废、连自己有过这 3 天都不记得的老员工；司龄跳档后额度变了但从未核对过批次的人；年底被 HR 一句「假期月底清零」突袭、手头项目正 crunch 排不进去的骨干；休了一堆「东一天西一天」的碎片假、体感却比上班还累的认真工作者。 |
| **场景** | 12 月中旬 HR 群发「未休年假作废」通知的那个下午；3 月底结转额度清零、无声无息的那一天；国庆拼假攻略里纠结「请 9/29 还是 9/30」的那一晚；年底复盘「今年好像休过假？」翻遍日历才发现最长连休只有 2 天的那个瞬间；项目 crunch 中盘算「现在休假会不会太不合群」的每一次犹豫。 |
| **问题** | ① **假期是工资，但它是唯一不发账单的工资**：日历记录你要去哪，HR 系统只显示一个余额数字——批次、到期日、作废倒计时全部黑箱，作废发生时连一行日志都没有；② **结转规则是黑箱**：「上年结转额度次年 3 月 31 日清零」写在员工手册里，从没有工具把它翻译成「你还有 X 天将在 Y 日死亡」；③ **休假形状没有度量**：休了 9 天散成 7 个碎片和休了 3 次长假，在「已休天数」里是同一个数字，而恢复价值天差地别；④ **拼假没有杠杆账**：周五请 1 天连周末休 3 天（杠杆 3.0）和周三请 1 天（杠杆 1.0）消耗同一个额度，没人算过你把额度花在了哪种假上——9/29 休是 1.0，9/30 休是 9.0，桥就一板之隔；⑤ **年底冲刺没有还款计划**：剩 5 天、33 天清零、项目 crunch——每周该休几天？装不下的话注定作废几天？这笔「休息债务」的还款表没人排过。 |
| **价值与意义** | ① **批次白箱**：每批债权有授予日、天数、到期日，FIFO 先到期先消耗——「先休哪批」从不用纠结，作废倒计时第一次可见；② **损失折钱**：作废天数 × 日薪（`--daily-rate` 或 `--monthly-salary` ÷ 月计薪天数；不给工资就不折钱——不发明你的收入），蒸发的工资第一次有对账单；③ **节奏预警**：时间进度 vs 消耗进度、burn 线性外推年底作废——「按你自己的节奏，今年要有 4.9 天直接蒸发」从感觉变成判决，双门禁（临期 45 天/预测线 15%）全可调；④ **拼假杠杆**：连休段合并（周末桥、法定桥、调休补班日反桥）把「休得聪明不聪明」变成一个可比较的比率，平均杠杆与碎片段点名最亏的那笔钱；⑤ **还款计划**：周窗口分摊 + 常态节奏上限（pace-cap），装不下时如实说 INFEASIBLE 并给出注定作废的天数和金额——休息是工资，不休假是自愿降薪；⑥ 门禁分层诚实：批次临期是账本事实，账再薄也爆灯；节奏外推是统计推断，覆盖 < 60 天或年假行 < 3 如实 DECLINE exit 3；⑦ 零依赖 + 纯本地 + 不连任何 HR 系统，休不休、什么时候休，仍是人的决定。 |

## 核心思想：把「余额数字」换成一本债权账——批次会死，桥有杠杆

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **批次债权** | 每批授权 =（授予日，天数，到期日）；到期日当天可用、日终清零 | 「我的假期里，哪几天然着 fuse？」 |
| **FIFO 消耗** | 休假按日期优先消耗最早到期的批次（同到期日先授予的先用） | 「这笔假动用的是哪批债权？」 |
| **作废入账** | as-of 晚于到期日时，到期日终了的余额记作废——作废也是账本事件 | 「已经无声蒸发了几天的工资？」 |
| **守恒恒等式** | 授予 = 已休 + 作废 + 余额（残差钉到 1e-9） | 「账本自洽吗？」 |
| **节奏账** | burn = 年假已休 ÷ 覆盖天数；预测作废 = max(0, 余额 − burn × 剩余窗口) | 「按我自己的节奏，年底会蒸发几天？」 |
| **门禁分层** | L1 临期（余额 > 0 且 ≤45 天清零，算术事实，薄账也爆）；L2 节奏（预测作废 > 授予 15%，统计推断，薄账 DECLINE） | 「现在是不是已经该动身了？」 |
| **连休段** | 极大连续自由日区间（自由日 = 休假 ∪ 周末 ∪ `--holidays` 法定日 − `!` 调休补班日），头尾桥都吃 | 「这笔假实际买来了几天连休？」 |
| **拼假杠杆** | 段跨度 ÷ 段内年假天数；≥2.0 聪明假 / 1.5–2.0 平价假 / <1.5 全价假；span < 2 为碎片段 | 「同样 1 天额度，我买回了几天？」 |
| **还款计划** | 余额按周窗口分摊（每窗 ≤ pace-cap），先到期先还；容量不足判 INFEASIBLE 并给出注定作废量 | 「现在开始还，还来得及吗？」 |
| **模拟过闸** | `simulate --take N --on D`：动用哪批、余额变化、预计作废前后对比 | 「这一笔假能救回来多少？」 |

三条设计立场刻在实现里：**「今天」绝不取自系统时钟**——缺省 as-of = 账本最大日期（含批次到期日：作废也是事件），`--as-of` 显式钉死，同一本账任何机器任何时间跑出的结果逐字节一致；**算术门禁不拒答，统计门禁拒薄账**——批次临期是账本事实，账再薄也爆灯（exit 4 优先），而节奏外推依赖你自己的历史节奏，覆盖 < 60 天或年假行 < 3 时如实 DECLINE（exit 3），宁可不说也不编一个判决；**不发明你的收入**——不给 `--daily-rate` / `--monthly-salary` 就只报天数不折钱，日薪默认月薪 ÷ 21.75（中国劳动法口径，`--pay-days` 可覆盖）。

**与近邻的边界**：midnight-oil（深夜灯火）从 git 时间戳量**燃烧端**——你在怎么把自己烧掉；本件量**恢复端**——公司欠你的休息你兑付了几成，它管加班的账，本件管休假的账。year-like-a-day（度年如日）量日子的**新意密度**，本件量休息的**债权去向**——一个管回忆的厚度，一个管额度的死亡。social-jetlag（社交时差）管睡眠的**生理恢复**（睡在钟面哪里），本件管休假的**制度兑付**（额度死在日历哪里）——一个是身体的账，一个是劳动法的账。expiry-cliff（到期悬崖）给凭证装提前量（有效期是**资产**，到期前要办手续续命），本件给假期排还款计划（有效期是**工资**，到期不领即没收）——两者共享「到期」的语法，但一个是防失效，一个是催兑付。smooth-sailing（旱涝保收）平滑现金流的波动，本件清算休息债权的存量——钱和时间是你仅有的两种可过期资产，各记一本。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 账本格式

两本可手编的 TSV（`#` 开头为注释行）：

`grants.tsv` —— 批次授权（一行一批债权）：

```
grant_date	days	expires	note
2025-01-01	3	2025-03-31	2024 年结转，3 月底清零
2025-01-01	10	2025-12-31	2025 年度额度（司龄 3 年档）
```

`leave.tsv` —— 休假流水（一行一次休假）：

```
date	days	type	note
2025-02-14	1	annual	周五错峰，搭了个周末
2025-04-30	1	annual	五一前一天，桥值 6 天
2025-12-24	1	other	调休一天，额度外
```

规则：`days` 为 0.5 步进（半天合法）；`type=annual` 消耗额度，`other`（调休/病假/事假）只占连休段、不救年假；休假不得早于批次授予（预支 exit 2）、不得超出当时可用余额（透支 exit 2）。

`examples/holidays.txt`（可选，`--holidays` 提供）—— 法定节假日与调休补班：

```
2025-10-01..2025-10-08
!2025-09-28
```

一行一个 ISO 日期或 `a..b` 区间为假日；`!日期` 为调休补班日（本该休息的周末要上班，从自由日里扣掉）。没有它，长假桥不生效、形状账会看短——工具会在 validate 里如实披露。

## 用法

```
python3 leave_debt.py report   grants.tsv leave.tsv [--as-of D] [--holidays F]
                              [--monthly-salary M | --daily-rate R]     # 批次账+损失账+节奏账+门禁
python3 leave_debt.py shape    grants.tsv leave.tsv [--holidays F]      # 连休段+拼假杠杆+碎片
python3 leave_debt.py plan     grants.tsv leave.tsv [--pace-cap 1.0]    # 还款计划（INFEASIBLE 判决）
python3 leave_debt.py simulate grants.tsv leave.tsv --take 1.5 --on 2025-12-08   # 单笔休假过闸
python3 leave_debt.py validate grants.tsv leave.tsv                      # 账本体检（守恒恒等式）
```

Exit 码：`0` 正常；`2` 账本结构损坏（坏日期/步进外/预支/透支/expires 反序）；`3` 拒答（覆盖 < 60 天或年假行 < 3 时的统计判决、查无批次、模拟过去）；`4` 红线（批次临期作废、节奏性作废超线、还款计划装不下）。

## 验收标准

| # | 验收项 | 标准 | 状态 |
|---|---|---|---|
| 1 | 批次 FIFO | 休假优先消耗最早到期批次（同到期日先授予先用）；到期日当天可用、次日起不可用；溢出精确落到下一批 | ✅ |
| 2 | 作废语义 | as-of > 到期日时日终余额入账作废；as-of = 到期日当天不作废；作废量按**到期日终**的余额算，不受之后休假影响 | ✅ |
| 3 | 守恒恒等式 | 授予 = 已休 + 作废 + 余额，残差 < 1e-9（示例账本 + 10 组确定性伪随机账本全过） | ✅ |
| 4 | 损失折钱 | 作废 × 日薪；`--daily-rate` 直给或 `--monthly-salary` ÷ 21.75；不给工资参数只报天数、输出无 ¥ | ✅ |
| 5 | 节奏外推 | burn = 已休 ÷ 覆盖天数；预测作废 = max(0, 余额 − burn × 剩余窗口)，负值截断；时间进度 vs 消耗进度逐批披露 | ✅ |
| 6 | 门禁分层 | L1 临期（余额 > 0 且 ≤ `--warn-days` 清零）为算术事实，薄账也爆；L2 节奏（预测作废 > 授予 × `--forecast-line`）为统计推断，薄账 DECLINE；exit 4 优先于 exit 3 | ✅ |
| 7 | 连休桥接 | 段 = 极大连续自由日区间，头尾桥都吃：周五休 1 → span 3；4/30 + 五一 → span 6；10/9 吃国庆尾桥 → span 9；`!` 调休补班日断桥（9/29 span 1） | ✅ |
| 8 | 拼假杠杆 | 杠杆 = 段跨度 ÷ 段内年假；≥2.0 聪明 / <1.5 全价 / 其间平价；半天杠杆翻倍；other 占段不进分母；平均杠杆 = Σspan ÷ Σannual 年假加权 | ✅ |
| 9 | 还款计划 | 余额按 ceil(剩余天数/7) 个周窗口分摊（每窗 ≤ `--pace-cap`，先到期先还）；窗口容量 < 余额判 INFEASIBLE，缺口 = 余额 − 窗数 × cap，与逐窗分配表一致 | ✅ |
| 10 | 模拟过闸 | 动用 FIFO 批次、余额前后对比、预计作废前后对比；透支 exit 2、模拟过去/查无批次 exit 3 | ✅ |
| 11 | 拒答与护栏 | 覆盖 < 60 天或年假行 < 3 → 节奏/形状统计 DECLINE exit 3（段落表仍输出——日历算术不拒）；坏日期、0.5 步进外、预支、透支、expires ≤ granted、type 未知 → exit 2 | ✅ |
| 12 | 可复现 | 无 `date.today()`/`datetime.now()`；缺省 as-of = 账本最大日期（含到期日）；`--as-of` 截断未来流水并披露条数；同账重跑逐字节一致 | ✅ |
| 13 | 测试与快照 | 66 tests 全绿；`examples/build_examples.py --check` 对三本账与六份输出做字节级校验；CI 门禁 + advisory 快照 | ✅ |
