# 同框 · Same Frame

> 日历记你要去哪,相册记你拍过什么——**没有任何一本账记录「全到齐」这件事的间隔**。缺席是渐进的:先缺席聚会,再缺席照片,最后只剩空位;人眼对月尺度的渐进彻底失明,「下次再拍」的下次从不来。本件把每次聚齐抄成一行账,让「全家到齐已经 697 天」「爷爷 652 天没出现在照片里」第一次有分母。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 异地家庭的成员——城镇化一代的常态:爷奶在老家,三兄妹在城里,一年聚两三次;以及任何一个「总想着拍全家福」的家庭 |
| **场景** | 家族群翻照片,上一张全家同框是三年前的婚礼;每次散场都说「下次再拍」,下次从不来;某天发现爷爷的照片越来越少——他好像正从每张照片里退出去,而没有人说得出「上一张有他的照片是哪天」 |
| **问题** | 相册存了照片,但没有账:「全家到齐」的间隔、「谁在从照片里退出」、「哪两个人再也没有同框过」,没有一行记录。缺席是**渐进的**(fat-creep 式的月尺度蠕变,只不过退出去的不是体重,是人),而渐进正是肉眼的结构性盲区;等「看起来不对」的时候,空位已经在那很久了 |
| **价值** | 把「多聚聚」从叮嘱变成三个数字:①**全体同框间隔**(样例:13 次聚会只有 4 次全齐,上一次是 697 天前);②**成员间隔与缺席 streak**(样例:爷爷上次出现是 2024-11-16,652 天,连续缺席最近 6 次聚会——🔴 FADED);③**成对同框矩阵**(样例:爸妈同框 10 次,爷爷和奶奶 5 次,小妹和爷爷只有 4 次——上次还是 697 天前)。账本不数「还剩几次」,它只数**已经空了多久**——看见是它的全部功能 |

**本件不是**:不是预测(不算「还能同框几次」——那是算命加卖焦虑)、不是归因(缺席有千种原因:穷/忙/病/远/怨,账本一个都不猜)、不是指控(FADED 不是谁的错,是没人记着的数字)。

## 二、账本形态

手编 TSV,3 列,一行一次聚齐——拍完照随手记,5 秒钟:

```tsv
date	event	who
2024-10-02	国庆	爷爷,奶奶,爸,妈,大姐,二哥,小妹
2024-11-16	爷爷住院复查	爸,大姐,爷爷
```

- **date** 聚齐的那天(合影当天最好);**event** 场合可空;**who** 在场成员,逗号/顿号/分号/空格均可作分隔,**首见即注册**(不设名册表,写过的名字就是家里人)
- 「在场」是你声称的事实——照片为证最好,记忆也可以;「全体成员」= 写过的所有人的并集,所以一个只在第一行出现过的人,会把「全员同框」永远锚在第一行(这是特性不是缺陷:他缺席了之后的所有聚会,这正是账本要说的)
- 一场聚齐里同一名字写两次 = 账坏(引用同一个两次不是多一个人);`--alias 爷=爷爷` 可以后补归一

## 三、三命令

```
python3 same_frame.py report    # 成员表(在场率/上次/间隔/缺席streak)+ 全体同框 + 两盏灯
python3 same_frame.py pairs     # 成对同框矩阵,按「多久没同框」降序
python3 same_frame.py validate  # 恒等式与账本体检
```

公共参数:`--ledger`(缺省 `family.tsv`)、`--as-of`(时间机器,缺省 = 账本自身最大日期,零墙钟)、`--full-line N` / `--fade-line N`(两盏灯的线,缺省 365 天)、`--alias`。

### 退出码语义

| 码 | 含义 |
|---|---|
| 0 | 绿 |
| 2 | 账坏:坏日期(不补零/不存在的日历日)、who 空、一行内重复成员、缺列、坏 alias(含把两个名字归一后撞重的) |
| 3 | 空账(零字节/纯注释/有表头零行/文件不存在);薄账(<2 次聚会——间隔至少需要两个时间点,成员表照出) |
| 4 | 账面红灯:🔴 DRIFT(全体同框间隔 > full-line,或**从没有过全员同框**——那是 DRIFT 最响的形态)/ 🔴 FADED(某成员 > fade-line 没出现在任何一行) |

恰线语义:间隔恰等于线的日子不亮灯,超出一天才亮——宁可少报一天,不多冤枉一天。

## 四、样例:陈家的 2023–2026(13 次聚会,7 口人)

爷奶在老家,三兄妹在城里。2023 年春节到 2026 年奶奶生日,账上 13 次:

- **全体同框**:4 次(2023 春节、大姐婚礼、2024 春节、2024 国庆)——**上一次全家到齐是 697 天前**,🔴 DRIFT
- **爷爷**:7 次在场(53.8%),最后一次是 2024-11-16 的住院复查——**652 天没出现在任何一张照片里**,连续缺席最近 6 次聚会,🔴 FADED。2025 年春节第一次没有他的年夜饭,账上一行就一句 event:「春节」
- **时间机器**(`--as-of 2025-10-04`):那天全体同框已 367 天(DRIFT 恰过线),而爷爷 322 天没出现——**离 FADED 还有 43 天**。灯不是某天突然亮的,是一天天走过来的;账本让你在还来得及的时候看见它走
- **pairs**:爷爷和奶奶 5 次同框(最后是住院复查那次),爷爷和小妹 4 次;而妈和爸 10 次、妈和大姐 10 次——**同框次数的分布,就是这个家此刻的形状**

## 五、验收标准

| # | 验收标准 | 验证方式 |
|---|---|---|
| 1 | 恒等式:Σ各成员在场次数 ≡ Σ各行 who 人数;Σ成对同框次数 ≡ Σ各行 C(k,2);独立路径重算两两全等 | validate 双路径 + 字面值钉死(69=69、162=162) |
| 2 | who 解析:逗号/全角逗号/顿号/分号/空格均可分隔;行内重复成员 exit 2;who 空 exit 2 | 网格测试 |
| 3 | 日期严格:不补零与不存在的日历日一律 exit 2;行序无关(按日期重放,文件顺序不影响结果) | 网格 + 乱序测试 |
| 4 | 尾部制表符容忍(手编粘贴);缺列不容忍;注释与空行跳过 | 网格测试 |
| 5 | 空账(零字节/纯注释/有表头零行/文件不存在)exit 3;`--as-of` 早于一切行 exit 3 | 网格测试 |
| 6 | DRIFT:全体同框间隔恰 365 天不亮,366 天亮;从没有过全员同框 = DRIFT 最响形态,亮灯 | 阈值测试 |
| 7 | FADED:成员间隔恰 365 天不亮,366 天亮;缺席 streak = 账本尾部连续缺席次数 | 阈值测试 |
| 8 | 只在首行出现的成员把「全员同框」锚定在该行——随后每次不全员的聚会都在拉大这个间隔 | 锚定测试 |
| 9 | 薄账分层:<2 次聚会,间隔不存在(DECLINE exit 3),成员表照出 | 分层测试 |
| 10 | `--full-line` / `--fade-line` 一句话翻案;`--alias` 归一成员名、自映射幂等、归一后撞重 exit 2 | 翻案测试 |
| 11 | 时间机器:晚于 as-of 的行被排除(非报错);灯的状态随 as-of 逐日演变(2025-10-04 时 DRIFT 恰亮、FADED 未到) | 回放测试 + 字面值 |
| 12 | 零墙钟:as-of 缺省 = 账本自身最大日期;同账任何机器任何一天逐字节一致;报告只打印 basename | 双跑比对 + 路径断言 |

## 六、与近邻的边界

- **[渐行渐远](../drift-apart/)**(联系频率):那边按**关系**记**联系**——聊天间隔、沉默斜率、单程指数,一段关系一条节奏,线上的心跳;本件按**家庭组合**记**同框**——线下聚齐的影像证据,一个组合一份间隔。两本账可以同时记账:每周视频(drift-apart 全绿)但三年没全齐(本件红灯)——**线上心跳不等于线下同框,聊得再多也替代不了一张全员到齐的照片**。
- **[度年如日](../year-like-a-day/)**(初事密度):那边记**第一次**(新异事件,回忆的长度),本件记**重复事件的间隔**(全到齐的稀缺度)——一个管新,一个管齐;那边怕日子过得太快,本件怕人到得越来越不齐。
- **[年轮](../kin-ring/)**(家族病史):同是家族的账,那边问「家里谁得过什么病、几岁确诊」(问诊桌上的三句话),本件问「全家人多久没有真正到齐过」——一个管病,一个管人;那边怕问晚了,本件怕见晚了。
- **[数字阁楼](../digital-attic/)**(媒体库普查):那边**扫存量照片库**(文件系统的人口普查,管存储结构),本件手编**同框事件流**(拍完记一行,管人的在场)——不读文件系统,相册的治理归阁楼,人的到齐归本件。
- **[渐行渐远之外,handoff](../handoff/)** 交底管要紧物在哪(身后被找到),本件管人在不在(身前还同框)——一个怕东西找不到,一个怕人看不见。

## 七、诚实条款

- **账本不预测寿命、不数「还能同框几次」。** 那是算命加卖焦虑;它只数已经空了多久。FADED 的文案是陈述不是警报器:「absence has a thousand reasons and this is none of them」——缺席有千种原因(穷、忙、病、远、怨),账本一个都不猜,一个都不归罪。
- **「在场」是你声称的。** 照片为证最好,记忆也可以;账本记的是「你记得的同框」,补记允许,它不假装知道你没写下来的聚会。
- **薄是真实。** 一年只聚两次的家庭,账本就只有几行——薄不是坏,薄是这个家此刻的形状;判线按你自己的节奏 `--full-line` / `--fade-line` 翻案,城市家庭的频率不是标尺。
- **看见不等于修复。** 账本亮了灯,约不约、回不回、谁先开口,永远是人的决定——它只拒绝让你继续「以为没事」。
- **家庭关系是最敏感的数据。** 账本只存本地,不连任何接口,不上传任何字节;报告只打印账本文件名,不回显路径。
- **零墙钟。** as-of 缺省锚定账本自身最大日期,`--as-of` 是时间机器不是今天;同一本账任何机器任何一天跑出的结果逐字节一致。

## 八、快速开始

```bash
cd same-frame
python3 same_frame.py report  --ledger examples/family.tsv   # exit 4:FADED + DRIFT,设计内
python3 same_frame.py pairs   --ledger examples/family.tsv
python3 same_frame.py validate --ledger examples/family.tsv
python3 -m unittest discover -s tests                        # 44 tests
```

维护成本:拍完照记一行,一年十几行——这本账的全部成本,是一句「来,看镜头」的顺手。
