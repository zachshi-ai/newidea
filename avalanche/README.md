# 雪崩 · Avalanche

> 复习积压是**每天自动加息的债**——今天没碰的卡，明天连本带息回到队列。间隔复习的崩盘从来不是遗忘曲线的错，是排程的错；而 App 只肯给你看「今日到期 3352」这一个数，从不告诉你：债的存量是多少、进水比排水快多少、照此趋势哪天崩盘、哪 22 张卡在拖垮整个系统。等你在点开 App 的那一瞬间感到恶心、把牌组暂停再也不看的时候，三个月的记忆系统一夜作废——**雪崩不是一瞬间发生的，是每一片没清理的雪**。

## 它是什么

一本手编的间隔复习积压账本（2 个 TSV + 一个零依赖 Python CLI）。把**每日到期流水、惯犯卡名册**钉成同一本账，在四个时刻给你四样从来没有人给过的东西：

| 时刻 | 账本回答的问题 | 命令 |
|---|---|---|
| 每天复习完 | 债滚到多大了？利差多少？哪天崩盘？ | `report` |
| 手痒想加新卡 | 今天这 N 张新卡，你的日流水养得起吗？ | `add N` |
| 意识到不对劲 | 冻结新卡还来得及吗？每天加倍要多久清零？ | `simulate` |
| 复习越来越像点手指 | 是哪些卡在把遗忘率顶上去？ | `leeches` |

## 角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 用任何间隔复习工具（Anki / SuperMemo / 墨墨背单词 / Quizlet / 考研·医考·法考卡组）的自学者——记忆系统是他亲手搭的资产，也是他唯一没有对过账的资产 |
| **场景** | ①开工雄心每日 30 新卡，蜜月期全都清得动；②开学/加班后日清偿能力掉一半，而新卡一张没停；③某天「今日到期」四位数，硬扛两周越还越多；④点开 App 感到恶心，暂停牌组，再也不打开 |
| **问题** | 积压是每天自动加息的债：今天欠的卡明天带着逾期回到队列，逾期越久、复习失败率越高（遗忘曲线），失败又让卡更快回到队列——**拖延本身在给债加息**。App 只显示单日流量，不显示债的存量（卡·日）、表面利差（到期压力−清偿能力）、结构利差（老卡回炉流−清偿能力，决定冻结新卡能不能自救）、崩盘日、惯犯卡的遗忘集中度。用户在信息盲区里凭意志力硬扛——而排程问题从来没有意志力解法 |
| **价值** | `report` 把「我是不是不行」翻译成「你的日历不行」：崩盘日提前几周亮出来；`add` 在加新卡前过配额闸（quota = 能力−压力，配额是今天的余量不是终身额度）；`simulate` 给出冻结/加倍两情景的最早清零日，或一纸 MATH-DEAD 判决（结构性超载只能砍牌组或加时间，不是加自律）；`leeches` 用遗忘帕累托点名惯犯卡，挂起建议附「每天至少少几张到期」的下界 |

## 样例账本讲了什么故事

小林，考研英语，一本 3600 张的核心词牌组，120 天（2025-09-01..12-29，缺 3 天没打开 App）：

- **蜜月（9/1–9/28）**：假期里 done=due，一天没欠过——「我状态很好」。没人告诉他 30 张/天的新卡管道正在装填弹药：每张新卡是一个终身到期流的起点。
- **开学（9/29）**：日清偿能力掉到 60 张/天，当天欠 59 张。**他从未停过加新卡**。
- **10/5（开学第一周）**：`report --as-of` 回放这一天——积压 417 张，已经越过当期崩盘线 330，OVERFLOW 亮灯。比他第一次跑账早了 **85 天**。
- **考试月（10/19–11/13）**：每天只付得起 12 张复习，积压从一千涨到一千九。注意：**他一天都没断**（除了 10/9–10/11 三天抽屉日）——60 张/天也好、12 张/天也好，他每天都在还，只是新卡管道比他的水管粗。
- **恢复期（11/14 起）**：回到 60 张/天，但积压已 3000+，而且逾期卡片大量复习失败——遗忘率涨到 **83.8%**：拖了两个月的卡，看了也白看。这 60 张复习里有 51 张明天就回来重新排队。
- **12/29 第一次跑账**：积压 **3352** 张（全牌组的 93%），债 **171,711 卡·日**，表面利差 +2910/天——`OVERFLOW` exit 4。`simulate`：冻结新卡？老卡回炉流 89/天 > 能力 60/天，`MATH-DEAD` exit 4——**连什么都不加都救不动了**；每天加倍到 120 张，最早 **2026-04-17** 清零（109 天）。`add 30`：配额 0（近 28 天他还在往水里加 840 张新卡），`LEVERAGED` exit 4。
- **leeches**：2092 张卡有前科；遗忘高度集中——前 20% 的卡占全部遗忘的 **40.5%**；22 张惯犯卡（≥8 次遗忘，Anki 同款线）占 5.8% 的遗忘，挂起它们每天**至少**少 6.9 张到期。双账核对：名册 lapses 合计 3313 ≡ 每日 again 合计 3313。

这条曲线真正令人难受的地方在于：**每一步都「合理」**——假期多学点没毛病，开学忙一点没毛病，考试月少复习点没毛病。雪崩从来不在单日的决定里，只在 30 张/天 × 120 天的乘法里。

## 方法一句话

每日欠账 carried = max(0, due − done)（App 的 due 本来就含逾期回炉，所以欠账自动滚入明天）；债 = Σcarried（卡·日）；清偿能力 C 与到期压力 D 取尾随 28 个记账日的下中位数；新鲜进水 F = 中位（due − 前日欠账），即**剔除积压惯性后老卡的真实回炉流**；表面利差 = D−C（今天流多少血），结构利差 = F−C（冻结新卡后能否自愈）；崩盘线默认 3×C（积压超过三个日能力，复习已从记忆作业退化成手指运动），照表面利差线性外推得崩盘日，落入 42 天窗口即 AVALANCHE。

## 快速开始

```bash
python3 avalanche/avalanche.py report avalanche/examples/reviews.tsv --leeches avalanche/examples/leeches.tsv
python3 avalanche/avalanche.py report avalanche/examples/reviews.tsv --as-of 2025-10-05
python3 avalanche/avalanche.py add avalanche/examples/reviews.tsv 30
python3 avalanche/avalanche.py simulate avalanche/examples/reviews.tsv
python3 avalanche/avalanche.py leeches avalanche/examples/reviews.tsv --leeches avalanche/examples/leeches.tsv
python3 avalanche/avalanche.py --help
```

两个 TSV（[examples/](examples/) 有完整样例）：

- `reviews.tsv` —— 每日一行，数字在 App 首页都有，抄 30 秒：`date/due/done/again/new`
  - `due`：App 显示的今日到期数（**含逾期回炉，不含新卡**——Anki 与墨墨首页口径）
  - `done`：今日完成的复习数（不含新学）
  - `again`：其中答错（遗忘）的张数
  - `new`：今日新学新卡数
- `leeches.tsv` —— 可选，**完整**遗忘名册：`card/lapses`（每张卡的历史遗忘次数；Anki 卡浏览页的 Lapses 列，或统计面板的 leech 列表）。给出则做双账核对与遗忘帕累托。

`--as-of` 是截断回放：钉回任何一天看「当时的账」，未来行不进重放。缺省 as-of = 账本最大日期；源码无墙钟，同一本账任何机器任何一天逐字节一致。

## 判级与退出码

| 退出码 | 含义 |
|---|---|
| 0 | 正常（HARVEST / TREADING / ACCRUING / PASS / FEASIBLE / CLEAN / LEDGER OK） |
| 2 | 账坏：结构非法（缺列/负数/again>done/日期乱序/非法日期/双账不平等） |
| 3 | 薄账 DECLINE：<7 个记账日，统计判级拒答，存量算术照出 |
| 4 | 门禁红：`OVERFLOW`（积压已越线）/ `AVALANCHE`（崩盘日落入 42 天窗口）/ `LEVERAGED`（加新卡超过配额）/ `MATH-DEAD`（冻结也永远清不完）/ `KILL-LIST`（存在 ≥线的惯犯卡） |

## 与近邻的边界

- **pace-gap 赶考线**：同是学习域，那边对账**进度**（章节覆盖 vs 考试日的 required/proven/peak 三速率），本件对账**记忆维持的债务动力学**（进水-排水利差与积压存量）。备考可以 pace-gap 绿灯而雪崩红灯：复习完了全部章节，和复习过的东西还记不记得，是两本账。
- **leave-debt 欠休**：同为「债+作废」结构，但年假是**雇主授予的批次债权**（FIFO 消耗、到期作废、拼假杠杆），本件是**自我生成的每日到期流**（无授予方、无批次、积压自动复利）。那边问「休掉没有」，这边问「还记得住吗」。
- **todo-rot 承诺锈蚀**：TODO 没有排程器，承诺半衰期是统计僵尸；本件的每一笔债都有调度器给出的确切到期日，且未偿还的债**主动生息**（逾期卡回炉+失败率上升）。
- **silent-rot 暗蛀**：那边是治疗只做加法的器官棘轮（等级不可逆），本件是队列只做加法的排程棘轮（积压不可逆）——机制同构（看不见的单向恶化），资产不同（牙齿 vs 记忆），数据源不同（病历事件流 vs 每日流量）。
- **past-prime 超役**：那边是买入即倒计时的**实体判废**（日历年限），本件的卡片不判废——逾期只是变贵，不会死。
- **dusty-subs 吃灰订阅**：那边是持续付费的服务闲置（钱在漏），本件是免费资产的维护欠账（记忆在漏）；共同点只在「闲置不是零成本」。

## 诚实条款

账本不是记忆科学家，不建模遗忘曲线的形状，只用你自己的 again 流计量遗忘；不建模 Anki 的当日重学步（again 卡按次日回炉的保守口径）；崩盘投影是速率恒定的线性外推，F 恒定假设下清零日是**最早**下界（清掉的卡会按间隔回流，真实清零只会更晚）；卡·日债只按记账日累计，断更日的债没有入账——真实债更大。账本从不说「你不该学这么多的」，它只说管道多粗、水池多满、哪天漫堤；冻结不冻结、砍不砍牌组、约不约考试，永远是人的决定。
