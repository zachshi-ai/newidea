# 人情账 · Gift Ledger

> 请帖到手的那一晚，你要在 24 小时内拍出一个数——这本书替你把账算完，随不随仍是你的事。
> The invitation gives you 24 hours to invent a number. A zero-dependency CLI that keeps a two-way, inflation-adjusted reciprocity ledger — and prices the next red envelope from history instead of anxiety.

---

## 一句话

随礼是人情社会里唯一「**当场定生死、事后无对账**」的支付：金额是场合基线 × 关系层级 × 通胀年代 × 两人历史余额的四变量函数，没有人手算得出，全靠碎片记忆加焦虑——而记忆只记得「**他上次随多少**」，从不记得「**我上次随多少**」。同一份人情在两颗心里各记一版，账对不齐的那天，关系就散了。`gift-ledger` 的立场：**随礼是支付，人情是余额——支付是流水的学问，余额才是关系的学问**。工具从一本可手编的往来账（TSV：日期/方向/对方/关系/场合/金额）确定性算出：每段关系的**净余额**（全部历史按通胀折算到今日购买力，正 = 你欠着人情）、请帖之夜的**建议区间**（基线 × 关系系数 × 场合系数为骨架，对方当年同场合随礼折算成**对价锚**托底，未平余额计入下限但按两倍基线封顶）、全员**余额排行**与**礼崩名单**（只进不出超线 → exit 4）、以及从你自己的随礼史里读出的**随礼通胀率**（样例自证 9.5%，常年跑赢 CPI——它随的是面子，不是篮子）。账本不教你讨债，它只拒绝让任何人假装没看见方向。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 人情往来密集期的成年人——正在被婚礼请帖、满月酒、乔迁宴轮番轰炸的上班族；办过喜事、收了一堆礼将来都要还的人；给家里记账、替爸妈管人情往来的年轻当家。 |
| **场景** | 收到请帖的当晚（「表妹下月结婚，我该随多少」）；办完自己的喜事翻旧账时（「姑姑随了 2000，这份情怎么还」）；年底盘点时（「老周这五年我只进不出……还是只出不进？」）；夫妻对账时（「你记的是他随 600，我记得明明是 800」）。 |
| **问题** | ① 金额是**四变量函数**（基线 × 关系 × 场合 × 往来余额），直觉只能算一个变量，剩下三个全靠拍脑袋；② 往来余额是**双向账**且要跨年代比较——他 2019 年随的 500 和你 2026 年要还的礼，中间隔着 40% 的购买力差，记忆不做复利；③ 回礼**只有一次机会**，当场定生死，而没有任何工具在事前帮你算——事后的「随少了」只能变成心里的疙瘩；④ 单向关系**静默恶化**：只进不出的人不觉得自己在欠，只出不出的你不好意思提，直到某天对不齐，关系散伙——礼崩没有声音。 |
| **价值与意义** | ① **净余额**：`Σ 折算(收进) − Σ 折算(随出)`，把「感觉他没回礼」变成「表哥还欠 311 元（今日值）」；② **对价锚**：婚对婚的直接对价是通行礼俗，账本把「他当年随你 500」折算成「今日对价 701」，建议下限自动托底——礼金市场的**棘轮**（只升难降）第一次有了精确刻度；③ **建议区间有结构**：场面骨架（基线 600 × 关系系数 × 场合系数）定上沿，对价锚与未平余额抬下沿，大额旧账按两倍基线封顶——**剩下的一半明示「不是一张请帖能平的账」**；④ **礼崩 gate**：折算欠额超线 + 三年无往来 + 从未回流，三条件同时满足才亮灯 exit 4——它不是讨债工具，是防自欺工具；⑤ **随礼通胀自证**：从你自己随出的年度中位数里挖几何年化（9.5%），差假设超过 2 个点就建议重跑折算；⑥ 零依赖 + 纯本地 + `--as-of` 钉死逐字节可复现。 |

## 核心思想：把「人情感觉」换成「双向余额」

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **折算 adjust** | `金额 × (1+通胀)^间隔年数`，全部折到基准日购买力；`--inflation` 可调，也可用 `inflation` 自证值 | 「2019 年的 500 元今天算多少？」 |
| **净余额 balance** | `Σ adj(in) − Σ adj(out)`，正 = 你欠人情；判定带 = max(200, 15%×总流) | 「我和他之间，到底谁欠谁、欠多少？」 |
| **对价锚 anchor** | 对方最近一次同场合随你的折算值；婚对婚直接对价，白事不通胀不讲对价 | 「他当年随 500，我今天最少回多少？」 |
| **建议区间 suggest** | 下限 = max(0.8×骨架, 对价锚, min(未平余额, 2×骨架))，上限 = max(1.5×骨架, 1.25×下限)，取整到十元 | 「请帖在手，今晚拍哪个数不失礼也不破产？」 |
| **礼崩 gate** | ① 折算欠额 ≥ 红线（1000）② 任意方向 ≥ 3 年无往来 ③ 对方从未随礼或流入不足你流出一半——三条同时成立 → exit 4 | 「这段关系是不是只剩一个方向了？」 |
| **随礼通胀 inflation** | 你随出流水的年度中位数 → 几何年化；与折算假设差 > 2 个点 → 建议重跑 | 「我自己的随礼在以什么速度涨价？」 |

三条诚实条款刻在实现里：**系数是礼数结构的粗编码，不是行情**——地区差异巨大（基线 `--base` 请按你家乡校准），工具给的是「不失礼的结构解」，不是「标准答案」；**账本永不建议断亲**——礼崩名单的落款是「维持、降温还是了断，是人的决定」，账本只负责让方向可见；**建议区间是下限思维**——下沿是「不失礼」线，上沿之上不设限，因为随礼市场的现实是抬价容易降价难，工具不假装能扭转棘轮。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 命令速查

```bash dd:ignore
python3 gift_ledger.py ledger gifts.tsv --as-of 2026-09-04            # 账本体检 + 系数表
python3 gift_ledger.py balance gifts.tsv 表哥                          # 单人对账：折算 + 余额 + 逐笔
python3 gift_ledger.py suggest gifts.tsv 表妹 --occasion wedding      # 请帖之夜的建议区间
python3 gift_ledger.py book gifts.tsv                                 # 全员排行 + 礼崩名单（exit 4）
python3 gift_ledger.py inflation gifts.tsv                            # 从自己的史里自证通胀
python3 gift_ledger.py simulate gifts.tsv 老周 --amount 300           # 若今天随 X，账怎么走
```

账本是一份可手编的 TSV（Tab 分隔），方向 `in` = 对方随给你、`out` = 你随出去：

```
date        direction  party  relation      occasion  amount  note
2019-10-01  in         表妹   close-friend  wedding   500     我婚礼表妹随的
2020-06-06  out        老周   colleague     wedding   500     老周婚礼
```

## 一个真实样例

老陈的人情账见 [examples/gifts.tsv](examples/gifts.tsv)（13 笔 / 6 人）。表妹下月结婚，请帖在手，`suggest` 三秒钟给出有出处的答案（[examples/sample-suggest-cousin.txt](examples/sample-suggest-cousin.txt)）：

```
  场面骨架   基线 600 × 关系 1.2 × 场合 1.0 = 720 元
  对价锚     2019-10-01 他随你 500 元（wedding 收）→ 今日对价 701 元
  未平余额   你欠着 701 元，本次计入下限 701 元

  建议区间   710 – 1080 元
```

「当年随 500，今天还 500」会无声地亏掉 40% 购买力——账本不做这种亏本假设。面对欠着大额人情的姑姑（她随了你婚礼 2000、满月 800），下限被抬到两倍基线封顶（[examples/sample-suggest-aunt.txt](examples/sample-suggest-aunt.txt)）：

```
  未平余额   你欠着 2502 元，本次计入下限 1080 元（大额旧账只还一半，剩下的不是一张请帖能平的）
  建议区间   1080 – 1350 元
```

`book` 一眼看穿全图的形状（[examples/sample-book.txt](examples/sample-book.txt)，退出码 4）：

```
  对方                    净余额  判定         备注
  姑姑                   2502  你欠人情
  表妹                    701  你欠人情
  阿凯                    301  你欠人情
  小林                     26  balanced
  表哥                   -311  他欠人情
  老周                  -1875  礼崩         自 2023-05-20 起再无往来

  全账总余额 1345 元  ·  balanced 1 · 你欠 3 · 他欠 1 · 礼崩 1
```

老周的礼崩不是一次婚礼的错，是三笔随出之后七年零回流的形状。而 `inflation` 会告诉你：你对「钱变毛速度」的假设可能太保守了（[examples/sample-inflation.txt](examples/sample-inflation.txt)）：

```
  自证年化   9.5%（2020 → 2022 年）
  当前假设   5.0%（--inflation）
  两者差超过 2 个点：重跑时建议 --inflation 0.10，让折算长在你自己的历史上。
```

`simulate` 把「抬价」的代价摆上台面（[examples/sample-simulate.txt](examples/sample-simulate.txt)）：今天随老周 300，两年后他办喜事的对价锚就变成 331——**随礼是会传染的定价，你抬的每一档，都是他下一次的起点**。

## 与哪些点子不混淆

- 与 **contribution-gap**（贡献错觉）：同是「关系对账」，那边记**家务分钟**——时间不讲通胀、不讲棘轮；这边记**货币对价**——礼金跨年代可比是刚需。家务吵的是「谁干得多」，人情哑的是「谁欠着谁」。
- 与 **drift-apart**（渐行渐远）：drift 记的是**联系频率**的沉默账，「三个月没说话」就是信号；gift-ledger 记的是**货币方向**账——天天聊天也可能礼崩（老周跟你熟归熟，礼是断的）。一个是关系的时间形状，一个是关系的资金形状。
- 与 **repair-ledger / cost-per-wear / optimism-tax**：那些是**单人账**——你自己与物品、与未来的对账；gift-ledger 是仓库第一个**双人账**——同一笔钱必须同时活在两个人的账本里、方向相反、金额相同，对不上的部分就是关系的裂缝。
- 与 **expiry-cliff**（到期悬崖）：都在做「把时间变成可运算的量」——那边是提前量，这边是通胀折算；一个防凭证静默失效，一个防余额静默失真。

## 验收标准（已全部转成自动化测试）

| # | 标准 | 测试 |
|---|---|---|
| A1 | 折算闭式 `金额×(1+r)^(天数/365.25)`；零通胀恒等；旧钱折算更大；负通胀收缩 | `test_a1_*` |
| A2 | 关系/场合系数表正确；坏行带行号 exit 2（枚举越界/坏日期/未来日期/金额≤0/缺列）；表头行跳过；`--inflation ≤ −1` exit 2 | `test_a2_*` |
| A3 | 净余额 = Σadj(in) − Σadj(out)：正 = 你欠、负 = 他欠；零通胀时等于原始差额；逐笔今日值列出 | `test_a3_*` |
| A4 | 基线 = base × 关系系数 × 场合系数；`--base` 整体缩放 | `test_a4_*` |
| A5 | 对价锚 = 最近同场合 in 的折算值；无同场合历史无锚；白事永不讲对价 | `test_a5_*` |
| A6 | 建议区间：锚托底、未平余额计入但按 2×骨架封顶、无历史按 0.8×骨架起步、取整到十元；查无此人 exit 3 | `test_a6_*` |
| A7 | 礼崩三条件缺一不可（欠额超线/三年无往来/流入不足流出之半）；`book` 有礼崩 exit 4；`--red-amount` 松闸后 exit 0；排行按余额降序；`balance` 标注礼崩风险 | `test_a7_*` |
| A8 | 通胀自证 = 年度中位数的几何年化；随出 < 4 笔或不足两个成对年份 → exit 3；与假设差 > 2pt 建议重跑 | `test_a8_*` |
| A9 | simulate：新余额正确；未来对价锚 = 金额×(1+r)^2；欠账时低于下限警告、对方欠你时中性提示；amount ≤ 0 与未知场合 exit 2 | `test_a9_*` |
| A10 | 普查数字（笔数/人数/方向/总余额）与系数表输出正确；空账本 exit 3 | `test_a10_*` |
| A11 | exit codes 全表（0/2/3/4）；同参数逐字节同输出；缺省基准日 = 今天；balanced 判定带语义 | `test_a11_*` |
