# 阴晴表 · Mood Barometer

> 单日的心情是天气，九十天的记录才是气候——天气没有预测力，气候有基线、有节律、有趋势。

## 问题

**谁**：长期高压、隐约觉得「最近不对劲」却说不清不对劲在哪的人——大厂运营、新手妈妈、慢性内耗的清醒者。她也可能是心理咨询的来访者：每次被问「最近怎么样」，只能交出最近三天的记忆。

**场景**：周日晚上莫名颓掉、怀疑自己是不是抑郁了；和朋友说完「我最近状态不好」被追问「多不好？从什么时候开始？」答不上来；咨询室里被要求「举几个具体的例子」时大脑一片空白。

**问题**：情绪数据每天都在产生，但没有任何账本记录它。于是三类模式永远不可见：

1. **基线不可见**——「我最近状态不好」没有分母：比什么不好？低多少？
2. **节律不可见**——周日晚的颓、周一的回血，发生了几十次，从未被确认为规律。
3. **因果不可见**——「和某人聊完总是很累」「deadline 其实不伤我」是感觉不是统计；自我叙事（「我内向所以社交累」）从不与自己的数据对账。

而最重要的那个信号——**坏状态的持续时间**——完全活在体感里：低落三天和低落三周，在「最近有点丧」这句话里是同一个人。

## 价值与意义

- 把「最近有点丧」翻译成有分母的陈述：**比你的基线低 1.0，第 11 天，你的历史中位回弹是 3 天**。
- 心理学的经验采样法（ESM）是研究工具，本件把它变成个人账本：主观量表靠行为锚点跨日可比，中位数抗单日崩溃，样本下限拒绝噪声结论。
- 双信号门禁（气候漂移 ∧ 滞留）给「该不该找专业帮助」一个可判定的标准——不是诊断，是**让就医决策第一次有史料可依**；报告本身就是能带进咨询室的东西。
- 自我叙事对账：小满以为自己「内向所以社交累」，90 天的账说 social 是 +1.0 的充电场合，头号耗电是 conflict——**感觉会撒谎，账不会**。

## 设计

### 账本（可手编 TSV，一天一行，偶尔漏记不补）

```text
# date	time	mood	events	note
2026-08-11	22:10	2	conflict,deadline	跨部门推锅会议
2026-08-12		4	exercise	健身房团课
```

mood 是 1-5 的整数，**锚定到行为而不是感觉**（`log` 命令给出锚点：5=高涨、3=平、1=谷底的行为描述）——主观量表不锚定就是噪声。events 是逗号分隔的自定义标签，同一标签攒够 5 次进入事件账单。

### 方法论骨架：以日为单位的气象学

- **日度口径**：一天多条记录取日均值，之后一切统计都是日度序列。
- **中位数基线**：全史中位数是「你的气候常数」——单日崩溃绑架不了 90 天。
- **样本下限**：气候与事件账需要 ≥21 个记录日（不足 exit 3 拒判）；事件标签 ≥5 次；星期效应 ≥4 个样本日。**宁可拒绝下结论，不制造伪精度。**

### 四层读数

| 读数 | 算法 | 回答 |
|---|---|---|
| **天气** | 近 7 天逐日 vs 基线 | 今天低 ≠ 不正常：对照季节看异动 |
| **节律** | 星期几均值偏移（≥4 样本才判） | 你的周日晚综合征统计上存在吗 |
| **事件账单** | 事件当天+后 2 天均值 vs 基线，按次取中位 | 哪类场合你最付不起、哪类其实在充电 |
| **回弹** | 低点（≤基线−1）到回到基线−0.5 的天数；连续低点合并 | 你的恢复力；当前这个坑正常该几天爬出来 |

### 门禁：两个信号同时成立才亮红灯

- **气候漂移**：近 30 天中位比前 30 天低 ≥0.5（窗口覆盖 ≥14 天才判）。
- **滞留**：当前低点已超过 **2× 个人中位回弹期**未回基线（回弹样本 ≥3 才判）。

单一信号不进门禁——一个坏季节人人都有。两个同时成立（exit 4），文案指向专业帮助而不做诊断：**「这不是天气，是气候在变」**。

### 命令

```bash
python3 mood_barometer.py climate moods.tsv --today 2026-09-04  # 气候报告 + 门禁
python3 mood_barometer.py weather moods.tsv --today 2026-09-04  # 近 7 天 + 滞留计时
python3 mood_barometer.py events  moods.tsv --today 2026-09-04  # 事件成本排行
python3 mood_barometer.py log                                    # 格式与量表锚点
```

`--today` 钉死即逐字节可复现（examples 由 `examples/build_examples.py --check` 在 CI 逐字节校验）。

## 验收标准

| # | 验收标准 | 落在 |
|---|---|---|
| 1 | 日度口径：一天多条取均值；一切统计基于日度序列 | `test_normal_rows_and_daily_mean` |
| 2 | 中位数基线抗单日崩溃（10 天 3 分 + 1 天 1 分 → 基线不动） | `test_median_resists_outlier` |
| 3 | mood 越界（0/6/3.5/非数字）→ exit 2；未来记录 → 2；坏时间/日期/列数 → 2 | `ParseTests` 全部 |
| 4 | 样本下限：气候/事件账 <21 记录日 → exit 3；weather 薄样本仍可看（基线收集中） | `test_climate_thin_refused_exit_3` 等 |
| 5 | 星期效应：构造周一全低 → 偏移 −1.0 排最前；样本 <4 的星期几不判 | `WeekdayTests` 全部 |
| 6 | 事件成本：冲突窗口显著为负；次数 <5 的标签不判；按成本升序 | `EventTests` 全部 |

| 9 | 气候漂移：30 天窗口中位差；窗口覆盖 <14 天不判 | `DriftTests` 全部 |
| 10 | 门禁：漂移 ∧ 滞留 → exit 4；单一信号 → 0；稳定 → 0 | `test_both_signals_light_red` 等 |

| 12 | 空账本 → 3；缺文件 → 2；`log` 命令给出量表锚点 | `CliParseTests`、`test_log_command` |

## 小满的账（dogfood）

31 岁的大厂运营小满，感觉「最近不对劲」三个月后开始记，记满 90 天：

- **基线 3.0**——她的「普通一天」是「平」：不高不低，靠惯性。这是她自己从没说出来过的常数。
- **气候漂移 −2.0**：前 30 天中位 4.0 → 近 30 天中位 2.0。不是「最近有点丧」，是一个月内整个下了一档。
- **周日晚综合征统计上存在**（13 个周日，均值 −0.8）：她以为是自己矫情，账本说是节律。
- **事件账单推翻自我叙事**：conflict −1.3 是头号耗电场合；而她以为最耗电的 deadline 是 **+0.0 中性**——「我对截止日其实是麻木的，真正杀我的是人际冲突」；social +1.0、exercise +0.5 都是充电场合。
- **回弹史给出最有力的对比**：她的低点历史上 3 天回基线（周日的坑甚至 1 天就爬出来——身体知道那只是周日）；而 **8 月 24 日的低点已经 11 天**。11 > 2×3，滞留成立。
- 漂移 ∧ 滞留 → **exit 4**：「这不是天气，是气候在变。这份报告可以直接带进咨询室，它比『最近有点丧』诚实得多。」

## 局限，说在前面

- 情绪是自报数据：工具的职责是用中位数、样本下限和锚定量表把它处理成**诚实的弱信号**，而不是伪精确的强结论。所有读数都该以「参考」对待。
- 门禁不是诊断。exit 4 的全部语义是「两个统计信号同时成立，值得让专业的人看看」——它对抑郁症一无所知，也不想知道。
- 记录本身会改变行为（记录效应）。这不是 bug：能靠记录爬出低谷的用户，是这门工具最好的结局。
- 漏记就是漏记：工具拒绝补记（补的是记忆不是记录），缺失日以「未记录」显示，不插补。
