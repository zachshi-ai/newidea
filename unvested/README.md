# 未兑现 · Unvested

> 期权是工资之外的另一半报酬,却是**唯一没有人替你记账的报酬**:授予协议 PDF 躺进邮箱的那天之后,再没有任何日历提醒归属节点——cliff 是悬崖(悬崖前离职一分不得),未归属的股份在你提离职那天整体作废,而已归属未行权的期权通常只有几十天行权窗口,窗口一关,连已经「挣到手」的部分也归零。平台只给一张日程表:不给作废倒计时、不给行权现金需求、不给「纸面 ≠ 到手 ≠ 落袋」的翻译,更没有一本把换过的每家公司并排的总账。**纸面财富不是你的财富,它是一张带倒计时的合同。**

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 拿股权报酬的员工——大厂 RSU 持有者与创业公司期权持有者;尤其是换过公司的人:期权散在两个 ESOP 平台、一封律所邮件和一份纸协议里,「我到底有多少股票」从来没有一个总账 |
| **场景** | 授予协议签完就再没人提;每年想一次「我的期权现在值多少」;动离职念头时搜「离职期权怎么办」;猎头递来新 offer,两家公司的期权包没法比;老东家裁员,HR 说「行权窗口 90 天」而你不知道那意味着什么 |
| **问题** | 股权的时间结构对持有者完全不可见:①cliff(悬崖)——一年内离职一分不得,差一天的归属在日程表上谁也不提醒;②未归属部分在离职日整体作废,「挣了四年」和「带走多少」是两个数字;③已归属未行权的期权有行权窗口(通识 90 天)和期权大限(通识 10 年),窗口一关**已挣到的也归零**;④行权要先掏现金(strike × 股数),很多人不是不想行权,是不知道要掏多少、也凑不出;⑤纸面市值按上一轮优先股价折算,和你的普通股之间隔着清算优先权——没有人把「在册纸面 / 已落袋 / 已作废」这三本账并排放 |
| **价值** | 把纸面财富翻译成时间与现金:`report` 摊开授予总账与三种形态(样例:在册纸面 ¥800,000 · 行权现金 ¥39,200 · 已落袋 ¥62,000 · **作废记忆 ¥375,600**);`exit` 对任何一个假想的离职日推演带走/作废/行权现金,并把「下一节点」摆上桌(样例:深流 cliff 93 天后 4,000 股——**差这一下,少四千股**);`clock` 给全部倒计时(下一个节点 / cliff / 行权窗口 / 期权大限)与 12 个月归属日历。星尘的教训钉在样例账本里:27,000 股已归属,90 天窗口没行权,净代价 ¥197,100——**这笔损失无人替你记账,账本记** |

**本件不是**:不是估值工具(不预测下一轮、不折算流动性折扣,latest_price 你自己抄)、不是税务顾问(归属/行权的税另算,税务机关永远赢)、不是离职建议(它只摆事实,走不走、行不行权永远是人的决定)、不是「征信修复」式的玄学——本件不做任何加速条款(trigger)的猜想,授予协议写的才算。

## 二、账本形态

一个目录三份手编 TSV(`--dir`,缺省当前目录)。数据源是**你自己的授予协议和 ESOP 平台截图**,抄录一份授予就是一行——全部数据工程:

```tsv
# grants.tsv —— 授予账(核心账,必需;同公司多份授予合法,top-up)
company	kind	grant_date	shares	strike	vest_years	cliff_months	interval	status	end_date	window_days	latest_price	price_date	note
星尘科技	option	2022-03-01	48000	1.20	4	12	quarterly	left	2024-06-30	90	8.50	2024-07-15	2024 年年中裁员离开
巨潮科技	rsu	2023-07-01	24000	0	4	12	quarterly	active				32.00	2026-06-30	现东家回购价
```

- **kind**:`option` 期权(strike 必填,有行权窗口)/ `rsu` 限制性股票(strike 填 0,无窗口——归属即到手)
- **status**:`active` 在职 / `left` 已离职(end_date=离职日,必填)/ `dead` 已清算(价值按 0 计,end_date 必填——**账本不替你猜公司哪天死**)
- **latest_price + price_date**:最新一轮/回购价及其日期,要么都填要么都不填——不填只数股份,**不发明估值**

```tsv
# events.tsv —— 事件账(可缺席=无事件)
date	company	event	shares	price	note
2025-12-15	巨潮科技	tender	2000	31.00	年度回购窗口卖了一批
2026-03-15	青苔智能	exercise	1000		掏了 800 元行权
```

- **exercise** 行权(不填 price——行权价是授予条款 strike,不是事件属性)/ **tender** 变现落袋(price 必填——落袋账没有价格就不是账)
- **作废不用记**——离职/窗口关闭是算出来的,不是你填出来的(少填一处少错一处)

```tsv
# schedule.tsv —— 日程覆盖(可缺席=按公式;出现即整表覆盖该公司)
company	date	shares
甲	2025-01-01	500
甲	2026-01-01	300
```

- 公式只覆盖最常见形态(cliff + 等额分期);performance vest、花式节奏,把授予协议的日程表抄进来——**授予协议永远赢过公式**

## 三、四命令

```
python3 unvested.py report                     # 授予总账+三种形态+灯
python3 unvested.py exit --date 2026-12-31     # 假设那天离职:带走/作废/行权现金/下一节点
python3 unvested.py clock                      # 倒计时(升序)+未来 12 个月归属日历
python3 unvested.py validate                   # 恒等式(六桶)+双路径对拍
```

公共参数:`--dir`、`--as-of`(时间机器,缺省 = 三本账最大日期,零墙钟)。通识先验全部 `--` 可翻案:`--warn-days 30`(窗口警报线)/ `--stale-days 548`(旧地图线)/ `--cliff-days 180`(悬崖雷达窗)/ `--term-years 10`(期权大限)/ `--months 12`(日历展望窗)。

### 灯

| 灯 | 语义 | 缺省线 | 恰线 |
|---|---|---|---|
| 🔴 BLOWN-WINDOW | 行权窗口已关,未行权的已归属股份归零 | 窗口关闭日 < as-of 且剩余 >0 股 | —(已成事实,记账) |
| 🔴 WINDOW-CLOSING | 行权窗口将关,再不掏钱就没了 | 剩余 < 30 天且在册 >0 股 | 恰 30 天不亮 |
| 🔴 TERM-EXPIRED | 期权大限已过,未行权股份作废 | 授予日起 10 年 | 当天不亮 |
| 🟡 CLIFF-AHEAD | 最大的一笔还在悬崖对面 | cliff ≤ 180 天且 ≥10% 股数 | 恰线/恰 10% 不亮 |
| 🟡 STALE-PRICE | 价格是旧地图 | price_date 距 as-of > 548 天 | 恰线不亮 |
| 🟡 DEAD-STAKE | 已清算/关闭,全部价值按 0 计 | status=dead | — |

### 退出码语义

| 码 | 含义 |
|---|---|
| 0 | 绿(exit/clock 恒 0——推演与日历是事实不是警报) |
| 2 | 账坏:补零缺失/不存在的日历日、未知 kind/status/interval/event、shares≤0、option 缺 strike、rsu 带 strike/window_days、left/dead 缺 end_date、end 早于授予、active 带 end_date、cliff 超全程、价格与日期不同填同空、事件悬空引用/早于授予/超池行权/窗口外行权/空头变现、schedule 悬空引用/Σ不齐/多授予冲突、同公司 kind 混账、表头不符/列数超限 |
| 3 | 空账(grants.tsv 不存在/零字节/纯注释/有表头零行——报错文案教建第一行) |
| 4 | 账面红灯:任一 🔴 亮 |

## 四、样例:小陈的三家公司(2026-06)

- **星尘科技**(option,2022-03-01,48,000 股,strike 1.20):2024-06-30 被裁,彼时已归属 27,000 股、未归属 21,000 股;90 天窗口(至 2024-09-28)没行权——`report` 亮 **BLOWN-WINDOW**:净代价 ¥197,100(按旧价 ¥8.50 记忆,715 天前的旧地图)。**时间机器**(`--as-of 2024-09-10`)回到窗口关闭前 18 天:27,000 股还活着,在册纸面 ¥229,500,行权现金 ¥32,400,WINDOW-CLOSING 正在响——**当时行权,现在不红**。
- **巨潮科技**(rsu,现东家):已归属 16,500(68.8%),2025-12 回购 2,000 股落袋 ¥62,000——这是唯一离开纸面的钱;在册纸面 ¥704,000。`exit --date 2026-12-31`:带走 19,500、作废 4,500(¥144,000),下一节点 2027-01-01——**差一天,少 1,500 股**。
- **青苔智能**(option,天使轮无价格):只数股份不发明估值;已归属 4,372,行权 1,000 掏了 ¥800,在册可行权 3,372 股需掏 ¥2,697.60——**没有估值,行权要掏的现金是确定的**。
- **深流科技**(option,新东家):全部 16,000 股在悬崖对面,cliff 2026-10-01(93 天后,25%)→ **CLIFF-AHEAD**——动离职念头之前先看这行。

## 五、验收标准

| # | 验收标准 | 验证方式 |
|---|---|---|
| 1 | cliff 语义:悬崖日含当天(前一天 0、当天 300);cliff==全程一次性归属;cliff=0 时全部节点(含授予日)平摊——节点 0 重复计数的引擎 bug 被对拍网格当场抓住 | 边界测试 + 对拍 |
| 2 | 等额分期余数落末节点(10,001 股:cliff 2,500 + 11×625 + 626);月末钳制(01-31+1mo=02-28,闰年 02-29);Σ节点 ≡ 总股数 | 字面值测试 |
| 3 | end_date 截断归属:离职后日程表上的节点不再归属(恰在离职日前的节点照常) | 截断测试 |
| 4 | 双路径对拍:前向累加 == 补集 == 判定式,样例 + 三授予构造,5 年逐 37 天全网格 | 对拍恒等测试 |
| 5 | 事件校验:超池行权/窗口外行权/期权大限外行权/rsu 行权/空头变现/无价变现/悬空引用/早于授予/超额分摊——全部 exit 2,宁可拒绝不静默吞 | 网格测试 |
| 6 | 作废是算出来的不是填的:窗口关闭自动 F_WIN,价值归零、股份入桶,恒等式照平 | 状态机测试 |
| 7 | FIFO 分摊:同公司两份授予 top-up,行权按授予日吃池;池不足 exit 2 | top-up 测试 |
| 8 | schedule 整表覆盖公式(performance vest),Σ 不齐/悬空/多授予冲突 exit 2,覆盖行数在 validate 披露 | 覆盖测试 |
| 9 | 灯阈值:WINDOW-CLOSING 恰 30 天不亮、29 天亮(--warn-days 可翻案);STALE 恰 548 不亮、549 亮;CLIFF-AHEAD 需 ≤180 天且 ≥10%(两个条件各自独立拦) | 阈值 + 翻案测试 |
| 10 | TERM-EXPIRED:授予 10 年大限外未行权作废(dead 公司黄灯不红灯,价值按 0 计) | 大限测试 |
| 11 | 时间机器:缺省 as-of=账本最大日期;未来授予是后视行不进总账;未来事件/未来价格被排除;BLOWN 在窗口关闭前回放时未发生(WINDOW-CLOSING 还在响)——**当时行权,现在不红** | 回放测试 + 字面值 |
| 12 | 估值诚实:无价格只数股份不发明估值;但行权现金是授予条款,无价格也确定(3,372×0.80=¥2,697.60 进 exit,9,000×0.80=¥7,200 进 report 在册口径);旧价盖「旧地图」戳 | 诚实性测试 |
| 13 | 恒等式:总股数 ≡ 六桶之和(样例 98,000 ≡ 29,128+17,872+1,000+2,000+21,000+27,000,残差 0.00e+00) | validate + 字面值 |
| 14 | 零墙钟:源码无系统时钟;as-of 缺省自锚定;同账双跑逐字节一致;报告只打印 basename | 源码断言 + 双跑比对 |
| 15 | exit code 语义:report 红灯 4、exit/clock 恒 0、账坏 2、空账 3(四形态文案教建第一行) | 语义测试 |

## 六、与近邻的边界

- **[交底](../handoff/)**:那边管要紧物**在哪、除我之外谁知道**(交接面,身后被找到),本件管这份股权**值多少、哪天是我的、哪天会飞**(时间与价值,身前别弄丢)——handoff 的投资类目下该交底的第一件物,就是本件的账本。
- **[明白账](../fair-exit/)**:那边管离职的**劳动法结算**(N+1、年假折算、竞业——对 HR 的报价),本件管离职的**股权结算**(归属、行权窗口、作废——对授予协议的条款)。同是离开公司那天,两本账。
- **[赎契](../redemption/)**(房贷)与**[暗息](../stealth-interest/)**(分期):那边审**负债端**(借来的钱的价格与还法),本件审**资产端**(挣来的股的时间与归属)——资产负债表的两侧。
- **[净值幻觉](../nav-illusion/)**:那边管**已到手的基金**的行为差(XIRR vs TWR,你的钱已在场),本件管**还没到手的股权**(vesting 日程,你的钱还在悬崖对面)——一个审计过去的手,一个倒计时未来的股。
- **[求职漏斗](../job-funnel/)**:那边管你**进门**的转化率,本件管你在门里攒下的**延期支付的那半份工资**——offer 谈判桌上,两边该一起看。
- **[暗基数](../shadow-base/)**:那边审公司替你缴的法定福利(对手方是公司的经办人),本件审公司发给你的股权报酬(对手方是授予协议自己)——同是「工资条之外的另一半」。
- **[到期悬崖](../expiry-cliff/)**:那边管**凭证**的失效提前量(护照/保单,续了就还在),本件管**权益**的作废倒计时(窗口一关不是续,是永久归零)——同为会静默死掉的东西,一个能续保一个不能。

## 七、诚实条款

- **纸面不是口袋。** 未上市股份没有流动性;latest_price 是上一轮的优先股价格,和你的普通股之间隔着清算优先权与稀释;报告里每一个 ¥ 后面都站着这个假设,旧价再盖一道「旧地图」戳。本件不预测估值,不折算折扣——你抄什么价,它算什么数。
- **行权要先掏现金,税另算。** 报告把 strike 现金单列(无估值也确定),但行权/归属产生的个税不建模——行权前问税务顾问,他们永远赢。
- **条款以授予协议为准,律所永远赢。** 公式只覆盖 cliff+等额分期;窗口天数、大限、加速条款(single/double trigger)、回购权、performance vest 全部是通识先验且全部 `--`/schedule 可翻案。你的协议写了 30 天窗口,就以 30 天为准。
- **它不建议你走或不走。** exit 推演把「今天走 vs 撑到下一节点」的差额摆上桌,但那不是建议——差一天少一千股是事实,值不值得等,是人的决定;clock 的日历只摆事实,不裁决「该不该等」。
- **作废是算出来的,不是你填的。** 离职、窗口关闭、大限过期全部由引擎推算,账本拒绝手填作废(少填一处少错一处);已发生的损失(样例 ¥197,100)记账不抹平——**这笔损失无人替你记账,账本记**。
- **股权是最敏感的财产数据。** 不连任何接口,不上传任何字节;报告只打印账本目录名;抄录一份授予的一行是全部数据工程。
- **零墙钟。** as-of 缺省锚定三本账最大日期,`--as-of` 是时间机器不是今天;同一本账任何机器任何一天逐字节一致。

## 八、快速开始

```bash
cd unvested
python3 unvested.py report  --dir examples                     # exit 4:BLOWN-WINDOW,设计内
python3 unvested.py report  --dir examples --as-of 2024-09-10  # exit 4:窗口还剩 18 天,当时行权现在不红
python3 unvested.py exit    --dir examples --date 2026-12-31   # exit 0:带走/作废/行权现金
python3 unvested.py clock   --dir examples                     # exit 0:倒计时+12 个月日历
python3 unvested.py validate --dir examples                    # 恒等式 98,000 ≡ 六桶
python3 -m unittest discover -s tests                          # 80 tests
```

维护成本:每次拿到新授予、每轮新融资、每次动离职念头时各抄一行——这本账的全部成本,是离职谈判前 5 分钟的底气。
