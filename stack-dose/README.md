# 叠方 · Stack Dose

> 药名不同 ≠ 成分不同。感冒了早上泰诺、中午感冒灵、晚上维 C 银翘片——三种药挂在货架的不同位置，却共享同一个活性成分：对乙酰氨基酚。每一种都按说明书吃，叠起来就是同一成分的两遍、三遍。

## 问题定义

**角色**：同时吃多种药的人——感冒季把复方感冒药当「不同药」换着吃的成人；给父母管药、想在上桌前查一句「这些药撞不撞车」的家庭成员。

**场景**：
- 高烧第二天，退烧不满意，于是「再加一种」：泰诺 → 感冒灵 → 银翘片 → 散利痛……每一步都合规，每一步都在加同一个酚。
- 药店柜台前：「这几个能一起吃吗？」——店员看的是药名，不是成分。
- 老人一天 5-8 种药，医院各开各的，家人想整体看一眼却没有任何工具按「成分」加总。

**问题**：上限是公开的算术（对乙酰氨基酚保守 2 g/日、药典 4 g/日；布洛芬 OTC 1.2 g/日），药盒背面印着每片含量，但从没有人替你把它们**按成分加起来**：医院系统看处方名、药店按货架卖、家庭凭「好像没吃几次吧」的记忆。而对乙酰氨基酚过量是急性肝衰竭的主要病因之一——这不是罕见病叙事，是每个药盒都印着、没人加在一起的加法。

**伪需求检查**：复方感冒药共享对乙酰氨基酚是中文药品市场的结构性事实（10 种家喻户晓 OTC 里 7 种含酚，见 `share` 命令输出）；「叠方」的真实案例形态（多药叠加致肝损伤）被药监部门反复通报。本件不发明问题，只把已有的事实做成一行灯。

## 设计

零依赖 Python CLI（Python 3.8+ 标准库），两份可手编 TSV：

- **服药账本** `doses.tsv`：一行一次服药（date/time/drug/qty/note）。中英列名同效，药名归一（`泰 诺`≡`泰诺`），乱序载入自动重排。
- **药表**（可选）`meds.tsv`：name/ingredient/mg/unit，一行一个成分——自备药、诊所白瓶药自己教给账本；**同名药整药替换内置**（本地知识赢）。内置十种家喻户晓 OTC 的公开说明书成分作 folk 先验：泰诺、泰诺林、999 感冒灵、维 C 银翘片、白加黑夜片、散利痛、快克、新康泰克、芬必得、美林。

五个命令：

| 命令 | 回答的问题 | exit |
|---|---|---|
| `report` | 这一周每天每种成分吃了多少？离线还有多远？ | 0/3/4 |
| `combo` | 药店 30 秒：这几种一起吃，成分撞不撞车？（不记账本） | 0/4 |
| `interval` | 同一成分相邻两次，间隔够不够？（酚 q4h、布洛芬 q6h） | 0/3/4 |
| `share` | 酚藏在哪几个药盒里？（成分→药盒反向索引） | 0 |
| `validate` | 账本体检：恒等式闭合、判级完备、展开一致 | 0/2 |

**三道闸互相独立**：

1. **日暴露闸**——按日聚合每种成分的 mg，对先验上限判级：`OK ≤ 保守线 < STACKED ≤ 药典上限 < OVERDOSE`。判级恰线语义：**恰线不亮**——泰诺林 500 mg×4 次/日 = 2,000 恰在保守线上，单药按说明书满频次吃不冤枉；叠加才亮。
2. **间隔闸**——同一成分相邻两次的间隔 < 最短间隔（酚 240 分钟、布洛芬 360 分钟）逐段点名 CROWDED，归属后一笔之日。间隔也是叠加：两次之间是身体清算上一笔的时间。
3. **组合闸（预防性）**——`combo` 不记账本，现场把组合单次合计 × 频次日外推，越线即亮——用在买药那一刻，而不是记账那一晚。

**先验全部是旗标**：`--soft 成分=mg`、`--hard 成分=mg`、`--gap 成分=分钟` 一句话翻案；没有先验的成分（伪麻黄碱、氯苯那敏……）如实 `n/a` 只发表不判级——**没有先验就不判级，不装懂**。药盒说明书永远赢。

## 验收标准（全部转成自动化测试，63 项）

1. **聚合恒等式**：Σ逐行剂量 ≡ Σ按日聚合（validate 双路径重放，残差钉到 1e-9）；成分展开笔数 ≡ Σ(每笔药的成分数)。
2. **判级恰线语义**：恰 2,000 不亮；2,000.01 亮 STACKED；恰 4,000 仍 STACKED；4,000.01 亮 OVERDOSE；无先验 n/a 不参与日灯——`n/a` 不冒充绿灯也不冒充红灯。
3. **间隔闸**：恰 240 分钟不亮；239 分钟亮；跨日间隔正确累计（23:00→06:00 = 7h）；`--gap` 翻案后同段不亮。
4. **无先验可教**：`--soft 伪麻黄碱=150` 后判级生效；自定义药表同名整药替换内置；账本引用未教过的药名 exit 2。
5. **组合闸**：泰诺+感冒灵+银翘片共享酚被点名；新康泰克+芬必得无共享成分不亮（机器不做有罪推定）；`--times 4` 外推 2,520 越线 exit 4。
6. **薄账分层**：空账本 report/interval exit 3（半夜想知道吃了多少不该被拦，但空账连算术都没有）；combo 恒开庭——药店场景不需要样本。
7. **账坏 exit 2**：坏日期（`2026-1-5` 补零拒绝）、坏时间、非正数量、重复（date,time,drug）行、未知药名、坏药表行。
8. **零墙钟**：无 `--as-of` 时锚定账本最大日期（账本末日），`--as-of` 钉死即逐字节可复现；报告只打印账本 basename。
9. **快照**：`examples/build_examples.py --check` 对样例账本与全部输出做字节级校验（CI）。

## 使用

```bash
# 一周的成分叠加日账(样例)
python3 stack-dose/stack_dose.py report stack-dose/examples/doses.tsv --meds stack-dose/examples/meds_custom.tsv

# 药店 30 秒:这几种一起吃撞不撞车
python3 stack-dose/stack_dose.py combo --drugs 泰诺,999感冒灵,维C银翘片 --times 4

# 间隔审计
python3 stack-dose/stack_dose.py interval stack-dose/examples/doses.tsv

# 酚藏在哪些药盒里
python3 stack-dose/stack_dose.py share --ingredient 对乙酰氨基酚

# 测试
python3 -m unittest discover -s stack-dose/tests
```

## 诚实条款

- **账本不是药师**。它不做药物相互作用（两种成分之间的化学反应是临床决策），不做药代动力学（半衰期是另一门算术），不建议剂量（吃多少是医嘱）。它只回答一个加法问题：同一成分，今天吃了几毫克、隔了多久。
- 红灯 = 拿着这几只药盒去问药师或医生的理由，**不是诊断，更不是停药指令**。
- 内置药表与上限是通识先验（folk），来自公开说明书常识；你手头的药盒说明书永远赢，`--meds`/`--soft`/`--hard`/`--gap` 一句话翻案。
- 账本只记你声称的事实——没记的那顿不在账上。想被账本温柔对待，先如实记账。
- 不连任何药房/处方接口，不上传任何字节。吃什么药是敏感信息，账本只存在本地。

## 与近邻的边界

- **medicine-rollcall（#55 药箱点名）**：那边管药箱**库存**的第二口钟（开封效期——药死了没有），本件管**摄入端**的成分对账（今天身体里进了多少）——「药箱里有多少能用的药」和「今天吃进去的成分叠了几遍」是两本账，一个问货架，一个问嘴巴。
- **afterburn（#22 余燃）**：那边是摄入→浓度残留的药代动力学（半衰期 5h），本件刻意不做半衰期，只做日聚合与最短间隔——上限算术不需要动力学执照。
- **hidden-tab（#72 瘾账）**：那边戒断行为的恢复账，本件摄入剂量的暴露账。
- **true-pocket（#71 实掏）**：那边对账医疗费用的分摊，本件对账药物成分的暴露。
- **borderline（#32 贴线）**：那边化验值纵向爬坡（连续量+Theil-Sen），本件是日级加法（离散事件+恒等式）——共同的敌人是「看不见的逼近」，但化验单一个月一张、退烧药一天四次。
