# 应承 · Owed Word

> 答应发生在对话里,零成本、零记录。微信里回一句「包在我身上」,三天后这条消息沉进聊天记录;大脑把「我说了」直接误记成「我在办了」。欠钱有欠条,欠自己的有 TODO——欠别人的话,从来没有账本。最消耗关系的不是拒绝,是悬着的答应:对方不好意思催,你不好意思提,两个人一起假装它不存在。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 答应过别人事的所有成年人:帮看简历的、答应引荐的、说「回头给你找个师傅」的、酒桌上应承亲戚的——说「好」比说「不」容易,所以人人都有几笔悬着的 |
| **场景** | ①表弟两个月后问「哥你上次说的装修师傅呢」——你才发现那句「包在我身上」从没动过,而当时还说好了「过年前」;②同事的简历在收藏夹放了三周,见面还得装作在办;③对老同学说了「改天聚聚」,一晃一个季度,谁都没再提——但两个人都记得;④想拒绝的时候没拒绝,现在开口更难:拖得越久,「办不了」越说不出口 |
| **问题** | 应承是关系里唯一「开口即成立、却从不入账」的债:iou 管欠钱(有借条、有时效),todo-rot 管「写给未来自己的支票」(代码 TODO),但「欠别人的话」没有任何账本——它发生在口语里,零成本、零记录、不可检索;它的违约不会收到账单,只会收到一次「他是不是忘了」的重新评估。悬着的应承是**暗债**:不产生利息,产生尴尬 |
| **价值** | 把口头应承记成可对账的账:①**期限债**——note 里钉下说过的期限(`due:`),到期当天恰线亮灯,宽容为零:说出口的「周三给你」是证词;②**悬龄债**——没说期限的按悬龄计,第 15 天 🟡AGING 预警、第 31 天 🔴STALE 点名,连「改天聚聚」都悬成了债;③**体面出口**——每一盏灯的行动文案只有两句:办掉它,或回一句办不了——**declined 是一等公民的结案**,说出口的「不」是已结的账,拒绝占比是这本账的健康指标,不是污点;④**人排行**——「你在谁那里悬着最多」,见面之前先看这一行 |

**本件不是**:不是办事工具(账本不替你办任何一件事)、不是道德法庭(灯只照「悬着」,不审判「没办成」)、不是话术教练(怎么开口拒绝是你自己的事)。账本在你自己的机器上,不连任何接口、不上传任何字节。

## 二、账本形态

手编 TSV,5 列,单行型——**结案不另起行,改一个词**:

```tsv
who	what	date	state	note
表弟小舟	找靠谱的装修师傅	2025-12-08	open	due:2025-12-31 饭桌上答应的,说过年前给名字
邻居周姐	帮遛一周的狗	2025-10-15	declined	那周出差,当天就回了办不了
```

- `who` 你应承了谁;`what` 应承的事——**写到能验收**(「帮忙」没法结案,「找靠谱的装修师傅」可以);`date` 答应日
- `state` 词表:`open`(悬着)/ `did`(办了)/ `declined`(明说办不了)/ `returned`(对方收回),中文短名也收(办了/办不了/收回);缺省按 open
- `note` 自由文本,内置两个键:`due:YYYY-MM-DD` 是**答应时说过的期限**(没说就不钉,宁可不亮灯不编期限);`done:YYYY-MM-DD` 是结案日(不记则办结周期如实披露「未记」)
- 手编不拘小节:右侧缺列视为空、行尾制表符容忍、`#` 注释行、note 里不像日期的文字原样保留
- 账坏即拒:日期不补零/假日期(02-30)拒、结案日早于答应日拒(时间倒转)、期限早于答应日拒(答应之前交不了卷)、同人同事同日重复拒(同一句应承只记一次)、`open` 却预写 `done:` 拒(悬着的账不能预写结局)

## 三、灯(各管各的案)

| 灯 | 点亮条件 | 它在说什么 |
|---|---|---|
| 🔴 **OVERDUE** | `open` 且已过 `due:`(当天恰线亮) | 期限债,宽容为零——「今天就是说过交卷的日子」。行动文案:办掉它,或回一句办不了 |
| 🔴 **STALE** | `open` 无期限,悬龄 ≥ 31 天 | 悬账:没有任何下文。「对方不好意思催,不等于对方忘了」 |
| 🟡 **AGING** | `open` 无期限,15 ≤ 悬龄 ≤ 30 | 预警带,恰线即亮:第 15 天亮、第 14 天不亮。排进本周,或现在就回一句进度 |
| 🟢 **OK** | `open` 且正常等待 | 悬龄未满/期限未到——账本不吵没到期的债;**有期限的行期限内不按悬龄吵**,答应再久都是正常等待 |
| ✅ **DONE** | `did` / `declined` / `returned` | 已结的账不用照。declined 单独获一句注脚:「说出口的『不』是已结的账」 |

**阈值全是设计常数、无 `--` 旗标**:15 天预警带、31 天悬账线——应承对账没有外部权威,给阈值开门就是给「把红灯调成绿灯」的冲动开门(cry-wolf 同款立场)。期限与悬龄**互不越界**:有期限的只看期限,没期限的才按悬龄——两条规则各管各的案。

## 四、命令

```bash
python3 owed_word.py report   words.tsv --as-of 2026-02-10  # 对账单:按人聚合,悬着的先亮
python3 owed_word.py next     words.tsv --as-of 2026-02-10  # 该回话清单:期限债在前,悬账按悬龄降序
python3 owed_word.py settled  words.tsv --as-of 2026-02-10  # 结案簿:办结率、拒绝占比、办结周期
python3 owed_word.py validate words.tsv                     # 恒等式 + 双路径重放
```

退出码:`0` 全绿 · `2` 账坏 · `3` 拒判(空账——包括纯注释的空文件:对第一次打开的人,没有账本是「还没开始」,不是「账坏了」) · `4` 账面带灯(OVERDUE/STALE/AGING 任一)。

## 五、样例走读(老蒋,as-of 2026-02-10)

7 句应承,5 悬 2 结:

- **表弟小舟·装修师傅 🔴 期限债**:12 月 8 日饭桌上答应,说了「过年前」——期限 2025-12-31,已过 41 天。这是账本里最响的一盏灯:不是因为它最久,是因为它**带着证词**
- **老同学大鹏·「改天聚聚」🔴 悬账**:11 月 30 日的应承,悬了 72 天没有下文——`what` 不设词表,连「改天」都会被悬龄点名
- **同事阿岚 ×2 🟡 预警**:看简历(20 天)、内推(16 天)——人排行第一:「见阿岚之前,先看这两行」
- **朋友老唐·绘本 ✅**:11 月 2 日答应、20 日带到,办结周期 18 天;**邻居周姐·遛狗 ✅**:当天回了「办不了」——结案日没记,周期如实标「未记」,注脚照给:「说出口的『不』是已结的账」
- **物业小陈·充电桩 🟢**:才悬 9 天,正常等待——账本不制造焦虑

**时间机器钉回 2025-12-15**:剪掉 3 笔晚于 as-of 的后视行(当时还没答应),表弟的期限还剩 16 天——**一切都来得及的那天,账本只有一个黄灯:大鹏的「改天」恰好悬满 15 天**。期限债从来不是欠出来的,是拖出来的。

## 六、恒等式与确定性

- **恒等式一**:总行数 ≡ open + did + declined + returned(state 空间守恒——每一句应承恰好处于一种状态)
- **双路径重放**:解析层(路径 A)与文本层独立重放(路径 B)的四元组序列逐行全等,行号可 grep 回账本
- **零墙钟**:缺省 as-of 锚定账本最大答应日并如实披露,`--as-of` 钉死即逐字节可复现;报告只打 basename,同账任何机器任何一天输出一致

## 七、诚实条款与边界

- 账本不替你办事:它只把「悬着的答应」照亮;办掉或回话,是灯之外的你的事
- declined 不是失败:拒绝占比是敢说「不」的频率,是这个账本的健康指标;把 declined 做成一等结案,是因为大多数失约不是忘了,是「不好意思说办不成」
- `due:` 只记**说出口的期限**:没说过就不钉——宁可不亮灯,不替你回忆没发生过的承诺
- 阈值是设计常数不是权威:15/31 天没有科学依据,只有一个立场——一个月是「对方还当真」的心理线
- 应承内容可能涉及第三人(帮谁引荐、替谁办事):数据不出本机,不连任何接口、不上传任何字节

## 八、测试

54 项验收测试 + 7 份字节级快照(见 `tests/`、`examples/`):中文状态归一、恰线语义(due 当天亮/悬龄第 15 天亮/第 31 天 STALE/第 14 天不亮)、期限与悬龄互不越界、declined 三态不亮灯、时间机器剪后视行、人排行并列按名序、恒等式与双路径重放、空注释账 exit 3、同账两跑逐字节一致。方法论详见 [METHODOLOGY.md](METHODOLOGY.md)。
