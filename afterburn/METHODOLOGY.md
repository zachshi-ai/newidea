# 余燃 · Afterburn — 方法论与 FAQ

> 本文讲清楚三件事：模型从哪来、数字从哪来、以及它不能做什么。

## 1. 模型：单室一级消除

### 1.1 为什么是它

咖啡因在健康成人体内的处置，药代动力学（PK）的标准一级近似是**单室模型 + 一级消除**：身体近似为一个均匀室，摄入即吸收（口服 30–60 分钟达峰，本件将其近似为瞬时），消除速率与当前浓度成正比。这个模型只需要一个参数——**消除半衰期 t½**——就能把「喝了几杯、几点喝的」翻译成「任意时刻血液里还剩多少」：

```
C(t) = Σᵢ Dᵢ · 2^(−Δtᵢ / t½)        Δtᵢ = t − tᵢ（第 i 杯经过的小时数）
```

两条性质使它成为一本「账」而非一次拟合：

- **叠加原理**：多杯的浓度是各自浓度之和。线性系统没有交互项——早上的美式不会因为下午又喝了拿铁而烧得更快。
- **跨夜连续**：账本按天记录，浓度按小时演化，昨天的摄入自动计入今晨底座。

### 1.2 它忽略了什么（以及为什么可以）

| 忽略 | 真实情况 | 对本件的影响 |
|---|---|---|
| 吸收相 | 口服 30–60 分钟达峰 | 就寝判定看的是 6 小时外的摄入，吸收延迟对结论影响 < 5%；对「刚喝完 5 分钟」的 now 读数会低估峰值 |
| 分布相 | 咖啡因先分布后消除，初期下降快于纯消除 | 使估计偏保守（高估残留）——对睡眠预警这个用途是安全方向的误差 |
| 代谢物 | 副黄嘌呤等代谢物仍有轻微活性 | 忽略不计；量级远小于母药 |
| 耐受 | 慢性摄入者对主观效应耐受 | **浓度账不受耐受影响**（药还在血里），但「多少毫克会让你睡不好」的阈值因人而异——这正是阈值可调的原因 |

## 2. 数字从哪来

### 2.1 半衰期：缺省 5h，范围横跨 2–10h

均值 5h 来自健康成人研究的主流报告区间（约 3–7h，中心 5h）。**个体差异是本件最大的不确定性来源**，且不是随机的，有明确的生理学因素：

| 人群 | 半衰期量级 | 建议参数 |
|---|---|---|
| 健康成人，不吸烟 | ~5h | 缺省 |
| 吸烟者 | ~3h（快 30–50%） | `--half-life 3` |
| 口服避孕药 | ~7h | `--half-life 7` |
| 孕晚期 | 可达 15h+ | `--half-life 15` |
| 肝功能受损 | 显著延长 | 遵医嘱，本件仅供参考 |
| CYP1A2 慢代谢型 | 偏长 | 若「下午一杯就失眠」持续成立，试 8h |

自我校准的土办法：如果你**只在早晨喝**仍然偶尔入睡困难，或下午一杯必然失眠，说明你对缺省 5h 不典型——往 8h 方向调，看红绿灯是否更符合你的体感。本件刻意不做「从睡眠观察自动拟合半衰期」：样本太少、混杂太多，拍脑袋给参数反而诚实。

### 2.2 阈值：缺省 50mg

就寝残留多少毫克会干扰睡眠，文献没有单一共识值。Drake 等（2013）的对照实验发现就寝前 6 小时内的 400mg 仍使客观睡眠减少逾 1 小时；更小剂量的效应研究结论分散。本件取 **50mg**（约半杯滴滤、或一杯下午拿铁在 8 小时后的典型残留）作为保守缺省——它足够低，能把「有实际干扰嫌疑」的夜晚标红；足够高，不把只喝早杯的日子误伤。**它是一个可调的治理阈值，不是临床诊断线**：敏感者应调低（30），迟钝者可调高（80）。

### 2.3 饮品表：粗略中位 + 行级覆盖

缺省表取 USDA FoodData Central 与厂商标签的常见中位（如 espresso 单份 63mg、240ml 滴滤 95mg、330ml 可乐 34mg、250ml 功能饮料 80mg）。但现实波动巨大：同一杯「拿铁」，单 shot 与双 shot 差一倍；奶茶横跨 20–100+mg；冷萃随浓度与容量变化。**所以本表的哲学是「宁可贵在覆盖，不贵在精确」**——查得到品牌标牌就写第 4 列覆盖，查不到就用缺省并接受误差。

### 2.4 戒断窗：文献标注，不是计算

wean 输出的三个时间窗来自 Juliano & Griffiths（2004）对咖啡因戒断的系统综述：症状起病通常在末次摄入后 12–24h，头痛等峰值在 20–51h，2–9 天消退。工具做的是把这几个窗**排到你的日历上**（达峰落在周几），计算的部分只有「残留何时降到安静线以下」。把达峰安排在周末，是戒断策略里性价比最高的一步。

## 3. 命令背后的数学

### 3.1 cutoff：闭式反解

给定就寝时刻 b、阈值 θ、已排入摄入在 b 时刻的底座 C(b)、目标剂量 D，最晚饮用时刻：

```
t* = b + ln((θ − C(b)) / D) / k ,   k = ln2 / t½
```

推导：t* 时刻喝 D，在 b 时刻贡献 `D·e^(−k(b−t*))`；令 `C(b) + D·e^(−k(b−t*)) = θ` 解出 t*。三个边界情形都有明确语义：

- `θ − C(b) ≤ 0`：不喝这杯都已越线 → 额度尽（返回 None，报告「额度已尽」）；
- `D ≤ θ − C(b)`：就寝当口喝全额都不越线 → 「随时」；
- `t* < 现在`：窗口已关，这杯留给明天。

验证方式：把 t* 回代，就寝总浓度恰好等于 θ（见测试 `test_a5_solution_lands_on_the_line`）。

### 3.2 steady：几何级数闭式

每日固定节奏 {（tᵢ, Dᵢ）} 在天内时刻 s 的稳态浓度：

```
C_ss(s) = Σᵢ Dᵢ · Σₙ₌₀^∞ exp(−k·(((s − tᵢ) mod 24) + 24n))
```

内层是对「过去无穷多天里同一杯」的几何级数求和，实现截断 31 项（30 天前的贡献已 < 1e-18 mg）。验收：闭式解与「从远过去逐日暴力铺 40 天」的模拟差 < 0.1%。直觉读法：**天天喝的人没有零点**——他的每个清晨都从昨天的余燃开始。

### 3.3 lookback 截断：72h

浓度计算只回看 72 小时内的摄入（t½=5h 时 95mg 杯在 72h 后剩 0.0004mg）。wean 的扫描例外地敞开 lookback——扫描终点本身就可能越过 72h，若沿用截断，边界处浓度会突降为 0、把「还没安静」误判成「已经安静」（这个交互 bug 曾真实存在，被测试 A9 的极端半衰期用例抓住后修复）。

## 4. FAQ

**Q：我不是应该直接戒了吗？**
A：如果睡眠是你的第一优先级，是。但咖啡因对多数人是净收益物质（警觉、运动表现、甚至社交）。本件的立场不是道德立场：**它不劝你少喝，它告诉你几点之后不能喝**。把下午 3:30 的拿铁挪到 1:30，对多数人已是绿灯——这是零戒断成本的改进。

**Q：mg 数说不准，这个工具还有什么意义？**
A：账本的价值在**时序**而非绝对值。缺省表 ±30% 的误差，反映到「就寝残留 54mg 还是 42mg」也许跨过阈值——但你真正需要的洞察是「15:30 之后喝的日子全红、只喝早杯的日子全绿」这种**结构性的模式识别**，它对参数误差稳健。参数错了，模式还在。

**Q：为什么阈值/半衰期不自动学习我？**
A：需要「真实睡眠结局」的标签（入睡延迟、睡眠结构），可穿戴设备给的主观精度不足以拟合两参数模型，而且混杂（压力、光线、酒精）比信号多。让用户拿体感当反馈手动调两个参数，比一个假装聪明的黑箱诚实。

**Q：decaf / 可可 / 茶怎么办？**
A：都含咖啡因，都记。dark-chocolate 一行 40g 约 20mg——晚上那块巧克力是不是无辜的，账本说了算（82.5% 可可的黑巧含量更高，覆盖第 4 列）。抹茶、奶茶同理。

**Q：和「睡眠卫生」清单里的『下午别喝咖啡』有什么区别？**
A：那条建议是一把没有刻度的尺子。「下午」是几点？一杯是多少？喝半杯呢？晚睡两小时呢？本件把这条建议**参数化**了：你的就寝时间、你的半衰期、你的这杯剂量，反解出你的、今天的、这一杯的最晚时刻。

**Q：模型会说谎吗？**
A：会——所有模型都会。它的三个诚实承诺：① 所有缺省值在本文档给了来源与波动区间；② 所有参数（半衰期、阈值、行级毫克）可调可审计，没有藏在代码里的魔法数影响结论方向；③ `--now` 钉死后输出逐字节可复现，同一个账本在谁的机器上跑都是同一个答案。它是「有账可查的估计」，不是血液检测。

## 5. 局限

- **不是医疗设备**：睡眠障碍的成因复杂（睡眠呼吸暂停、焦虑、时相延迟等），咖啡因只是最常见且最可修改的嫌疑犯之一。持续睡眠问题请就医，本件不诊断任何疾病。
- **吸收延迟未建模**：now 读数在刚摄入后的 1 小时内偏低估（达峰前）。就寝判定不受影响（看的是小时级之外的摄入）。
- **饮品表是中位缺省**：真实世界的一杯可以差 3 倍。严肃使用请覆盖毫克数。
- **主观音效与浓度解耦**：耐受让慢性摄入者「感觉不到」50mg，但它对睡眠结构的客观影响仍在文献中可见。感觉不到不等于没烧。
