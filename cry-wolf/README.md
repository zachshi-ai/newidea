# 虚惊 · Cry Wolf

> 警报响的时候永远像第一次——因为你的大脑从没对过这笔账。把每场灾难想象抄成一行可检验的预测,到期回来结案:同一主题的担忧第 N 次重播时,账本指着它自己的历史说「又是你」。

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 慢性担忧者——不是焦虑症患者,是每个正常人。38 岁的产品经理、5 岁孩子的爸妈、上有老下有小的中年人:担忧是想象力的副作用,人人都有 |
| **场景** | 半夜睡不着,脑内过电影:「下季度重组名单上有我」「孩子咳嗽不会拖成肺炎吧」「体检那个结节不会是坏东西吧」「爸妈总有一天要用一大笔钱」。同一个担忧每月回来一次,每次都像头一次一样真实可怕 |
| **问题** | 担忧只在脑内播放、从不对账。你记得「那阵子很焦虑」(情绪记忆),但不记得:(a) 具体怕的是什么;(b) 后来到底发生了没有;(c) 同一个担忧已经回来多少次。于是「90% 的担心不会发生」永远是别人的鸡汤统计,你的警报器误报率没有任何人见过——包括你自己;重播的担忧没人点破,第 5 次担心孩子咳嗽时,没人对你说「前 4 次全是虚惊」;为虚惊熬的夜(真实成本)被记进「那阵子状态不好」的模糊印象里,从没绑在具体哪场担忧头上 |
| **价值** | 把「别瞎担心」从安慰变成你自己的统计:①**虚惊率**——你写下的灾难,到期结案,几件真发生了(样例:7 件结案 5 件虚惊,含半击中 6 件);②**狼链**——同一主题的重播串成链,每次重播入账时点你已知的战绩就钉在行上(样例:child-health 链第 4 场入账时战绩 0H/0P/3M,你还是记了它);③**虚惊账单**——为没发生的狼熬的夜 vs 为真火熬的夜(样例:9 夜 vs 1 夜)。狼来了寓言里孩子喊了三次狼没来;在你脑子里喊了三十年的那个声音,没有一次被点名过 |

**本件不是**:不是心理治疗、不诊断焦虑症(GAD-7 是医生的事)、不给「该不该担心」的答案——它只对账:你怕过的东西,到底来了没有。

## 二、账本形态

手编 TSV,8 列,两种行型:

```tsv
date	type	topic	fear	due	nights	ref	outcome
2026-03-02	fear	child-health	kindergarten flu: his cough turns into pneumonia	2026-03-16	2		
2026-03-16	check										6	miss
```

- **fear 行**(入账一场担忧):`fear` 写到**能检验**(谁/会出什么事——「会出事」没法结案);`due` 是你答应自己回来看结果的日期,**留空的担忧是一台没有出口的循环**,会被 OPEN-ENDED 点名;`nights` 是为它失眠的夜数(可空,空按 0 记并披露笔数)
- **check 行**(到期结案):`ref` 指向 fear 行的**物理行号**(含注释与表头,编辑器可直达);`outcome` 三态——`hit`(核心灾难真发生)/ `partial`(沾边但轻/变形:「拖成肺炎住院」→ 支气管炎吃药)/ `miss`(虚惊一场)
- 一场担忧只结案一次;同主题再担心 = 另起一行入账,`wolves` 命令替你把重播串成链
- 判可检验性的不是机器,是你自己:入账那天写下的 due,就是在训练大脑把恐惧变成可对账的预测——**这是本账本唯一的皮肤游戏**

## 三、四命令

```
python3 cry_wolf.py report    # 全账体检:虚惊率、夜账、三类未结案、三盏灯
python3 cry_wolf.py wolves    # 重播惯犯链 + 每次重播入账时点的既有战绩
python3 cry_wolf.py due       # 催验单:你欠自己的裁决
python3 cry_wolf.py validate  # 恒等式与账本体检
```

公共参数:`--ledger`(缺省 `worries.tsv`)、`--as-of YYYY-MM-DD`(时间机器,缺省 = 账本自身最大日期,零墙钟)、`--alias 娃咳嗽=child-health`(主题词归一,可重复)。

### 退出码语义

| 码 | 含义 |
|---|---|
| 0 | 绿(或 due/validate 正常出账) |
| 2 | 账坏:坏日期(不补零/不存在的日历日)、未知 type/outcome、ref 悬空/双验、裁决早于担忧、缺列、负 nights |
| 3 | 空账(零字节/纯空行/有表头零行/文件不存在);report 已验 <5 件薄账拒绝判虚惊率(算术照出) |
| 4 | 账面红灯:WOLF(某主题已验 ≥3 场全 miss)/ OVERDUE-CHECK(任一裁决逾期 >30 天)/ OPEN-ENDED(无检验日的担忧 ≥5 场) |

## 四、样例:小周的 2026(10 场担忧,7 场结案)

小周,38 岁,产品经理,儿子糖糖上幼儿园。2026 年他入账了 10 场担忧、结案 7 场:

- **虚惊率**:5/7(71.4%)从没发生;把半击中(money 链:回撤 12% 没到强平线)也算进「没全信过」:6/7(85.7%)
- **夜账**:12 夜 = 为虚惊熬的 9 夜 + 为真火(job 链:客户真流失了)熬的 1 夜 + 挂着没结案的案件上还压着的 2 夜。**警报器响 7 次,只有 1 次真火,但每次响都像第 10 次**
- **狼链**:child-health 三次咳嗽三次虚惊(3 月/5 月/7 月),🔴 WOLF 灯亮——而 9 月流感季它第 4 次响起时,**入账那一刻链上战绩已是 0H/0P/3M**
- **时间机器**(`--as-of 2026-05-23`):当时只结案 3 场(2 虚惊 1 半击中),child-health 链才 2 场(▲ monitor 还不到狼线)——账本证明:7 月他又为同一件事熬 2 夜时,**不是不知道前两次都没事,是从没看过这笔账**

## 五、验收标准

| # | 验收标准 | 验证方式 |
|---|---|---|
| 1 | 恒等式:已验 = hit + partial + miss;场次 = 已验 + 未验;夜账四桶(狼/半/火/未结)之和 ≡ Σ nights | validate 独立路径重算 + 字面值钉死 |
| 2 | ref 是物理行号(含注释与表头);指向不存在/指向 check 行/二次结案/裁决早于入账,一律 exit 2 | 账坏网格测试 |
| 3 | 日期严格:不补零(`2026-3-2`)与不存在的日历日(`2026-02-30`)一律拒绝 exit 2 | 账坏网格测试 |
| 4 | 尾部制表符容忍(手编从表格粘贴),缺列不容忍 | 网格测试 |
| 5 | 空账(零字节/纯空行/有表头零行/纯注释/文件不存在)exit 3;`--as-of` 早于一切行 exit 3 | 网格测试 |
| 6 | WOLF 判级:同主题已验 ≥3 场全 miss 亮灯 exit 4;恰 2 场全 miss 只 ▲ monitor;hit/partial 任一破功;未结案场不计入链判级 | 链边界测试 |
| 7 | OVERDUE-CHECK:due 当天不算逾期(恰线不亮);逾期 ≤30 天点名不亮;>30 天亮灯 exit 4 | 阈值测试 |
| 8 | OPEN-ENDED:无 due 的担忧逐条点名;≥5 场亮灯 exit 4,4 场不亮 | 阈值测试 |
| 9 | 薄账分层:已验 <5 件,report 拒绝虚惊率(DECLINE exit 3)但计数/夜账/单案灯照出;WOLF 链自带 ≥3 门槛不受总账薄账拦截(薄账 + 狼 = exit 4 优先) | 分层测试 |
| 10 | 重播战绩:每场入账时点只统计**当时已写下**的同主题裁决(晚于入账日的结案不算);链上战绩随场次递推 | 字面值钉死 + 乱序测试 |
| 11 | 时间机器:晚于 as-of 的行被排除(非报错);check 晚于 as-of 的案退回未验状态 | as-of 回放测试 |
| 12 | `--alias` 主题归一可跨词并链;自映射幂等;坏格式 exit 2 | alias 测试 |
| 13 | 零墙钟:as-of 缺省 = 账本自身最大日期;同账任何机器任何一天逐字节一致;报告只打印 basename | 双跑比对 + 路径断言 |

## 六、与近邻的边界

- **[阴晴表](../mood-barometer/)**(情绪结果计量):那边记**感受的量**——今天几分、基线在哪、几天回弹;本件验**恐惧的内容**——你怕的那件事后来到底发生了没有。那边回答「我最近怎么样」,本件回答「我怕过的东西都怎么样了」。两本账可以记在同一本日记的两页。
- **[替罪羊](../scapegoat/)**(外部诱因归因):那边审**外面的嫌疑**(哪个食物/缺睡害的,Fisher 检验 + lift);本件审**里面的警报**(灾难想象本身可信吗,命中率 + 重播链)。都是「直觉 vs 基线」,一个的被告在餐桌上,一个的被告在脑子里。
- **[警报疲劳](../alarm-fatigue/)**(flaky 测试警报信用):机制最近的本家兄弟——那边给**代码测试的警报**建误报信用账,本件给**脑内的警报**建;那边的火警有 CI 日志作证,这边的火警只有你的账本。两边同一个道理:误报多了没人再信警报——所以更要分清哪些是误报、哪些是真火。
- **[稍后永不](../later-never/)**:那边是「点星即结算焦虑」的注意力信用卡;本件不管注意力,只管想象力开出的空头支票。
- **[瘾账](../hidden-tab/)**(戒烟):同是行为账本,那边记**行为**(抽没抽),本件记**想象**(怕不怕)——想象不产生任何可观测行为,只有账本本身是它的存在证明。

## 七、诚实条款

- **本件不诊断焦虑、不做治疗建议。** 红灯文案永远指向专业帮助;如果你的担忧已经影响吃饭睡觉工作,看医生,不是看账本。
- **狼链 3:0 降低的是先验,不是免检通行证。** 过去全虚惊不担保下一次——孩子咳嗽第 4 次该看医生还是要看。狼链退役的是**重播的惯性**,不是**警觉本身**;把红灯当「以后不用管了」的借口,是对这本账最坏的误用。
- **outcome 是你的裁决,不是客观记录。** hit/partial/miss 的界线写进 METHODOLOGY,但结案那一刻的判断只有你自己能做——账本拒绝替你结案,所以也没有结案命令,check 行永远是手编的。
- **可检验性是皮肤游戏,不是准入门槛。** 模糊的恐惧(「总有一天出事」)照样入账,但它会被 OPEN-ENDED 灯点名:没有检验日的担忧是一台没有出口的循环——入账时写下的 due,就是给想象装上的刻度。
- **nights 是自报的,虚惊夜不是「白熬」的指控。** 熬的夜是真的痛,本件只是让你看见它绑在哪个预测头上;「为没发生的狼熬了 9 夜」是陈述,不是「你不该熬」的判词。
- **担忧内容是心理敏感数据。** 账本只存本地,不连任何接口,不上传任何字节;`report` 只打印账本文件名,不回显路径。
- **零墙钟。** as-of 缺省锚定账本自身最大日期,`--as-of` 是时间机器不是今天;宁可不亮灯,不借系统时钟装懂——同一本账任何机器任何一天跑出的结果逐字节一致。

## 八、快速开始

```bash
cd cry-wolf
python3 cry_wolf.py report --ledger examples/worries.tsv   # exit 4:狼链亮灯,设计内
python3 cry_wolf.py wolves --ledger examples/worries.tsv
python3 cry_wolf.py due    --ledger examples/worries.tsv
python3 cry_wolf.py validate --ledger examples/worries.tsv
python3 -m unittest discover -s tests                     # 58 tests
```

账本放哪、叫什么随你——它只是另一个 TSV。真正的成本不是维护它,是每次警报响起时,多写的那一行。
