# 秋毫 · Shed Count

> 掉发是唯一「每天照镜子、却看不见月尺度变化」的身体信号：头发以每天几十根的速率脱落，任何肉眼与任何镜子都对月尺度渐变彻底失明——地漏里那一撮毛引发的焦虑没有分母（比什么时候？多多少？），生理性脱发 50–100 根/天的先验从未被逐日对过账。而米诺地尔宣称 3–4 个月起效、非那雄胺 6 个月评估、停药可能反弹——这些决定一年上千上万，**「你家起没起效」却从来没有对过账**。明察秋毫，先得把毫记下来。

## 一句话

把每次洗头的掉发计数抄成一本可手编的事件流账（TSV：日期/口径/根数/干预事件），开出五本账：**间隔归一的速率判级**（根/天，OK ≤ 100 < SHED ≤ 200 < FLOOD，先验垫底、自己的基线做主判据）、**干预三庭**（起效潜伏窗外才算账、混药 CONFOUNDED、治疗没全程在场判 VOID）、**停药反弹庭**（REBOUND）、**季节月历**（秋季签 + 同月同比）、**账本体检**（恒等式 + 双算法 + 口径门）。

## 角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 20–45 岁正在为掉发焦虑的人——尤其已经或正在考虑米诺地尔/非那雄胺等长期干预的人 |
| **场景** | 每天照镜、每次洗头看地漏；皮肤科医生问「掉多久了、有没有变稀」凭感觉答；米诺地尔涂了半年不知道起没起效，凭感觉停药；停了之后更没人告诉你有没有反弹 |
| **问题** | ① 掉发量没有分母：比什么时候？多多少？② 洗头间隔污染：两天洗一次掉 160 根 ≠ 一天洗一次掉 90 根；③ 干预宣称「3 个月见效」，但你家起没起效只有前后同口径速率对比能回答；④ 停药反弹无账可查；⑤ 秋季换发季背不背锅没人分得清 |
| **价值** | 把「数一数这次洗头掉了多少根」（与皮肤科 60 秒计数试验同源的家里唯一可采集的物理量）变成一本账，确定性回答：是不是真在超量掉、干预起没起效、停药有没有反弹、季节背不背锅。**账本不是皮肤科医生**——不鉴别 AGA 与休止期脱发，不下药；开始、停止、复诊永远是人和医生的决定 |

## 验收标准

1. 五命令零依赖（Python 3.8+ 标准库）跑通；样例账本关键读数全部钉死（全期 91.8 / 近90d 92.4 / 近30d 101.3 SHED exit 4 / 基线 127.5）。
2. 间隔归一恒等：池化 = Σ根数 ÷ Σ观测天，双算法（逐对累加 == 过滤一次求和）一致。
3. GAP 剔除边界：恰 45 天入池，46 天打 GAP 签剔除分母；观测天 ≤ 跨度恒等。
4. 绝对判级恰线：恰 100 = OK（宁可少亮灯），100.01 = SHED；恰 200 = SHED，200.01 = FLOOD。
5. 干预庭：after 窗从事件日 + 起效潜伏窗（米诺地尔 90d / 非那雄胺 180d，`--lag` 可翻案）起才开；drop 恰 0.30 = RESPONDING（含边界），rise 恰 0.15 = NO-CHANGE（不亮 WORSE）。
6. CONFOUNDED：其他干预落在 before 窗 ∪ [事件日, after 窗尾]（潜伏期混药不漏检）；VOID：同药 stop 在 after 窗 / 同药 start 在 before 窗——算术照出，判决作废。
7. 反弹庭：停药日 + 90d 延迟后 rise 恰 0.15 不亮，0.16 亮 REBOUND。
8. 口径门：wash 与 comb 六十秒采样各自配对统计、永不混算；表外口径点名不入统计；每行数据不重不漏。
9. 薄账分层：1 行账本统计 DECLINE exit 3 但档案照出；基线 < 3 对「不装知道」。
10. 账坏 exit 2：重复 (日期，口径)、负数/非整数根数、坏日期、孤儿根数、未知事件动词。
11. 零锚定：as-of 缺省 = 账本最大日期，`--as-of` 截断回放（未来行排除，不是透视）；同账同 as-of 逐字节一致；报告只打印 basename；源码无系统时钟。

以上全部由 52 个验收测试钉死。

## 快速开始

```bash
# 总账：三窗速率 + 两层判级 + 干预时间线（近30天 101.3 > 100 → SHED exit 4）
python3 shed_count.py report examples/sheds.tsv

# 速率明细：逐行间隔归一 + GAP 签 + 季节签 + 口径分离
python3 shed_count.py rate examples/sheds.tsv

# 干预三庭：米诺地尔 RESPONDING 43.2%（CONFOUNDED 联合用药）
#           非那雄胺 VOID（起效窗没走完就停药）
#           停非那反弹庭 REBOUND 23.9%
python3 shed_count.py intervention examples/sheds.tsv

# 月历：秋季签 + 同月同比（5 月 127.5 → 85.3，−33.0%）
python3 shed_count.py season examples/sheds.tsv

# 账本体检：双算法 / 恒等式 / 口径门 / 判级恰线 / as-of 确定性
python3 shed_count.py validate examples/sheds.tsv

# 时间机器：钉回停药反弹之前
python3 shed_count.py report examples/sheds.tsv --as-of 2025-12-31   # OK 73.1 绿灯

# 测试
python3 -m unittest discover -s tests -v
```

样例账本是小徐的四幕真实节奏：2025-05 地漏焦虑开始计数（基线 127.5）→ 06-14 米诺地尔、08-02 加非那雄胺（潜伏期照旧 128，之后降到 72.8）→ 2026-01-17 副作用顾虑自行停非那 → 春节断记 72 天（GAP 剔除）→ 5 月起爬坡，7 月近窗 101.3 回到红线——**停药的第二幕，是账本替记忆记住的**。

## 账本格式

TSV，五行一事件，`#` 开头为注释：

```
date	kind	count	event	note
2025-06-14			start minoxidil	皮肤科就诊 AGA 米诺地尔5%每晚
2025-06-15	wash	257
2026-07-19	comb	35			60秒采样
```

  - **date**：YYYY-MM-DD，必填；同一日期同口径只能一行；手编乱序没关系，载入即排序；
  - **kind**：口径——`wash`（洗头，别名 洗头/洗发/shampoo）或 `comb`（60 秒采样，别名 梳头/60秒/六十秒）；留空 = 纯事件行；
  - **count**：本次洗头（或采样）拢下来的根数，非负整数；**count 是本行与上一行之间掉的根数**，速率 = count ÷ 间隔天数；
  - **event**：`start|stop + 药名`（start ≡ 开始/用/用上，stop ≡ 停/停用/停药；米诺地尔 ≡ minoxidil ≡ 米诺/蔓迪/落健，非那雄胺 ≡ finasteride ≡ 非那/保法止，另有 度他雄胺/螺内酯/PRP/植发/补剂；表外药名保留原名、潜伏窗未知点名）；
  - **note**：自由文本，原样展示，永不参与计算。

## 判级与门禁

| 灯/档 | 线（全部可调） | 含义 |
|---|---|---|
| OK | ≤ 100 根/天（`--shed-line`） | 生理先验线内（恰线=OK，宁可少亮灯） |
| SHED | > 100 | 超生理先验线——把这张纸带去下一次就诊 |
| FLOOD | > 200（`--flood-line`） | 急性休止期脱发量级——灯文指向皮肤科就诊 |
| ELEVATED | 近窗 > 基线×1.5（`--elevate-line`） | 相对你自己的过去在恶化（与绝对线并排挂出） |
| RESPONDING | drop ≥ 30%（`--respond-line`） | 干预后速率显著下降（含边界） |
| WORSE / REBOUND | rise > 15%（恰线不亮） | 干预后恶化 / 停药后反弹 |
| CONFOUNDED / VOID | — | 联合用药功劳存疑 / 治疗未全程在场，判决作废 |
| GAP | 间隔 > 45 天（`--gap-cap`） | 断记：那几天没有观测，剔除分母 |

Exit codes：**0** 绿 · **2** 账本/参数损坏 · **3** 样本太薄/统计拒绝（算术照出）· **4** 近30天超生理先验线（SHED/FLOOD，就诊线索）。

## 与近邻的边界

  - **borrowed-silence** 同是「慢性不可逆的感官/身体消耗」，那边管噪音暴露剂量（耳朵没有复查记录，账本从暴露端推），本件管掉发速率（头发每两天给一次物理计数，账本从观测端算）——一个记暴露，一个记结果；
  - **borderline** 是化验指标连续量的纵向趋势（Theil-Sen 抗抖动），本件是离散计数流的间隔归一与干预对账——化验单医院开，根数自己数；
  - **silent-rot** 同是身体治疗史，那边管牙位治疗棘轮（治疗只做加法、价签只升不降），本件管毛发速率与药效对账（头发不是器官事件流，是持续流量）——棘轮问「下一次多贵」，本件问「现在掉多快、药有没有用」；
  - **repair-ledger** 的画饼系数（宣称续命 vs 实测续命）与本件的干预庭同源：宣称 3 个月见效 vs 实测第几天降速——但那边裁决机器修还是换，本件不裁决、只把前后速率并排挂出；
  - **deficit-illusion / fat-creep** 同是「肉眼对月尺度渐变失明」，那边对账摄入与体重（两本账互证），本件只有一本计数账——所以判级先验与个人基线双层并挂，绝不拿单一观测孤证下结论；
  - **scapegoat** 是症状-暴露归因法庭（谁害的），本件是干预-效果对账庭（药有没有用）——一个向后找凶手，一个向前验承诺。

## 诚实条款

洗头计数是「洗走的那部分毛」的样本，不是全头清点——绝对先验线只是通识垫底（50–100 根/天，folk），真正可比的是你自己的前后对比与基线，所有线 `--*` 一律可翻案，医嘱永远赢。账本不是皮肤科医生：不鉴别 AGA 与休止期脱发，不下药，不外推「哪天秃」——发际线不是债务到期日。红灯的灯文指向就诊；开始、停止、复诊，永远是人和医生的决定。隐私纯本地：报告只打印账本 basename，不连任何接口，不上传任何字节。账本只拒绝让「感觉」继续独裁。
