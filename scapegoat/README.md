# 替罪羊 · Scapegoat

> 发作当晚，直觉当场指认昨晚离得最近的那样东西；账本要求证据——单次巧合不再定罪，白戒三个月也有平反的一天。
> Intuition convicts whatever was nearest the night before; the ledger demands evidence. No more convictions by coincidence — and the wrongly banned walk free.

---

## 一句话

偏头痛、肠易激、荨麻疹、湿疹——反复发作的老毛病，人人手里都有一份二十条起步的「忌口清单」，每一条都源于某次发作后的当场指认：「昨晚喝了红酒，今早就痛，肯定是它。」单次巧合当庭定罪，然后永不平反——你不吃它的日子你也在发作，但凭感觉归因的人从不看基线。本件把发作与暴露记成一本可手编的日更账本（TSV：日期/是否发作/当日暴露），对每个嫌疑人开庭：**在场发作率 vs 对照发作率**（lift）、**Fisher 精确检验**、**Bonferroni 多重检验门槛**（十名嫌疑里总有一个像凶手，k 名受审就按 0.05/k 定罪）。判决阶梯：✗ 定罪 > ▲ 嫌疑重大 > ○ 监视名单 > ◌ 在逃 > ✓ 平反。示例账本实测（16 周、88 个记录日、12 名嫌疑人）：直觉定罪的**红酒是头号冤案**——10 天在场只发作 1 次（lift 0.49，比对照还低，平反时连「保护色」警告都附上）；真凶是毫无戏剧性的**缺睡**——在场发作率 57.1% vs 对照 12.2%，lift 4.70、p=5.9e-04，Bonferroni 之后照样定罪，归因发作 6.3 次；**陈年奶酪** lift 2.69 看着吓人，但只暴露过 2 天——在逃，拒判，「现在的样本连巧合都算不上」；还有 **4/17（23.5%）的发作发生在没有任何记录暴露的日子**——名单之外另有凶手，别把每次发作都赖给名单上的嫌疑人。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 偏头痛/肠易激/荨麻疹/湿疹等反复发作的老毛病患者；帮家人排查诱因、眼看对方越戒越窄的家属；被网上「八大诱因」清单吓得什么都不敢吃的疑病症候选人。 |
| **场景** | 发作当晚或次日清晨（「昨晚那杯红酒？」——离得最近的东西自动成为被告）；决定要不要把某样东西永久拉黑之前；已经戒了三个月、毫无改善、不知道该不该解禁的时候；医生问「你觉得诱因是什么」，只能交出一串感觉的时候。 |
| **问题** | ① **单次巧合定罪**：一次共现就拉黑，从不问「我不吃它的日子发作率是多少」——基线盲视让每个嫌疑人看起来都像凶手；② **永不平反**：冤案没有复核程序，戒了三个月没改善也不会还人清白，清单只进不出；③ **清单越长生活越窄**：二十条忌口叠上去，饭局、咖啡、奶酪全没了，生活质量单边下跌；④ **真凶在名单外面**：缺睡、空腹、激素这些没有戏剧性的诱因从不被怀疑，因为发作那晚它们不「像」嫌疑犯；⑤ **样本量从来不被考虑**：吃过两次、痛过一次的东西和吃了五十次、痛过一次的东西，在直觉法庭里判得一样重。 |
| **价值与意义** | ① **基线进场**：lift = 在场发作率 ÷ 对照发作率——没有对照臂的指认不予受理，这是直觉法庭和证据法庭的分界线；② **单侧 Fisher 精确检验**：超几何分布精确计算「如果它无辜，在场这么多次还能发作这么多次的概率」，零依赖 20 行实现；③ **Bonferroni 挡住「总有一个像凶手」**：k 名嫌疑人受审，定罪门槛就是 0.05/k——同一份证据，单独受审定罪、12 人陪审团在庭就只能算嫌疑重大（测试 A10 钉死这一对照）；④ **平反条款**：暴露 ≥ 6 天且 lift ≤ 1.15 即宣判无罪——冤案的成本是真实的，「这些日子你白戒了」第一次有人说出口；⑤ **THIN 拒判**：任一臂不足 3 天不开庭，lift 再吓人也不开庭——宁漏判不冤判；⑥ **无暴露发作单列**：零暴露日的发作占比就是「名单之外还有凶手」的计量，防止账本变成清单的复读机；⑦ 零依赖 + 纯本地 + `--today` 钉死逐字节可复现。 |

## 核心思想：把「昨晚吃了 X 今早发作了」换成一张 2×2 表

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **在场/对照两臂** | 记录在案的日子按「当天是否暴露」分成两臂；无记录日不进任何分母 | 「它不在场时你发作吗？」——直觉从不问的一问 |
| **lift** | 在场发作率 ÷ 对照发作率；1.0 = 无辜面相，4.7 = 每次在场都危险 | 「它让发作风险变了多少倍？」 |
| **Fisher 单侧 p** | 固定边际的超几何精确检验：`P(在场臂发作 ≥ 实测)` | 「如果它无辜，这份证据有多凑巧？」 |
| **Bonferroni 门槛** | k 名受审者，定罪门槛 0.05/k | 「十个小偷里总有一个案发时在场——你抓的是凶手还是倒霉蛋？」 |
| **归因发作** | `a_e − E×rate_u`：不暴露它时这些天本可以不发作 | 「避开它到底值几次发作？」 |
| **无暴露发作** | 发作但当日零暴露的日子单列占比 | 「名单之外还有没有凶手？」 |
| **THIN 纪律** | 暴露臂或对照臂 < 3 天 → 在逃，拒判 | 「这点证据够开庭吗？」——大多数时候不够 |

三条设计立场刻在实现里：**定罪必须过 Bonferroni，lift 大不够**——空腹 lift 3.08、p=0.042 单看漂亮，但 11 人受审门槛 0.0045，它只能算嫌疑重大；**平反需要 6 天暴露**——没受过考验的清白不算清白，不敢吃就没有平反的一天；**组合线索永不定罪**——「缺睡 × 红酒」看着像搭伙作案，但共暴露 5 天的样本连单人卷宗都不如。

## 判决阶梯

| 档位 | 判据 | 语义 |
|---|---|---|
| ✗ 定罪 CONVICTED | lift ≥ 2.0 且 p < 0.05/k | 证据级定罪，账本亮红灯 exit 4 |
| ▲ 嫌疑重大 TENTATIVE | lift ≥ 2.0 且 0.05/k ≤ p < 0.05 | 过单人线、未过家族线——先盯着，别急着拉黑 |
| ○ 监视名单 WATCHLIST | 其余可审情形（lift 未达线 / 不显著 / 样本薄） | 继续记录，继续生活 |
| ◌ 在逃 SUSPECT | 任一臂 < 3 天 | 拒判——现在的样本连巧合都算不上 |
| ✓ 平反 ACQUITTED | 暴露 ≥ 6 天且 lift ≤ 1.15 | 证据不支持定罪，可以解禁——解禁与否仍由你决定 |

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 账本格式

一份可手编的 TSV，每行 = 一天：

```
date	attack	triggers	note
2026-05-07	1	缺睡,红酒	先兆：闪光 20 分钟
2026-05-11	0	咖啡因,压力
2026-05-27	1	-
```

- `attack`：1 = 当天发作，0 = 没发作；`triggers` = 当日暴露，逗号/顿号分隔，`-` 或留空 = 记了账但零暴露；
- **缺席日期（整行不写）不进任何分母**——账本只记你声称的事实，缺席的周末既不是证据也不是不在场证明；
- 嫌疑人名自由取（中英文皆可），大小写与空白自动折叠；`note` 可选。

## 命令速查

```bash dd:ignore
python3 scapegoat.py verdicts diary.tsv --today 2026-08-24       # 全员审判台（有定罪 → exit 4）
python3 scapegoat.py judge diary.tsv --trigger 缺睡               # 单人卷宗：2×2、恒等式、Fisher、门槛
python3 scapegoat.py acquitted diary.tsv                          # 平反名单
python3 scapegoat.py case diary.tsv --date 2026-05-07             # 案发夜复盘
python3 scapegoat.py simulate diary.tsv --avoid 缺睡 --months 3   # 反事实：避开某人至多少发几次
python3 scapegoat.py combo diary.tsv                              # 组合作案排查（永不据此定罪）
python3 scapegoat.py validate diary.tsv                           # 账本体检：覆盖率、缺席条款
```

## 一个真实样例

小周，偏头痛十几年，5 月初那次发作前一晚喝了红酒——红酒进了黑名单，巧克力和咖啡因是更早的受害者。2026-05-04 起他把发作与暴露记成日更账本，16 周、88 个记录日（覆盖率 80%）、17 次发作、12 名嫌疑人，见 [examples/diary.tsv](examples/diary.tsv)。8 月底开庭（`verdicts`，exit 4）：

三本账读过之后：**红酒平反**（`judge --trigger 红酒`：在场未作案 9 次，「这些日子你戒得毫无收益」）；**真凶是缺睡**——`simulate --avoid 缺睡 --months 3` 折算「当前基线 19.3% → 3 个月约 17.4 次；避开后约 10.9 次」，账面至多少发 6.4 次（诚实条款：相关上限，非因果承诺）；**陈年奶酪不许审也不许放**——2 天暴露 lift 2.69 看着吓人，账本的原话是「现在的样本连巧合都算不上」。巧克力黑名单撤诉，空腹进嫌疑重大，激素（那 4 次无暴露发作）头一次以嫌疑人的形态出现在纸面上。

## 验收标准

全部转成自动化测试（[tests/test_scapegoat.py](tests/test_scapegoat.py)，48 个用例）：

| # | 验收标准 |
|---|---|
| A1 | 坏行带行号 exit 2：列数/日期/attack 非法/未来日期/重复记账/文件缺失 |
| A2 | 表头、注释行与空行跳过 |
| A3 | 诚实条款：无记录日不进任何分母（对照臂 = 记录日 − 暴露日） |
| A4 | 恒等式：每个嫌疑人 a_e + a_u = 总发作数，一天不多一天不少（示例账本全员核对） |
| A5 | lift 精确：rate_e ÷ rate_u；对照臂零发作 → ∞ |
| A6 | Fisher 单侧精确检验与手算超几何对表（4/220、246/252 两组） |
| A7 | THIN：任一臂 < 3 天在逃拒判；全员在逃 → exit 3 |
| A8 | 平反门槛：暴露 ≥ 6 天且 lift ≤ 1.15；5 天清白不够格（监视名单·偏无辜） |
| A9 | 定罪门禁：lift ≥ 2 且 p < 0.05/k → RED exit 4 |
| A10 | 唯一嫌疑人偏见：同一份证据 k=1 定罪、13 人陪审只判嫌疑重大——Bonferroni 对照钉死 |
| A11 | lift 达线但 p 不显著 → 监视名单，不定罪 |
| A12 | 归因发作 = a_e − E×rate_u（示例缺睡 +6.3；平反者可为负） |
| A13 | 无暴露发作占比单列（示例 4/17 = 23.5%） |
| A14-A17 | judge 未知嫌疑人 exit 3；acquitted 空名单诚实输出；case 缺席日期 exit 3；simulate 对 THIN/监视名单/平反者一律 exit 3 |
| A18 | combo 共暴露 < 5 天不判，线索永不触发门禁 |
| A19-A21 | verdicts 排序确定；零发作账本全线 exit 3；空账本 exit 3 |
| A22-A24 | validate 覆盖率与缺席条款；`--today` 钉死逐字节可复现；只 import 标准库 |

## 诚实条款

这本账只记你声称的事实，它不化验血液也不监测睡眠——所以**前瞻记录**（当天记暴露，而不是发作后倒推）是它唯一的皮肤游戏。倒果为因（发作前兆让人翻旧账找原因）与混杂（缺睡的人也更爱喝酒）都藏在 lift 里，simulate 的每个推演都背着同一句话：**相关性的上限，不是因果的承诺**。它不下医嘱：红酒平反不是解禁许可证，缺睡定罪也不是处方——把卷宗带去给医生看，判决与否仍是人的决定。
