# 冷暖自知 · Own Thermometer

> 天气预报只播空气的温度，通用穿衣表写的是「平均人」的刻度；而你每次出门后的冷热后悔，一年发生几百次，没有一次被记账。
> A zero-dependency CLI that turns "what do I wear today" from a daily dice roll into a skin ledger: your own comfort terrain, every garment's real temperature window, combo win rates, a miss autopsy — and tomorrow morning's verdict, all mined from the days you already lived.

---

## 一句话

「今天穿什么」是全年最高频的重复决策——每天一次、每次 30 秒、错一次难受一天——但它也是唯一没有账本的决策：天气预报给的是空气的温度，穿衣 App 给的是「平均人」的表格（15 度穿风衣？那是平均人的 15 度），而你昨天冻着了、去年这个温度热了一天、上个月倒春寒连冷三天——这些体感数据每天都在产生、说完就蒸发，于是同样的错年年在同一个温度带上重演。`own-thermometer` 把体感记成一本可手编的账（TSV：日期/预报低温/高温/天气/穿着/体感 −2..+2），从你自己穿过的日子里确定性长出六样东西：**温度地形**（失误率按 3°C 桶分布，舒适段与雷区自动浮出）、**失误账**（冷热后悔第一次有了分母和方向）、**换季惯性**（骤变日 vs 渐变日的失误率对照——温度跳水的早晨，你的衣柜还停在昨天）、**单品温区**（每件衣服从你的记录里长出刻度，从没穿对过的孤儿被点名）、**温度断档**（衣柜在温度轴上的空洞——雷区往往是它的伤口）、**明晨裁决**（输入预报温度，用近邻战绩投票：SAFE/RISKY/DEAD/WASTELAND，exit code 可进脚本）；再加上**失误解剖**：同温带明明有 ≥80% 胜率的组合你却没穿，是「怪手」；同温带根本没有好答案，是「怪衣柜」——有解和无解第一次分账。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 每年换季都难受一次的人——「穿少了冻一天、穿多了热一天」反复横跳的人；衣柜满满当当却说「没衣服穿」的人；体感异于家人（怕冷/怕热）却被通用穿衣表代表的人；买外套时答不出「我缺一件几度穿的衣服」的人。 |
| **场景** | 早晨出门前 30 秒：天气 App 写着 8~16°C，衣柜前站 20 秒，凭感觉抓两件，出门后悔或下午后悔，回家把「冻死了/热死了」说出口——然后蒸发。换季周末整理衣柜：「这件要不要收」全凭印象。降温预警弹出来的晚上：明天该翻出哪件，全靠赌。 |
| **问题** | **体感是唯一没有账本的高频主观数据**：一年几百次出门决策，冷热结局从不被记录，「上次这个温度穿它冷」的记忆活不过两周，同样的错年年重演。**通用穿衣表是平均人的**：个人偏差（代谢、耐热、湿冷敏感）从没有被量化，「我妈觉得我冷」是别人的账本。**衣柜按品类组织、从不按温度组织**：「16~20 度穿什么」你答不出来，因为没一件衣服被标过实测刻度——换季难受的真相常常是衣柜在温度轴上有断档。**失误不可解性不分**：冷了一天，是衣柜没这件衣服（无解，该购物），还是明明有答案却没穿（有解，该反省）？从不区分，于是买新衣服和自责都可能是错的。 |
| **价值与意义** | 1) **温度地形**：失误率按 3°C 桶摊开，舒适段与雷区自动浮出——示例账本 111 天里，[9,18)°C 是连续 3 桶失误率 ≤20% 的舒适段，而 [18,21)°C 失误率 66.7% 是雷区；「每年春秋 20 度左右难受」从玄学变成地图上的一块红。<br>2) **失误有了分母和方向**：失误 23/111 = 20.7%，冷 13 : 热 10 = 1.3:1（穿少的乐观税）；雨天失误率 30.0% vs 干天 18.7%，湿冷多罚 11.3pp。<br>3) **换季惯性**：与上一记录日温差 |Δt| ≥3°C 的骤变日，失误率 44.4% vs 渐变日 18.8%——**2.4 倍**，「你按昨天的体感穿今天的衣服」第一次是可测的；月度解剖再补一刀：3 个换季月（11 月 35.0%、3 月 37.5%、4 月 40.0%）对深冬的 4.3%/0%/10.0%——失误不住在冷的地方，住在温度换挡的地方。<br>4) **单品温区与孤儿**：轻型羽绒 8 穿 0 好（win 0.00）、长袖T 15 穿 12 冷热（win 0.20）——衣柜里的孤儿温区被点名；毛衣+风衣 26 次 win 0.96 是真正的台柱。<br>5) **温度断档**：[20,22)°C 连续 3 度没有任何单品穿对过 ≥2 次，而那一段已经有 5 天出门硬扛记录（冷 0 · 热 5）——「每年换季在 20 度栽跟头」是衣柜的洞，不是你的手。<br>6) **明晨裁决**：明天 7~13°C → 近邻 18 天里「毛衣+风衣」13 次 13 好，SAFE exit 0；有人想穿「轻型羽绒+长袖T」→ 全史兜底 8 穿 8 冷，DEAD exit 4；明天 18~23°C → 近邻 7 天 0 次刚好，WASTELAND exit 4——这段温度你的衣柜没有答案。<br>7) **失误解剖**：23 天失误里 16 天（69.6%）**有解**（同温带存在 ≥80% 胜率组合你却没穿），7 天（30.4%）**无解**（衣柜的锅），恒等式 16+7+0=23 钉死；连败线再兜底：[6,9)°C 桶 3 月初连续 3 天偏冷，exit 4。<br>8) **零依赖 + 纯本地**：Python 3.8 标准库，账本手编 TSV，一行不出电脑。 |

## 核心思想：一本皮肤账，两张地图，一次开庭

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **体感标尺 feel** | −2 很冷 / −1 偏冷 / 0 刚好 / +1 偏热 / +2 很热，只记你的主报告——账本把它当声称，不当真理 | 「今天到底行不行？」 |
| **决策温度** | tmean = (tmin+tmax)/2，用你出门前抄的预报，不用气象站实测——审计对象是你决策时的信息 | 「用什么温度记账？」 |
| **温度地形** | 失误率按 3°C 桶分布（桶 n≥5 才判）：连续失误率 ≤20% 的最长段是**舒适段**，≥50% 的最长段是**雷区** | 「我的体感长什么地形？」 |
| **换季惯性** | 骤变日（与上一记录日温差 \|Δt\|≥3°C）vs 渐变日的失误率对照 | 「我是不是按昨天的体感穿今天的衣服？」 |
| **单品温区** | 该单品全部记录 tmean 的 P10/P50/P90（出现温区）+ win（feel=0 占比）；win<0.50 且 ≥5 次点名**孤儿温区** | 「这件到底几度穿？」 |
| **温度断档** | 舒适带（feel=0 的 P10–P90）内连续 ≥2.0°C 的 1.5°C 档无实测覆盖：覆盖 = 档内某单品穿对 ≥2 次——**穿过 ≠ 穿对，覆盖不做插值外推** | 「衣柜在温度轴上的洞在哪？」 |
| **组合胜率** | 组合 = outfit 原文（+ 连接）；win = feel=0 占比，n≥3 才判：★闭眼穿 / ◐看情况 / ✗该退役 | 「哪套是真的能打？」 |
| **明晨裁决** | 近邻 = \|tmean−目标\| ≤1.5°C 的历史日：推荐 feel=0 组合；指定组合过闸 SAFE（win≥0.70）/ RISKY（0.40–0.70）/ DEAD（<0.40）；近邻全失误 → **WASTELAND**；近邻不足 → UNKNOWN 拒答 | 「明天穿什么？」 |
| **失误解剖** | 同温带（±1.5°C，不含当天）≥3 天历史才受理：存在 ≥80% 胜率组合 → **有解（怪手）**；没有 → **无解（怪衣柜）**；都不足 → 不可判。恒等式：有解+无解+不可判 ≡ 失误总数 | 「怪衣柜还是怪手？」 |
| **连败线** | 3°C 桶内按日期末尾连续 ≥3 次同向失误 → exit 4：这段温度该补衣服，不是硬扛 | 「账本什么时候报警？」 |
| **红线与门槛** | 记录 <20 → exit 3；组合/单品/近邻样本不足 → THIN 不判；账本损坏 → exit 2——宁可沉默，不出没有证据的穿搭建议 | 「这个结论背后有多少证据？」 |

三条边界刻在实现里：**账本只记你声称的事实**——feel 是主观报告，本件把它当数据不当真理，它不做生理学也不做医疗建议；**每人一本账**——「怕冷」是个人参数不是缺陷，账本不可迁移，「我妈觉得冷」是另一本账；**账本自锚定**——所有「今天」以账本末期为锚（`--today` 可显式钉死），同一本账在任何机器任何时间跑出逐字节一致的结果。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

```bash dd:ignore
python3 own_thermometer.py report examples/ledger.tsv
```

## 命令速查

```bash dd:ignore
python3 own_thermometer.py report   ledger.tsv              # 体感总账：温度地形/失误账/换季惯性/换季解剖/近30天
python3 own_thermometer.py garments ledger.tsv              # 单品温区 + 孤儿点名 + 温度断档（有伤口 exit 4）
python3 own_thermometer.py combos   ledger.tsv              # 组合胜率：★闭眼穿 / ◐看情况 / ✗该退役
python3 own_thermometer.py plan     ledger.tsv --tmin 7 --tmax 13          # 明晨推荐（近邻战绩投票）
python3 own_thermometer.py plan     ledger.tsv --tmin 7 --tmax 13 --wear "轻型羽绒+长袖T"
                                                            # 指定组合过闸：SAFE 0 / RISKY 1 / DEAD 4 / UNKNOWN 3
python3 own_thermometer.py autopsy  ledger.tsv              # 失误解剖：有解(怪手)/无解(怪衣柜) + 连败线（exit 4）
python3 own_thermometer.py validate ledger.tsv              # 行级 + 恒等式 V1–V6（破即 exit 2）
```

账本格式（TSV，`outfit` 用 `+` 连接单品，`cond` 可留空）：

```bash dd:ignore
date        tmin  tmax  cond    outfit        feel
2025-11-13  4     9     cloudy  轻型羽绒+长袖T  -1
```

## 示例：一本 111 天的账本说出的话

示例账本（`examples/ledger.tsv`，2025-10-01 → 2026-04-12，小陈的一个完整秋冬春）跑出的全部结论，每一条都由 `examples/sample-*.txt` 快照逐字节固定：

- **温度地形**：舒适段 [9,18)°C（连续 3 桶失误率 ≤20%），雷区 [18,21)°C 失误率 66.7%——「每年春秋 20 度难受」有了地址。
- **失误账**：23/111 = 20.7%，冷 13 : 热 10（穿少的乐观税）；雨天 30.0% vs 干天 18.7%，湿冷多罚 11.3pp。
- **换季惯性**：骤变日失误率 44.4% vs 渐变日 18.8%（2.4 倍）——温度跳水的早晨，衣柜还停在昨天。
- **换季解剖**：3 个换季月（11/3/4 月，35.0%/37.5%/40.0%）对深冬（4.3%/0%/10.0%）——失误不住在冷的地方，住在温度换挡的地方。
- **单品温区**：轻型羽绒 8 穿 0 好（win 0.00）、长袖T 15 穿 12 冷热（win 0.20）双双进孤儿名单；毛衣+风衣 26 次 win 0.96 是台柱。
- **温度断档**：[20,22)°C 三度真空，5 天出门硬扛（冷 0 · 热 5），exit 4——衣柜的洞，不是手的错。
- **明晨裁决**：7~13°C → 毛衣+风衣近邻 13 次 13 好，SAFE；18~23°C → 近邻 7 天 0 次刚好，WASTELAND exit 4。
- **失误解剖**：有解 16 天（69.6%）/ 无解 7 天（30.4%）/ 不可判 0，恒等式 16+7+0=23；连败线在 [6,9)°C 桶逮到 3 月初倒春寒连续 3 天偏冷，exit 4。

## 与近邻的边界

- **cost-per-wear（每穿成本）** 量衣柜的**经济账**（买的值不值：吊牌价 ÷ 穿的次数），本件量衣柜的**舒适账**（穿的合不合适：什么温度、穿对了没有）。一件 CPW 冠军完全可以同时是孤儿温区——便宜、常穿、但从来没让你舒服过；两本账对同一件衣服给出正交的判决。
- **make-it（来得及）** 用经验分布回答「现在走来得及吗」，对象是**分钟**；本件用近邻战绩回答「明天穿什么」，对象是**温度**。同属「用你自己的历史回答今天」的家族，刻度不同。
- **felt-inflation（体感通胀）** 审计价格的体感与官方 CPI 的差；本件审计温度的体感与通用穿衣表的差——「你的篮子」与「你的皮肤」，同一家族的两位表亲。
- **social-jetlag（社交时差）** 的对象是睡眠钟面，**mood-barometer（阴晴表）** 的对象是情绪气候；本件的主观量表（feel −2..+2）与它们同构，但体感信号**当天闭环**（出门即验证，不存在气候漂移的长程问题），所以本件有雷区/断档这类空间结构，而它们有时间结构。
- **wilting-point（凋萎点）** 给植物装水位计，**redline（加量红线）** 给跑者装转速表；本件给人装的是**皮肤温度计**——三者都是「把无从感知的余量变成刻度」，对象互斥。

## 诚实条款

- **feel 是自报的主观值**：账本只把它当你的声称，同一温度两次可以记出不同的分；它不做生理学、不做医疗建议，「怕冷」不是病，是参数。
- **温度是你抄的预报，不是气象站实测**：审计对象是你决策时的信息——你按预报穿的，就用预报对账；预报错了是天气的锅，不是你的。
- **日均温是刻意简化**：不建模早晚温差、室内外切换、通勤时段；早晚出门温差大的城市，这条会钝化但方向不变。
- **每人一本账，不可迁移**：它不从网上抄任何「X 度穿衣表」，所有刻度从你自己穿过的日子里长出来；换城市等于开新账本。
- **拒答优先**：记录 <20 天 exit 3；组合 <3 次、单品 <3 次、近邻 <3 天一律 THIN 不判——宁可沉默，不出没有证据的穿搭建议。
- **它只把账摆上台面**：穿什么、买什么、退役什么，仍是人的决定；断档说的是「衣柜有洞」，不是「你必须买」。

## 验收标准

以下全部转成自动化测试（`tests/test_own_thermometer.py`），随代码一起交付：

**A. 账本纪律（exit 2 = 拒收）**
- A1 表头行/注释/空行跳过；非 6 列拒收。
- A2 feel 必须为 −2..+2 整数；tmin > tmax 拒收；cond 非法拒收；outfit 空/含空单品拒收。
- A3 日期重复拒收；日期无法解析拒收；账本为空拒收。

**B. 温度地形（report）**
- B1 桶宽 3°C，桶 n<5 THIN 不判；桶容量之和 = 记录数（恒等式）。
- B2 舒适段 = 连续可判桶失误率 ≤20% 的最长段；雷区 = ≥50% 的最长段；示例账本检出舒适段 [9,18)、雷区 [18,21)。
- B3 失误率与方向账：冷 + 热 = 失误（恒等式）；方向文案按 1.25 倍阈值分支。
- B4 雨干对照：任一侧 n<5 时不比（宁可沉默）。
- B5 骤变日（|Δt|≥--steep，默认 3.0）vs 渐变日对照，任一侧 n<5 不比；骤变倍数按实测钉死（2.4）。
- B6 月度解剖：月 n<5 THIN；换季月 = 失误率 ≥30%；示例账本检出 3 个换季月。
- B7 记录 <20 天 → exit 3 拒绝总账。

**C. 单品温区与断档（garments）**
- C1 温区 = 该单品全部记录 tmean 的 P10/P50/P90，线性插值与手算值钉死。
- C2 win = feel=0 占比；GOOD ≥0.75 / MIXED ≥0.50 / POOR <0.50；n<3 THIN；POOR 且 n≥5 点名孤儿。
- C3 断档 = 舒适带内连续 ≥2.0°C 的 1.5°C 档无实测覆盖（qualified 单品档内穿对 ≥2 次、出现 ≥3 次）；带出门记录 → exit 4，无误 → exit 0。
- C4 覆盖不做插值外推：3 次零星成功（18/23/23.5°C）不得声称 [19.0, 23.4] 全覆盖——本条是设计课的回归测试。

**D. 组合胜率（combos）**
- D1 组合 = outfit 原文；win 与三档门槛同 C2；n<3 进 THIN 名单。
- D2 「该退役」行显示最近一次失误（而非最近一次记录）。

**E. 明晨裁决（plan）**
- E1 近邻 = |tmean−目标| ≤ window（默认 1.5°C）；近邻 <3 → UNKNOWN exit 3。
- E2 推荐模式：近邻内 feel=0 组合按次数排行 top3；近邻无任何 feel=0 → WASTELAND exit 4。
- E3 指定组合：近邻 n≥3 用近邻口径；近邻不足而全史 ≥5 → 全史兜底（署名口径）；仍不足 → exit 3。
- E4 阈值：win ≥0.70 → SAFE exit 0；[0.40, 0.70) → RISKY exit 1；<0.40 → DEAD exit 4。
- E5 连败降档：该组合按日期末尾连续 3 次同向失误 → SAFE 降 RISKY、RISKY 降 DEAD，文案署名 STREAK。
- E6 --tmin > --tmax → exit 2；账本 <20 天 → exit 3。

**F. 失误解剖（autopsy）**
- F1 受审资格：同温带（±window，不含当天）≥3 天历史；不足 → 不可判，不予指认。
- F2 有解 = 同温带存在对照臂 ≥3 天且 win ≥0.80 的组合；否则无解。
- F3 恒等式：有解 + 无解 + 不可判 = 失误总数（测试钉死）。
- F4 连败线 = 3°C 桶内按日期末尾连续 ≥--streak（默认 3）次同向失误；存在 → exit 4，不存在 → exit 0。
- F5 记录 <20 天 → exit 3。

**G. 账本体检（validate）**
- G1 V1 行级 / V2 日期唯一 / V3 体感桶和 = 记录数 / V4 冷+热 = 失误 / V5 单品出场 ≥ 记录数 / V6 舒适带 ⊆ 温度范围；全过 exit 0，破任何一条 exit 2。

**H. 确定性与可复现性**
- H1 `--today` 缺省 = 账本末日；显式传入改变近 30 天窗口输出。
- H2 同一账本连续两次运行输出逐字节一致。
- H3 快照字节级校验：`examples/build_examples.py --check` 对 8 个 `sample-*.txt` 逐字节比对，报告只打印账本文件名（跨机器可复现）。
