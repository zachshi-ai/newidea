# 寻物税 · Search Tax

> 每次找不到东西的五分钟都感觉是运气差；账本说那是一笔没入账的开支——年化十个小时，外加为「以为自己没有」再买一遍的钱。
> Every five minutes spent hunting for your keys feels like bad luck; the ledger calls it an unledgered expense — ten-plus hours a year, plus everything you rebought because you thought it was gone.

## 一句话

寻物时间没有账单：门禁卡在沙发缝里、剪刀在第二个抽屉、充电线「丢了」于是又买了一根——买完第二天旧的原形毕露。每次翻找三五分钟不心疼，`search-tax` 把散落的「又没找到」记成一本事件流账（TSV 手编，三种事件：`search` 翻找 / `buy` 重购 / `fix` 设固定位置），确定性算出五本账：**年化寻物税**——样例家庭 8 个账本周 21 次翻找 96 分钟，周均 12 分钟，年化 624 分钟 = **10.4 小时/年**（一个整天花在找自己拥有的东西上）；给了时薪才有钱账（40 元/时：寻物税 ¥416/年 + 重购 ¥126.60 = **¥542.60/年**，诚实条款：不报价不谈钱）；**惯犯审计**——90 天窗口内翻找 ≥3 次判 REPEAT OFFENDER（门禁卡 x5、剪刀 x4、充电线 x3 三犯在册）exit 4，灯亮在你再去配一把钥匙/下一单剪刀之前；**重购税对账**——每笔「再买一个」 confront 寻物史：¥126.60 里 ¥112.70（剪刀/充电线/门禁卡）有寻史坐实为「找不到导致」，卷尺的 ¥16.9 无寻史如实标 UNEXPLAINED 让你自己解释；**固定位置诊所**——处方就是寻获地众数（剪刀 x3 都在抽屉找到：给它一个抽屉里的家），设位后按**每观察日比率**回访（门禁卡设位前 0.190 次/天 → 设位后 0.033 次/天，WORKING）；**反事实**——`simulate fix` 的治愈率只从账本内部的 fix 回访实测（门禁卡案实测缩减 82%），没有内部证据就拒绝发明数字 exit 3。账本自锚定：所有窗口钉在账本日期上，不读墙上的钟——同一本账任何机器任何一天跑出的结果逐字节一致。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 东西总是不翼而飞的人——钥匙、门禁卡、剪刀、充电线、指甲刀的永久失主；合租或家庭成员多、公共物品流动快的家；以及「找不到就再买一个」导致家里有三把剪刀的人。 |
| **场景** | 出门前翻找钥匙的第 8 分钟（样例里那次迟到 20 分钟）；网购的新剪刀还没到货、旧的自己在抽屉里现形；物业查消防前夜找不到灭火器；补办门禁卡的第二天在另一件外套口袋里摸到旧卡。 |
| **问题** | ① **寻物时间无账**——每次 5 分钟不心疼，年化 10 小时无人看见，因为它做完就消失、从不进任何账本；② **重购无对账**——为「以为自己没有」付的钱混在正常消费里，没人问过「这件东西你买了几遍」；③ **惯犯无从识别**——哪些东西反复失踪、该设固定位置，全靠感觉；设了位置有没有用，更没有回访；④ **找不到 → 买新 → 东西更多 → 更难找**的飞轮在静默加速。 |
| **价值与意义** | 1) **第一次有账**：10.4 小时/年的寻物税 + ¥126.60 的重购税有了分母，「我怎么老在找东西」从抱怨变成可管理科目。<br>2) **钱花在刀刃上**：惯犯清单告诉你该给哪三样东西安家，处方就是寻获地众数——它总在哪儿被找回，家就该安在哪儿，而不是再买一个。<br>3) **干预有回访**：fix 前后按每观察日比率对比，门禁卡案 WORKING、指甲刀案如实 TOO EARLY——疗效是测出来的，不是感觉出来的。<br>4) **诚实条款**：翻找时长是回忆值不建模秒表（±2 分钟足够，精确是幻觉）；重购是自报动机；治愈率只从账本内部估计，没证据不外推；漏记只会低估税额——宁可低估，不虚报。 |

## 核心思想：找不到的瞬间才发生，所以记账是事件流，不是物品台账

物品台账（「剪刀登记在抽屉 A」）会腐烂，因为它描述的是从未被更新过的静态世界。寻物只在**翻找的瞬间**发生——那是唯一的记账时机，也是账本的全部原料。三种事件构成最小闭环：

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **年化寻物税 report** | 账本周 = 首事件所在周一 → 末事件所在周日（含两端）；年化 = 总分钟 ÷ 账本周数 × 52；寻获地直方图只数找到的（`-` = 没找到，单列披露）；钱是翻译，`--wage` 或 `--salary/--hours` 才给钱账 | 「我一年花多少时间找东西？」 |
| **惯犯审计 repeat** | 账本末日为锚往前 `--window`（默认 90）天，窗口内翻找 ≥ `--hits`（默认 3）次 → REPEAT OFFENDER，任一在册 exit 4；差一次的进 WATCH 观察位；附处方（寻获地众数）或「尚无固定窝点」 | 「哪几样东西该设固定位置了？」 |
| **重购对账 dup** | `buy` 行按物品聚合金额；有寻物史（账上任何时点翻找过）→ CONFIRMED「丢了然后买了两遍」；无寻史 → UNEXPLAINED 如实披露，确认率 = 确认物品 ÷ 重购物品 | 「为『以为自己没有』花了多少钱？」 |
| **固定位置诊所 place** | 处方：未设位物品的寻获地众数 ≥2 次且无平局；平局判「游荡型」先观察；回访：fix 前后各 30 天按**每观察日比率**对比（窗口钳到账本末日），post ≤ pre ÷ 2 → WORKING，覆盖 <7 天 → TOO EARLY，两侧全无事件 → QUIET | 「给它安家之后，真的治好了吗？」 |
| **反事实 simulate** | `simulate fix --item X`：治愈率只取账本内可判 fix 案的实测缩减中位数；没有可判案例且未显式给 `--cure` → 拒绝发明 exit 3；显式 `--cure` 挂「外部假设」横幅；回放恒 exit 0，红线在 `repeat` | 「给这件惯犯安个家，一年省多少？」 |
| **账本体检 validate** | 恒等式：分型计数之和 == 总行数、分物品分钟之和 == 总分钟；完全相同的重复行是账目腐败 exit 2；没找到的翻找逐行披露 | 「这本账配不配得上结论？」 |

三条边界刻在实现里：

- **分钟是硬通货，钱是翻译**——不给时薪，全部命令照常出账，只是没有钱的行；给了才有「一年 ¥542.60」这张看不见的工资单的反面。
- **账本自锚定**——没有 `--today`，没有墙钟：90 天窗口、fix 回访窗口全部钉在账本自己的日期上。同一本账在任何机器、任何日期跑出的报告逐字节一致（examples 快照有 CI 字节级校验）。
- **工具不替你安家**——它点名惯犯、给出处方、实测疗效、给反事实标价；弯腰把剪刀放进抽屉的，仍然是人。它拒绝的是「再买一个」继续免费。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

```bash
python3 search_tax.py report examples/lostfound.tsv
```

## 命令速查

```bash
python3 search_tax.py report   lostfound.tsv --wage 40   # 年化寻物税 + 排行 + 寻获地
python3 search_tax.py repeat   lostfound.tsv             # 惯犯审计：≥3 次 exit 4
python3 search_tax.py repeat   lostfound.tsv --window 60 --hits 4   # 收紧判据
python3 search_tax.py dup      lostfound.tsv             # 重购税对账：确认率
python3 search_tax.py place    lostfound.tsv             # 处方 + fix 回访
python3 search_tax.py simulate lostfound.tsv fix --item 剪刀        # 内部治愈率反事实
python3 search_tax.py simulate lostfound.tsv fix --item 剪刀 --cure 0.5 --wage 40
python3 search_tax.py validate lostfound.tsv             # 恒等式与披露
```

## 账本格式（可手编 TSV，一行一个事件）

```text
date	event	item	minutes	place	amount	note
2026-07-19	search	剪刀	6	-		拆快递找不到剪刀
2026-07-19	buy	剪刀			19.9	找不到就下了单
2026-07-20	fix	门禁卡		玄关托盘		口袋不配拥有它
```

- `event` 三选一：`search`（minutes ≥ 1；place = 在哪儿找到，空或 `-` = 没找到）/ `buy`（amount > 0，只因「找不到」而重购的才记）/ `fix`（place = 它的新家）。
- 各事件字段纪律：search 不带金额、buy 不带分钟地点、fix 只带地点——串型即腐败，exit 2。
- 完全相同的两行是手抄事故，exit 2；同日多事件合法。
- 记录纪律：发生了才记（不是每天盘点）；漏记只会低估税额，账本宁可低估不虚报。
- 家人共用物品记物品名不记人——家是一本账，不是每人一本。

## 验收标准（全部转为自动化测试，52 个）

1. **解析守卫**：表头、列数（6–7）、日期格式、非法事件、空物品、search 分钟数（缺失/0/负/非整数/小数）、search 带金额、buy 缺金额或串型带分钟地点、fix 缺地点或串型带数字、完全相同重复行——全部 exit 2；注释与空行跳过；`-` 归一为「没找到」；乱序输入按日期稳定排序。
2. **周与年化口径**：账本周 = 首周一 → 末周日含两端（样例 07-27 → 08-09 恰 2.0 周）；年化 = 总分钟 ÷ 周数 × 52（35 分 → 17.5/周 → 910 分 = 15.2 h/年，手算钉死）；排行分钟降序、同名按名称升序；寻获地直方图只数找到的；样本不足（<8 次翻找或 <14 天覆盖）exit 3。
3. **诚实条款**：unpriced 全命令可用、无任何钱的输出、明示 NOTE；`--wage` 与 `--salary/--hours` 互斥、`--salary` 缺 `--hours` 报错；同一账本两次运行逐字节一致。
4. **惯犯门禁**：90 天窗口 ≥3 次 exit 4、差一次 WATCH 并附图例；`--window/--hits` 可调（收紧后红灯熄灭）；有寻获众数附处方；<8 次翻找拒绝审计 exit 3。
5. **重购对账**：有寻史 CONFIRMED、无寻史 UNEXPLAINED 带追问；总金额与确认率恒等式（1/2 = 50.0%）；账上没有 buy 行 exit 3。
6. **固定位置诊所**：众数 ≥2 且无平局才处方；2–2 平局判「游荡型」；fix 回访按每观察日比率（窗口钳到账本末日）：QUIET / WORKING（post ≤ pre÷2）/ NO-CURE / TOO EARLY（post 覆盖 <7 天——账本末日太近，不是「没再丢」）。
7. **反事实不发明治愈率**：可判 fix 案的实测缩减中位数（QUIET 案 = 100%）；无可判案例且无 `--cure` exit 3；显式 `--cure` 挂外部假设横幅；`--cure` 必须严格在 (0,1)；查无此物 exit 2；回放恒 exit 0。
8. **体检恒等式**：分型计数和 == 行数、分物品分钟和 == 总分钟钉死；「没找到」逐行披露；examples 快照 `search-tax/examples/build_examples.py --check` 字节级一致。
9. **exit 语义**：0 正常 / 2 账目或用法错误 / 3 样本不足或证据不足 / 4 惯犯红线击穿。
