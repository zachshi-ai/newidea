# 复现那杯 · Rebrew

> 你以为在调参，其实在抽奖：没有测过自己的手抖幅度之前，每一次「我发现 94°C 更好喝」都可能只是噪声。
> A zero-dependency CLI that turns a pour-over log into a kitchen lab: it measures your reproducibility radius, ranks which knob actually moves the score, and prescribes the next single-factor experiment.

---

## 一句话

每个手冲爱好者都有过这样的时刻：某个早晨，水温、研磨、注水节奏鬼使神差地凑在一起，冲出了从未有过的好喝——然后那杯再也没有回来。笔记本里躺着几十条冲煮记录，但从来没人回去分析它。`rebrew` 把冲煮日志（TSV）变成一个**厨房实验室**：先量出你的**复现半径**（同一配方重复冲的评分波动，也就是你的「手抖幅度」σ̂），再对每个旋钮（水温 / 研磨 / 粉水比…）计算它与评分的相关性排出**旋钮排行**，最后用**最小可检测效应**（MDE）回答「多大的评分差异才值得相信」，并给出下一步的**单因素实验计划**。核心反直觉洞见：**在过程噪声降下来之前，一切调参都是抽奖**。

---

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 手冲咖啡爱好者：家里有磨豆机、手冲壶、电子秤，每次冲煮都会微调参数，偶尔惊艳、常常困惑的人。 |
| **场景** | 冲出好喝的一杯却无法复现；想认真探索参数，但在咖啡论坛的「玄学」建议里无所适从；记了几十条冲煮笔记却从未回看。 |
| **问题** | **调参没有对照组**：① 不知道自己的**过程噪声**有多大——同配方冲两次能差 1 分还是差 3 分，从没量过，于是把手抖当成了发现；② 不知道**哪个旋钮在起作用、方向是正是负**——水温、研磨、粉水比同时在动，好消息坏消息混在一起；③ 不知道**多大的差异才可信**——0.3 分的「提升」在 0.5 分的噪声里毫无意义。 |
| **价值与意义** | 1) **玄学变科学**：把「我感觉」换成三条可计算的量——复现半径 σ̂、旋钮相关排行、最小可检测效应 MDE。<br>2) **先测手抖，再谈参数**：σ̂ ≥ 1.5 分（10 分制）时工具会拒绝给你调参建议，先练一致性——这是实验室的第一性原理，也是社区经验里从没人明说的前置条件。<br>3) **行动清单**：四阶段建议阶梯（复现 → 降方差 → 散开探索 → 单因素实验），永远告诉你下一杯冲什么。<br>4) **零依赖 + 纯本地**：Python 3.8 标准库，一个 TSV 文件就是全部数据库，不联网不上传。 |

## 核心思想：复现半径 → 旋钮排行 → 单因素实验

数据模型是一张人类可直接编辑的 TSV 表，一行一次冲煮。分析在**同豆域**内进行（不同豆的评分不可比，多豆日志自动取记录最多的豆）。

| 概念 | 定义 | 直觉 |
|---|---|---|
| **配方指纹** | 豆 + 粉量 + 水量 + 水温 + 研磨 | time_s 是过程结果，不入指纹 |
| **复现半径 σ̂** | 各重复配方组内评分标准差的均方根 | 你的手抖幅度：评分差小于 σ̂ 的对比都是噪声 |
| **旋钮排行** | 每个变量与评分的 Pearson r，按 \|r\| 排序 | 哪个旋钮真的在动评分，哪个根本没动过 |
| **MDE** | 2.8 · σ̂ · √(2/n)（每组 n 杯重复） | 均值差超过它才值得相信，否则维持原判 |
| **建议阶梯** | 复现 → 降方差 → 散开探索 → 单因素实验 | 逐级解锁，拒绝在数据不足时假装能调参 |

四阶段阶梯是产品的灵魂：日志里**没有任何同配方重复**时，工具承认测不了噪声，让你先复冲当前最高分配方（复现）；**σ̂ 超过实验线**时拒绝调参建议，让你先练一致性（降方差）；**配方只有一个**时让你把参数空间散开（探索）；三者都通过，才开出「锁定最优配方、只动一个旋钮 ±1 档、各冲 2 杯、按 MDE 判读」的实验计划。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

```bash
python3 rebrew.py analyze examples/realistic.tsv   # 完整分析报告
```

## 命令速查

```bash
python3 rebrew.py analyze examples/realistic.tsv            # 报告：总览/复现半径/旋钮排行/分组均值/MDE
python3 rebrew.py analyze examples/realistic.tsv --bean "Colombia Huila"  # 限定分析域
python3 rebrew.py suggest examples/realistic.tsv            # 下一步：下一杯冲什么
python3 rebrew.py validate examples/minimal.tsv             # 日志格式体检
python3 examples/build_examples.py                          # 重建示例数据（固定 seed）
```

你自己的日志：九列 TSV（表头固定、列序随意），`#` 开头是注释——

```text
date	bean	dose_g	water_g	temp_c	grind	time_s	rating	notes
2026-08-01	Ethiopia Chelbesa	15	225	93	6	145	7.0	酸质明亮
2026-08-02	Ethiopia Chelbesa	15	225	93	6	150	8.0	第二天更稳
```

## 一个真实样例

`examples/realistic.tsv`：59 条合成但真实感的日志（固定 seed 可重建），埃塞豆 49 条里**埋入了已知效应**——水温 +0.9 分/2°C、研磨越细越过萃、1:15 是这支豆的最优粉水比、噪声 σ=0.5。工具的分析报告：

```text
【复现半径】你的手抖幅度
同配方重复组 12 组；过程噪声 σ̂ ≈ 0.47 分（10 分制）
→ 评分差小于 0.47 的对比都可能是手抖，不是参数。

【旋钮排行】哪些变量真的在动评分
 1. 水温       r=+0.67（49 杯，4 个取值）  ← 最相关
 2. 研磨       r=-0.17（49 杯，4 个取值）
 ...
    过程变量 总时间：r=-0.05（time_s 是结果不是旋钮，相关≠因果）

【最小可检测效应】均值差多大才值得相信
每组 2 杯重复：差异 ≥ 1.32 分（近似 2.8σ√(2/n)）
```

埋进去的水温正效应登顶、研磨负方向被恢复、噪声估计 0.47（真值 0.5）、1:15 分组最优——**工具挖出了埋入的因果，而不是在叙述感觉**。验收测试把这个「已知答案」钉死成了断言。

## 验收标准

每条标准都有对应的自动化测试（`python3 -m unittest discover -s rebrew/tests`，共 91 例）：

| # | 标准 | 测试 |
|---|---|---|
| A1 | TSV 解析：表头校验、列序随意、注释/空行跳过、坏行汇总一次报全（带行号）、ratio 推导 | `tests/test_parsing.py` |
| A2 | 复现半径：重复组标准差 RMS 精确（1e-9）；无重复配方时诚实返回「测不了」，不假装能算 | `tests/test_analysis.py` |
| A3 | 埋入效应恢复：构造水温强正相关的合成日志，水温必须登顶旋钮排行且 r > 0.8 | `tests/test_analysis.py` |
| A4 | 噪声阈值：σ̂ ≥ 1.5 时 suggest 必须走「先降方差」，拒绝给出调参建议 | `tests/test_suggest.py` |
| A5 | 阶梯顺序：复现 → 降方差 → 散开探索 → 单因素实验，四级各自的前置条件精确触发 | `tests/test_suggest.py` |
| A6 | 单因素计划：低噪声 + 方向明确时输出「锁定最优配方、只动一个旋钮 ±1 档、按 MDE 判读」 | `tests/test_suggest.py` |
| A7 | MDE 性质：随 σ̂ 增大而增大、随每组杯数增大而减小；已知值精确 | `tests/test_stats.py` |
| A8 | CLI 端到端：analyze/suggest/validate 退出码与输出节齐全；坏日志、缺文件、未知豆优雅失败 | `tests/test_cli.py` |
| A9 | 统计原语：mean/stdev/pearson/rms 在已知数据集上与参考值一致，边界（n<2、恒定序列）返回 None | `tests/test_stats.py` |
| A10 | Dogfood：示例数据埋入的效应（水温 +、研磨 −、1:15 最优、σ≈0.5）全部被报告恢复；固定 seed 重跑生成器与提交文件逐字节一致 | `tests/test_dogfood.py` |
