# 明白账 · Fair Exit

> 离职结算单是大多数人一生中签过的唯一一份由对方起草、对方定价、对方审计的合同。HR 递来「N+1，今天签最好」，没有第二个人替你核对算术——而法定应得的每一项都有明确的算法。**签「一次性了结」条款的那一笔，关掉的不只是这张单子，是仲裁时效之门。**

经济补偿的基数是**离职前 12 个月应发工资的平均**（奖金、津贴、补贴都是应发），不是「基本工资」；未休年假按日工资的额外 200% 逐天折算，是结算单上**最常整行消失**的一项；竞业限制的义务写在你的页面上，补偿却常常没写在任何人的页面上。这些差不是感觉，是算术——本件把算术摊在桌上。

## 谁在什么场景下的什么问题

| | |
|---|---|
| **角色** | 面临协商解除/裁员/合同到期的上班族；想在在职期间就看清自己「账面 N」的人 |
| **场景** | HR 约谈后的 24 小时（「今天签有 N+1，过了这周方案就收回」）；签字前翻劳动法的深夜；签完之后偶尔泛起的「是不是给少了」 |
| **问题** | 离职结算没有对账单：基数被偷换成基本工资、年假折算整行消失、代通知金被包装成「厚道」、竞业只写义务不写补偿、差额被「再无其他争议」一句锁死——而仲裁时效只有 1 年 |
| **价值** | 把法定算术变成一份可对质的清单：逐项应得 + 与 HR 报价的差额定价到分 + 三个结算世界并排 + 时效倒计时。**它不替你决定签不签，它只拒绝让「我没算过」替你签字** |

## 方法速览：四份手编账本，五个命令

账本是四份 TSV（`#` 注释行合法，中英列名同效）：

```text dd:ignore
tenure.tsv（一行一段任期）
employer  start       end         kind  offer   notice  noncomp_months  noncomp_monthly
星云科技  2021-03-15  2026-08-31  协商  105000  y       6

payslips.tsv（一行一个月度应发）        leave.tsv（一行一个年度年假）
month     gross  overtime  note       year  entitled  used  note
2026-01   66000            含年终奖    2026  10        1     离职当年按日历折算
...

overtime.tsv 可选（一行一笔未付加班）
date        hours  kind     note
2026-06-13  6      weekend  周六上线
```

```bash dd:ignore
python3 fair_exit.py report   tenure.tsv payslips.tsv leave.tsv [overtime.tsv]  # 应得清单+恒等式
python3 fair_exit.py check    ...   # 签字门禁：报价 vs 应得，差额定价到分（红灯 exit 4）
python3 fair_exit.py clock    ...   # 仲裁时效倒计时（1 年）
python3 fair_exit.py worlds   ...   # 三个结算世界并排：HR 世界/法定协商世界/2N 世界
python3 fair_exit.py validate ...   # 账本体检 + 恒等式
# 别名：statement≡report · sign≡check · deadline≡clock · scenarios≡worlds · verify≡validate
```

## 硬应得的四项算术

1. **经济补偿 N 个月**——年限逐日游走：每满一年 +1.0；余 ≥6 个整月 +1.0（「六个月以上」含本数）；不满 +0.5；恰满整年周年日解除不多算半个月。基数 = 窗口 12 个月**应发**平均（不满 12 个月按实际月数，缺行披露不发明）。
2. **代通知金（+1）**——只有无过失性辞退是法定项（按上月应发）；**协商解除没有法定 +1**：HR 若给，那是谈判，不是义务，账本如实说。
3. **未休年假折算**——离职当年按日历折算舍尾（`floor(应享×已过天数/365)`，不足 1 整天不支付；多休不倒扣）；按日薪 × 200% 计价（法条 300% 口径含已发的正常工资）。日薪口径**剔除加班费**——与经济补偿基数不是一个口径，账本两把尺子并排亮。
4. **欠付加班费**——只算写下的（工作日 1.5× / 休息日 2× / 法定节假日 3×，时薪 = 日薪 ÷ 8）；声称的周末与真实日历对质，周三写「休息日」直接账坏 exit 2。

**恒等式**：`Σ分项 ≡ 硬应得合计`（残差钉到 0）。

## 判级与出口码

| 灯 | 语义 |
|---|---|
| `SHORTFALL`（exit 4） | HR 报价低于法定硬应得——差一分也点名（`--tolerance` 翻案） |
| `CAUTION` | 仲裁时效窗口只剩 ≤60 天 |
| `EXPIRED` | 时效已过——账本不装救护车，过期如实说 |
| `DOUBLE-CAP` | 双封顶触发：基数按社平 3 倍封、年限按 12 年封（需 `--soc-avg`，不给则不启用并点名） |
| `LEGAL-CAP` | 竞业月数超 24 个月上限——超出部分无效，按 24 算 |
| `LEAVE-GAP` | 有任期年度没记年假——没记 ≠ 没有，这些年的折算没有计入 |
| `ASSUMED` | 基数窗口应有的月份缺行——平均按你交的算，补上流水口径自动变严 |
| `DECLINED`（exit 3） | 在职（解除日未知）/ 零工资流水 / 无报价——档案照出，判级拒绝 |

出口码：`0` 绿 · `2` 账坏（缺列/坏日期/越界/重复/日历对质失败）· `3` 薄账 · `4` 红灯。

## 三个世界（worlds）

| 世界 | 语义 |
|---|---|
| HR 世界 | 报价签字后定格，「再无其他争议」随之生效 |
| 法定协商世界 | 逐项算术之和——谈判桌的锚，check 的对价 |
| 违法解除世界 | 2N——需要你举证；**签字关掉的正是这扇门**，而它与法定世界之差 ≡ 经济补偿本身 |

## 验收标准（全部转为自动化测试）

- **手算钉数**：样例账本的每个数字先在纸上算出再钉进测试——N=5.5、基数 27,750/27,500、经济补偿 152,625.00、年假折算 17,701.15、加班费 3,872.13、硬应得 174,198.28、差额 +69,198.28、竞业主张 49,950.00、2N 世界 326,823.28、时效剩 365 天。
- **边界网格**：年限折算在 3 个起步日（含月末/闰日）× 0–39 月 × ±1 天/半年/闰月钳位的网格上，逐日游走与闭式月差两算法逐点全等。
- **舍尾边界**：`10×243/365 → 6`、`10×7/365 → 0（不足 1 整天不支付）`、`10×182/365 → 4`、`10×186/365 → 5` 等已知真值往返。
- **账坏矩阵**：双任期行、解除早于入职、未知类型、重复月、解除后流水、负数、重复年度、年度越界、周三声称周末、周六声称工作日、缺列——全部 exit 2。
- **薄账分层**：在职（解除日未知）判级拒绝 exit 3 但基数档案照出；无报价 check 拒绝；`--as-of 2026-06-30` 钉回过去 = 在职视角 + AS-OF 剪除披露。
- **确定性**：同一份账本任何机器任何一天逐字节一致；源码无系统时钟，账本只从自己的行里长出「今天」；报告只打印 basename。

## 诚实条款

**计算器不是律师。** 全部比例与口径是通识先验且全部是 `--` 旗标：`--soc-avg`（社平，双封顶用）、`--min-wage`（基数下限）、`--exclude-overtime`（部分地区司法口径不计加班费）、`--leave-rate`（年假倍数）、`--noncomp-rate`（竞业 30% 线）、`--tolerance`。各地仲裁口径有差异，**本地仲裁委、你的律师和最新法规永远赢**。本件不判断解除合法与否（2N 世界需要你举证），不预测仲裁结果，不构成法律意见；签字与否、仲裁与否，永远是人的决定。工资是敏感数字：账本全部本地计算，不连任何接口，不上传任何字节。

## 与近邻的边界

- **job-funnel**（#24）管你**进公司**的那扇门（投递漏斗与沉默线），本件管你**离开公司**的那扇门（结算对质与时效）——一进一出，同一份雇佣关系的两端。
- **leave-debt**（#48）管**在职期间**的年假批次兑付（FIFO 消耗、拼假杠杆），本件管**劳动关系终结时**的年假法定折算（300% 口径、舍尾、多休不扣回）——同一笔假，两种命运。
- **mute-levy**（#68）对**税务局**对账（预扣 vs 汇算），本件对**雇主**对账（报价 vs 法定应得）——同是「没有人替你核对的钱」。
- **claim-line**（#73）的 NCD 与本件的 N 不是同一个 N：那边是攒出来的保费折扣，这边是按月折算的经济补偿；两个工具都在谈判前给你一个「自己的数」。
- **float-loan**（#57）审垫出去的钱（应收占用），本件审被结算的钱（应得清单）——都拒绝让「没记」变成「没有」。
