# 欠针 · Due Dose

> 接种本是孩子身上人手一份的官方账本,但它只记录「打了什么」,从不计算「还欠什么」:下一针靠门诊短信,换一个城市就断链;欠没欠针,只有入园查验那一刻才揭晓——每年五到八月,全国家长在查验截止日前突击补种。更根本的一层:接种本印的是**产品名**(「五联」「麻腮风」),查验读的是**抗原**齐不齐——同一份记录两种读法,中间没有翻译。**本子记的是打过的,没有人替你数欠下的。**

---

## 一、角色 / 场景 / 问题 / 价值

| | |
|---|---|
| **角色** | 0–6 岁孩子的家长——尤其是换过城市、换过接种门诊的家庭(接种记录跟着人走,提醒不跟着走),和孩子快到入园/入学年龄、查验在即的父母 |
| **场景** | 接种本记完就塞抽屉,下一针全靠门诊短信;搬家/换城市后短信断链,18 月龄的针掉档;听说「入园要查验接种证」,翻出本子却不知道齐不齐;二类自费(五联/手足口/水痘/流感)打了一路,从没算过花了多少、哪个系列只打了一半 |
| **问题** | ①**翻译缺失**——本子印的是产品名,查验读的是抗原:打满四支五联的孩子,本子上没有一个字告诉他「4 岁那剂口服脊灰已经被换掉了」;②**没有欠账视图**——按月龄该齐的抗原 vs 实际齐的抗原,只有门诊查,而门诊只看你约的那一种;③**没有补种几何**——查验截止日摆在那里,缺几针能不能补完、最晚哪天去第一针,没人算;④**二类是决策黑洞**——花了多少钱、哪支是半程(手足口两针只打了一针),从没有账本 |
| **价值** | `report` 把本子翻译成抗原覆盖矩阵,每剂判定 未到龄/该种/超龄欠针(样例:22 剂已 17,麻腮风第 2 剂与甲肝超龄 390 天——搬家丢的两针);`catchup --by 查验日` 排出最快并种日程与最晚启动日(样例:欠 3 剂,10-10 并种两剂 + 次年 3-15 流脑AC,余量 169 天);`paid` 给二类自费记账并点名半程针;时间机器钉回搬家前,一针不欠——**欠账是搬家搬丢的,账本让它看得见** |

**本件不是**:不是接种提醒器(门诊短信管「下一次」,本件管「欠下的」)、不是医疗建议(欠针红灯指向接种门诊的咨询,补种间隔与替代程序以门诊为准)、不是二类推销员(打不打、补不补,家长和医生的决定)、不是查验细则的权威(各地查验口径有差异,校医的清单永远赢)。

## 二、账本形态

一个目录两份手编 TSV(`--dir`,缺省当前目录)。数据源是**你手里那本接种证**,抄一针就是一行——0–6 岁一类共 22 剂,这就是全部数据工程:

```tsv
# kids.tsv —— 孩子名册(一行一个孩子,接种记录跟着人走)
kid	birth	note
小满	2023-03-15	2023 年春出生;2024 年秋从杭州搬到成都
```

```tsv
# doses.tsv —— 接种账(一行一针,产品名照本子抄,词表自动归一)
date	kid	product	price	note
2023-05-20	小满	五联疫苗	628	自费选了五联,一顶三
2023-11-17	小满	麻腮风疫苗		8 月龄,与乙脑同天两针
```

- **price 就是分类**:留空 = 一类(免费),填了 = 自费进 `paid` 账——少填一处少错一处
- **产品名自由书写**:「五联」「DTaP-IPV-Hib」「杭州五联白」都行——词表归一(`五联` → 百白破+脊灰+hib 各一剂);词表外的名字本件**不猜**(猜错一个名字,整本覆盖账全是假),exit 2 请你用 `--map "杭州五联白=五联疫苗"` 教一句
- **同日多针合法**(不同部位,含两个活疫苗);同日同产品、同日同抗原都是账坏——抄重还是打重,本件不替你挑

## 三、五命令

```
python3 due_dose.py report                     # 欠账总账:抗原翻译+每剂判定+灯
python3 due_dose.py gaps                       # 欠针清单:欠哪剂/应种日/超龄天数
python3 due_dose.py catchup --by 2026-08-31    # 补种排期:最快日程/最晚启动/来得及吗
python3 due_dose.py paid                       # 二类自费账:系列小计/半程针/合计
python3 due_dose.py validate                   # 恒等式与账本体检
```

### 判定阶梯(每剂)

`✓齐` → `·未到龄`(程序表只欠到龄的,不欠还没到的)→ `●该种`(到龄,超 3 个月内)→ `✗超龄欠针`(超 3 个月,`--overdue-months` 可翻案,**恰线不亮**——宁少报不冤枉)

### 灯

| 灯 | 级别 | 语义 |
|---|---|---|
| **OVERDUE** | 🔴 exit 4 | 一类剂次超应种月龄仍未记录——欠账不会自己消失,补上即平;「本子上从未见过」的出生剂次(乙肝/卡介苗)单加注记(那一针常写在出生证明页,不是没打过) |
| **INTERRUPTED** | 🟡 | 同抗原相邻两针 < 28 天(通识,`--min-gap` 可翻案)——门诊排的针也要亮出来,门诊永远赢,账要亮 |
| **HALF-COURSE** | 🟡 | 二类先验程序到龄未齐(样例:EV71 两针只打了一针)——补不补问门诊,不是催单 |
| **RUSH** | 🟡 | 查验前余量 < 14 天(恰线不亮)——来得及,别再等下一个假期 |
| **GATE-BLOCKED** | 🔴 exit 4 | 按通识间隔最快补完日仍晚于查验日——报「差几天」,并指向门诊的同日并种与替代程序 |

### 退出码语义

`0` 绿灯/仅黄灯 · `2` 账坏(日期补零/早于出生/悬空引用/同日同产品/同日同抗原/词表外/缺列/重复孩子/坏价格) · `3` 空账(教建第一行;有孩子无一针时用 `--as-of` 照常开庭) · `4` 红灯

## 四、样例:小满的 2024 年秋搬家

2023-03-15 出生;一岁前 12 针全部准点(含四支五联——**本子上最后一张「五联」,把 4 岁那剂口服脊灰也换掉了**);2024-10 搬家,18 月龄档的麻腮风第 2 剂和甲肝掉在了旧城市的日程表外;手足口第 1 剂打完,第 2 剂「一直没约上」。

- `report`(as-of 2025-10-10,账本最大日期):应 22 剂 · 已 17 · **超龄欠 2 项**(双双超 390 天)🔴,EV71 半程 🟡
- `report --as-of 2024-08-01`(时间机器,搬家前一个月):**超龄欠 0 项**——欠账是搬家搬丢的,不是天生的
- `catchup --by 2026-08-31 幼儿园入园查验`:到查验日需补 3 剂(含查验前才到龄的流脑AC)——10-10 并种两剂 + 2026-03-15 流脑AC,**最晚启动 2026-03-28,余量 169 天**
- `paid`:自费合计 ¥3,279(五联系列 ¥2,512 · EV71 ¥268 半程 · 水痘 ¥172 · 流感 ¥327)

## 六、与近邻的边界

- **fat-creep**:那边的免疫日历是**宠物的**(狂犬年免/猫三联),嵌在体重蠕涨账里;本件是孩子的,且核心不是「下次打什么」的日历——门诊短信就是日历,本件是「欠了什么」的对账与补种几何
- **medicine-rollcall**:那边管药箱库存的第二口钟(摆着的药死没死),本件管接种档案的欠账视图(打过的针欠没欠)——一个问货架,一个问档案
- **off-track**:同一本儿保手册的两页——那边是**身体的轨道**(身高在人群带里滑没滑),本件是**免疫的轨道**(针在程序表里欠没欠)
- **stack-dose**:同是「产品名→成分」的翻译,方向相反——那边把药盒名翻译成成分求和防**过量**(上限),本件把接种本翻译成抗原覆盖防**欠账**(下限);一个怕加起来多,一个怕数起来少
- **leave-debt**:同是「批次+时限」的债,方向相反——假期不用会作废(不用的蒸发),欠针到龄会积累(欠着的生长);那边管雇主授予的额度,本件管国家规定的程序
- **avalanche**:复习债每天自动加息、雪崩是复利;欠针按月龄阶梯累积、补上即平——线性的账
- **expiry-cliff**:到期是凭证失效,办了就续上;欠针不会自己消失,但补上即平——一个管提前量,一个管欠账
- **pace-gap**:同是「大纲覆盖 vs 实际进度」的结构——那边的大纲是自己选的、进度靠自己挣(节奏账),本件的程序表是国家给的、剂次是门诊打的(对账账);盖章的日程不需要意志力,只需要有人替你数
- **kin-ring**:同是家族的账——那边管病与年纪(上两代的确诊史),本件管针与月龄(这一代的免疫程序)
- **filial-desk**:一个家庭的两代——那边是子女给父母的运维工单,本件是父母给孩子的免疫对账

## 七、诚实条款

1. **程序表是通识先验**:国家免疫规划 2021 版是垫底口径;各省有增补、有替代程序(乙脑灭活 4 剂/甲肝灭活 2 剂/联合疫苗替代),全部 `--schedule` 整表翻案——**接种门诊永远赢**
2. **不做医疗建议**:欠针红灯指向接种门诊的咨询,不是诊断;补种间隔、同日并种、替代方案,以门诊排针为准
3. **二类不推荐只记账**:价签在册才进账本,没打过的不点名;半程针是陈述不是催单——打不打、补不补,家长和医生的决定
4. **「本子上没有」≠「没打过」**:NEVER-SEEN 只说本子上没有,不说针没进过身体;出生剂次的注记收窄到乙肝/卡介苗——「出生证明页」对它们才有特指含义
5. **词表不猜**:猜错一个名字,整本覆盖账全是假的——宁可 exit 2 请你用 `--map` 教一句
6. **查验口径是通识简化**:各地查验细则(查哪些针、按几岁)有差异,catchup 的「按查验日月龄应种剂次」是通识口径——老师/校医的清单永远赢
7. **孩子的健康档案是最敏感的数据之一**:不连任何接口、不上传任何字节;抄本子的一行是全部数据工程,账本只存在本地
8. **零墙钟**:as-of 缺省 = 账本最大日期,`--as-of` 钉死后同一本账任何机器任何一天逐字节一致,报告只打印账本目录名

## 八、快速开始

```bash
cd due-dose
python3 due_dose.py report --dir examples            # 小满的欠账总账(红灯 exit 4 是故事)
python3 due_dose.py gaps --dir examples              # 欠哪两剂、超龄多少天
python3 due_dose.py catchup --dir examples \
        --by 2026-08-31 --label 幼儿园入园查验        # 来得及吗、最晚哪天去
python3 due_dose.py paid --dir examples              # 二类自费 ¥3,279 与半程针
python3 due_dose.py validate --dir examples          # 恒等式与双路径体检
python3 -m unittest discover -s tests                # 64 项验收测试
```
