# 交底 · Handoff

> 日历记行程、账单记钱、相册记生活——没有任何一本账记录「要紧物在哪、除我之外谁知道、找回的线索失效了没有」。这不是遗嘱问题（遗嘱分配财产），是**寻宝图问题**：先找得到，才谈分配。

## 问题定义

**角色**：家庭的「信息枢纽人」——银行卡、保单、房产证、基金账户、老家借条的位置高度集中在他一人脑中的当家人；以及突发时刻被迫当侦探的家属（配偶/成年子女）。

**场景**：
- 一次住院、一次意外之后，家属要边悲伤边回答公证处继承流程的第一步——「列财产凭证清单」：有几张卡？保单在哪家、受益人是谁？房产证在哪个抽屉？提供不出，流程就停在那。
- 银行「久悬户」公告、保险「寻找失主」名单每年都在发：存款转入久悬不再计息、保单到期无人领——**钱不是没了，是找不到了**。
- 枢纽人自己知道该交代，但「交代」永远排不上日程：写遗嘱门槛太高，写密码表不敢放，「回头跟孩子说一声」说了三年。

**问题**：信息单点故障。枢纽人一倒，整个家庭的资产地图跟着断电——而这不是罕见的意外叙事，是每个中年家庭都欠着、没人动笔的一张图。

**伪需求检查**：公证继承的第一步材料就是财产凭证清单（家属要自己列）；银行久悬账户与保险业「寻找失主人」公告是每年都在发生的公共事实；「重要的东西放哪」是每年春节家庭对话真实出现的句子。本件不发明问题，只把「该交代的」结构化成一张可体检的图。

## 设计

零依赖 Python CLI（3.8+ 标准库），一份可手编 TSV：

- **交底账本** `handoff.tsv`：一行一件要紧物。中英列名同效，列序自由。
- **六类分区固定**：bank 银行与支付 / invest 投资与公积金 / policy 保单 / deed 产权与证件 / debt 债权与债务 / digital 数字账号——覆盖矩阵的恒等式地基。
- **量级(scale)只记档位不记金额**：k(<1万) / w(1–10万) / tw(10–100万) / hw(≥100万) / na(不适用)。足够家属排序，账本泄露也不构成精准攻击面。
- **密码永不入账本**：`key_clue` 记「密码线索在哪个本子第几页」，不记密码本身。1Password 管密码，交底管「家人知不知道密码管理器存在」。
- **盘点日声明**：账本头部一行 `# checked: 2026-09-06`，可多行（盘点轨迹）。as-of 缺省锚定最后一行——**零墙钟**：宁可不判新鲜度，不借系统时钟装懂。

四个命令：

| 命令 | 回答的问题 | exit |
|---|---|---|
| `report` | 要紧物清单：六类覆盖矩阵 + 带灯清单 + 盲区反问 | 0/3/4 |
| `brief` | 家属交接卡：急件优先、行号回溯、`--mask` 防窥 | 0/3/4 |
| `who` | 知情人账：哪些事只有我知道（SOLO 工单） | 0/3/4 |
| `validate` | 账本体检：恒等式 + 双路径重放 | 0/2/3 |

**三盏条目灯，各管各的案**：

1. **STALE**——verified 距 as-of > ttl（缺省 730 天，`--ttl` 一句话翻案，恰线不亮）。位置会变、密码会改、银行会合并：位置信息有自己的半衰期，「三年前记的抽屉」对家属已不可信。
2. **SOLO**——knows=self-only。这件事只有我知道：信息单点故障本身。SOLO 的解药不是加密，是一句说出口的「这件事你知道吗」。
3. **NO-TRACE**——where 与 key_clue 全空。家属拿着这张卡无处下手。

**一盏类别灯**：**MISSING**——六类中整类零记录。缺类不是账坏，是盲区；报告用反问句点它，不替你回答（「借出去的钱、欠别人的账,真的都不存在吗?说不出口,公证处也会问。」）。MISSING 让 exit 4：**门禁的语义是「账本还不完备」**。

**家属交接卡**：急件（`urgent=y`，还在月月扣费的、停机会连锁的）排第一页，其余按账本行序；每条带物理行号，可以从卡上那行 grep 回账本；`--mask` 把名目与线索里 ≥4 位连续数字打成 `****`（固定四星，不泄露长度）——贴出来防窥的版本。

**时间机器翻的是灯，不是清单**：`--as-of` 钉到过去，verified 晚于 as-of 的条目如实呈现（STALE 不亮），但条目计数与六类矩阵恒不变化——盘点表是状态不是流水，把「还没核实」假装成「没记过」，恒等式不答应。

## 验收标准（全部转成自动化测试，69 项）

1. **判级恰线语义**：verified 距 as-of 恰 730 天不亮；731 天亮；`--ttl 365` 翻案后同条 730 天亮；`--ttl 0` 全亮。线画在保守线上的意义是提前量，不是精确度。
2. **零墙钟**：源码无 `date.today`/`datetime.now`/`time.time`（静态扫描测试）；无盘点日声明且未 `--as-of` 钉死时 STALE 闸跳过并显著披露，SOLO/NO-TRACE 照出——宁可不亮灯，不装懂。
3. **灯的独立性**：SOLO 只认 self-only；NO-TRACE 要求 where+clue 全空（只空其一无警）；同一行可以 STALE+SOLO+NO-TRACE 三灯齐挂。
4. **MISSING 语义**：六类矩阵恒等（Σ各类件数 ≡ 条目数）；缺类出反问句；六类齐全不出现 MISSING；单行账本五类 MISSING 照亮 exit 4——「你只记了一件事」正是账本想说的。
5. **交接卡**：急件优先、余按行号；`--top` 截断/0=全部/超数=全部；行号回溯账本物理行 100%；`--mask` 遮 ≥4 位连续数字、短数字与文字不动、幂等（mask∘mask=mask）、条目守恒；账本别处的灯也让 brief exit 4——交接时知道全貌有暗角；**report 永不打码**（本人看的盘点）。
6. **时间机器**：缺省 as-of = 最后一行 `# checked:`；钉回 2024-02-10 时基金 STALE（830 天）、重疾险恰当天不亮、旧邮箱只剩 SOLO+NO-TRACE；两视角条目计数恒等。
7. **账坏 exit 2**：日期补零拒绝（2026-9-6）、日历拒绝（2月30日）、未知类别/量级/知情人、坏急件旗标、空名目、空核实日、未知表头列、缺必需列、重复列、字段数不匹配、无表头、坏 checked 声明、负 `--ttl`/`--top`。
8. **空账 exit 3**：零字节文件、纯空行、有表头零数据行；四命令一律拒绝。
9. **确定性**：报告只打印 basename；同账任意机器逐字节一致；快照 `examples/build_examples.py --check` 字节级校验（CI）。

## 使用

```bash
# 要紧物清单:六类覆盖+带灯清单+盲区反问
python3 handoff/handoff.py report handoff/examples/handoff.tsv

# 家属交接卡:急件优先,防窥打码版
python3 handoff/handoff.py brief handoff/examples/handoff.tsv --top 5 --mask

# 哪些事只有我知道
python3 handoff/handoff.py who handoff/examples/handoff.tsv

# 钉回第一次盘点那天,看看当时哪些灯还没亮
python3 handoff/handoff.py report handoff/examples/handoff.tsv --as-of 2024-02-10

# 测试
python3 -m unittest discover -s handoff/tests
```

## 诚实条款

- **交底账本不是遗嘱，更不是法律意见**。它不分配任何东西，只保证找得到；继承、公证、过户的流程问题去问公证处和律师，本件只把第一步的「列清单」变成一行一行的账。
- **它也不是密码管理器**。密码本身写进账本的那天，这本账就从寻宝图变成了炸弹——`key_clue` 只记线索在哪。
- 账本只记你写下的事实。没写的那件不在账上；MISSING 反问句是提醒不是指控——有些角落没敢看，账本替你说第一句。
- SOLO 灯记的是「账面上只有你知道」，不是「实际上没人知道」；反过来，写了 spouse 也不代表她真记得——所以每年盘一次，把 verified 改成今天。
- 量级档是主观估计不是审计数字；报少不报多不丢人，这本账的唯一读者是你在乎的人。
- 不连任何接口，不上传任何字节。这本账是你家里最敏感的一页纸，它只存在本地。

## 与近邻的边界

- **ghost-login** 管账号的**攻击面**（忘掉的账号是黑客的门），本件管资产的**交接面**（忘掉的账号是家人的墙）——同一批「被遗忘的账号」，一个怕它被陌生人打开，一个怕它没人能打开。
- **bus-factor** 把「这段代码只有一个人懂」记账，本件把「这笔钱只有一个人知道」记账——同一种单点故障，两份不同的账本。
- **paper-shield** 管备份回不回得来（数据的复活演练），本件管家人们知不知道去哪找（凭证的寻宝图）——那边验证 bit 能否读回，这边验证抽屉能否打开。
- **expiry-cliff** 管有效期的提前量（还活着吗），本件管位置的可达性（在哪、谁能找到）。
- **iou** 是债权人记别人欠我的明细账；本件的 debt 类只记一行「我借出去过一件事本身」——iou 的账本文件，就是 debt 类下该交底的第一件物。
- **fair-exit** 对质雇主递来的结算单，本件没有人需要对质——它对质的不是别人，是「我一直以为来得及」这件事。
