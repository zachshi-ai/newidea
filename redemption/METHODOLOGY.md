# METHODOLOGY · 赎契

本文档回答四件事：数学从哪来（推导）、口径怎么定（期界）、流行说法错在哪（对质）、以及边界在哪（不建模什么）。

## 1. 摊销的数学

### 1.1 等额本息（annuity）

本金 P、月利率 i（= 年利率/12）、n 期。月供 M 使余额恰好 n 期清零：

```
B_k = B_{k-1}·(1+i) − M，  B_0 = P，  B_n = 0
⟹ M = P·i·(1+i)^n / ((1+i)^n − 1)
```

每期拆分：`利息 = 期初余额 × i`，`本金 = M − 利息`。这两个式子是**会计恒等式**不是近似——validate 对全部 360 期钉死 `payment − interest − principal = 0`（最大残差 0.00e+00）与本金回归 `Σ本金 = P`。

**利息半程点**：累计利息达到总利息一半的期号。annuity 的形状保证它必然落在时间半程**之前**（样例：第 121/360 期，33.6% 处）。这不是「银行前几年收了你双份利息」，是余额前几年更大——租 100 万的月租当然比租 30 万贵。形状，不是阴谋。

### 1.2 真实利率

中国房贷报价「年利率 4.2%」按月计息：每月 0.35%。月复利口径的真实年化是：

```
(1 + 0.042/12)^12 − 1 = 4.2818%
```

银行没骗你（总利息就是按月复利算的），但「4.2%」这个数被拿去和理财的「年化收益」直观比较时会系统性低估价格 0.08 个点。本件所有与投资收益的对质都用月复利口径。

### 1.3 等额本金（linear）

每期本金恒定 P/n，利息按余额计，月供逐月递减。首期供 = P/n + P·i，末期最小。总利息 = P·i·(n+1)/2——比 annuity 少，代价是前期月供更重。两种方式**没有优劣**：它们是同一笔钱的不同排布，真实的比较只在「你的现金流形状」和「预付自由度」上。

## 2. 提前还款的两种去向

预付金额 A 在某期还款后生效，余额变为 B′ = B − A（B 为当期期初余额）。

**缩期（term）**：月供 M 不变，解新期数：

```
B′ = M·(1 − (1+i)^−n′)/i
⟹ n′ = ln( M / (M − B′·i) ) / ln(1+i)   （向上取整）
```

前 n′−1 期按 M 还，末期供 = 剩余余额 × (1+i) < M（schedule 自动收缩末期）。

**减供（payment）**：剩余期数 n_rem 不变，重解月供：`M′ = B′·i·(1+i)^n_rem/((1+i)^n_rem − 1)`。

**省息** = 原剩余计划总利息 − 新剩余计划总利息。恒等式（测试钉死）：term 模式的省息 ≥ payment 模式——缩期让钱离场得更早。样例：50 万缩期省 330,252，减供省 211,244，差 +56.3%。

## 3. 等效收益率定理（本件的灵魂）

**陈述**：一笔预付 A，在财务上等价于买入一份**年化恰等于合同利率（月复利口径）的无风险、税后投资**。

**两世界模拟**（`equivalent_check`）：设今天预付 A。
- 世界 A（还贷）：余额即刻减 A，按新计划走；每月省下的现金流（工资 − 更小的月供，或提前还清后整笔工资结余）按月利率 m 复利到原计划末日。
- 世界 B（投资）：A 按月利率 m 复利；原计划照走，月供从工资出。
- 两世界工资相同，在原计划末日同时点结账，比较财富。

**定理**：m = 月合同时，两世界终值差恒为 0。

**证明**（终值口径）：设原剩余计划 N 期、期初余额 B₀、月供流 M_t；新计划 N′ 期、月供流 M′_t。由摊销自洽（§1.1 递推的终值形式）：

```
Σ M_t·g^{N−t}   = B₀·g^N            （g = 1+i）
Σ M′_t·g^{N−t}  = (B₀−A)·g^N        （M′_t = 0 对 t > N′）
w_B − w_A = A·g^N − Σ (M_t − M′_t)·g^{N−t} = A·g^N − A·g^N = 0  ∎
```

数值面：`validate` 与 vsinvest 的输出都印着这条校验（样例：3.5e-15）。测试在 annuity/linear × term/payment 全组合上钉死 < 1e-9，并验证方向：m < i 时还贷世界赢，m > i 时投资世界赢，且差与工资水平无关（wage 不变性）。

**推论**：2026 年的存款/低风险理财收益率若低于你的合同利率（月复利口径），「先还贷再攒钱」不是保守，是套利方向的纠正。等效线不需要预测未来——它只需要合同利率，这也是本件拒绝在无 `--yield` 时发明收益率的原因。

**推论二（谬误审判）**：省息 = A × ((1+i)^提前期数 − 1)。公式里只有利率和提前时长，**没有「已还进度」**。「等额本息还到一半利息早还完了，再还不划算」把「已还的钱里利息占多数」（真的：样例 63.1%）偷换成了「以后还的每元钱里利息占多数」（假的：下一元预付的省息率仍是 i，一分不少）。对质表：同样 10 万，剩余计划第 12 期后还省 92,137、半程后省 39,934、85% 处省 9,007——越早越多、越晚越少、**永不为负**。不存在「不划算期」，只存在「早还更划算期」。

## 4. 口径与期界

- **start = 首期还款日**。第 k 期还款日 = start + (k−1) 月，月末钳制（31 号起供 → 2 月 28/29 日算当期还款日）。
- **months_done(date)**：截至 date 已完成的整期数；还款日当天算完成。
- **预付生效期界**：第 p 期还款**后**、第 p+1 期计息**前**（p = 生效日的 months_done）。下一期利息按新余额计——与两世界模拟同相，这是 §3 恒等式成立的前提。
- **三种进度**（position）：期数（按实际总期数，缩期后会小于出厂期数并标注）、本金（1 − 余额/初始本金）、利息（已还利息/全周期利息）。三个数永远互不相等——「你在契约里的位置」本来就不是一根轴。
- **出厂口径 vs 实际口径**（plan）：出厂 = 无预付的全期计划（贷款的「标价」）；实际 = 计入历史预付重放（你实付的「成交价」）。两个数都给，差值就是历史预付已省的息。
- **--today 显式钉死**：快照全部以 2026-09-04 生成，跨机器逐字节可复现。

## 5. 门禁与拒答

| 灯/拒答 | 条件 | exit | 语义 |
|---|---|---|---|
| 双倍房灯 | 出厂总利息 ≥ 本金（如 30 年 6.5% → 127.5%） | 4 | 这套房按出厂口径要付 227.5% 的价——期限与利率是价格把手，预付是第三个 |
| 先还低息灯 | 指定低息贷款而高息贷款在册，利差 > 0.5pp | 4 | 钱去错了债；附反平反条款（违约金锁定期/转贷计划可翻案） |
| 跑输灯 | 实绩年化 < 等效线 − 0.5pp | 4 | 这笔钱在债上更值钱 |
| 投资灯 | 实绩年化 > 等效线 + 0.5pp | 0 | 投资世界赢——但先确认税后、可复制 |
| 结清拒绝 | 预付 ≥ 期初余额，或缩期后只剩 1 期 | 2（历史）/ 3（拟议） | 那是银行柜台的另一道题，本件只管「还一部分」 |
| 收益率缺席 | vsinvest 不给 --yield | 3 | 不发明收益率，只给保本等效线 |
| 小额横幅 | 预付 < 1 万 | 0（不拒绝） | 多数银行有最低额与预约门槛 |

`validate` 的恒等式体检：逐期拆分、本金回归（含预付）、期末归零、缩期末期供不超常规供、等效定理数值面、分配恒等式——任何一条失败 Gate exit 4，账本先于用户看见错误。

## 6. FAQ

**Q：为什么减供省息更少还要选减供？**
A：省息不是唯一变量。缩期省 330,252 但月供不动；减供省 211,244 却每月多出 3,323 的现金流。如果你的月供已贴着收入红线，那 3,323/月 的呼吸空间可能比 12 万省息值钱——判据在 compare 的输出里，选择不替你做。

**Q：公积金贷款利率低，是不是干脆别提前还它？**
A：纯数学上：每 1 元的预付省息与利率成正比，钱永远该先去最贵的债。但现实里公积金提取还贷政策、商贷违约金锁定期都可能翻案——所以先还低息灯的旁边写着反平反条款。

**Q：一次还 50 万和分 5 年每年还 10 万，差多少？**
A：样例：330,252 vs 277,177，少省 53,076——那是后 4 批在场外多待 1-4 年、按 4.2% 计的机会成本。但分批保留的流动性不是免费的错：应急现金的价值本账本不定价。

**Q：为什么不算 LPR 降息后的情况？**
A：LPR 是预测，预测不是账本。降息落地那天，把新执行利率抄进 loans.tsv 的 rate 列，全部数字自动跟着动——账本对现实的全部责任，就是对你抄进来的数负责。

**Q：和银行 App 里的「试算」有什么区别？**
A：银行试算不告诉你：已还的钱里利息占多少、利息半程点在哪、预付的等效收益率、缩期与减供的省息差、组合贷该先还哪笔、以及「利息早还完了」为什么是错的。App 是柜台表单，本件是对质法庭。

**Q：它会建议我还贷吗？**
A：不会。它把三条东西摆上台面——你的契约形状、预付的等效价格、流行说法的真伪——然后闭嘴。跑输灯说「这笔钱在债上更值钱」，但这不是指令：失业风险、置换计划、睡得着哪边，都在账本外面。
