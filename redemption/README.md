# 赎契 · Redemption

> 月供是赎契的分期，利息是租钱的价格。银行 App 只给你看剩余本金和月供，从不给你看你在契约里的位置——「提前还贷划不划算」这笔全民年度之问，第一次有一本账接得住。
> A mortgage is a lease on your own money. Redemption shows where you stand in the contract, what a prepayment is really worth — a risk-free, after-tax investment yielding exactly your contract rate — and which popular belief about it is pure math error.

---

## 一句话

背房贷的人每年都要在「提前还贷」和「留着投资」之间重投一次票，而票箱边只有三种东西：银行 App 的三个数（剩余本金、月供、已还期数）、群里转发的说法（「等额本息还到一半利息早还完了，再还不划算」）、和一团没有分母的焦虑。本件把贷款抄成可手编的账本（loans.tsv：1-4 笔组合贷；prepays.tsv：已发生的提前还款历史），从你自己的契约里算出五样从没有人替你算过的东西：**贷款的时间结构**（已还的钱里利息占多少、累计利息到哪一年过半、30 年出厂口径的总利息是本金的几成）、**等效收益率定理**（提前还款 = 一笔年化恰等于合同利率的无风险、税后投资——月复利口径 4.2% 其实是 4.28%，数值验证到 1e-15）、**谬误法庭**（「利息早还完了」当庭对质：省息 = 本金 × ((1+i)^提前期数 − 1)，公式里根本没有「已还进度」这个变量）、**缩期 vs 减供**的对决账（同样 50 万，缩期多省 56% 但不减月供——判据给你，选择不替你做）、和**组合贷分配**（每 1 元预付都该先去利率最高的债上：还 30 万进商贷省 242,848，进公积金只省 193,790，指定低息直接亮灯 exit 4）。

## 它解决谁的、什么场景下的、什么问题

| 维度 | 说明 |
|---|---|
| **角色** | 背着房贷、手里攒下一笔闲钱的家庭——年终奖到账的、卖旧车拿到钱的、存款到期续存的；组合贷（商贷+公积金）不知道先还哪笔的人；被「等额本息是个阴谋」式转发困扰的人。 |
| **场景** | 存款利率又降了的那个季度，理财 2.3%、房贷 4.2%，同事群里都在约提前还款；银行客户经理问「您选缩期还是减月供」，然后补一句「都差不多」；还了五年打开 App 看到「已还总额 44.6 万」心里发凉：「怎么感觉一直在还利息」；有人劝「都还一半了再还没划算」的时候。 |
| **问题** | ① **银行只给三个数**：剩余本金、月供、已还期数——已还的钱里利息占 63.1% 这个事实、30 年出厂口径总利息是本金的 76%、「4.2%」的真实价格是月复利 4.28%，全都要自己算，而绝大多数人一辈子没算过；② **流行说法统治决策**：「利息早还完了」是把「已还的钱里利息占多数」错当成「以后还的都不划算」——没人当庭对质过；「提前还款会减月供」是错的（银行默认缩期）；「缩期减供差不多」没人摆过两本账；③ **组合贷没人算分配**：钱先还 3.1% 的公积金还是 4.2% 的商贷，每 1 元的年租差 1.1 个点，从没有工具指出钱去错了债；④ **还贷 vs 投资的等效线缺失**：理财收益 2.3% 要不要还 4.2% 的贷，等效线其实就是合同利率本身，但没人肯把这句话和它的数值证明一起给你；⑤ **没有账本**：预付过一次之后，银行 App 的「已还期数」就再也不等于你的真实进度，缩期缩了多少、减供降了多少，全靠自己记性。 |
| **价值与意义** | ① **时间结构进场**：利息半程点（第 121/360 期，33.6% 处累计利息就过半）、已还利息占比、三种进度（期数 20.9% · 本金 27.1% · 利息 38.0%——你在契约里的位置不是一个数），「感觉白还了」第一次有数字：不是白还，是过去 5.6 年租钱的价格；② **等效定理钉死**：预付 50 万省息 330,252、提前 11.1 年脱契，而这笔钱「相当于」一笔年化 4.28%（月复利）的无风险税后投资——两世界终值模拟在 m=合同时差 3.5e-15，这是数学不是话术；③ **谬误法庭**：同一笔 10 万在剩余计划第 12 期后还省 92,137、半程后省 39,934、85% 处省 9,007——越早越多、越晚越少、永不为负，「不存在不划算期，只存在早还更划算期」；④ **对决与分配**：缩期 vs 减供两本账并排（省息差 +56.3% 与月供 −3,323/月 各占一边），组合贷按利率降序自动分配并披露去向；⑤ **三盏灯**：双倍房灯（出厂利息 ≥ 本金，30 年 6.5% 的贷款会亮——你的房实际按 227.5% 的价在买）、先还低息灯（钱去错了债，附违约金锁定期反平反条款）、跑输灯（实绩收益率跑输等效线 0.5pp 以上）；⑥ 零依赖、纯本地、不预测 LPR、不算违约金（挂横幅披露）、不构成理财建议——赎与不赎，人的决定。 |

## 核心思想：把「还贷焦虑」拆成一本摊销账 + 一条等效线

| 概念 | 规则 | 回答的问题 |
|---|---|---|
| **摊销时间结构** | 每期利息 = 期初余额 × 月利率；本金 = 月供 − 利息；出厂口径 = 无预付的全期计划 | 「我已经还了什么、还要还什么？」——利息半程点、已还利息占比、出厂总利息/本金 |
| **真实利率** | (1 + 年利率/12)^12 − 1 | 「4.2% 是多少钱？」——单利话术的月复利价格 4.28% |
| **等效收益率定理** | 预付金额 ≡ 一笔年化 = 合同利率（月复利口径）的无风险、税后投资；两世界终值模拟在 m=合同时必平（数值验证 < 1e-9） | 「还贷到底相当于多大的投资收益？」——本件的灵魂，测试钉死 |
| **缩期 vs 减供** | term：月供不变解新期数（n′ = ln(M/(M−B·i))/ln(1+i) 向上取整）；payment：期数不变重解月供 | 「同样一笔钱，两种还法差在哪？」——缩期省息更多（钱离场更早），减供买每月呼吸空间 |
| **组合贷分配** | 利率降序依次填装（同利率按余额），每 1 元先去最贵的债 | 「先还商贷还是公积金？」——指定低息贷款而高息在册 → 先还低息灯 exit 4 |
| **预付生效期界** | 预付在「第 p 期还款后、第 p+1 期计息前」生效；历史账本逐笔重放 | 「我 2024 年还的那 20 万，现在处于什么状态？」——缩了多少期/降了多少供，账本记得 |
| **双倍房灯** | 出厂总利息 ≥ 本金 → exit 4 | 「这套房我实际按多少钱在买？」——30 年 6.5% 的答案：227.5% |
| **谬误法庭** | 同一笔钱在剩余计划的不同进度点模拟省息并排 | 「利息早还完了，对吗？」——省息公式里没有已还进度；越早越多，永不为负 |

三条设计立场刻在实现里：**账本只记事实、拟议只在命令行**（prepays.tsv 是已发生的历史，`--amount` 是假想的预付——两本账永不混淆）；**结清不进本件**（预付 ≥ 期初余额、或预付后只剩 1 期 → 拒绝：那是银行柜台的另一道题，本件只管「还一部分」）；**没收益率就不谈投资**（vsinvest 不给 `--yield` 直接 exit 3，只给保本等效线——沿仓库「不给套餐不发明单价」的传统）。

**与近邻的边界**：nav-illusion（净值幻觉）算的是投资侧的行为差（XIRR−TWR），本件算负债侧的摊销结构与预付决策——一个审计你怎样买卖，一个解构你怎样欠钱；smooth-sailing（旱涝保收）管自由职业者的现金流平滑，本件的单笔闲钱是一次性事件；move-line（挪窝线）的搬家税把一次性成本按年摊销，本件的利息半程点是同一「时间形状」直觉在负债侧的镜像；expiry-cliff（到期悬崖）管凭证何时失效，本件管贷款何时了结；repair-ledger（续命账）的「修还是换」与「还还是投」共享边际思维，但那边比的是每服务年成本，这边比的是利率与等效线。

## 安装（零依赖）

只需 Python 3.8+，无需 `pip install` 任何东西。

## 账本格式

两份可手编的 TSV（第二份可选）：

`loans.tsv`（贷款账本，1-4 笔）：

```
name	principal	rate	years	start	method	note
商贷	1400000	4.2	30	2021-03-01	annuity	2024-10 存量房贷利率调整后执行值
公积金	600000	3.1	30	2021-03-01	annuity	5 年期以上首套
```

`prepays.tsv`（预付历史，可选——文件可以不存在）：

```
date	amount	target	mode	note
2024-01-15	200000	商贷	term	2023 年终奖
2025-01-10	100000	商贷	payment	2024 年终奖改减月供，缓解现金流
```

- `rate` 抄合同**当前执行**年利率（%）；`start` = 首期还款日；`method` 支持 `annuity/等额本息`、`linear/等额本金`；
- `mode`：`term` 缩期（月供不变期限变短）/ `payment` 减供（期限不变月供变低）；`target` 必须写具体贷款名——**历史要记到具体账上，不收 ALL**；
- 预付 ≥ 届时余额是结清，不进本账本（exit 2）；拟议预付同理（exit 3）。

## 命令速查

```bash dd:ignore
python3 redemption.py plan loans.tsv prepays.tsv --today 2026-09-04           # 摊销总账（双倍房灯）
python3 redemption.py plan loans.tsv --years-detail                           # 年度移交表：利息/本金逐年反超
python3 redemption.py position loans.tsv prepays.tsv                          # 位置单：三种进度+结清代价
python3 redemption.py prepay loans.tsv prepays.tsv --amount 500000            # 拟还 50 万·缩期（默认 ALL 按利率降序）
python3 redemption.py prepay loans.tsv prepays.tsv --amount 300000 --target 公积金   # 指定低息 → 先还低息灯 exit 4
python3 redemption.py compare loans.tsv prepays.tsv --amount 500000           # 缩期 vs 减供对决
python3 redemption.py myth loans.tsv prepays.tsv                              # 谬误法庭：利息早还完了？
python3 redemption.py vsinvest loans.tsv prepays.tsv --amount 500000 --yield 2.3     # 两世界终值（不给 --yield 拒绝）
python3 redemption.py batch loans.tsv prepays.tsv --total 500000 --parts 5    # 一次 vs 分批
python3 redemption.py validate loans.tsv prepays.tsv                          # 恒等式体检
```

通用参数：`--today` 口径日（默认今天；示例与快照固定 2026-09-04 逐字节可复现）、`--at` 预付生效日、`--mode term|payment`。

## 一个真实样例

小澄家 2021-03-01 起供杭州组合贷：商贷 140 万 @4.2%、公积金 60 万 @3.1%，都 30 年等额本息；2024 年终奖缩期预付商贷 20 万，2025 年终奖减供预付商贷 10 万；2026-09-04，存款又降息，手里有 50 万。账本见 [examples/loans.tsv](examples/loans.tsv) 与 [examples/prepays.tsv](examples/prepays.tsv)。

总账（`plan`）：商贷出厂口径总利息 1,064,647 = 本金的 76.0%，利息半程点在第 121 期（33.6% 处）——**三分之一的年份付掉了一半的利息**；计入两笔预付后实际全周期利息 676,768，已省 387,879。公积金出厂利息只有本金的 53.7%——同是 30 年，价格差 22 个点全在利率。组合出厂总利息 1,387,002 / 本金 200 万 = 69.4%，双倍房灯未亮。

位置单（`position`）：三种进度 **期数 20.9% · 本金 27.1% · 利息 38.0%**——已还的 44.6 万里利息占 63.1%，「感觉一直在还利息」是对的，但它是过去 5.6 年租钱的价格，不欠未来一分钱。

预付模拟（`prepay --amount 500000`）：

```
提前还款模拟 · 拟还 ¥500,000 · 模式 缩期（月供不变、期限变短） · 生效 2026-09-04
  商贷：预付 ¥500,000（余额 ¥932,484）→ 省息 ¥330,252 · 期限 214→81 期（提前 11.1 年脱契） · 月供不变 ¥6,217.93
  合计省息 ¥330,252
  等效收益率定理：这些钱等于一笔年化 4.20%（月复利 4.28%）的无风险、税后投资——没有第二个免费午餐
```

对决（`compare --amount 500000`）：同样 50 万，缩期省息 330,252（+56.3%）但月供纹丝不动；减供省 211,244，月供 6,217.93→2,894.35（每月多出 3,323 的呼吸空间）——判据给你，选择不替你做。误投公积金（`--target 公积金`）直接亮灯 exit 4：**先还低息灯 ✗ 每 1 元年租差 1.10 个点**（附违约金锁定期反平反条款）。

谬误法庭（`myth`）当庭对质「利息早还完了」：已还利息占 63.1% 是真的；但同样还 10 万，剩余计划第 12 期后还省 92,137、半程后省 39,934、85% 处省 9,007——**越早越多、越晚越少、永不为负**；并案谬误二「提前还款会减月供」：错，银行默认缩期。

vsinvest（`vsinvest --amount 500000 --yield 2.3`，exit 4）：世界 A（还贷）末日财富 4,231,305 vs 世界 B（投资）4,039,400——还贷世界多 191,904；同一行里印着等效校验「m=合同时两世界终值差 3.5e-15」——**这条等效线是定理，不是观点**。分批派（`batch --total 500000 --parts 5`）：一次省 330,252，分 5×10 万省 277,177，少省的 53,076 是后 4 批在场外多待 1-4 年的代价；「应急现金的价值本账本不定价」。

## 诚实条款

rate 抄的是合同执行利率，本件不预测 LPR——降息那天你自己改账本，改完的每个数字都跟着动；违约金（多数银行头 1-3 年收 1%）不建模，只在输出的诚实条款里挂横幅；「利息半程点」「已还利息占比」描述的是摊销的数学形状，不是银行的道德指控——利息是租钱的价格，前期本金多所以租钱多，没有阴谋。等效定理的「无风险、税后」是还贷的属性，不是投资收益的：vsinvest 只对质你给的历史实绩，不预测你的未来，波动率没有进这道账。组合贷分配假设两笔贷款都允许无门槛提前还款（公积金 extraction 政策、商贷违约金锁定期都可能在现实里翻案——灯的旁边写着平反条款）。它不连银行、不猜利率、不替你赎契——赎与不赎，人的决定。
